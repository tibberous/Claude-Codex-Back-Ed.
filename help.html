API keys

The first time you send, the extension prompts for an API key for the active provider. Keys live in VSCode's secrets store — never in code, never in config.ini, never committed to git. Use the Settings modal to change providers; each one has its own slot.

SuperGrok bridges

For providers that authenticate through a browser (Gemini Web, ChatGPT Web, Grok Web), click the Codex pill → choose the provider → an external Chromium window opens for sign-in. Close that window once signed in; the bridge keeps the session.

Logs & troubleshooting

  • VSCode monitor (toolbar) shows live extension trace.
  • Right-click anywhere in the chat for “View Source” / DevTools (in --debug mode).
  • Audio cues are SFX — toggle them in Settings if they get in the way.
