CBE Debug Sprint — 2026-05-10
==============================

## What Was Broken

Auto-wakeup message was pasting DOUBLED text into Claude Code's input box,
but never submitting (no Enter sent). User had to submit manually every time.

Root cause: `submitText()` in both extension.js files calls
  `vscode.commands.executeCommand('type', { text: '\n' })`
after clipboard paste. This `type` command routes to the VSCode text editor,
NOT the Claude Code webview chat textarea. Paste lands (clipboardPasteAction
somehow reaches the textarea), but Enter does not — so message sits, unsent.

Doubling cause: multiple retry attempts (5 × 4s) each pasted the text before
any submit landed, stacking the wakeup message in the input box.

## Fix Applied

In BOTH extension.js files:
  - C:\Users\moren\claude-voice\extension.js
  - C:\Users\moren\Desktop\Claude Codex Black\extension.js

Replaced the broken `type` Enter command in `submitText()` with a real
Windows keystroke via mouse.py:

  BEFORE:
    await vscode.commands.executeCommand('type', { text: '\n' });

  AFTER:
    require('child_process').execSync(
      'python C:/Users/moren/claude-tools/mouse.py key enter'
    );

This sends a real Win32 keydown Enter to whatever window has focus, which
reaches the Claude Code webview textarea correctly.
