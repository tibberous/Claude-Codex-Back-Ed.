# Codex Black Ed. v1.1.0 — Vision Pilot

GPT-4o now drives the per-target offscreen Chromium directly. Screenshots + structured tool-calls + CDP — no DOM scrapers, no fragile selectors, no API keys to leak. The user's existing logged-in browser sessions are reused.

## Bridges
- **NEW: DeepSeek** — 7th tray target. Tray exe on `127.0.0.1:8794`, CDP child on `9794`, native deepseek.com login + reasoner/chat/V3 model picker.
- **bridge_pilot.py** — the C++ tray's `/chat` handler now shells out to a one-shot vision-pilot driver per request for every browser target. Replaces the broken passthrough that expected a `--serve-bridge` python child on `g_childPort`.
- **Static model lists** in the tray now include DeepSeek (`deepseek-chat`, `deepseek-reasoner`, `deepseek-v3`).

## Vision-pilot core (tools/cdp_minicomputer.py + tools/gpt_vision_pilot.py)
- **Input.insertText** replaces per-character `dispatchKeyEvent`. Previous impl emitted `keyDown(text=ch) + char(text=ch) + keyUp` and chatgpt.com double-inserted each character ("ppoonngg" instead of "pong"). The CDP-native single-insert path works cross-site.
- **Network event filter** — `_pkt()` no longer writes `Network.requestWillBeSent` / `responseReceived` / `dataReceived` / `loadingFinished` to the packet log. On chatty SPAs (Gemini, Copilot) the disk-flush in `_send`'s drain loop was dominating turn latency. Gemini went from a multi-minute stall to a 2-step pass.
- **429 retry with backoff** — `_postOpenAI` now retries on rate limits with 10/30/60/120/180 s exponential backoff (~6.5 min total budget) and honors `Retry-After` when present.
- **Per-target LOGIN_STRATEGY** in the pilot's goal prompt — Claude prefers `Continue with email`, DeepSeek goes straight to native form, Copilot routes through `login.live.com`. Google SSO is the fallback, not the default.

## Matrix verification (run_all_pilots.py)
- New `tools/run_all_pilots.py` matrix runner exercises every browser target end-to-end. Per-target log wipe between runs. Optional `--targets` subset selector.
- **4/6 round-trips working today**: grok, chatgpt, gemini, copilot all return real `pong`. Claude is auth-blocked (claude.ai dropped password login in favor of magic-link); DeepSeek's runtime works but needs a clean retry after OpenAI rate-limit cools.

## Known limitations
- **Claude** — magic-link-only login. Needs either one-time manual sign-in via a visible chrome window OR a Gmail-API hook to fetch the magic link inbox-side.
- **OpenAI vision rate limits** bite when the matrix runs all six targets back-to-back. The new 6.5-min retry budget covers most cases but a fresh OpenAI key on the higher tier is the cleanest fix.
