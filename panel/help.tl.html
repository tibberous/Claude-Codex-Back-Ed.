Claude Codex — Black Edition

Isang offline-first multi-provider AI chat panel para sa VSCode. Pindutin ang Ctrl+Alt+B upang i-toggle.

1. Maligayang pagdating

Claude Codex Black ay isang VSCode webview na nagbibigay-daan sa iyo na makipag-usap sa maraming AI provider (Claude, OpenAI, Gemini, Grok, Azure, local Ollama) mula sa isang solong, themable panel. Lahat ng kailangan ng isang key ay binabasa mula sa config.ini sa extension root — walang extension settings UI na kinakailangan, ngunit ang Settings modal ay sumasalamin sa pinaka-kapaki-pakinabang na mga field para sa click-only na pag-edit.

Bago pa lang ba rito? Magsimula sa pamamagitan ng pagbubukas ng Settings (gear icon), pumili ng iyong provider, i-paste ang iyong API key, pagkatapos ay mag-type ng prompt at pindutin ang Enter. Lahat ng ibang feature sa gabay na ito ay opsyonal.

3. Ang prompt box

Ang malalaking editable textarea sa ibaba. Mag-type, mag-paste, mag-drag ng file, mag-attach sa pamamagitan ng paperclip — anumang inilalagay mo dito ay ang user turn ng susunod na API call.

Ang font ay nakalock sa iyong VSCode editor's monospace font (sa pamamagitan ng --vscode-editor-font-family CSS variable) kaya ang panel ay mukhang tahanan sa loob ng editor.

5. Mga modelo at provider

CBE ay may kasamang 11 bridges bilang drop-in .bridge plugins sa ilalim ng bridges/. Bawat isa ay isang self-contained zip na may manifest.xml + bridge.py + icons. Maglagay ng bagong .bridge file at ito ay lilitaw sa cartridge dropdown — walang extension code change na kailangan.

Text-chat bridges (7)

  • ChatGPT — chatgpt.com, Plus/Pro subscription
  • Grok — grok.com, native xAI login (ang anonymous tier ay malaking nakagating; mag-log in muna)
  • Gemini — gemini.google.com, Google account
  • Claude — claude.ai, magic-link login (magpatakbo ng tools/sign_in_helper.py claude minsan)
  • Copilot — copilot.microsoft.com, libreng Microsoft account
  • DeepSeek — chat.deepseek.com, native email/password (HUWAG gamitin ang Google SSO)
  • Ollama — local 127.0.0.1:11434, walang login na kinakailangan

Video-generation bridges (4)

  • Sora 2 — sora.com, reusable ang iyong ChatGPT Plus/Pro login
  • Google Veo — gemini.google.com (Veo mode), Gemini Advanced subscription
  • Runway Gen-3/4 — app.runwayml.com, hiwalay na Runway subscription
  • Bing Video Creator — bing.com/videos/create, libreng Sora-2 na may Microsoft account

Ang mga generated na video ay nagsasave sa videos/<bridge>/<timestamp>_<prompt-slug>.mp4 at automatic na tumutugtog sa Video Library panel (tingnan ang §Video Library sa ibaba).

Pumili ng bridge + model mula sa cartridge dropdown sa susunod ng prompt box, o sa pamamagitan ng Settings → General. Ang selection ay bawat workspace at nanatili sa workspaceState. Upang magdagdag ng bagong bridge, tingnan ang docs/WRITING_BRIDGES.md.

5a. Video Library

Isang dedicated panel para sa pag-browse at panoorin ng mga video na nabuo ng video bridges (Sora, Veo, Runway, Bing Video Creator). Bumubukas sa pamamagitan ng Command Palette: Claude Codex Black: Open Video Library o ang codexBlackEd.openVideoPlayer command.

  • Ang sidebar ay naglilista ng bawat .mp4 / .webm / .mov sa ilalim ng videos/<bridge>/, na kinabibilangan ng bridge at pinagsort ng pinakabago-una.
  • Ang pinakasariwang video ay automatic na tumutugtog sa unang pagbubukas.
  • Ang panel ay bantay ng videos/ dir sa isang 2-segundo tick — anumang bagong generated na video ay dumarating na may ✨ "Just generated" badge at automatic na tumutugtog (i-toggle off sa pamamagitan ng Auto ▶ new).
  • I-click ang 📂 Open upang ipakita ang videos/ folder sa iyong OS file manager.

6. Pagsasalita sa Teksto

I-click ang mic, magsalita, i-click muli upang ihinto (o maghintay para sa silence-timeout). Dalawang engine ang sinubukan sa pagkakasunod-sunod:

  1. Web Speech API — Ang Google's cloud recognizer na tumatakbo sa webview. Gumagamit ng iyong Gmail/Google session; walang karagdagang key na kailangan.
  2. Windows SAPI (fallback) — pre-warmed PowerShell process na ina-invoke kapag ang webview ay naghahadlang sa mic access. Configurable listen window sa pamamagitan ng [voice] listen_seconds sa config.ini.
Ang SAPI ay pre-warmed sa extension activate kaya ang unang mic click ay nakakaiwas sa 2-4 segundo na cold start na dating gumagamit ng early stop-clicks.

7. Auto Prompt

Ang badge-with-spinner button. Kapag ON, pagkatapos ng N segundo ng inactivity ang panel ay automatic na nagpapadala ng iyong configured na wake-up text. Ang countdown digit ay ini-render sa --cbe-highlight-color, na bawat skin ay nagtutukoy.

I-edit ang wake-up text sa pamamagitan ng 🔁 Wake button — ito ay round-trips wake.txt.

8. Auto Read (TTS)

Ang mouth icon. Kapag ON, bawat assistant reply ay sinasalita sa pamamagitan ng Web Speech synthesizer (Google) o SAPI fallback. Ang isang buo na halo ay sumisilang sa paligid ng icon habang ang audio ay tumutugtog.

9. Compact at context usage

Ang conversation array na ipinapadala sa modelo ay lumalaki sa bawat turn. Ang ring sa paligid ng Compact icon ay nagpapakita ng kasalukuyang context-window usage bilang conic gradient — walang laman kapag bago, puno kapag malapit sa modelo's context limit.

I-click ang Compact upang paghiwayin ang history hanggang sa huling apat na turn. Ang susunod na API call ay gumagamit ng mas maliit na array.

10. Wake-up response

Nakatipid sa wake.txt sa extension root. Ginagamit ng Auto Prompt bilang mensahe na ipadala kapag ang inactivity timer ay nag-apoy. I-edit sa pamamagitan ng 🔁 toolbar button.

11. Mga file attachment

I-click ang 📎 upang pumili ng isa o higit pang file. Hawakan ang Ctrl o Shift sa picker upang mag-multi-select. Bawat file ay inlined sa prompt bilang fenced code block na may filename at wika. Ang binary files na higit sa 1 MB ay nilalabasan na may notice.

12. Git modal

I-click ang 📁 Git. Kung walang project folder na configured, makakakuha ka ng folder picker muna — ang piniling path ay isinulat sa [project] path sa config.ini. Ang susunod na git invocations ay tumatakbo na may cwd na itakda sa path na iyon.

13. GitHub repositories

Naglilista ng bawat repo na accessible sa iyong [github] pat. I-click ang isang row upang isama ang clone URL nito sa prompt. Ang list ay paginated at cached.

14. NameSilo Domains

Kumukuha ng bawat domain sa iyong NameSilo account gamit ang [namesilo] api_key (o [api_keys] namesilo_api_key bilang fallback). Sa unang pagbubukas, ang mga resulta ay cached sa domains.txt; ang susunod na panel boots ay nagsisilbi mula sa cache. I-click ang Reload sa modal upang pilitin ang bagong fetch.

Kung kailanman makikita mo ang "no domains" na may 300 reply code, tiyakin ang trace channel — ang walang laman na caches ay hindi na kumakamay sa hinaharap na panel boots, ngunit ang isang lumang domains.txt sa ibang install path ay maaaring magkaroon ng problema.

15. Mga skins at tema

Ang 🎨 button ay nagbubukas ng discovery picker na sumusubaybay sa skins/ live (hindi sa startup), kaya ang paglagay ng bagong folder sa runtime ay sapat na. Bawat skin ay may manifest.xml na nagtutukoy sa palette — kasama ang highlight color, na ang Auto Prompt countdown badge, focus rings, at supervisor pulse ay lahat ay tumutugon dito.

Ang built-in skins ay kinabibilangan: gnome (Adwaita gray), terminal (itim/berde na may mainit na kulay ng pink accent), tamagotchi (egg-shell pastels na may sprite mascot panel), blocky, at iba pa.

16. Mga setting

Bumubukas mula sa ⚙ gear. Ang mga tab:

  • General — display name, default model, send-on-enter
  • Voice — mic device, listen_seconds, STT engine pick, TTS auto-read
  • Updates — is_admin flag, WinSCP session, remote path
  • Keys — ang bawat provider's API key
  • Monitor — VSCode supervisor toggle, port, poll interval
  • Language — pumili mula sa 39 locales; tingnan ang § 17

Ang modal ay naaalala ang laki at posisyon nito sa mga session.

17. Wika

Ang panel ay may kasama ang mga pagsasalin para sa 39 pinakasinayang wika. Ang locale files ay nakatira sa languages/<code>.xml at ay na-load minsan sa extension activate. Ang mga missing keys ay bumabalik sa English.

Pumili ng iyong wika sa Settings → Language. Ang isang flag icon ay ipinapakita sa susunod ng bawat opsyon (na-load mula sa assets/flags/<code>.svg). Ang selection ay nakatipid sa [settings] language sa config.ini.

18. VSCode supervisor

Isang Windows service (CBEVSCodeSupervisor) ay sumasaklaw sa tools/vscode_supervisor.ps1 script sa pamamagitan ng NSSM at sumasaklaw sa HttpListener sa http://127.0.0.1:3434/. Ang monitor button ng panel ay sumisilang asul kapag ang supervisor's /status endpoint ay sumagot ng 200 OK.

Kung ang HTTP probe ay nabigo ngunit ang service ay naka-install, ang panel's watchdog ay automatic na nag-restart ng service (30-segundo cool-down kaya't hindi ito restart-storm).

Ang left-click sa monitor button ay magsasama-sama / mag-start / mag-stop. Ang right-click ay magbubukas ng trace channel.

19. Auto-update (pull)

4 segundo pagkatapos ng extension activate, ang panel ay kumukuha https://trentontompkins.com/cbe/manifest.xml.php — isang MD5+size manifest ng pinakabagong published na file. Para sa bawat remote file, ang local copy's MD5 ay inihambing; tanging nagbago/nawawalang file lamang ang ini-download sa HTTPS.

Ang user-local state (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) ay nasa pull exclusion list at hindi kailanman nao-overwrite.

20. Admin push

Tanging mga kliyente na may [updates] is_admin = true ay nagpupush sa server. Trigger sa pamamagitan ng:

  • Command Palette → Claude Codex Black: Push update
  • Slash command /push

Gumagamit ng WinSCP saved session na pinangalan sa [updates] winscp_session (default vps). Nagpupush sa pamamagitan ng /script=… na may synchronize command at filemask na naglalabas ng mga secret at per-machine state.

21. Extensions marketplace

I-click ang 🧩 Extensions button. Ang iframe modal ay bumubukas sa https://trentontompkins.com/cbe/extension/extension_marketplace.php, na kumukuha ang catalog sa extensions.xml.php at ini-render ang bawat available extension bilang isang card na may description, tags, version, file size, MD5, at Install button.

Ang extension ay naka-package bilang <id>.ext — isang zip archive na naglalaman manifest.xml kasama ang extension code (karaniwang isang solong extension.html). Kapag i-click mo ang Install, ang marketplace iframe ay nagpapadala ng postMessage pabalik sa panel; ang panel ay nag-download ng .ext file direkta mula sa server at ini-extract ito sa ilalim ng extensions/ sa extension folder.

Tatlong demo extension ay kasama sa launch catalog: Calculator, Minesweeper, at Emoji Picker.

22. Slash commands

I-type ang / sa prompt box upang buksan ang slash-command palette. I-click ang isang row upang isama ang command text sa iyong prompt (editable), o pindutin ang Enter sa isang runnable row upang i-fire ito kaagad.

Ang hindi kumpleto na listahan:

23. Right-click menu

Right-click saanman sa panel para sa contextual menu (na tinukoy bilang isang solong XML string sa panel.js). Ang mga entry ay kinabibilangan ng Refresh (muling i-load ang panel nang hindi tinatamaan ang extension host — huwag gamitin ang reloadWindow), Clear conversation, Open settings, at Inspect (DevTools, debug builds lamang).

24. Trace channel

Ang extension ay nagsusulat ng granular timeline sa debug.log sa susunod ng extension. Lahat ng kapansin-pansin ay nakarating doon: provider switches, STT lifecycle, supervisor probes, NameSilo reply codes, panel↔host bridge messages, push/pull manifest counts.

Right-click ang monitor button para sa one-click open ng trace channel.

25. Paglutas ng mga problema

SymptomMalamang na dahilan
Ang prompt box ay mukhang proportional, hindi monospace --vscode-editor-font-family ay hindi naiapply; tiyakin ang :root vars
Ang Auto Prompt spinner ay isang itim na tuldok Maling SVG asset; dapat ay auto_read_spinner.svg na may drop-shadow halo
Ang Compact button ay walang ginagawa Host handler ay nawawala — case 'compactConversation' sa extension.js router
"0 domains" sa Domains modal NameSilo reply.code != 300 (trace channel ay mayroong ito), o lumang domains.txt
Ang STT "no speech detected" agad Huminto ka bago ang SAPI ay nagsama sa mic. Ang pre-warm ay ngayon ay nag-skip ng hintay — tiyakin gamit ang stt: using pre-warmed SAPI sa debug.log
Ang push ay nabigo sa path na may mga space Gumagamit ng /command= inline; laging gamitin ang /script=tempfile.winscp
Ang Supervisor blue glow ay hindi sumisilang Service ay hindi tumatakbo. Left-click monitorBtn upang i-install/magsimula, o magpatakbo ng Start-Service CBEVSCodeSupervisor
Reload ay "nag-aayos" ng something Hindi ito. Huwag kailanman gamitin ang reloadWindow. Gamitin ang Refresh context-menu entry sa halip.
