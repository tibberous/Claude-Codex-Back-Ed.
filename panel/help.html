Claude Codex — Black Edition

An offline-first multi-provider AI chat panel for VSCode. Press Ctrl+Alt+B to toggle.

1. Welcome

Claude Codex Black is a VSCode webview that lets you chat with multiple AI providers (Claude, OpenAI, Gemini, Grok, Azure, local Ollama) from a single, themable panel. Everything that needs a key reads from config.ini at the extension root — no extension settings UI is required, but a Settings modal mirrors the most useful fields for click-only editing.

New here? Start by opening Settings (gear icon), pick your provider, paste your API key, then type a prompt and hit Enter. Every other feature in this guide is optional.

3. The prompt box

The big editable textarea at the bottom. Type, paste, drag a file, attach via the paperclip — anything you put here is the user turn of the next API call.

The font is locked to your VSCode editor's monospace font (via the --vscode-editor-font-family CSS variable) so the panel looks at home inside the editor.

5. Models & providers

Six providers are wired:

  • Claude (Anthropic) — keys in [api_keys] anthropic_api_key
  • OpenAI — keys in [api_keys] openai_api_key
  • Gemini (Google) — keys in [api_keys] gemini_api_key
  • Grok (xAI) — keys in [api_keys] xai_api_key
  • Azure OpenAI — [azure] section: endpoint, api_key, deployment_name
  • Ollama (local) — no key needed; hits http://127.0.0.1:11434

Pick a provider + model from the cartridge dropdown next to the prompt box, or via Settings → General. The selection is per-workspace and persisted in workspaceState.

6. Speech to Text

Click the mic, speak, click again to stop (or wait for the silence-timeout). Two engines are tried in order:

  1. Web Speech API — Google's cloud recognizer running in the webview. Uses your Gmail/Google session; no extra key needed.
  2. Windows SAPI (fallback) — pre-warmed PowerShell process invoked when the webview blocks mic access. Configurable listen window via [voice] listen_seconds in config.ini.
SAPI is pre-warmed at extension activate so the first mic click avoids the 2-4 second cold start that used to swallow early stop-clicks.

7. Auto Prompt

The badge-with-spinner button. When ON, after N seconds of inactivity the panel auto-sends your configured wake-up text. The countdown digit is rendered in --cbe-highlight-color, which each skin defines.

Edit the wake-up text via the 🔁 Wake button — it round-trips wake.txt.

8. Auto Read (TTS)

The mouth icon. When ON, every assistant reply is spoken out via the Web Speech synthesizer (Google) or a SAPI fallback. A blue halo glows around the icon while audio is playing.

9. Compact & context usage

The conversation array sent to the model grows with every turn. The ring around the Compact icon shows current context-window usage as a conic gradient — empty when fresh, full when close to the model's context limit.

Click Compact to truncate history down to the last four turns. The next API call uses the smaller array.

10. Wake-up response

Stored in wake.txt at the extension root. Used by Auto Prompt as the message to send when the inactivity timer fires. Edit via the 🔁 toolbar button.

11. File attachments

Click 📎 to pick one or more files. Hold Ctrl or Shift in the picker to multi-select. Each file is inlined into the prompt as a fenced code block with its filename and language. Binary files over 1 MB are skipped with a notice.

12. Git modal

Click 📁 Git. If no project folder is configured, you get a folder picker first — the chosen path is written to [project] path in config.ini. Subsequent git invocations run with cwd set to that path.

13. GitHub repositories

Lists every repo accessible to your [github] pat. Click a row to insert its clone URL into the prompt. The list is paginated and cached.

14. NameSilo Domains

Pulls every domain in your NameSilo account using [namesilo] api_key (or [api_keys] namesilo_api_key as fallback). On first open, results are cached to domains.txt; subsequent panel boots serve from cache. Click Reload in the modal to force a fresh fetch.

If you ever see "no domains" with a 300 reply code, check the trace channel — empty caches no longer poison future panel boots, but a stale domains.txt in another install path could.

15. Skins & themes

The 🎨 button pops a discovery picker that scans skins/ live (not at startup), so dropping a new folder in at runtime is enough. Each skin has a manifest.xml defining its palette — including the highlight color, which the Auto Prompt countdown badge, focus rings, and supervisor pulse all key off of.

Built-in skins include: gnome (Adwaita gray), terminal (black/green with hot-pink accent), tamagotchi (egg-shell pastels with a sprite mascot panel), blocky, and others.

16. Settings

Opens from the ⚙ gear. Tabs:

  • General — display name, default model, send-on-enter
  • Voice — mic device, listen_seconds, STT engine pick, TTS auto-read
  • Updates — is_admin flag, WinSCP session, remote path
  • Keys — every provider's API key
  • Monitor — VSCode supervisor toggle, port, poll interval
  • Language — pick from 39 locales; see § 17

The modal remembers its size and position between sessions.

17. Language

The panel ships with translations for the 39 most-spoken languages. Locale files live at languages/<code>.xml and are loaded once at extension activate. Missing keys fall back to English.

Pick your language in Settings → Language. A flag icon is shown next to each option (loaded from assets/flags/<code>.svg). The selection is saved to [settings] language in config.ini.

18. VSCode supervisor

A Windows service (CBEVSCodeSupervisor) wraps the tools/vscode_supervisor.ps1 script via NSSM and binds an HttpListener on http://127.0.0.1:3434/. The panel's monitor button glows blue when the supervisor's /status endpoint replies 200 OK.

If the HTTP probe fails but the service is installed, the panel's watchdog auto-restarts the service (30-second cool-down so it doesn't restart-storm).

Left-click the monitor button to install / start / stop. Right-click to open the trace channel.

19. Auto-update (pull)

4 seconds after extension activate, the panel fetches https://trentontompkins.com/cbe/manifest.xml.php — an MD5+size manifest of the latest published files. For each remote file, the local copy's MD5 is compared; only changed/missing files are downloaded over HTTPS.

User-local state (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) is on the pull exclusion list and is never overwritten.

20. Admin push

Only clients with [updates] is_admin = true ever push to the server. Triggered via:

  • Command Palette → Claude Codex Black: Push update
  • Slash command /push

Uses the WinSCP saved session named in [updates] winscp_session (default vps). Pushes via /script=… with the synchronize command and a filemask that excludes secrets & per-machine state.

21. Extensions marketplace

Click the 🧩 Extensions button. An iframe modal opens to https://trentontompkins.com/cbe/extension/extension_marketplace.php, which fetches the catalog at extensions.xml.php and renders each available extension as a card with a description, tags, version, file size, MD5, and an Install button.

An extension is packaged as <id>.ext — a zip archive containing manifest.xml plus the extension code (typically a single extension.html). When you click Install, the marketplace iframe sends a postMessage back to the panel; the panel downloads the .ext file directly from the server and extracts it under extensions/ in the extension folder.

Three demo extensions ship with the launch catalog: Calculator, Minesweeper, and an Emoji Picker.

23. Right-click menu

Right-click anywhere in the panel for a contextual menu (defined as a single XML string in panel.js). Entries include Refresh (reload the panel without touching the extension host — never use reloadWindow), Clear conversation, Open settings, and Inspect (DevTools, debug builds only).

24. Trace channel

The extension writes a granular timeline to debug.log next to the extension. Everything noteworthy lands there: provider switches, STT lifecycle, supervisor probes, NameSilo reply codes, panel↔host bridge messages, push/pull manifest counts.

Right-click the monitor button for a one-click open of the trace channel.

25. Troubleshooting

SymptomLikely cause
Prompt box looks proportional, not monospace --vscode-editor-font-family not applied; check :root vars
Auto Prompt spinner is a black dot Wrong SVG asset; should be auto_read_spinner.svg with drop-shadow halo
Compact button does nothing Host handler missing — case 'compactConversation' in extension.js router
"0 domains" in Domains modal NameSilo reply.code != 300 (trace channel has it), or stale domains.txt
STT "no speech detected" instantly You stopped before SAPI bound the mic. The pre-warm now skips that wait — verify with stt: using pre-warmed SAPI in debug.log
Push fails on path with spaces Using /command= inline; always use /script=tempfile.winscp
Supervisor blue glow not lighting Service not running. Left-click monitorBtn to install/start, or run Start-Service CBEVSCodeSupervisor
Reload "fixes" something It didn't. Never use reloadWindow. Use the Refresh context-menu entry instead.
