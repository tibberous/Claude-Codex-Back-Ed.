Claude Codex — Black Edition

Um painel de chat IA multi-provedor offline-first para VSCode. Pressione Ctrl+Alt+B para alternar.

1. Bem-vindo

Claude Codex Black é uma webview do VSCode que permite conversar com múltiplos provedores de IA (Claude, OpenAI, Gemini, Grok, Azure, Ollama local) a partir de um único painel temático. Tudo que precisa de uma chave é lido de config.ini na raiz da extensão — nenhuma interface de configurações de extensão é necessária, mas um modal de Configurações espelha os campos mais úteis para edição apenas com cliques.

Novo por aqui? Comece abrindo Configurações (ícone de engrenagem), escolha seu provedor, cole sua chave de API e digite um prompt e pressione Enter. Todos os outros recursos neste guia são opcionais.

3. A caixa de prompt

A grande textarea editável na parte inferior. Digite, cole, arraste um arquivo, anexe via o clipe de papel — tudo que você coloca aqui é o turno do usuário da próxima chamada de API.

A fonte está bloqueada na fonte monoespacial do seu editor VSCode (via a variável CSS --vscode-editor-font-family) para que o painel pareça estar em casa dentro do editor.

5. Modelos & provedores

CBE vem com 11 bridges como plugins .bridge prontos para uso em bridges/. Cada um é um zip independente com manifest.xml + bridge.py + ícones. Solte um novo arquivo .bridge e ele aparece no menu suspenso de cartuchos — nenhuma mudança de código de extensão necessária.

Bridges de chat de texto (7)

  • ChatGPT — chatgpt.com, assinatura Plus/Pro
  • Grok — grok.com, login nativo xAI (o tier anônimo é muito restrito; faça login primeiro)
  • Gemini — gemini.google.com, conta Google
  • Claude — claude.ai, login por link mágico (execute tools/sign_in_helper.py claude uma vez)
  • Copilot — copilot.microsoft.com, conta Microsoft gratuita
  • DeepSeek — chat.deepseek.com, email/senha nativa (NÃO use Google SSO)
  • Ollama — local 127.0.0.1:11434, nenhum login necessário

Bridges de geração de vídeo (4)

  • Sora 2 — sora.com, reutiliza seu login ChatGPT Plus/Pro
  • Google Veo — gemini.google.com (modo Veo), assinatura Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, assinatura Runway separada
  • Bing Video Creator — bing.com/videos/create, Sora-2 gratuito com conta Microsoft

Os vídeos gerados são salvos em videos/<bridge>/<timestamp>_<prompt-slug>.mp4 e reproduzidos automaticamente no painel de Biblioteca de Vídeos (veja §Biblioteca de Vídeos abaixo).

Escolha um bridge + modelo no menu suspenso de cartuchos ao lado da caixa de prompt, ou via Configurações → Geral. A seleção é por espaço de trabalho e persistida no workspaceState. Para adicionar um novo bridge, veja docs/WRITING_BRIDGES.md.

5a. Biblioteca de Vídeos

Um painel dedicado para navegar + assistir vídeos gerados pelos bridges de vídeo (Sora, Veo, Runway, Bing Video Creator). Abre via a Paleta de Comandos: Claude Codex Black: Open Video Library ou o comando codexBlackEd.openVideoPlayer.

  • A barra lateral lista cada .mp4 / .webm / .mov sob videos/<bridge>/, agrupado por bridge e ordenado do mais novo para o mais antigo.
  • O vídeo mais recente é reproduzido automaticamente na primeira abertura.
  • O painel observa o diretório videos/ em um tick de 2 segundos — qualquer vídeo gerado recentemente aparece com um crachá ✨ "Acabado de gerar" e é reproduzido automaticamente (desative via Auto ▶ new).
  • Clique em 📂 Abrir para revelar a pasta videos/ no gerenciador de arquivos do seu SO.

6. Fala para Texto

Clique no mic, fale, clique novamente para parar (ou aguarde o tempo limite de silêncio). Dois motores são tentados em ordem:

  1. Web Speech API — O reconhecedor de nuvem do Google em execução na webview. Usa sua sessão Gmail/Google; nenhuma chave extra necessária.
  2. Windows SAPI (fallback) — Processo PowerShell pré-aquecido invocado quando a webview bloqueia o acesso ao mic. Janela de escuta configurável via [voice] listen_seconds em config.ini.
SAPI é pré-aquecido no ativar da extensão então o primeiro clique do mic evita o tempo frio de 2-4 segundos que costumava engolir cliques de parada iniciais.

7. Auto Prompt

O botão de crachá com spinner. Quando LIGADO, após N segundos de inatividade o painel envia automaticamente seu texto de ativação configurado. O dígito da contagem regressiva é renderizado em --cbe-highlight-color, que cada aparência define.

Edite o texto de ativação via o botão 🔁 Ativar — ele faz round-trip com wake.txt.

8. Leitura Automática (TTS)

O ícone da boca. Quando LIGADO, cada resposta do assistente é falada via o sintetizador Web Speech (Google) ou um fallback SAPI. Um halo azul brilha ao redor do ícone enquanto o áudio está sendo reproduzido.

9. Compacto & uso de contexto

O array de conversas enviado ao modelo cresce a cada turno. O anel ao redor do ícone Compacto mostra o uso atual da janela de contexto como um gradiente cônico — vazio quando novo, cheio quando próximo ao limite de contexto do modelo.

Clique em Compacto para truncar o histórico para os últimos quatro turnos. A próxima chamada de API usa o array menor.

10. Resposta de ativação

Armazenado em wake.txt na raiz da extensão. Usado pelo Auto Prompt como a mensagem a enviar quando o temporizador de inatividade dispara. Edite via o botão 🔁 da barra de ferramentas.

11. Anexos de arquivo

Clique em 📎 para escolher um ou mais arquivos. Mantenha Ctrl ou Shift no seletor para multi-selecionar. Cada arquivo é incorporado no prompt como um bloco de código cercado com seu nome de arquivo e idioma. Arquivos binários maiores que 1 MB são ignorados com um aviso.

12. Modal Git

Clique em 📁 Git. Se nenhuma pasta de projeto estiver configurada, você recebe um seletor de pasta primeiro — o caminho escolhido é escrito em [project] path em config.ini. Invocações git subsequentes são executadas com o cwd definido para esse caminho.

13. Repositórios GitHub

Lista cada repo acessível ao seu [github] pat. Clique em uma linha para inserir sua URL de clone no prompt. A lista é paginada e armazenada em cache.

14. Domínios NameSilo

Obtém cada domínio em sua conta NameSilo usando [namesilo] api_key (ou [api_keys] namesilo_api_key como fallback). Na primeira abertura, os resultados são armazenados em cache em domains.txt; inicializações subsequentes do painel servem do cache. Clique em Recarregar no modal para forçar uma busca nova.

Se você vir "sem domínios" com um código de resposta 300, verifique o canal de rastreamento — os caches vazios não prejudicam mais os inicializadores futuros do painel, mas um domains.txt antigo em outro caminho de instalação pode.

15. Aparências & temas

O botão 🎨 abre um seletor de descoberta que escaneia skins/ ao vivo (não na inicialização), então soltar uma pasta nova em tempo de execução é suficiente. Cada aparência tem um manifest.xml definindo sua paleta — incluindo a cor de destaque, que o crachá de contagem regressiva do Auto Prompt, anéis de foco, e pulso do supervisor usam.

As aparências integradas incluem: gnome (cinza Adwaita), terminal (preto/verde com acento rosa-quente), tamagotchi (pastéis cor de casca de ovo com um painel sprite mascote), blocky, e outros.

16. Configurações

Abre a partir da engrenagem ⚙. Abas:

  • Geral — nome de exibição, modelo padrão, enviar-ao-pressionar-enter
  • Voz — dispositivo mic, listen_seconds, escolha do mecanismo STT, auto-leitura TTS
  • Atualizações — flag is_admin, sessão WinSCP, caminho remoto
  • Chaves — chave de API de cada provedor
  • Monitor — alternância do supervisor VSCode, porta, intervalo de votação
  • Idioma — escolher entre 39 locales; veja § 17

O modal lembra seu tamanho e posição entre sessões.

17. Idioma

O painel vem com traduções para os 39 idiomas mais falados. Os arquivos de locale residem em languages/<code>.xml e são carregados uma vez no ativar da extensão. As chaves ausentes voltam para o inglês.

Escolha seu idioma em Configurações → Idioma. Um ícone de bandeira é mostrado ao lado de cada opção (carregado de assets/flags/<code>.svg). A seleção é salva em [settings] language em config.ini.

18. Supervisor VSCode

Um serviço Windows (CBEVSCodeSupervisor) envolve o script tools/vscode_supervisor.ps1 via NSSM e liga um HttpListener em http://127.0.0.1:3434/. O botão monitor do painel brilha em azul quando o endpoint /status do supervisor responde 200 OK.

Se a sonda HTTP falhar mas o serviço estiver instalado, o watchdog do painel reinicia automaticamente o serviço (cooldown de 30 segundos para não reiniciar constantemente).

Clique esquerdo no botão monitor para instalar / iniciar / parar. Clique direito para abrir o canal de rastreamento.

19. Auto-atualização (pull)

4 segundos após o ativar da extensão, o painel busca https://trentontompkins.com/cbe/manifest.xml.php — um manifesto MD5+size dos arquivos publicados mais recentes. Para cada arquivo remoto, o MD5 da cópia local é comparado; apenas os arquivos alterados/ausentes são baixados via HTTPS.

O estado local do usuário (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) está na lista de exclusão de pull e nunca é sobrescrito.

20. Push admin

Apenas clientes com [updates] is_admin = true fazem push para o servidor. Acionado via:

  • Paleta de Comandos → Claude Codex Black: Push update
  • Comando slash /push

Usa a sessão salva WinSCP nomeada em [updates] winscp_session (padrão vps). Faz push via /script=… com o comando sincronizar e uma máscara de arquivo que exclui segredos & estado por máquina.

21. Marketplace de extensões

Clique no botão 🧩 Extensões. Um modal iframe abre para https://trentontompkins.com/cbe/extension/extension_marketplace.php, que busca o catálogo em extensions.xml.php e renderiza cada extensão disponível como um cartão com uma descrição, tags, versão, tamanho de arquivo, MD5, e um botão Instalar.

Uma extensão é empacotada como <id>.ext — um arquivo zip contendo manifest.xml mais o código da extensão (normalmente um único extension.html). Quando você clica em Instalar, o iframe do marketplace envia uma postMessage de volta ao painel; o painel baixa o arquivo .ext diretamente do servidor e o extrai sob extensions/ na pasta da extensão.

Três extensões de demonstração vêm com o catálogo de lançamento: Calculadora, Campo Minado, e um Seletor de Emoji.

22. Comandos slash

Digite / na caixa de prompt para abrir a paleta de comando slash. Clique em uma linha para inserir o texto do comando em seu prompt (editável), ou pressione Enter em uma linha executável para disparar imediatamente.

Uma lista não exaustiva:

23. Menu de contexto

Clique direito em qualquer lugar do painel para obter um menu contextual (definido como uma única string XML em panel.js). As entradas incluem Atualizar (recarregar o painel sem tocar o host da extensão — nunca use reloadWindow), Limpar conversas, Abrir configurações, e Inspecionar (DevTools, apenas builds de debug).

24. Canal de rastreamento

A extensão escreve uma linha do tempo granular em debug.log ao lado da extensão. Tudo digno de nota chega lá: trocas de provedor, ciclo de vida STT, sondas de supervisor, códigos de resposta NameSilo, mensagens ponte painel↔host, contagens de manifesto push/pull.

Clique direito no botão monitor para abrir o canal de rastreamento com um clique.

25. Solução de problemas

SintomaCausa provável
A caixa de prompt parece proporcional, não monoespacial --vscode-editor-font-family não aplicado; verifique as variáveis :root
O spinner Auto Prompt é um ponto preto Ativo SVG errado; deve ser auto_read_spinner.svg com halo drop-shadow
Botão Compacto não faz nada Handler do host ausente — case 'compactConversation' no roteador extension.js
"0 domínios" no modal Domínios Resposta NameSilo reply.code != 300 (o canal de rastreamento tem), ou domains.txt antigo
STT "nenhuma fala detectada" instantaneamente Você parou antes do SAPI vincular o mic. O pré-aquecimento agora pula essa espera — verifique com stt: using pre-warmed SAPI em debug.log
Push falha em caminho com espaços Usando /command= inline; sempre use /script=tempfile.winscp
Brilho azul do supervisor não acendendo Serviço não em execução. Clique esquerdo no monitorBtn para instalar/iniciar, ou execute Start-Service CBEVSCodeSupervisor
Recarregar "corrige" algo Não foi. Nunca use reloadWindow. Use a entrada de menu de contexto Atualizar.
