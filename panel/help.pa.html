Claude Codex — Black Edition

VSCode ਲਈ ਇੱਕ ਆਫ਼ਲਾਈਨ-ਪਹਿਲਾ ਮਲਟੀ-ਪ੍ਰਦਾਤਾ AI ਚੈਟ ਪੈਨਲ। ਟੌਗਲ ਕਰਨ ਲਈ Ctrl+Alt+B ਦਬਾਓ।

1. ਸਵਾਗਤ

Claude Codex Black ਇੱਕ VSCode webview ਹੈ ਜੋ ਤੁਹਾਨੂੰ ਇੱਕ ਥੀਮਯੋਗ ਪੈਨਲ ਤੋਂ ਬਹੁ ਪ੍ਰਦਾਤਾ AI (Claude, OpenAI, Gemini, Grok, Azure, ਸਥਾਨਕ Ollama) ਨਾਲ ਚੈਟ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਸਭ ਕੁਝ ਜਿਸ ਨੂੰ ਕੁੰਜੀ ਦੀ ਲੋੜ ਹੈ ਇਹ config.ini ਤੋਂ ਎ਕਸਟੈਨਸਨ ਰੂਟ ਵਿਖੇ ਪੜ੍ਹਦਾ ਹੈ — ਕੋਈ ਐਕਸਟੈਨਸਨ ਸੈਟਿੰਗ UI ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ, ਪਰ ਇੱਕ Settings ਮੋਡਲ ਕਲਿੱਕ-ਓਨਲੀ ਸੰਪਾਦਨ ਲਈ ਸਭ ਤੋਂ ਲਾਭਦਾਇਕ ਖੇਤਾਂ ਨੂੰ ਪ੍ਰਤੀਬਿੰਬਤ ਕਰਦਾ ਹੈ।

ਨਵੇ ਹੋ? Settings (ਗੀਅਰ ਆਈਕਨ) ਖੋਲ ਕੇ ਸ਼ੁਰੂ ਕਰੋ, ਆਪਣਾ ਪ੍ਰਦਾਤਾ ਚੁਣੋ, ਆਪਣੀ API ਕੁੰਜੀ ਪੇਸਟ ਕਰੋ, ਫਿਰ ਇੱਕ ਪ੍ਰਾਂਪਟ ਟਾਈਪ ਕਰੋ ਅਤੇ Enter ਦਬਾਓ। ਇਸ ਗਾਈਡ ਦੀ ਹਰ ਦੂਸਰੀ ਵਿਸ਼ੇਸ਼ਤਾ ਐਚਛਾਲਕ ਹੈ।

3. ਪ੍ਰਾਂਪਟ ਬੌਕਸ

ਹੇਠਾਂ ਵੱਡੀ ਸੋਧਯੋਗ textarea। ਟਾਈਪ ਕਰੋ, ਪੇਸਟ ਕਰੋ, ਇੱਕ ਫਾਈਲ ਖਿੱਚੋ, ਪੇਪਰਕਲਿਪ ਦੁਆਰਾ ਅਨੁਲਗਨ ਕਰੋ — ਜੋ ਕੁਝ ਤੁਸੀਂ ਇੱਥੇ ਰੱਖਦੇ ਹੋ ਪਰ ਅਗਲੀ API ਕਾਲ ਦਾ ਯੂਜ਼ਰ ਟਰਨ ਹੈ।

ਫੌਂਟ ਤੁਹਾਡੇ VSCode ਐਡੀਟਰ ਦੇ monospace ਫੌਂਟ ਲਈ ਲਾਕ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (--vscode-editor-font-family CSS ਵੇਰੀਏਬਲ ਤੋਂ) ਇਸ ਲਈ ਪੈਨਲ ਐਡੀਟਰ ਅੰਦਰ ਘਰ ਵਰਗਾ ਲੱਗਦਾ ਹੈ।

5. ਮਾਡਲ ਅਤੇ ਪ੍ਰਦਾਤਾ

CBE 11 bridges ਨਾਲ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ bridges/ ਹੇਠ drop-in .bridge ਪਲੱਗਇਨ ਵਜੋਂ। ਹਰ ਇੱਕ manifest.xml + bridge.py + ਆਈਕਨ ਦੇ ਨਾਲ ਇੱਕ ਸਵੈ-ਸਮਾਓ ਜ਼ਿੱਪ ਹੈ। ਇੱਕ ਨਿਆਂ .bridge ਫਾਈਲ ਵਿਚ ਸੁੱਟੋ ਅਤੇ ਇਹ ਕਾਰਟ੍ਰਿਜ dropdown ਵਿਖੇ ਪ੍ਰਗਟ ਹੁੰਦੀ ਹੈ — ਕੋਈ ਐਕਸਟੈਨਸਨ ਕੋਡ ਤਬਦੀਲੀ ਦੀ ਜ਼ਰੂਰਤ ਨਹੀਂ ਹੈ।

ਪਾਠ-ਚੈਟ bridges (7)

  • ChatGPT — chatgpt.com, Plus/Pro ਸਬਸਕ੍ਰਿਪਸ਼ਨ
  • Grok — grok.com, ਜਨਮ xAI ਲਾਗ-ਇਨ (ਅਨਾਮ ਸਥਰ ਬਹੁਤ ਬੰਦ ਹੈ; ਪਹਿਲਾਂ ਲਾਗ-ਇਨ ਕਰੋ)
  • Gemini — gemini.google.com, Google ਖਾਤਾ
  • Claude — claude.ai, magic-link ਲਾਗ-ਇਨ (tools/sign_in_helper.py claude ਇਕ ਵਾਰ ਚਲਾਓ)
  • Copilot — copilot.microsoft.com, ਫ੍ਰੀ Microsoft ਖਾਤਾ
  • DeepSeek — chat.deepseek.com, ਜਨਮ ਈਮੇਲ/ਪਾਸਵਰਡ (Google SSO ਨਾ ਵਰਤੋ)
  • Ollama — ਸਥਾਨਕ 127.0.0.1:11434, ਲਾਗ-ਇਨ ਦੀ ਜ਼ਰੂਰਤ ਨਹੀਂ

ਵੀਡੀਓ-ਜਨਰੇਸ਼ਨ bridges (4)

  • Sora 2 — sora.com, ਆਪਣੇ ChatGPT Plus/Pro ਲਾਗ-ਇਨ ਦੀ ਪੁਨਰਵਰਤੀ
  • Google Veo — gemini.google.com (Veo ਮੋਡ), Gemini Advanced ਸਬਸਕ੍ਰਿਪਸ਼ਨ
  • Runway Gen-3/4 — app.runwayml.com, ਵੱਖਰੀ Runway ਸਬਸਕ੍ਰਿਪਸ਼ਨ
  • Bing Video Creator — bing.com/videos/create, ਫ੍ਰੀ Sora-2 Microsoft ਖਾਤਿਆਂ ਨਾਲ

ਜਨਰੇਟ ਕੀਤੀਆਂ ਵੀਡੀਓ videos/<bridge>/<timestamp>_<prompt-slug>.mp4 ਵਿਖੇ ਬਚਾਈਆਂ ਜਾਂਦੀਆਂ ਹਨ ਅਤੇ Video Library ਪੈਨਲ ਵਿਚ ਆਟੋ-ਪਲੇਅ ਕਰਦੀਆਂ ਹਨ (ਹੇਠ §Video Library ਦੇਖੋ)।

ਪ੍ਰਾਂਪਟ ਬੌਕਸ ਦੇ ਅਗਲੀ ਕਾਰਟ੍ਰਿਜ dropdown ਤੋਂ ਇੱਕ bridge + ਮਾਡਲ ਚੁਣੋ, ਜਾਂ Settings → General ਦੁਆਰਾ। ਸਲੈਕਸ਼ਨ ਫੀ ਪ੍ਰਤੀ ਹੈ ਅਤੇ workspaceState ਵਿਖੇ ਪਬੱਧ ਹੈ। ਇੱਕ ਨਵਾਂ bridge ਸ਼ਾਮਲ ਕਰਨ ਲਈ, docs/WRITING_BRIDGES.md ਦੇਖੋ।

5a. ਵੀਡੀਓ ਲਾਇਬ੍ਰੇਰੀ

ਵੀਡੀਓ bridges (Sora, Veo, Runway, Bing Video Creator) ਦੁਆਰਾ ਜਨਰੇਟ ਕੀਤੀਆਂ ਵੀਡੀਓ ਨੂੰ ਬ੍ਰਾਊਜ਼ ਕਰਨ + ਵੇਖਣ ਲਈ ਇੱਕ ਸਮਰਪਿਤ ਪੈਨਲ। Command Palette ਤੋਂ ਖੁੱਲਦਾ ਹੈ: Claude Codex Black: Open Video Library ਜਾਂ codexBlackEd.openVideoPlayer ਕਮਾਂਡ।

  • Sidebar ਹਰ .mp4 / .webm / .mov ਨੂੰ videos/<bridge>/ ਅਧੀਨ, bridge ਦੁਆਰਾ ਗਰੁੱਪ ਕੀਤਾ ਅਤੇ ਨਵਿਆ-ਪਹਿਲਾ ਕ੍ਰਮਬੱਧ ਸੂਚੀਬੱਧ ਕਰਦਾ ਹੈ।
  • ਤਾਜ਼ਾ ਵੀਡੀਓ ਪਹਿਲਾ ਖੁੱਲ 'ਤੇ auto-plays।
  • ਪੈਨਲ 2-ਸਕਿੰਟ ਟਿੱਕ ਉੱਤੇ videos/ ਡਾਇਰ ਨੂੰ ਨਿਗਰਾਨੀ ਕਰਦਾ ਹੈ — ਕੋਈ ਵੀ ਨਵਿਆ ਜਨਰੇਟ ਕੀਤੀ ਵੀਡੀਓ ✨ "Just generated" ਬੈਜ ਨਾਲ ਪੌਪ ਅਪ ਕਰਦੀ ਹੈ ਅਤੇ auto-plays (Auto ▶ new ਤੋਂ ਟੌਗਲ ਆਫ)।
  • 📂 Open ਕਲਿੱਕ ਕਰੋ videos/ ਫੋਲਡਰ ਨੂੰ ਆਪਣੇ OS ਫਾਈਲ ਮੈਨੇਜਰ ਵਿਖੇ ਦਿਖਾਉਣ ਲਈ।

6. ਵਾਣੀ ਤੋ ਪਾਠ

Mic ਕਲਿੱਕ ਕਰੋ, ਬੋਲੋ, ਦੁਬਾਰਾ ਕਲਿੱਕ ਕਰੋ ਰੁਕਨ ਲਈ (ਜਾਂ ਖਾਮੋਸ਼ੀ-ਟਾਈਮ ਆਊਟ ਦੀ ਉਮੀਦ ਕਰੋ)। ਕ੍ਰਮ ਵਿਚ ਦੋ ਇੰਜਣ ਕੋਸ਼ਸ਼ ਕੀਤੇ ਜਾਂਦੇ ਹਨ:

  1. Web Speech API — Google ਦਾ ਕਲਾਉਡ recognizer webview ਵਿਚ ਚੱਲ ਰਿਹਾ ਹੈ। ਆਪਣੇ Gmail/Google ਸਤਰ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ; ਕੋਈ ਵਧੀ ਕੁੰਜੀ ਦੀ ਲੋੜ ਨਹੀਂ।
  2. Windows SAPI (fallback) — ਪੂਰਵ-ਤਾਤੀ PowerShell ਪ੍ਰਕ੍ਰਿਆ webview jab mic ਪਹੁੰਚ ਨੂੰ ਰੋਕਦਾ ਹੈ। [voice] listen_seconds ਦੁਆਰਾ ਸੰਯੋਜਿਤ ਸੁਣਨ ਵਿੰਡੋ config.ini ਵਿਚ।
SAPI ਨੂੰ ਐਕਸਟੈਨਸਨ ਐਕਟੀਵੇਟ 'ਤੇ ਪੂਰਵ-ਤਾਪਾਹੀ ਕੀਤਾ ਜਾਂਦਾ ਹੈ ਇਸ ਲਈ ਪਹਿਲਾ mic ਕਲਿੱਕ 2-4 ਸਕਿੰਟ ਦੀ ਕੋਲਡ ਸ਼ੁਰੂਆਤ ਨੂੰ ਜ਼ਹਰੀਲਾ ਕਰਨ ਨਾਲਿ ਬਚਾਉਂਦਾ ਹੈ।

7. ਆਟੋ ਪ੍ਰਾਂਪਟ

ਬੈਜ-ਨਾਲ-spinner ਬਟਨ। ON ਹੌਂਦਾ ਹੈ, N ਸਕਿੰਟ ਅਗ਼ੜਤਾ ਤੋ ਬਾਅਦ panel auto-sends ਆਪਣੀ ਸੰਰਚਿਤ ਜਾਗਣ-ਅਪ ਪਾਠ। Countdown ਅੰਕ --cbe-highlight-color ਵਿਚ ਬੇਸ਼ਕੀ ਹੁੰਦਾ ਹੈ, ਹਰ skin ਜੋ ਪਰਿਭਾਸ਼ਿਤ ਕਰਦਾ ਹੈ।

🔁 Wake ਬਟਨ ਦੁਆਰਾ ਜਾਗਣ-ਅਪ ਪਾਠ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰੋ — ਇਹ round-trips wake.txt।

8. ਆਟੋ ਰੀਡ (TTS)

ਮਾਉਥ ਆਈਕਨ। ON ਹੌਂਦਾ ਹੈ, ਹਰ ਸਹਾਇਕ ਉੱਤਰ Web Speech synthesizer (Google) ਜਾਂ SAPI fallback ਦੁਆਰਾ ਬੋਲਿਆ ਜਾਂਦਾ ਹੈ। ਇੱਕ ਨੀਲਾ halo audio ਖੇਡ ਰਿਹਾ ਹੈ ਜਿੰਨੇ ਆਈਕਨ ਦੁਆਲੇ glows।

9. ਸੰਖੇਪ ਅਤੇ ਸੰਦਰਭ ਵਰਤੋਂ

Conversation ਅਰੇ ਮਾਡਲ ਨੂੰ ਭੇਜੀ ਵਧਦਾ ਹੈ ਹਰ ਟਰਨ ਨਾਲ। ਸੰਖੇਪ ਆਈਕਨ ਦੁਆਲੇ ਰਿੰਗ ਮੌਜੂਦਾ context-window ਵਰਤੋਂ ਦਿਖਾਉਂਦੀ ਹੈ ਇੱਕ conic gradient ਵਜੋਂ — ਖਾਲੀ ਜਦ ਤਾਜ਼ਾ, ਪੂਰਣ ਜਦ ਮਾਡਲ ਦੀ context limit ਦੇ ਨਜ਼ਦੀਕ ਹੋਵੇ।

Compact ਕਲਿੱਕ ਕਰੋ ਇਤਿਹਾਸ ਨੂੰ ਆਖਰੀ ਚਾਰ ਟਰਨਾਂ ਤੱਕ ਕੱਟਨ ਲਈ। ਅਗਲੀ API ਕਾਲ ਛੋਟੇ ਅਰੇ ਦੀ ਵਰਤੋਂ ਕਰਦੀ ਹੈ।

10. ਜਾਗਣ ਦਾ ਜਵਾਬ

wake.txt ਵਿਖੇ ਸਮਰਪਿਤ extension ਰੂਟ ਵਿਖੇ। Auto Prompt ਦੁਆਰਾ ਵਰਤੀ ਮੈਸੇਜ ਜਦ inactivity ਟਾਈਮਰ fires। 🔁 toolbar ਬਟਨ ਦੁਆਰਾ ਸੰਪਾਦਿਤ ਕਰੋ।

11. ਫਾਈਲ ਸੰਲਗਨ

📎 ਕਲਿੱਕ ਕਰੋ ਇੱਕ ਜਾਂ ਵਧੇਰੇ ਫਾਈਲ ਚੁਣਨ ਲਈ। Picker ਵਿਖੇ Ctrl ਜਾਂ Shift ਹੋਲਡ ਕਰੋ ਬਹੁ-ਸਲੈਕਟ ਕਰਨ ਲਈ। ਹਰ ਫਾਈਲ ਪ੍ਰਾਂਪਟ ਵਿਚ ਇੱਕ fenced code ਬਲੌਕ ਵਜੋਂ ਅਨੁਲਗਨ ਹੈ ਇਸ ਦੇ ਨਾਮ ਅਤੇ ਭਾਸ਼ਾ ਨਾਲ। 1 MB ਤੋ ਵੱਧ Binary ਫਾਈਲਾਂ ਨੋਟਿਸ ਨਾਲ ਸਕਿਪ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।

12. Git ਮੋਡਲ

📁 Git ਕਲਿੱਕ ਕਰੋ। ਜੇ ਕੋਈ ਪ੍ਰੋਜੈਕਟ ਫੋਲਡਰ ਸੰਰਚਿਤ ਨਹੀਂ ਹੈ, ਤੁਹਾਨੂੰ ਪਹਿਲਾਂ ਇੱਕ folder picker ਪ੍ਰਾਪਤ ਹੋਂਦਾ ਹੈ — ਚੁਣਿਆ ਗਿਆ ਪਾਥ [project] path ਨੂੰ config.ini ਵਿਖੇ ਲਿਖਿਆ ਜਾਂਦਾ ਹੈ। ਅਗਲੀ git invocations ਕਿਹ ਸੱਟ ਕਦ ਚਲਦੀਆਂ ਹਨ।

13. GitHub ਖਜਾਨੇ

ਆਪਣੇ [github] pat ਲਈ ਅਰਾਧ ਹਰ repo ਸੂਚੀ ਬਿਲਿਤ। ਇੱਕ ਪੰਕਤੀ ਕਲਿੱਕ ਕਰੋ ਇਸ ਦੀ clone URL ਨੂੰ ਪ੍ਰਾਂਪਟ ਵਿਚ ਸੰਮਿਲਿਤ ਕਰਨ ਲਈ। ਸੂਚੀ paginated ਅਤੇ ਕੈਸ਼ ਕੀਤੀ ਹੈ।

14. NameSilo ਡੋਮੇਨ

ਹਰ domain ਤੁਹਾਡੇ NameSilo ਖਾਤਿਆਂ ਵਿਚ [namesilo] api_key ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਖਿੱਚੋ (ਜਾਂ [api_keys] namesilo_api_key ਫਾਲਬੈਕ ਦੇ ਰੂਪ ਵਿਖੇ)। ਪਹਿਲੀ ਖੋਜ ਉੱਤੇ, ਨਤੀਜੇ cached ਕੀਤੇ ਜਾਂਦੇ ਹਨ domains.txt ਨੂੰ; ਅਨੁਸਾਰੀ panel boots cache ਤੋ serve ਕਰਦੀਆਂ ਹਨ। Reload ਕਲਿੱਕ ਕਰੋ ਮੋਡਲ ਵਿਚ ਤਾਜ਼ਾ ਫੈਚ ਜ਼ਬਰਦਸਤ ਕਰਨ ਲਈ।

ਜੇ ਤੁਸੀਂ "no domains" ਨੂੰ 300 reply code ਨਾਲ ਦੇਖਦੇ ਹੋ, trace channel ਚੇਕ ਕਰੋ — ਖਾਲੀ caches ਹੋਰ panel boots ਨੂੰ poison ਨਹੀਂ ਕਰਦੇ, ਪਰ ਇੱਕ stale domains.txt ਇੱਕ ਹੋਰ ਸਥਾਪਨ ਪਾਥ ਵਿਖੇ ਕਰ ਸਕਦਾ ਹੈ।

15. ਸਕਿਨ ਅਤੇ ਥੀਮ

🎨 ਬਟਨ ਇੱਕ discovery picker ਪੱਪ ਕਰਦਾ ਹੈ ਜੋ skins/ ਨੂੰ scan ਕਰਦਾ ਹੈ live (startup ਵਿਖੇ ਨਹੀਂ), ਇਸ ਲਈ runtime ਵਿਖੇ ਇੱਕ ਨਿਆਂ ਫੋਲਡਰ ਸੁੱਟਣਾ ਕਾਫੀ ਹੈ। ਹਰ skin ਆਪਣਾ manifest.xml ਹੈ ਜੋ ਆਪਣਾ palette ਪਰਿਭਾਸ਼ਿਤ ਕਰਦਾ ਹੈ — ਸਮੇਤ highlight color, ਜੋ Auto Prompt countdown badge, focus rings, ਅਤੇ supervisor pulse ਸਭ ਕੁਝ key off of।

ਬਿਲਿਤ-ਸਕਿਨ ਸ਼ਾਮਲ: gnome (Adwaita gray), terminal (black/green hot-pink accent ನqr), tamagotchi (egg-shell pastels sprite mascot panel ਨਾਲ), blocky, ਅਤੇ ਹੋਰ।
