Codex Black Ed.

Panel obrolan AI multi-penyedia offline-first untuk VSCode. Tekan Ctrl+Alt+B untuk mengalihkan.

1. Selamat datang

Codex Black adalah webview VSCode yang memungkinkan Anda mengobrol dengan berbagai penyedia AI (Claude, OpenAI, Gemini, Grok, Azure, Ollama lokal) dari satu panel yang dapat disesuaikan. Semua yang memerlukan kunci membaca dari config.ini di root ekstensi — tidak ada UI pengaturan ekstensi yang diperlukan, tetapi modal Pengaturan mencerminkan bidang paling berguna untuk pengeditan hanya klik.

Baru di sini? Mulai dengan membuka Pengaturan (ikon roda gigi), pilih penyedia Anda, tempel kunci API Anda, lalu ketik prompt dan tekan Enter. Setiap fitur lain dalam panduan ini bersifat opsional.

3. Kotak prompt

Textarea besar yang dapat diedit di bagian bawah. Ketik, tempel, seret file, lampirkan melalui klip kertas — apa pun yang Anda letakkan di sini adalah giliran pengguna dari panggilan API berikutnya.

Font terkunci ke font monospace editor VSCode Anda (melalui variabel CSS --vscode-editor-font-family) sehingga panel terlihat di rumah di dalam editor.

Baris bawah, kiri ke kanan. Tooltip muncul saat mengarahkan kursor; panel juga membacanya dalam bahasa pilihan Anda (lihat Bahasa).

5. Model & penyedia

CBE dilengkapi dengan 11 jembatan sebagai plugin .bridge drop-in di bawah bridges/. Masing-masing adalah zip berdiri sendiri dengan manifest.xml + bridge.py + ikon. Lepaskan file .bridge baru dan itu akan muncul di dropdown cartridge — tidak ada perubahan kode ekstensi yang diperlukan.

Jembatan obrolan teks (7)

  • ChatGPT — chatgpt.com, langganan Plus/Pro
  • Grok — grok.com, login xAI asli (tingkat anonim sangat terbatas; masuk terlebih dahulu)
  • Gemini — gemini.google.com, akun Google
  • Claude — claude.ai, login tautan ajaib (jalankan tools/sign_in_helper.py claude sekali)
  • Copilot — copilot.microsoft.com, akun Microsoft gratis
  • DeepSeek — chat.deepseek.com, email/password asli (JANGAN gunakan Google SSO)
  • Ollama — lokal 127.0.0.1:11434, tidak memerlukan login

Jembatan pembuatan video (4)

  • Sora 2 — sora.com, menggunakan kembali login ChatGPT Plus/Pro Anda
  • Google Veo — gemini.google.com (mode Veo), langganan Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, langganan Runway terpisah
  • Bing Video Creator — bing.com/videos/create, Sora-2 gratis dengan akun Microsoft

Video yang dihasilkan disimpan ke videos/<bridge>/<timestamp>_<prompt-slug>.mp4 dan diputar secara otomatis di panel Perpustakaan Video (lihat §Perpustakaan Video di bawah).

Pilih jembatan + model dari dropdown cartridge di sebelah kotak prompt, atau melalui Pengaturan → Umum. Pilihan adalah per-workspace dan tetap di workspaceState. Untuk menambahkan jembatan baru, lihat docs/WRITING_BRIDGES.md.

5a. Perpustakaan Video

Panel khusus untuk browsing + menonton video yang dihasilkan oleh jembatan video (Sora, Veo, Runway, Bing Video Creator). Buka melalui Palet Perintah: Codex Black: Buka Perpustakaan Video atau perintah codexBlackEd.openVideoPlayer.

  • Sidebar mencantumkan setiap .mp4 / .webm / .mov di bawah videos/<bridge>/, dikelompokkan berdasarkan jembatan dan diurutkan terbaru-dulu.
  • Video terbaru diputar secara otomatis saat pertama kali dibuka.
  • Panel memantau dir videos/ pada tick 2 detik — video yang baru dihasilkan muncul dengan badge ✨ "Baru saja dibuat" dan diputar secara otomatis (matikan melalui Putar ▶ baru).
  • Klik 📂 Buka untuk memperlihatkan folder videos/ di pengelola file OS Anda.

6. Ucapan ke Teks

Klik mikrofon, bicara, klik lagi untuk berhenti (atau tunggu timeout diam). Dua mesin dicoba secara berurutan:

  1. Web Speech API — pengenalan cloud Google yang berjalan di webview. Menggunakan sesi Gmail/Google Anda; tidak memerlukan kunci tambahan.
  2. Windows SAPI (fallback) — proses PowerShell yang dipanaskan sebelumnya dipanggil ketika webview memblokir akses mikrofon. Jendela mendengarkan yang dapat dikonfigurasi melalui [voice] listen_seconds di config.ini.
SAPI adalah dipanaskan sebelumnya saat ekstensi aktifkan sehingga klik mikrofon pertama menghindari start dingin 2-4 detik yang dulu menelan klik henti awal.

7. Prompt Otomatis

Tombol dengan lembaran-spinner. Ketika AKTIF, setelah N detik ketidakaktifan panel secara otomatis mengirim teks bangun yang dikonfigurasi. Digit hitung mundur dirender dalam --cbe-highlight-color, yang masing-masing kulit mendefinisikan.

Edit teks bangun melalui tombol 🔁 Bangun — itu round-trip wake.txt.

8. Baca Otomatis (TTS)

Ikon mulut. Ketika AKTIF, setiap balasan asisten diucapkan melalui synthesizer Web Speech (Google) atau fallback SAPI. Aura biru bersinar di sekitar ikon saat audio diputar.

9. Ringkas & penggunaan konteks

Array percakapan yang dikirim ke model tumbuh dengan setiap giliran. Ring di sekitar ikon Ringkas menunjukkan penggunaan jendela konteks saat ini sebagai gradien konik — kosong ketika baru, penuh ketika mendekati batas konteks model.

Klik Ringkas untuk memotong riwayat menjadi empat giliran terakhir. Panggilan API berikutnya menggunakan array yang lebih kecil.

10. Respons bangun

Disimpan di wake.txt di root ekstensi. Digunakan oleh Prompt Otomatis sebagai pesan untuk dikirim ketika timer ketidakaktifan membara. Edit melalui tombol 🔁 toolbar.

11. Lampiran file

Klik 📎 untuk memilih satu atau lebih file. Tahan Ctrl atau Shift di pemilih untuk multi-pilih. Setiap file dimasukkan ke dalam prompt sebagai blok kode yang dibatasi dengan nama file dan bahasa. File biner di atas 1 MB dilewati dengan pemberitahuan.

12. Modal Git

Klik 📁 Git. Jika tidak ada folder proyek yang dikonfigurasi, Anda mendapatkan pemilih folder terlebih dahulu — jalur yang dipilih ditulis ke [project] path di config.ini. Pemanggilan git berikutnya berjalan dengan cwd diatur ke jalur itu.

13. Repositori GitHub

Mencantumkan setiap repo yang dapat diakses oleh [github] pat Anda. Klik baris untuk menyisipkan URL klonnya ke dalam prompt. Daftar dipaginasi dan di-cache.

14. Domain NameSilo

Menarik setiap domain di akun NameSilo Anda menggunakan [namesilo] api_key (atau [api_keys] namesilo_api_key sebagai fallback). Pada pembukaan pertama, hasil di-cache ke domains.txt; boot panel berikutnya disajikan dari cache. Klik Muat Ulang di modal untuk memaksa pengambilan segar.

Jika Anda pernah melihat "tidak ada domain" dengan kode balasan 300, periksa saluran jejak — cache kosong tidak lagi meracuni boot panel masa depan, tetapi domains.txt yang ketinggalan zaman di jalur instalasi lain bisa.

15. Kulit & tema

Tombol 🎨 menampilkan pemilih penemuan yang memindai skins/ secara langsung (bukan pada startup), sehingga menjatuhkan folder baru saat runtime sudah cukup. Setiap kulit memiliki manifest.xml yang mendefinisikan palet — termasuk warna sorotan, yang hitung mundur Prompt Otomatis, ring fokus, dan pulsa pengawas semua kunci.

Kulit bawaan termasuk: gnome (abu-abu Adwaita), terminal (hitam/hijau dengan aksen panas merah muda), tamagotchi (pastel kulit telur dengan panel sprite maskot), blocky, dan lainnya.

16. Pengaturan

Buka dari roda gigi ⚙. Tab:

  • Umum — nama tampilan, model default, kirim-on-enter
  • Suara — perangkat mikrofon, listen_seconds, pilihan mesin STT, baca-otomatis TTS
  • Pembaruan — flag is_admin, sesi WinSCP, jalur jauh
  • Kunci — kunci API setiap penyedia
  • Monitor — pengawas VSCode toggle, port, interval jajak
  • Bahasa — pilih dari 39 lokal; lihat § 17

Modal mengingat ukuran dan posisinya antar sesi.

17. Bahasa

Panel dilengkapi dengan terjemahan untuk 39 bahasa yang paling banyak digunakan. File lokal ada di languages/<code>.xml dan dimuat sekali saat aktivasi ekstensi. Kunci yang hilang kembali ke Inggris.

Pilih bahasa Anda di Pengaturan → Bahasa. Ikon bendera ditampilkan di sebelah setiap opsi (dimuat dari assets/flags/<code>.svg). Pilihan disimpan ke [settings] language di config.ini.

18. Pengawas VSCode

Layanan Windows (CBEVSCodeSupervisor) membungkus skrip tools/vscode_supervisor.ps1 melalui NSSM dan mengikat HttpListener di http://127.0.0.1:3434/. Tombol monitor panel bersinar biru ketika titik akhir /status pengawas menjawab 200 OK.

Jika probe HTTP gagal tetapi layanan terpasang, anjing pengamat panel secara otomatis memulai ulang layanan (cool-down 30 detik sehingga tidak restart-storm).

Klik kiri tombol monitor untuk memasang / memulai / berhenti. Klik kanan untuk membuka saluran jejak.

19. Pembaruan otomatis (tarik)

4 detik setelah aktivasi ekstensi, panel mengambil https://trentontompkins.com/cbe/manifest.xml.php — manifesto MD5+size dari file terbaru yang dipublikasikan. Untuk setiap file jarak jauh, MD5 salinan lokal adalah dibandingkan; hanya file yang diubah/hilang yang diunduh melalui HTTPS.

Keadaan lokal pengguna (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) ada di daftar pengecualian tarik dan tidak pernah ditimpa.

20. Dorong admin

Hanya klien dengan [updates] is_admin = true yang pernah mendorong ke server. Dipicu melalui:

  • Palet Perintah → Codex Black: Dorong pembaruan
  • Perintah garis miring /push

Menggunakan sesi WinSCP yang disimpan bernama dalam [updates] winscp_session (default vps). Dorong melalui /script=… dengan perintah synchronize dan filemask yang mengecualikan rahasia & keadaan per-mesin.

21. Pasar ekstensi

Klik tombol 🧩 Ekstensi. Modal iframe terbuka ke https://trentontompkins.com/cbe/extension/extension_marketplace.php, yang mengambil katalog di extensions.xml.php dan merender setiap ekstensi yang tersedia sebagai kartu dengan deskripsi, tag, versi, ukuran file, MD5, dan tombol Pasang.

Ekstensi dikemas sebagai <id>.ext — arsip zip yang berisi manifest.xml ditambah kode ekstensi (biasanya satu extension.html). Ketika Anda mengklik Pasang, iframe pasar mengirimkan postMessage kembali ke panel; panel mengunduh file .ext secara langsung dari server dan mengekstraknya di bawah extensions/ di folder ekstensi.

Tiga ekstensi demo dikirim dengan katalog peluncuran: Kalkulator, Penyapu Ranjau, dan Pemilih Emoji.

22. Perintah garis miring

Ketik / di kotak prompt untuk membuka palet perintah garis miring. Klik baris untuk menyisipkan teks perintah ke dalam prompt Anda (dapat diedit), atau tekan Enter di baris yang dapat dijalankan untuk membakunya segera.

23. Menu klik kanan

Klik kanan di mana pun di panel untuk menu kontekstual (didefinisikan sebagai string XML tunggal di panel.js). Entri termasuk Refresh (muat ulang panel tanpa menyentuh host ekstensi — jangan pernah gunakan reloadWindow), Hapus percakapan, Buka pengaturan, dan Periksa (DevTools, hanya debug build).

24. Saluran jejak

Ekstensi menulis garis waktu granular ke debug.log di sebelah ekstensi. Semua yang penting mendarat di sana: saklar penyedia, siklus STT, probe pengawas, kode balasan NameSilo, pesan jembatan panel↔host, hitung dorong/tarik manifesto.

Klik kanan tombol monitor untuk pembukaan saluran jejak satu klik.

25. Pemecahan masalah

GejalaKemungkinan penyebab
Kotak prompt terlihat proporsional, bukan monospace --vscode-editor-font-family tidak diterapkan; periksa variabel :root
Spinner Prompt Otomatis adalah titik hitam Aset SVG salah; harus auto_read_spinner.svg dengan halo drop-shadow
Tombol Ringkas tidak melakukan apa pun Handler host hilang — case 'compactConversation' di router extension.js
"0 domain" di modal Domain Balasan NameSilo.code != 300 (saluran jejak memilikinya), atau domains.txt ketinggalan zaman
STT "tidak ada pidato terdeteksi" secara instan Anda berhenti sebelum SAPI mengikat mikrofon. Pra-hang sekarang melewati tunggu itu — verifikasi dengan stt: menggunakan SAPI yang dipanaskan sebelumnya di debug.log
Push gagal di jalur dengan spasi Menggunakan /command= inline; selalu gunakan /script=tempfile.winscp
Cahaya biru pengawas tidak menyala Layanan tidak berjalan. Klik kiri monitorBtn untuk memasang/memulai, atau jalankan Start-Service CBEVSCodeSupervisor
Muat ulang "memperbaiki" sesuatu Tidak. Jangan pernah gunakan reloadWindow. Gunakan entri menu konteks Refresh sebagai gantinya.
