Codex Black Ed.

Panel de chat multisuscriptor de IA sin conexión primero para VSCode. Presiona Ctrl+Alt+B para alternar.

1. Bienvenida

Codex Black es una vista web de VSCode que te permite chatear con múltiples proveedores de IA (Claude, OpenAI, Gemini, Grok, Azure, Ollama local) desde un único panel personalizable. Todo lo que necesita una clave se lee desde config.ini en la raíz de la extensión — no se requiere interfaz de configuración de extensión, pero un modal de Configuración refleja los campos más útiles para edición mediante clic.

¿Nuevo aquí? Comienza abriendo Configuración (icono de engranaje), elige tu proveedor, pega tu clave de API y luego escribe un prompt y presiona Enter. Todas las otras características en esta guía son opcionales.

3. El cuadro de prompt

El grande textarea editable en la parte inferior. Escribe, pega, arrastra un archivo, adjunta mediante el clip de papel — cualquier cosa que pongas aquí es el turno del usuario de la siguiente llamada de API.

La fuente está bloqueada a la fuente monoespaciada del editor de VSCode (a través de la variable CSS --vscode-editor-font-family) así que el panel se ve en casa dentro del editor.

5. Modelos y proveedores

CBE se envía con 11 puentes como plugins .bridge listas para usar bajo bridges/. Cada uno es un zip autónomo con manifest.xml + bridge.py + iconos. Suelta un nuevo archivo .bridge y aparecerá en el desplegable del cartucho — sin necesidad de cambios en el código de la extensión.

Puentes de chat de texto (7)

  • ChatGPT — chatgpt.com, suscripción Plus/Pro
  • Grok — grok.com, inicio de sesión nativo de xAI (el nivel anónimo está muy limitado; inicia sesión primero)
  • Gemini — gemini.google.com, cuenta de Google
  • Claude — claude.ai, inicio de sesión con enlace mágico (ejecuta tools/sign_in_helper.py claude una vez)
  • Copilot — copilot.microsoft.com, cuenta Microsoft gratuita
  • DeepSeek — chat.deepseek.com, correo electrónico/contraseña nativa (NO uses Google SSO)
  • Ollama — 127.0.0.1:11434 local, no se requiere inicio de sesión

Puentes de generación de video (4)

  • Sora 2 — sora.com, reutiliza tu inicio de sesión de ChatGPT Plus/Pro
  • Google Veo — gemini.google.com (modo Veo), suscripción Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, suscripción Runway separada
  • Bing Video Creator — bing.com/videos/create, Sora-2 gratuito con cuenta Microsoft

Los videos generados se guardan en videos/<bridge>/<timestamp>_<prompt-slug>.mp4 y se reproducen automáticamente en el panel de Biblioteca de Video (ver §Video Library más abajo).

Elige un puente + modelo desde el desplegable del cartucho junto al cuadro de prompt, o mediante Configuración → General. La selección es por espacio de trabajo y se persiste en workspaceState. Para agregar un nuevo puente, ver docs/WRITING_BRIDGES.md.

5a. Biblioteca de video

Un panel dedicado para navegar y ver videos generados por los puentes de video (Sora, Veo, Runway, Bing Video Creator). Se abre a través de la Paleta de comandos: Codex Black: Open Video Library o el comando codexBlackEd.openVideoPlayer.

  • La barra lateral lista cada .mp4 / .webm / .mov bajo videos/<bridge>/, agrupado por puente y ordenado más reciente primero.
  • El video más reciente se reproduce automáticamente al abrir por primera vez.
  • El panel observa el directorio videos/ cada 2 segundos — cualquier video recientemente generado aparece con una insignia ✨ "Acabado de generar" y se reproduce automáticamente (desactívalo mediante Auto ▶ new).
  • Haz clic en 📂 Open para revelar la carpeta videos/ en tu gestor de archivos del SO.

6. Conversión de voz a texto

Haz clic en el micrófono, habla, haz clic nuevamente para detener (o espera a que se agote el tiempo de silencio). Se prueban dos motores en orden:

  1. API de Web Speech — Reconocedor en la nube de Google ejecutándose en la vista web. Usa tu sesión de Gmail/Google; no se necesita clave adicional.
  2. Windows SAPI (fallback) — Proceso PowerShell precalentado invocado cuando la vista web bloquea el acceso al micrófono. Ventana de escucha configurable mediante [voice] listen_seconds en config.ini.
SAPI se precalienta al activar la extensión así que el primer clic del micrófono evita el inicio en frío de 2-4 segundos que solía tragarse los clics de parada tempranos.

7. Auto Prompt

El botón con insignia e hilador. Cuando está ACTIVADO, después de N segundos de inactividad el panel envía automáticamente tu texto de activación configurado. El dígito de cuenta regresiva se renderiza en --cbe-highlight-color, que cada skin define.

Edita el texto de activación mediante el botón 🔁 Wake — realiza viajes de ida y vuelta wake.txt.

8. Lectura automática (TTS)

El icono de boca. Cuando está ACTIVADO, cada respuesta del asistente se pronuncia mediante el sintetizador de Web Speech (Google) o un fallback SAPI. Un halo azul brilla alrededor del icono mientras se reproduce el audio.

9. Compacto y uso de contexto

El array de conversación enviado al modelo crece con cada turno. El anillo alrededor del icono Compacto muestra el uso actual de la ventana de contexto como un gradiente cónico — vacío cuando es nuevo, lleno cuando está cerca del límite de contexto del modelo.

Haz clic en Compacto para truncar el historial a los últimos cuatro turnos. La siguiente llamada de API usa el array más pequeño.

10. Respuesta de activación

Almacenada en wake.txt en la raíz de la extensión. Utilizada por Auto Prompt como el mensaje a enviar cuando se activa el temporizador de inactividad. Edita mediante el botón 🔁 de la barra de herramientas.

11. Adjuntos de archivos

Haz clic en 📎 para seleccionar uno o más archivos. Mantén Ctrl o Shift en el selector para seleccionar múltiples. Cada archivo se inserta en el prompt como un bloque de código entre vallas con su nombre de archivo e idioma. Los archivos binarios mayores a 1 MB se omiten con un aviso.

12. Modal de Git

Haz clic en 📁 Git. Si no hay carpeta de proyecto configurada, primero obtienes un selector de carpetas — la ruta elegida se escribe en [project] path en config.ini. Las invocaciones de git posteriores se ejecutan con cwd configurado en esa ruta.

13. Repositorios de GitHub

Lista todos los repositorios accesibles a tu [github] pat. Haz clic en una fila para insertar su URL de clonación en el prompt. La lista se pagina y se almacena en caché.

14. Dominios de NameSilo

Obtiene todos los dominios en tu cuenta de NameSilo usando [namesilo] api_key (o [api_keys] namesilo_api_key como fallback). Al abrir por primera vez, los resultados se almacenan en caché en domains.txt; los arranques posteriores del panel se sirven desde caché. Haz clic en Reload en el modal para forzar una búsqueda nueva.

Si alguna vez ves "sin dominios" con un código de respuesta 300, verifica el canal de rastreo — los cachés vacíos ya no envenenan arranques futuros del panel, pero un domains.txt antiguo en otra ruta de instalación podría.

15. Temas y skins

El botón 🎨 abre un selector de descubrimiento que escanea skins/ en vivo (no en el inicio), así que soltar una nueva carpeta en tiempo de ejecución es suficiente. Cada skin tiene un manifest.xml que define su paleta — incluyendo el color de resaltado, que la insignia de cuenta regresiva de Auto Prompt, anillos de enfoque, y el pulso del supervisor usan.

Los skins integrados incluyen: gnome (gris Adwaita), terminal (negro/verde con acento rosa brillante), tamagotchi (pasteles de cáscara de huevo con un panel de mascota de sprite), blocky, y otros.

16. Configuración

Se abre desde el engranaje ⚙. Pestañas:

  • General — nombre de visualización, modelo predeterminado, enviar al presionar enter
  • Voz — dispositivo de micrófono, listen_seconds, selección de motor STT, lectura automática TTS
  • Actualizaciones — bandera is_admin, sesión de WinSCP, ruta remota
  • Claves — clave de API de cada proveedor
  • Monitor — alternancia del supervisor de VSCode, puerto, intervalo de sondeo
  • Idioma — elige entre 39 locales; ver § 17

El modal recuerda su tamaño y posición entre sesiones.

17. Idioma

El panel se envía con traducciones para los 39 idiomas más hablados. Los archivos de locale están en languages/<code>.xml y se cargan una vez al activar la extensión. Las claves faltantes recurren al inglés.

Elige tu idioma en Configuración → Idioma. Se muestra un icono de bandera junto a cada opción (cargado desde assets/flags/<code>.svg). La selección se guarda en [settings] language en config.ini.

18. Supervisor de VSCode

Un servicio de Windows (CBEVSCodeSupervisor) envuelve el script tools/vscode_supervisor.ps1 via NSSM y enlaza un HttpListener en http://127.0.0.1:3434/. El botón del monitor del panel brilla azul cuando el endpoint /status del supervisor responde 200 OK.

Si el sondeo HTTP falla pero el servicio está instalado, el perro guardián del panel reinicia automáticamente el servicio (tiempo de enfriamiento de 30 segundos para que no reinicie por tormentas).

Haz clic con el botón izquierdo en el botón del monitor para instalar / iniciar / detener. Haz clic con el botón derecho para abrir el canal de rastreo.

19. Actualización automática (pull)

4 segundos después de activar la extensión, el panel obtiene https://trentontompkins.com/cbe/manifest.xml.php — un manifiesto de MD5 + tamaño de los archivos publicados más recientes. Para cada archivo remoto, se compara el MD5 de la copia local; solo se descargan archivos cambiaros/faltantes sobre HTTPS.

El estado local del usuario (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) está en la lista de exclusión de pull y nunca se sobrescribe.

20. Push de administrador

Solo los clientes con [updates] is_admin = true empujan al servidor. Se activa mediante:

  • Paleta de comandos → Codex Black: Push update
  • Comando slash /push

Usa la sesión guardada de WinSCP llamada en [updates] winscp_session (predeterminado vps). Empuja mediante /script=… con el comando de sincronización y una máscara de archivo que excluye secretos y estado por máquina.

21. Marketplace de extensiones

Haz clic en el botón 🧩 Extensiones. Se abre un modal iframe a https://trentontompkins.com/cbe/extension/extension_marketplace.php, que obtiene el catálogo en extensions.xml.php y renderiza cada extensión disponible como una tarjeta con descripción, etiquetas, versión, tamaño de archivo, MD5, y un botón Instalar.

Una extensión se empaqueta como <id>.ext — un archivo zip que contiene manifest.xml más el código de la extensión (típicamente un único extension.html). Cuando haces clic en Instalar, el iframe del marketplace envía un postMessage de vuelta al panel; el panel descarga el archivo .ext directamente del servidor y lo extrae bajo extensions/ en la carpeta de extensión.

Tres extensiones de demostración se envían con el catálogo de lanzamiento: Calculator, Minesweeper, y un Emoji Picker.

22. Comandos slash

Escribe / en el cuadro de prompt para abrir la paleta de comandos slash. Haz clic en una fila para insertar el texto del comando en tu prompt (editable), o presiona Enter en una fila ejecutable para dispararla inmediatamente.

Una lista no exhaustiva:

23. Menú contextual

Haz clic derecho en cualquier lugar del panel para obtener un menú contextual (definido como una única cadena XML en panel.js). Las entradas incluyen Actualizar (recargar el panel sin tocar el host de extensión — nunca uses reloadWindow), Limpiar conversación, Abrir configuración, e Inspeccionar (DevTools, solo compilaciones de depuración).

24. Canal de rastreo

La extensión escribe una línea de tiempo granular en debug.log junto a la extensión. Todo lo importante llega allí: cambios de proveedor, ciclo de vida de STT, sondeos del supervisor, códigos de respuesta de NameSilo, mensajes de puente panel↔host, conteos de manifiestos push/pull.

Haz clic derecho en el botón del monitor para una apertura de un clic del canal de rastreo.

25. Solución de problemas

SíntomaCausa probable
El cuadro de prompt se ve proporcional, no monoespaciado --vscode-editor-font-family no aplicado; verifica las vars :root
El hilador de Auto Prompt es un punto negro Activo SVG incorrecto; debería ser auto_read_spinner.svg con halo de sombra de gota
El botón Compacto no hace nada Controlador del host faltante — case 'compactConversation' en router de extension.js
"0 dominios" en modal de Dominios NameSilo reply.code != 300 (el canal de rastreo lo tiene), o domains.txt antiguo
STT "sin voz detectada" al instante Detuviste antes de que SAPI vinculara el micrófono. El precalentamiento ahora salta esa espera — verifica con stt: using pre-warmed SAPI en debug.log
El push falla en ruta con espacios Usando /command= en línea; siempre usa /script=tempfile.winscp
El halo azul del supervisor no se ilumina Servicio no ejecutándose. Haz clic izquierdo en monitorBtn para instalar/iniciar, o ejecuta Start-Service CBEVSCodeSupervisor
Recargar "arregla" algo No lo hizo. Nunca uses reloadWindow. Usa la entrada del menú contextual Actualizar en su lugar.
