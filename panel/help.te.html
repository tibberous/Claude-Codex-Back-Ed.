Claude Codex — Black Edition

VSCode కోసం ఆఫ్‌లైన్-ప్రధమ బహు-ప్రొవైడర్ AI చాట్ ప్యానెల్. టాగిల్ చేయడానికి Ctrl+Alt+B నొక్కండి.

1. స్వాగతం

Claude Codex Black అనేది VSCode వెబ్‌వ్యూ ఇది మీకు బహుళ AI ప్రొవైడర్‌ల (Claude, OpenAI, Gemini, Grok, Azure, స్థానిక Ollama) తో చాట్ చేయడానికి అనుమతిస్తుంది ఒక ఏకైక, థీమేబుల్ ప్యానెల్ నుండి. ఒక కీని చదవడానికి అవసరమైన సబ్బంధం లోని విస్తరణ రూట్ వద్ద config.ini నుండి చదువుతారు — విస్తరణ సెట్టింగ్‌ల UI అవసరం లేదు, కానీ సెట్టింగ్‌ల మోడల్ సব్బంధంలో చిన్న-క్లిక్ సవరణ కోసం ఉపయోగకరమైన ఖేతాలు ప్రతిబింబిస్తుంది.

ఇక్కడ కొత్తమైనవారు? సెట్టింగ్‌లు (గేర్ చిహ్నం) తెరవడం ద్వారా ప్రారంభించండి, మీ ప్రొవైడర్‌ను ఎంచుకోండి, మీ API కీని అతికించండి, ఆపై ప్రాంప్ట్ టైప్ చేసి Enter నొక్కండి. ఈ ఆధారం యొక్క ఇతర విషయం సంపూర్ణ ఐచ్ఛికమైనది.

2. కీబోర్డ్ చుక్కలు

కీప్రభావం
Ctrl+Alt+BCBE ప్యానెల్‌ను టాగిల్ చేయండి
Enterప్రస్తుత ప్రాంప్ట్‌ను పంపండి
Shift+Enterప్రాంప్ట్ బాక్స్ లో నవీన లైన్
↑ / ↓మీ గతంలో-పంపిన ప్రాంప్ట్‌ల ద్వారా సైకిల్ చేయండి (prompt_history.txt నుండి)
← / →మీ కుర్రీగా ఉండిన prompts.txt ఎంట్రీల ద్వారా సైకిల్ చేయండి కెరెట్ టెక్సిటెరియా ప్రారంభం/ముగ్గుకు ఉన్నప్పుడు
Escఏదైనా తెరిచిన మోడల్‌ను మూసివేయండి
/స్ల్యాష్-ఆదేశ ప్యాలెట్‌ను తెరవండి

3. ప్రాంప్ట్ బాక్స్

దిగువన పెద్ద సవరణీయ టెక్సిటెరియా. టైప్ చేయండి, పేస్ట్ చేయండి, ఫైల్‌ను డ్రాగ్ చేయండి, పేపర్‌క్లిప్ ద్వారా జత చేయండి — ఇక్కడ మీరు ఉంచేది తరువాత API కాల్ యొక్క ఉపయోగకర్త టర్న్.

ఫాంట్ మీ VSCode సంపాదకుని మోనోస్పేస్ ఫాంట్‌కు (ఉపయోగ --vscode-editor-font-family CSS వేరియబుల్ ద్వారా) లాక్ చేయబడింది కనుక ప్యానెల్ సంపాదక లో ఆనందంగా కనిపిస్తుంది.

4. టూల్‌బార్ బటన్‌లు

దిగువ వరుస, ఎడమ నుండి కుడికి. టూల్‌టిప్‌లు హోవర్‌లో కనిపిస్తాయి; ప్యానెల్ కూడా మీ ఎంచుకున్న భాషలో వాటిని చదువుతారు (చూడండి భాష).

🎤 మైక్రోఫోన్ఆడియో-టు-టెక్స్ట్ — Web Speech API SAPI ఫాల్‌బ్యాక్‌తో. చూడండి § 6.

5. మోడళ్లు & ప్రొవైడర్‌లు

CBE 11 పుళ్ళు డ్రాప్-ఇన్ .bridge ప్లగ్‌ఇన్‌ల నుండి bridges/ కోసం కూడా వస్తుంది. ప్రతిదీ నిజ స్వ-సంపూర్ణ zip manifest.xml + bridge.py + చిహ్నాలకు. ఒక కొత్త .bridge ఫైల్ మూపై డ్రాప్ చేయండి కనుక ఇది కెర్టిరిజ్ డ్రాప్‌డౌన్‌లో కనిపిస్తుంది — కోడ పరిమార్జన అవసరం లేదు.

టెక్స్ట్-చాట్ పుళ్ళు (7)

  • ChatGPT — chatgpt.com, Plus/Pro సభ్యత్వం
  • Grok — grok.com, స్థానిక xAI లాగిన్ (అనామక టియర్ బాగా గేటెడ్; ఎక్కడ లాగిన్ చేయండి)
  • Gemini — gemini.google.com, Google ఖాతా
  • Claude — claude.ai, మ్యాజిక్-లింక్ లాగిన్ (ఒకసారి tools/sign_in_helper.py claude నడుపుము)
  • Copilot — copilot.microsoft.com, ఖాళీ Microsoft ఖాతా
  • DeepSeek — chat.deepseek.com, స్థానిక ఇమెయిల్/పాస్‌వర్డ్ (Google SSO ఉపయోగించవద్దు)
  • Ollama — స్థానిక 127.0.0.1:11434, లాగిన్ అవసరం లేదు

వీడియో-ఉత్పత్తి పుళ్ళు (4)

  • Sora 2 — sora.com, మీ ChatGPT Plus/Pro లాగిన్‌ను పునర్ఉపయోగిస్తుంది
  • Google Veo — gemini.google.com (Veo విధ), Gemini Advanced సభ్యత్వం
  • Runway Gen-3/4 — app.runwayml.com, ఆధిక Runway సభ్యత్వం
  • Bing Video Creator — bing.com/videos/create, ఖాళీ Sora-2 Microsoft ఖాతా

రూపందిల వీడియోలు videos/<bridge>/<timestamp>_<prompt-slug>.mp4 కు సేవ్ చేయడం కనుక వీడియో లైబ్రరీ ప్యానెల్‌లో స్వయం-ప్లే చేయండి (చూడండి §Video Library సిబ్బంది).

కెర్టిరిజ్ డ్రాప్‌డౌన్ నుండి ఒక పుళ్ళు + మోడల్‌ను ఎంచుకోండి ప్రాంప్ట్ బాక్స్ పక్కన, లేదా సెట్టింగ్‌లు → సాధారణ ద్వారా. ఎంపిక కార్యక్ష్యత-ప్రతిపర్సు కనుక workspaceState లో నిల్ఖించు. ఒక కొత్త పుళ్ళు జోడించటానికి, చూడండి docs/WRITING_BRIDGES.md.

5a. వీడియో లైబ్రరీ

వీడియో పుళ్ళు (Sora, Veo, Runway, Bing Video Creator) ద్వారా రూపందిల వీడియోలను సరిపోతుంది + చూడటానికి ఒక అర్హ ప్యానెల్. కమాండ్ ప్యాలెట్ ద్వారా తెరవండి: Claude Codex Black: Open Video Library లేదా codexBlackEd.openVideoPlayer ఆదేశం.

  • సైడ్‌బార్ ప్రతిదీ సూచిస్తుంది .mp4 / .webm / .mov videos/<bridge>/ కిందిర, పుళ్ళు ద్వారా సమూహీకరించిన కనుక అత్యంత-ముందంలో నిర్దేశించిన.
  • ఆ సమీపమైన వీడియో ఉదయ ప్రారంభంలో స్వయం-ప్లే చేయండి.
  • ప్యానెల్ ఏ videos/ డిర్ ఉంటాయి 2-సెకండ్ టిక్‌లో పర్యవేక్షణ చేస్తాయి — ఏదైనా-కొత్త రూపందిల వీడియో ✨ "జస్ట్ జనరేటెడ్" బ్యాడ్జ్‌తో పూన్ చేస్తుంది కనుక స్వయం-ప్లే చేస్తుంది (Auto ▶ కొత్త ద్వారా టాగిల్ ఆఫ్).
  • 📂 తెరువుకు నొక్కండి videos/ ఫోల్డర్‌ను మీ OS ఫైల్ నిర్వాహకంలో చూపించటానికి.

6. ఆడియోను టెక్స్ట్‌కు

మైక్ నొక్కండి, మాట్లాడండి, మళ్ళీ నొక్కండి ఆపటానికి (లేదా సైలెన్స్-టైమआఉట్‌కు వేచి ఉండండి). రెండు ఇంజన్‌లు ఆదేశక్రమానికి ప్రయత్నించబడతాయి:

  1. Web Speech API — వెబ్‌వ్యూ నుండి నడుస్తున్న Google యొక్క క్లౌడ్ గుర్తించేవారు. మీ Gmail/Google సెషన్ ఉపయోగిస్తారు; ఎక్కువ కీ అవసరం లేదు.
  2. Windows SAPI (ఫాల్‌బ్యాక్) — వెబ్‌వ్యూ మైక్ ప్రవేశం తిరస్కరించినప్పుడు పిలిచిన ప్రీ-వార్మ్డ్ PowerShell ప్రక్రియ. కాన్ఫిగరేబుల్ విని విండో ద్వారా [voice] listen_seconds config.ini లో.
SAPI అనేది విస్తరణ యాక్టివేట్‌లో ప్రీ-వార్మ్‌ చేయబడింది కనుక మొదటి మైక్ క్లిక్ 2-4 సెకండ్ కోల్డ్ స్టార్ట్ నుండి ఆపటానికి ఆపటానికి పనిచేస్తుంది.

7. స్వయం ప్రాంప్ట్

బ్యాడ్జ్-స్పిన్నర్ బటన్. చालు చేసినప్పుడు, N సెకండ్ల నిష్క్రియాత్వం తర్వాత ప్యానెల్ మీ సంరూపిత మేల్కోత టెక్స్ట్‌ను స్వయం-పంపుతుంది. లెక్కవంట్ అంకెలు --cbe-highlight-color లో సూచిస్తారు, ఇక్కడ ప్రతిదీ చర్మం నిర్వచిస్తుంది.

🔁 Wake బటన్ ద్వారా మేల్కోత టెక్స్ట్ సవరించండి — ఇది wake.txt ను రౌండ్-ట్రిప్ చేస్తుంది.

8. స్వయం చదువుకోవడం (TTS)

నోటి చిహ్నం. చేతిలో, ప్రతిదీ సహాయక సమాధానం Web Speech సింథెసిజర్ (Google) లేదా SAPI ఫాల్‌బ్యాక్‌ ద్వారా చెప్పుకోబడుతుంది. నీలం ఏలూ చిహ్నం చుట్టూ ఆడియో ప్లేలో ఉన్నప్పుడు కాంతిపరచుతుంది.

9. కాంపాక్ట్ & సందర్భ వినియోగం

మోడల్‌కు పంపిన సంభాషణ శ్రేణి ప్రతిదీ టర్న్‌తో వృద్ధి పాలిస్తుంది. కాంపాక్ట్ చిహ్నం చుట్టూ రింగ్ సందర్భ-విండో వినియోగం కోనిక్ గ్రేడియంట్‌గా చూపుతుంది — తాజాగా ఖాళీ, మోడల్ సందర్భ పరిమితికి సమీపం చేసినప్పుడు పూర్ణ.

చరిత్రను తిరిగి నాలుగు టర్న్‌ల కుదించటానికి కాంపాక్ట్‌ను నొక్కండి. ఆ తర్వాత API కాల్ చిన్న శ్రేణిని ఉపయోగిస్తుంది.

10. మేల్కోత ప్రతిసందటి

wake.txt కు విస్తరణ రూట్‌లో నిల్ఖించిన. స్వయం ప్రాంప్ట్ ద్వారా నిష్క్రియాత్వ టైమర్ ఫైర్ చేసినప్పుడు పంపేవారిచ్చిన సందేశం ఉపయోగిస్తుంది. 🔁 టూల్‌బార్ బటన్ ద్వారా సవరించండి.

11. ఫైల్ జతలు

📎 నొక్కండి ఒక లేదా అంతకంటే ఎక్కువ ఫైల్‌లను ఎంచుకోవటానికి. Ctrl లేదా Shift పిక్‌లో పట్టుకోండి బహుళ-ఎంపిక చేయటానికి. ప్రతిదీ ఫైల్ ప్రాంప్ట్‌కు విభజన-కోడ్ బ్లాక్‌కు దాని ఫైల్‌నెం కనుక భాష. 1 MB కంటే ఎక్కువ బైనరీ ఫైల్‌లు నోటిస్‌కు దిగుపడతాయి.

12. Git మోడల్

📁 Git నొక్కండి. ఆయన ప్రాజెక్ట్ ఫోల్డర్ సంరూపిత నుండి, మీరు ఫోల్డర్ పిక్‌ను ఎదిరి పొందుతారు — ఎంచుకున్న మార్గం [project] path నుండి config.ini కు వ్రాయబడుతుంది. తరువాత git ఆహ్వానాలు ఆ మార్గం నుండి cwd చేసి నడుస్తాయి.

13. GitHub రిపోజిటరీలు

మీ [github] pat కు ప్రవేశయోగ్యమైన ప్రతిదీ రిపో జాబితా చేస్తుంది. ఒక వరుస క్లిక్ చేసి దాని క్లోన్ URL ప్రాంప్ట్‌కు చేర్చుకుందా. జాబితా పేజీకు చేయబడిన కనుక కాచెడ్.

14. NameSilo డొమైన్‌లు

ప్రతిదీ డొమైన్ మీ NameSilo ఖాతాలో [namesilo] api_key ఉపయోగించుతుంది (లేదా [api_keys] namesilo_api_key ఫాల్‌బ్యాక్‌గా). ఎక్కడ తెరిసిన ఫలితాలు domains.txt కు కాచెడ్ చేయబడతాయి; ఆ తర్వాత ప్యానెల్ బూట్‌లు కాచ్‌ నుండి సేవ్ చేస్తాయి. రీలోడ్ మోడల్‌లో నొక్కండి ఒక తీవ్రమైన పెట్టుబడిని బలవంతం చేయటానికి.

నుండిసరి "ఎక్కడ డొమైన్‌లు" 300 సమాధానం కోడ్‌తో చూస్తుంది, ట్రేస్ చానెల్‌ను చూడండి — ఖాళీ కాచెస్‌ భవిష్యత్ ప్యానెల్ బూట్‌ల్‌ను కానీ ఇతర సంస్థాపన మార్గం లో ఆనాడు domains.txt కోసం చేయవచ్చు.

15. చర్మాలు & థీమ్‌లు

🎨 బటన్ ఒక కనుగొనిపికర్‌ను పూపుటుంది skins/ లైవ్ (స్టార్టअপ్‌లో కాదు) స్కాన్ చేస్తుంది, కనుక నడుస్తున్న రూన్‌లో skins/ ఫోల్డర్ డ్రాప్ చేయటం కేవలం సరిపోతుంది. ప్రతిదీ చర్మం manifest.xml ను వెళ్ళదీ దాని పలేట్‌ను నిర్వచిస్తుంది — హైలైట్ రంగ్ సహా, ఆ ఆటో ప్రాంప్ట్ లెక్కవంటి బ్యాడ్జ్, ఫోకస్ రింగ్‌లు, కనుక సూపర్‌విజర్ పల్స్ సరిపోతుంది.

నిర్మిత చర్మాలు చేర్చుకుందా: gnome (Adwaita గ్రే), terminal (నలుపు/ఆకుతో వేలిసిన-గులాబీ ఉద్‌ఘోష), tamagotchi (స్పెర్చ్ పేస్టెల్‌లు తో ఒక స్ప్రితే మాస్కట్ ప్యానెల్), blocky, కనుక ఇతర.

16. సెట్టింగ్‌లు

⚙ గేర్ నుండి తెరవండి. ట్యాబ్‌లు:

  • సాధారణ — ప్రదర్శన నెం, అప్రమేయ మోడల్, పంపే-ఆన్-ఎంటర్
  • ఆవాజ — మైక్రోఫోన్ పరికరం, listen_seconds, STT ఇంజన్ పిక్, TTS స్వయం-చదువుకోవడం
  • నవీకరణలు — is_admin ఫ్లాగ్, WinSCP సెషన్, రిమోట్ మార్గం
  • కీలు — ప్రతిదీ ప్రొవైడర్ API కీ
  • పర్యవేక్షణ — VSCode సూపర్‌విజర్ టాగిల్, పోర్ట్, పోల్ విరామం
  • భాష — 39 థాటలు నుండి ఎంచుకోండి; చూడండి § 17

మోడల్ సెషన్‌ల మధ్య దాని సంఖ్య కనుక స్థానం గుర్తుంచుకుంటుంది.

17. భాష

ప్యానెల్ 39 అత్యంత-మాట్లాడిన భాషల కోసం అనువాదాలు తో పంపుతుంది. థాట ఫైల్‌లు languages/<code>.xml లో నివసిస్తుంది కనుక విస్తరణ యాక్టివేట్‌లో లోడ్ చేయబడతాయి. కోలిపోయిన కీలు ఆంగ్లికం నుండి ఫాల్‌బ్యాక్.

సెట్టింగ్‌లు → భాష లో మీ భాష ఎంచుకోండి. ఎక్కడ ఎంపిక (నుండి assets/flags/<code>.svg) యొక్క ఫ్లాగ్ చిహ్నం చూపబడుతుంది. ఎంపిక [settings] language కు config.ini లో సేవ్ చేయబడుతుంది.

18. VSCode సూపర్‌విజర్

ఒక Windows సేవ (CBEVSCodeSupervisor) tools/vscode_supervisor.ps1 స్క్రిప్ట్ NSSM ద్వారా విడిచిపెట్టుతుంది కనుక http://127.0.0.1:3434/ లో HttpListener బందిస్తుంది. సూపర్‌విజర్ /status ఎండ్‌పాయింట్ సమాధానం 200 OK చేసినప్పుడు ప్యానెల్ మానిటర్ బటన్ నీలం కాంతిపరచుతుంది.

HTTP జెండు విఫలమైతే కానీ సేవ సంస్థాపించబడితే, ప్యానెల్ వాచ్‌డాగ్ స్వయం-సేవ పునరారంభం చేస్తుంది (30-సెకండ్ శీతల-డౌన్‌న్ కనుక ఇది పునరారంభం-తుఫాన్ చేయదు).

మానిటర్ బటన్ ఎడమ-క్లిక్ సంస్థాపన / ప్రారంభం / నిలుపుటకు. సూక్ష్మమైన ట్రేస్ చానెల్‌ను తెరవటానికి కుడి-క్లిక్.

19. స్వయం-నవీకరణ (పుల్)

విస్తరణ యాక్టివేట్‌చేసిన తర్వాత 4 సెకండ్లు, ప్యానెల్ పెట్టుబడి చేస్తుంది https://trentontompkins.com/cbe/manifest.xml.php — చేసిన ఫైల్‌ల MD5+సంఖ్య మానిఫెస్ట్. ప్రతిదీ రిమోట్ ఫైల్‌కు, స్థానిక కాపీ MD5 చేసిన తర్వాత; కేవలం మార్పు/కోల్పోయిన ఫైల్‌లు HTTPS ద్వారా డౌన్‌లోడ్ చేయబడతాయి.

వినియోగకర్త-స్థానిక స్థితి (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) పుల్ నిషేధ జాబితాలో ఉంది కనుక ఎక్కడ ప్రతిలిఖ్యం చేయబడదు.

  • స్ల్యాష్ ఆదేశం /push

21. ఎక్సటెన్షన్‌ల మార్కెట్‌ప్లేస్

🧩 ఎక్సటెన్షన్‌ల బటన్‌ను నొక్కండి. ఒక iframe మోడల్ https://trentontompkins.com/cbe/extension/extension_marketplace.php లోకి తెరవుకుంటుంది, ఇది extensions.xml.php కు పెట్టుబడి చేస్తుంది కనుక ప్రతిదీ ఉపలబ్ధ ఎక్సటెన్షన్‌ను కార్డ్‌గా సూచిస్తుంది వివరణ, ట్యాగ్‌లు, సంస్కరణ, ఫైల్ సంఖ్య, MD5, కనుక ఒక సంస్థాపన బటన్.

ఒక ఎక్సటెన్షన్ <id>.ext గా పుష్పం చేయబడింది — manifest.xml చేర్చుకుందా ఒక zip ఆర్కైవ్ కనుక ఎక్సటెన్షన్ కోడ్ (సాధారణ ఏకైక extension.html). ఇన్‌స్టాల్‌ను నొక్కినప్పుడు, మార్కెట్‌ప్లేస్ iframe ప్రత్యక్ష ఉపయోగకర్త; ప్యానెల్ .ext సర్వర్ నుండి కూడా డౌన్‌లోడ్ చేస్తుంది కనుక extensions/ అందర్లో చెండితీయుకుందా విస్తరణ ఫోల్డర్‌లో.

మూడు ప్రదర్శన ఎక్సటెన్షన్‌లు ఉదయ కేటలాగ్‌తో పంపుతుంది: కాలిక్యులేటర్, Minesweeper, కనుక ఒక Emoji పిక్‌ర్.
