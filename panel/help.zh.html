快速开始 ↑ 顶部

  1. 点击设置（魔杖图标）并完成向导以输入 API 密钥。它们被保存到 config.ini（已被 gitignore - 永不提交）。
  2. 点击左下角的提供商药片（当前标签为"Claude Codex — Black Edition"）以切换您正在与之交谈的 AI。
  3. 在文本区域中输入并按 Enter 发送。Shift+Enter 插入新行。
  4. 在空文本区域中按 ↑ 以回调之前的提示（PowerShell 风格的历史）。

浏览器桥接（无需 API 密钥 - 驱动已登录的浏览器会话）

桥接目标端口
ChatGPT 桥接chat.openai.com8788
Grok 桥接grok.com / x.ai8789

每个桥接是一个小型 C++ 托盘 exe，位于 bin/CBE-Bridge-<Target>.exe，它打开一个已登录的 Chrome 配置文件，拦截您的提示并返回模型的回复。在设置中选择桥接提供商会自动启动匹配的 exe。第一次使用桥接时，您必须在其 Chrome 窗口中登录一次该网站。

桥接聊天在 TCP 上使用行协议：一行 JSON 输入（{action:"chat", target, message, model}），一行 JSON 输出。无需 API 密钥。

发送消息 ↑ 顶部

文本区域
输入您的提示。Enter 发送，Shift+Enter 插入新行。当回复流式传输时，其他提示将被排队并依次发送 - 在此状态下占位符显示"排队另一条消息…"。
发送按钮（球体）
文本区域右边缘的圆形按钮。与 Enter 相同。视觉上显示三种状态（空闲/悬停/活动）。
停止按钮
作曲器的右下角。取消当前流式回复和任何排队消息。流式文本被保留；仅中止的内请求。
提供商药片
作曲器的左下角。点击以获得您已配置的每个提供商的下拉菜单。选择新的会自动启动其桥接（如适用）并发送确认吐司。
提示历史
在空文本区域中 ↑ / ↓ 向后/向前遍历最后 500 个发送的提示（PowerShell 风格）。历史存储在扩展文件夹中的 prompt_history.txt 并在面板重新加载后仍然存在。

工具栏按钮 ↑ 顶部

按工具栏顺序列出。所有工具提示均可通过 languages/*.xml 按语言本地化。

新对话 addBtn
清除当前线程，擦除内存中的对话状态，从头开始。之前的线程保存在磁盘上的 chats/<UTC-date>.log 下，所以没有任何内容丢失。等同于 /clear。
存储的提示 storedPromptsBtn
打开一个模态窗口，列出 stored_prompts/ 下保存的每个提示模板。点击一个以将其插入文本区域；"+" 按钮添加新模板。模板支持变量替换。
聊天历史 chatHistoryBtn
浏览磁盘上的聊天日志（chats/ 下每个 UTC 日期一个文件）。选择日期以滚动浏览过去的对话。
附加文件 attachFileBtn
打开文件选择器。所选文件与下一个提示一起上传 - 图像内联显示（视觉），文本/代码文件在您的提示中成为围栏块。支持多重附加。
大声朗读（TTS） ttsBtn
大声朗读最新的助手回复。使用 ElevenLabs（如果设置了 [elevenlabs] api_key）或回退到 Windows SAPI。右键点击切换自动朗读模式，其中每条新回复都会自动朗读 - 按钮在活动时获得动画指示灯。
语音转文本（STT） sttBtn
记录麦克风音频并转录到文本区域。首先尝试 webview 的 Web Speech API；如果失败（not-allowed，在 VSCode 沙箱中常见），回退到通过 PowerShell 在主机上启动的 Windows SAPI（System.Speech.Recognition）。再次点击以停止。
自动提示 autoReplyBtn
打开自动提示模态窗口。定义提示 + 倒计时间隔；在每条助手回复后倒计时会递减，当倒计时达到零时自动重新发送自动提示。适用于"继续"、"下一步"、重复工具会话。再次点击以禁用。
唤醒回复 wakeUpBtn
编辑存储在 wake.txt 的唤醒消息。唤醒是自动提示在检测到模型已停滞时发送的内容 - 通常是短 ping，如"嘿！继续。"
显示命令菜单 showCommandsBtn
在模态窗口中打开斜杠命令面板。详见斜杠命令的完整列表。与在文本区域开头输入 / 相同。
压缩对话 compactBtn
发送总结和修剪请求，用压缩摘要替换当前线程。等同于 /compact。当对话变长且您想保留上下文但停止在重新发送整个历史上浪费令牌时很有用。
手册 handbookBtn
打开员工/项目手册模态窗口。加载 handbook.html 或任何配置的文档。用作模型可被要求查阅的系统提示参考。
设置 settingsBtn
打开设置模态窗口（提供商、模型、皮肤、语言、音效）。详见设置。
账户 accountsBtn
打开多账户管理器。按提供商添加/编辑/移除 API 密钥，在每个会话中在它们之间切换。详见账户。
扩展 extensionsBtn
打开面板内扩展浏览器。列出在 extensions/ 下安装的内容（每个都有 manifest.xml + 一个 entry HTML），让您将扩展固定到工具栏，从公共目录安装新的，或移除它们。
项目文件夹 projectFolderBtn
选择附加文件、终端、Git 和任何需要项目根目录的工具使用的工作目录。当前文件夹显示在提供商药片旁边。
浏览器 browserBtn
打开并排的 QtWebEngine 浏览器窗格，可以快速查找而无需离开面板。
VSCode 监视器 monitorBtn
切换 VSCode 监督程序监视狗 - 一个在 VSCode 崩溃时重启它的后台进程。左键点击切换运行/停止，右键点击打开监督程序的跟踪通道。
终端 terminalBtn
在项目文件夹中打开 VSCode 集成终端。如果项目文件夹未设置，回退到您的桌面。重新使用一个标签为"CBE"的持久终端。
设置向导 setupBtn
引导您完成扩展了解的每个 API 密钥 + 集成（约 12 步）。详见设置向导。
Git gitBtn
打开 VSCode 的源代码管理视图，聚焦于当前项目文件夹。
GitHub githubBtn
使用 [github] token 列出您的 GitHub 仓库。点击一个仓库以克隆/打开/浏览问题。
域名（NameSilo） domainsBtn
列出 NameSilo 账户上的每个域名及其名称服务器。需要 [namesilo] api_key。重新加载按钮强制新鲜获取。
字体大小 fontSizeBtn
在正常和大字体之间切换聊天线程。与 /font 相同。
帮助 helpBtn
打开此页面。与 /help 相同。
Tamagotchi tamaBtn
切换像素宠物面板（仅在tamagotchi皮肤上可见，其中它停靠在作曲器角落）。详见Tamagotchi。

右键菜单 ↑ 顶部

右键点击聊天文本或代码块以获得 CBE 上下文菜单。现在右键点击提示文本区域打开原生浏览器菜单（复制/剪切/粘贴/删除/全选）。

复制 / 复制代码块
复制当前选择。如果没有选择但您右键点击了 <pre><code>，它会复制整个代码块。
查看源代码
显示点击区域的原始 HTML/markdown - 要么是代码块要么是整个面板 DOM。适用于调试皮肤/CSS 问题。
打开开发者工具
要求 VSCode 打开其开发者工具，以便您可以实时检查 webview。
设置 new
打开工具栏设置按钮打开的相同设置模态窗口（提供商/模型/皮肤/语言/音效）。与 /settings 相同。
关于 new
小的面板内对话框，包含版本、作者、许可证、仓库链接、投资组合和联系电话。在背景点击、× 按钮或 Esc 时关闭。

重新读取 panel/index.html + panel.js + skins/* 并使用每个文件的 ?v=<mtime> 缓存破坏器并重新分配 panel.webview.html。无需重启 VSCode 即可获取 CSS/JS 编辑。扩展主机保持活动 - 终端、监督程序、聊天历史都保存。
重新加载窗口 new
触发 workbench.action.reloadWindow。仅在您编辑了 extension.js（主机端代码）且面板重新加载不够时使用。这是一个完整的 VSCode 窗口重新加载。

模态窗口和对话框 ↑ 顶部

设置模态窗口 - 提供商 / 模型 / 皮肤 / 语言 / 音效
  • 提供商：每个直接 API + 桥接提供商的完整下拉菜单。选择一个切换活动会话并自动启动匹配的桥接 exe（如适用）。
  • 模型：每个提供商允许的模型列表（例如 claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 用于 Anthropic）。
  • 皮肤：视觉主题。详见皮肤。
  • 语言：39 种语言环境可用。切换会重新提取字符串映射并实时重新转换每个工具提示/标签/帮助按钮。
  • 音效已启用：切换 UI 音效（点击、滴答声、模态打开/关闭等）。
  • 音效音量：0–100 滑块。在您拖动时实时预览。
  • 取消恢复您尝试的任何实时预览（音效/皮肤）；保存保存并发送 setProvider。
设置向导 - 多步 API 密钥输入

每个集成的演练。每一步都要求凭证并将它们写入 config.ini。跳过不写入而前进；下一步写入并前进；最后一步的完成关闭。步骤包括：Anthropic、OpenAI、Gemini、xAI/Grok、GitHub PAT、电子邮件/SMTP（Gmail 应用密码）、Cloudflare、Twilio、ElevenLabs、Stability AI、Runway、SendGrid、NameSilo 等。

账户模态窗口 - 多账户 API 密钥管理器

对于每个提供商，管理多个标记账户（例如"个人"、"工作"）。在每个会话中切换哪个是活动的，无需覆盖其他的。密钥被屏蔽端到端并按提供商保存在 config.ini 中。

域名模态窗口 - NameSilo

列出 NameSilo 账户上的每个域名及其名称服务器 + 注册日期。重新加载按钮强制新鲜 API 获取（否则它缓存在 domains.txt 中）。

手册模态窗口

呈现项目手册 HTML（用作模型可查阅的系统提示参考）。可按项目配置。

存储的提示模态窗口

来自 stored_prompts/ 的可插入提示模板。每个文件是一个模板；文件名前缀 NN- 控制排序顺序。"+" 按钮创建一个新的。

聊天历史模态窗口

选择 UTC 日期以加载来自 chats/<date>.log 的聊天日志。只读。

扩展模态窗口

每个已安装扩展的卡片。固定到工具栏/取消固定，从公共目录安装（extensions.xml.php 在服务器上）或从磁盘移除。

更改日志模态窗口

呈现 panel/change_log.html - 捆绑的发布说明。通过 tools/build_changelog.py 生成。

查看源代码模态窗口

任何代码块或面板的完整 HTML 的漂亮打印，带 Prism 语法高亮和复制按钮。通过右键点击 → 查看源代码 到达。

自动提示模态窗口

配置提示字符串 + 倒计时间隔。在每条助手回复后倒计时递减；当它达到零时 CBE 自动发送配置的提示。通过自动提示工具栏按钮切换打开/关闭。

设置 ↑ 顶部

所有设置都位于以下两个位置之一：

  • workspaceState（VSCode 管理，按工作区） - 提供商、模型、皮肤、语言、音效已启用/音量、字体大小。
  • config.ini（扩展根，已忽略） - API 密钥 + 按集成凭证。

设置自动在面板重新加载后持存。设置模态窗口是更改任何内容的安全方式；直接编辑 config.ini 也可以。

账户和 API 密钥 ↑ 顶部

每个提供商可以有多个标记账户 - 如果您想在个人和工作密钥之间切换或测试不同层级，这很有用。账户模态窗口让您：

  • 添加带标签 + 密钥的新账户
  • 编辑现有账户（重新标记、替换密钥）
  • 设置哪个账户对当前会话是活动的
  • 移除账户

密钥被屏蔽存储（仅可见最后四位）在 config.ini 中。workspaceState 中没有明文副本。

Tamagotchi 宠物 ↑ 顶部

Tamagotchi 是一个像素艺术宠物，在tamagotchi皮肤下的面板中生活。它老化，会变得饥饿/脏污，可以被玩耍，如果忽视足够长时间会死亡。状态在 workspaceState 中保存。

统计数据（小部件顶部）

统计跟踪什么
🥚 阶段生命周期：卵 → 婴儿 → 儿童 → 青少年 → 成人 → 老年人 → 死亡。以实时分钟老化。
🍖 饥饿0–100。随时间下降；喂食提高它。达到 0 → 健康下降。
😀 幸福0–100。随时间下降；玩耍提高它。
❤️ 健康0–100。生病或挨饿时下降。打针治疗。
✨ 清洁度0–100。当宠物排便时下降。清洁提高它。
⏱ 年龄自孵化以来的分钟数。

图标操作

🧹清洁 - 清扫粪便。

皮肤 ↑ 顶部

整个面板的视觉主题 - 按钮、模态窗口、代码块，甚至字体。在设置 → 皮肤中选择一个。每个皮肤在 skins/<id>/ 中生活，有 manifest.xml（声明颜色 + 强调）和 styles.css（覆盖 CSS 变量）。

  • codex-black（默认） - 暗色、等宽、霓虹青色强调
  • glassy - 软背景上的磨砂玻璃表面
  • tamagotchi - 石灰绿液晶显示屏便携式设备；自动在作曲器角落显示固定的宠物小部件
  • office - Word 风格的奶油/蓝色 chrome
  • macos-color-dock / mint-dock - 带玻璃图标的底部坞站工具栏
  • terminal / arch / kde / gnome / xfce / ubuntu / redhat - Linux 桌面主题

模态窗口颜色来自每个皮肤的清单中的 <colors> 条目，并被推送到 :root 作为 --cbe-modal-* 变量，所以每个模态窗口（包括此帮助）在主题中呈现。

扩展 ↑ 顶部

CBE 内部的迷你应用。每个是 extensions/<id>/ 下的文件夹，包含：

  • manifest.xml - ID、名称、版本、作者、描述、输入 HTML、图标（emoji 或 icon.svg）
  • extension.html（或清单的 <entry> 指定的任何内容） - 实际应用

点击扩展浏览安装的内容，固定到工具栏，从公共目录安装新的，或从磁盘移除。固定的 ID 在 extensions/_pinned.json 中。

自动更新（推送/拉取） ↑ 顶部

CBE 通过 WinSCP 推送 + HTTPS 拉取通道在机器之间同步其源。

推送（仅限管理员）

如果 config.ini 中的 [updates] is_admin = true，每次激活都会运行后台 WinSCP synchronize remote -mirror，将扩展文件夹推送到服务器上的 /home/trentontompkins.com/cbe。手动触发：/push 斜杠命令。排除每个机器状态：data/（1.74 GB Chrome 配置文件）、bridges/、node_modules/、.git/、logs/、chats/、config.ini、prompt_history.txt、domains.txt、wake.txt。

拉取（每个客户端）

激活 4 秒后，每个客户端获取 https://trentontompkins.com/cbe/manifest.xml.php 并 MD5 比较每个文件与本地副本。只有更改/丢失的文件通过纯 HTTPS GET 下载。排除的路径永远不会被拉取：config.ini、data/、bridges/、extension.js、panel/panel.js、panel/index.html、package.json、构建工具 - 理由是源代码通过 .vsix 提供，服务器的较旧副本不得覆盖进行中的开发工作。

热重载 ↑ 顶部

右键菜单中暴露了两条重新加载路径：

  • 重新加载面板 - 重新读取 panel/index.html + 每个 JS/CSS 资源，带每个文件的 ?v=<mtime> 缓存破坏器，并重新分配 panel.webview.html。无需重启 VSCode 即可获取 panel.js / 皮肤 CSS / dotmatrix 编辑。扩展主机保持活动（您的终端、监督程序、消息处理程序、聊天历史都保存）。
  • 重新加载窗口 - 触发 workbench.action.reloadWindow。仅当您编辑了 extension.js（主机端代码）且重新加载面板不够时使用。

皮肤 CSS 编辑也通过面板现有的皮肤监视器自动应用 - 不需要菜单点击。

故障排除 ↑ 顶部

"桥接 X 聊天失败：config.ini 中 API 密钥为空"

smart_bridge.py 守护程序在内存中缓存了旧的门控检查。在 C++ exe 路由枢轴中修复。如果您仍然看到它，请杀死陈旧的守护程序：

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
"Copilot 没有公共 REST API - 使用浏览器桥接"

旧的 extension.js 通过 REST 路由器路由桥接聊天而不是实际的 C++ 托盘 exe。重新加载窗口以获取固定的 extension.js，然后聊天将直接进入 bin/CBE-Bridge-Copilot.exe。

HTTP 404 模型：sonnet-4.6

Claude 桥接配置中的过时短别名。已修复 - 现在使用完整 ID（claude-sonnet-4-6、claude-opus-4-7、claude-haiku-4-5）。

我编辑了一个文件，但面板没有显示更改
  1. 如果是 panel.js / skins/*.css / index.html → 右键点击 → 重新加载面板。
  2. 如果是 extension.js / bridges_cpp/*.py → 右键点击 → 重新加载窗口。
  3. 如果您无法到达菜单（例如菜单本身尚未加载），使用隔离的用户数据目录启动新鲜 VSCode 实例：
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Claude Codex Black"
STT 失败，显示"not-allowed"

VSCode 将 webview 与麦克风权限隔离。CBE 自动回退到通过 PowerShell 启动的 Windows SAPI（System.Speech.Recognition）。您可能需要在操作系统级别授予麦克风访问权限（设置 → 隐私 → 麦克风）。

桥接 exe 丢失

跟踪日志显示 BRIDGE:MISSING target=<t> expected=<path>。C++ 托盘 exe 在 bin/CBE-Bridge-<Pretty>.exe 中。如果您的不存在，从 bridges_cpp/ 源代码（MSVC）重建或拉取一个新鲜的 .vsix。
