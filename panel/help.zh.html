Claude Codex — Black Edition

一款离线优先的多提供商 AI 聊天面板，用于 VSCode。按 Ctrl+Alt+B 切换。

1. 欢迎

Claude Codex Black 是一个 VSCode webview，让你可以从单个可主题化的面板与多个 AI 提供商（Claude、OpenAI、Gemini、Grok、Azure、本地 Ollama）聊天。所有需要密钥的内容都从扩展根目录的 config.ini 读取 — 不需要扩展设置 UI，但设置模态框会镜像最有用的字段以供仅点击编辑。

初来乍到？先打开设置（齿轮图标），选择你的提供商，粘贴你的 API 密钥，然后输入提示并按 Enter。本指南中的其他所有功能都是可选的。

2. 键盘快捷键

按键效果
Ctrl+Alt+B切换 CBE 面板
Enter发送当前提示
Shift+Enter在提示框中换行
↑ / ↓循环浏览之前发送的提示（来自 prompt_history.txt）
← / →当光标位于文本区域的开始/结束时，循环浏览策展的 prompts.txt 条目
Esc关闭任何打开的模态框
/打开斜杠命令调板

3. 提示框

底部的大型可编辑文本区域。输入、粘贴、拖动文件、通过回形针附加 — 你在这里放的任何内容都是下一个 API 调用的用户转述。

字体被锁定为你的 VSCode 编辑器的等宽字体（通过 --vscode-editor-font-family CSS 变量），所以面板在编辑器内看起来很协调。

4. 工具栏按钮

底行，从左到右。悬停时显示工具提示；面板也会用你选择的语言大声读出（见语言）。

5. 模型与提供商

CBE 随附 11 个桥接，作为 bridges/ 下的即插即用 .bridge 插件。每个都是一个独立的 zip，包含 manifest.xml + bridge.py + 图标。在其中放一个新的 .bridge 文件，它就会出现在墨盒下拉菜单中 — 无需修改扩展代码。

文本聊天桥接（7 个）

  • ChatGPT — chatgpt.com，Plus/Pro 订阅
  • Grok — grok.com，原生 xAI 登录（匿名层限制严格；请先登录）
  • Gemini — gemini.google.com，Google 账户
  • Claude — claude.ai，魔链接登录（运行 tools/sign_in_helper.py claude 一次）
  • Copilot — copilot.microsoft.com，免费 Microsoft 账户
  • DeepSeek — chat.deepseek.com，原生电子邮件/密码（请勿使用 Google SSO）
  • Ollama — 本地 127.0.0.1:11434，无需登录

视频生成桥接（4 个）

  • Sora 2 — sora.com，重用你的 ChatGPT Plus/Pro 登录
  • Google Veo — gemini.google.com（Veo 模式），Gemini Advanced 订阅
  • Runway Gen-3/4 — app.runwayml.com，独立的 Runway 订阅
  • Bing Video Creator — bing.com/videos/create，免费 Sora-2，支持 Microsoft 账户

生成的视频保存到 videos/<bridge>/<timestamp>_<prompt-slug>.mp4，并在视频库面板中自动播放（见下面的视频库）。

从提示框旁的墨盒下拉菜单或通过设置 → 常规选择桥接和模型。选择是按工作区的，并持久化在 workspaceState 中。要添加新桥接，见 docs/WRITING_BRIDGES.md。

5a. 视频库

用于浏览和观看由视频桥接（Sora、Veo、Runway、Bing Video Creator）生成的视频的专用面板。通过命令调板打开：Claude Codex Black: Open Video Library 或 codexBlackEd.openVideoPlayer 命令。

  • 侧栏列出 videos/<bridge>/ 下的每个 .mp4 / .webm / .mov，按桥接分组并按最新优先排序。
  • 最新视频在首次打开时自动播放。
  • 面板以 2 秒为周期监视 videos/ 目录 — 任何新生成的视频都会弹出一个 ✨ "刚刚生成" 徽章并自动播放（通过自动 ▶ 新视频切换关闭）。
  • 点击📂 打开在你的操作系统文件管理器中显示 videos/ 文件夹。

6. 语音转文字

点击麦克风，说话，再点击停止（或等待静音超时）。按顺序尝试两个引擎：

  1. Web Speech API — Google 的云识别器在 webview 中运行。使用你的 Gmail/Google 会话；无需额外密钥。
  2. Windows SAPI（降级方案）— 当 webview 阻止麦克风访问时调用的预热 PowerShell 进程。可通过 config.ini 中的 [voice] listen_seconds 配置侦听窗口。
SAPI 在扩展激活时预热，所以第一次麦克风点击避免了 2-4 秒冷启动，该冷启动曾经会吞掉早期的停止点击。

7. 自动提示

带微调器的徽章按钮。打开时，在 N 秒不活跃后，面板自动发送你配置的唤醒文本。倒数数字在 --cbe-highlight-color 中渲染，每个皮肤都定义了这个。

通过 🔁 唤醒按钮编辑唤醒文本 — 它往返 wake.txt。

8. 自动朗读（TTS）

嘴巴图标。打开时，每个助手回复都通过 Web Speech 合成器（Google）或 SAPI 降级方案大声说出。当音频播放时，图标周围会出现蓝色光晕。

9. 紧凑模式和上下文用量

发送给模型的对话数组随每一轮增长。紧凑图标周围的环形显示当前上下文窗口用量作为圆锥梯度 — 新鲜时为空，接近模型上下文限制时为满。

点击紧凑将历史截断为最后四轮。下一个 API 调用使用较小的数组。

10. 唤醒响应

存储在扩展根目录的 wake.txt。由自动提示使用，作为不活跃计时器触发时发送的消息。通过 🔁 工具栏按钮进行编辑。

11. 文件附件

点击 📎 选择一个或多个文件。在选择器中按住 Ctrl 或 Shift 进行多选。每个文件被内联到提示中作为带有其文件名和语言的围栏代码块。超过 1 MB 的二进制文件会被跳过并显示通知。

12. Git 模态框

点击 📁 Git。如果未配置项目文件夹，你会先得到一个文件夹选择器 — 所选路径被写入 config.ini 中的 [project] path。后续 git 调用运行时将 cwd 设置为该路径。

13. GitHub 仓库

列出你的 [github] pat 可访问的每个仓库。点击一行将其克隆 URL 插入提示。列表分页且被缓存。

14. NameSilo 域名

使用 [namesilo] api_key（或 [api_keys] namesilo_api_key 作为降级方案）拉取你的 NameSilo 账户中的每个域名。首次打开时，结果被缓存到 domains.txt；后续面板启动从缓存提供。在模态框中点击重新加载强制执行新获取。

如果你看到"无域名"且回复代码为 300，检查追踪通道 — 空缓存不再毒害未来的面板启动，但另一个安装路径中的陈旧 domains.txt 可能会这样做。

15. 皮肤和主题

🎨 按钮弹出一个发现选择器，实时扫描 skins/（不是在启动时），所以在运行时在其中放一个新文件夹就足够了。每个皮肤有一个 manifest.xml 定义其调色板 — 包括高亮色，自动提示倒数徽章、焦点环和监管脉搏都基于此。

内置皮肤包括：gnome（Adwaita 灰色）、terminal（黑色/绿色，带亮粉红色强调）、tamagotchi（蛋壳粉彩色，带精灵吉祥物面板）、blocky 等。

16. 设置

从 ⚙ 齿轮打开。标签页：

  • 常规 — 显示名称、默认模型、按 Enter 发送
  • 语音 — 麦克风设备、listen_seconds、STT 引擎选择、TTS 自动朗读
  • 更新 — is_admin 标志、WinSCP 会话、远程路径
  • 密钥 — 每个提供商的 API 密钥
  • 监管 — VSCode 监管切换、端口、轮询间隔
  • 语言 — 从 39 个区域中选择；见 § 17

模态框记住其大小和位置，在会话之间保留。

17. 语言

面板随附 39 种最常见语言的翻译。区域文件存储在 languages/<code>.xml，并在扩展激活时加载一次。缺失的键回退到英文。

在设置 → 语言中选择你的语言。每个选项旁显示一个国旗图标（从 assets/flags/<code>.svg 加载）。选择被保存到 config.ini 中的 [settings] language。

18. VSCode 监管

一个 Windows 服务（CBEVSCodeSupervisor）通过 NSSM 包装 tools/vscode_supervisor.ps1 脚本，并在 http://127.0.0.1:3434/ 上绑定一个 HttpListener。当监管 /status 端点回复 200 OK 时，面板的监管按钮会发蓝光。

如果 HTTP 探针失败但服务已安装，面板的监视狗会自动重启服务（30 秒冷却时间，防止重启风暴）。

左键点击监管按钮安装 / 启动 / 停止。右键点击打开追踪通道。

19. 自动更新（拉取）

扩展激活后 4 秒，面板获取 https://trentontompkins.com/cbe/manifest.xml.php — 最新发布文件的 MD5 + 大小清单。对于每个远程文件，比较本地副本的 MD5；仅通过 HTTPS 下载已更改/缺失的文件。

用户本地状态（config.ini、debug.log、domains.txt、wake.txt、prompt_history.txt）在拉取排除列表上，永远不会被覆盖。

20. 管理员推送

只有 [updates] is_admin = true 的客户端才会推送到服务器。通过以下方式触发：

  • 命令调板 → Claude Codex Black: Push update
  • 斜杠命令 /push

使用 [updates] winscp_session 中命名的 WinSCP 保存会话（默认 vps）。通过带同步命令的 /script=… 和排除机密和按机器状态的文件掩码进行推送。

21. 扩展市场

点击 🧩 扩展按钮。一个 iframe 模态框打开 https://trentontompkins.com/cbe/extension/extension_marketplace.php，它获取 extensions.xml.php 的目录并将每个可用扩展呈现为带有描述、标签、版本、文件大小、MD5 和安装按钮的卡片。

扩展被打包为 <id>.ext — 一个包含 manifest.xml 和扩展代码（通常是单个 extension.html）的 zip 存档。点击安装时，市场 iframe 向面板发送 postMessage；面板直接从服务器下载 .ext 文件，并在扩展文件夹中的 extensions/ 下提取它。

三个演示扩展随启动目录一起提供：计算器、扫雷 和表情符号选择器。

22. 斜杠命令

在提示框中输入 / 打开斜杠命令调板。点击一行插入命令文本到你的提示中（可编辑），或在可运行行上按 Enter 立即触发它。

一个非详尽的列表：

命令效果

/skin弹出皮肤选择器
/push触发自动更新推送（仅限管理员）
/license显示 LICENSE.TXT
/clear清除对话历史
/domains打开 NameSilo 域名模态框
/git打开 Git 模态框

/memory打开项目内存索引

23. 右键菜单

在面板中的任何地方右键点击弹出上下文菜单（定义为 panel.js 中的单个 XML 字符串）。条目包括刷新（重新加载面板而不触及扩展主机 — 永远不要使用 reloadWindow）、清除对话、打开设置和检查（DevTools，仅调试构建）。

24. 追踪通道

扩展将详细时间表写入扩展旁的 debug.log。所有值得注意的内容都到那里：提供商切换、STT 生命周期、监管探针、NameSilo 回复代码、面板↔主机桥接消息、推送/拉取清单计数。

右键点击监管按钮以一键打开追踪通道。

25. 故障排除

症状可能原因
提示框看起来是比例的，不是等宽的 --vscode-editor-font-family 未应用；检查 :root 变量
自动提示微调器是一个黑点 错误的 SVG 资源；应该是 auto_read_spinner.svg 带阴影光晕
紧凑按钮无任何作用 主机处理器缺失 — extension.js 路由器中 case 'compactConversation'
"0 域名"在域名模态框 NameSilo reply.code != 300（追踪通道有），或陈旧的 domains.txt
STT "未检测到语音"立刻 你在 SAPI 绑定麦克风前停止了。现在预热跳过该等待 — 在 debug.log 中用 stt: using pre-warmed SAPI 验证
带空格的路径推送失败 使用 /command= 内联；始终使用 /script=tempfile.winscp
监管蓝光不亮起 服务未运行。左键点击 monitorBtn 安装/启动，或运行 Start-Service CBEVSCodeSupervisor
重新加载"修复"了什么 它没有。永远不要使用 reloadWindow。改用刷新上下文菜单条目。
