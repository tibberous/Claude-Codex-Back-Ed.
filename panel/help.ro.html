Claude Codex — Black Edition

Panou chat IA multi-furnizor offline-first pentru VSCode. Apasă Ctrl+Alt+B pentru a comuta.

1. Bun venit

Claude Codex Black este o webview VSCode care te permite să chemi cu mai mulți furnizori de IA (Claude, OpenAI, Gemini, Grok, Azure, Ollama local) dintr-un singur panou tematic. Tot ceea ce necesită o cheie citește din config.ini la rădăcina extensiei — nu este necesar un UI de setări al extensiei, dar un modal Setări reflectă cele mai utile câmpuri pentru editare doar prin clic.

Nou aici? Deschide Setări (pictograma cu angrenaj), alege furnizorul tău, lipește cheia API, apoi tastează un prompt și apasă Enter. Orice altă funcție din acest ghid este opțională.

3. Caseta promptului

Aria de text editabilă mare din jos. Tastează, lipește, trage un fișier, atașează prin pictograma clip — orice pui aici este rândul utilizatorului al următorului apel API.

Fontul este blocat la fontul monospațiu al editorului tău VSCode (prin variabila CSS --vscode-editor-font-family) deci panoul arată bine în interiorul editorului.

5. Modele & furnizori

CBE se livrează cu 11 punți ca plugin-uri .bridge drop-in sub bridges/. Fiecare este un zip independent cu manifest.xml + bridge.py + pictograme. Trage un fișier nou .bridge și apare în lista derulantă cartridge — nu este necesară nicio schimbare a codului extensiei.

Punți text-chat (7)

  • ChatGPT — chatgpt.com, abonament Plus/Pro
  • Grok — grok.com, login xAI nativ (nivelul anonim este mult restricționat; conectează-te mai întâi)
  • Gemini — gemini.google.com, cont Google
  • Claude — claude.ai, login cu legătură magică (rulează tools/sign_in_helper.py claude o dată)
  • Copilot — copilot.microsoft.com, cont Microsoft gratuit
  • DeepSeek — chat.deepseek.com, email/parolă nativ (NU folosi Google SSO)
  • Ollama — local 127.0.0.1:11434, nu este necesar login

Punți generare video (4)

  • Sora 2 — sora.com, reutilizează login ChatGPT Plus/Pro
  • Google Veo — gemini.google.com (mod Veo), abonament Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, abonament Runway separat
  • Bing Video Creator — bing.com/videos/create, Sora-2 gratuit cu cont Microsoft

Videoclipurile generate se salvează în videos/<bridge>/<timestamp>_<prompt-slug>.mp4 și se redau automat în panoul Video Library (vezi §Video Library mai jos).

Alege o punte + model din lista derulantă cartridge lângă caseta promptului, sau prin Setări → General. Selecția este per-workspace și persistă în workspaceState. Pentru a adăuga o nouă punte, vezi docs/WRITING_BRIDGES.md.

5a. Biblioteca video

Un panou dedicat pentru navigare + vizionare videoclipuri generate de punțile video (Sora, Veo, Runway, Bing Video Creator). Se deschide prin Paleta de comenzi: Claude Codex Black: Open Video Library sau comanda codexBlackEd.openVideoPlayer.

  • Bara laterală listează fiecare .mp4 / .webm / .mov sub videos/<bridge>/, grupate după punte și sortate de la cel mai nou.
  • Videoclipul cel mai recent se redă automat la prima deschidere.
  • Panoul monitorizează directorul videos/ la fiecare 2 secunde — orice videoclip nou generat apare cu o insignă ✨ "Just generated" și se redă automat (dezactivează prin Auto ▶ new).
  • Clic pe 📂 Open pentru a deschide dosarul videos/ în managerul de fișiere.

6. Vorbire în text

Clic pe microfon, vorbește, clic din nou pentru a opri (sau așteptă timeout-ul silențiului). Două motoare sunt încercate în ordine:

  1. Web Speech API — recunoscător cloud Google care rulează în webview. Folosește sesiunea Gmail/Google; nu este necesară o cheie suplimentară.
  2. Windows SAPI (fallback) — proces PowerShell pre-încălzit invocat când webview-ul blochează accesul la microfon. Fereastră de ascultare configurabilă prin [voice] listen_seconds în config.ini.
SAPI este pre-încălzit la activarea extensiei deci primul clic pe microfon evită pornirea la rece de 2-4 secunde care obișnuia să gestioneze clicuri de oprire timpurii.

7. Prompt automat

Butonul insigne-cu-spinner. Când PORNIT, după N secunde de inactivitate panoul trimite automat textul de activare configurat. Cifra numărătorii se redă în --cbe-highlight-color, pe care fiecare temă o definește.

Editează textul de activare prin butonul 🔁 Wake — se rotunjește wake.txt.

8. Citire automată (TTS)

Pictograma gură. Când PORNIT, fiecare răspuns asistent este pronunțat prin sintetizatorul Web Speech (Google) sau un fallback SAPI. O aură albastră strălucitoare se aprinde în jurul pictogramei în timp ce audio-ul se redă.

9. Compact & utilizare context

Matricea conversației trimisă modelului crește la fiecare pas. Inelul în jurul pictogramei Compact arată utilizarea curentă a ferestrei de context ca gradient conic — gol când este nou, plin când este aproape de limita modelului.

Clic pe Compact pentru a trunchi istoricul la ultimii patru pași. Următorul apel API folosește matricea mai mică.

10. Răspuns de activare

Stocat în wake.txt la rădăcina extensiei. Folosit de Prompt automat ca mesajul de trimis când timer-ul inactivității se declanșează. Editează prin butonul 🔁 din toolbar.

11. Atașamente de fișiere

Clic pe 📎 pentru a alege unul sau mai multe fișiere. Ține apăsat Ctrl sau Shift în selector pentru a selecta mai multe. Fiecare fișier se inserează în prompt ca bloc de cod cu gard cu numele și limba sa. Fișierele binare mai mari de 1 MB sunt omise cu o notă.

12. Modal Git

Clic pe 📁 Git. Dacă nu este configurat dosarul proiectului, obții mai întâi un selector de dosare — calea aleasă se scrie în [project] path din config.ini. Invocațiile git ulterioare rulează cu cwd setat la acea cale.

13. Depozite GitHub

Listează orice depozit accesibil pentru [github] pat tău. Clic pe un rând pentru a insera URL-ul de clonare în prompt. Lista este paginată și memorată în cache.

14. Domenii NameSilo

Trage orice domeniu din contul NameSilo folosind [namesilo] api_key (sau [api_keys] namesilo_api_key ca fallback). La prima deschidere, rezultatele sunt memorate în cache în domains.txt; pornirile panelului ulterioare servesc din cache. Clic pe Reload în modal pentru a forța o preluare proaspătă.

Dacă vei vedea vreodată "no domains" cu cod 300 reply, verifică canalul de urmărire — cache-urile goale nu mai otrăvesc porniri viitoare, dar un domains.txt vechi într-o altă cale de instalare ar putea.

15. Teme & aspecte

Butonul 🎨 deschide un selector de descoperire care scanează skins/ în direct (nu la pornire), deci trage un dosar nou la runtime este suficient. Fiecare temă are un manifest.xml care definește paleta — inclusiv culoarea de evidență, pe care insigna numărătoare Auto Prompt, inelurile focus, și pulsul supervisor se raportează.

Temele încorporate includ: gnome (gri Adwaita), terminal (negru/verde cu accent roz fierbinte), tamagotchi (pastele coajă de ou cu panou sprite mascotă), blocky, și altele.

16. Setări

Se deschide din pictograma ⚙. File:

  • General — nume afișaj, model implicit, trimitere la apăsare Enter
  • Voce — dispozitiv microfon, listen_seconds, alegere motor STT, auto-citire TTS
  • Actualizări — steag is_admin, sesiune WinSCP, cale distantă
  • Chei — cheie API a fiecărui furnizor
  • Monitor — comutare supervisor VSCode, port, interval sondaj
  • Limbă — alege din 39 de locale; vezi § 17

Modala-și amintește dimensiunea și poziția între sesiuni.

17. Limbă

Panoul se livrează cu traduceri pentru 39 de limbi cele mai vorbite. Fișierele de locale se află la languages/<code>.xml și sunt încărcate o dată la activarea extensiei. Cheile lipsă se revin la limba engleză.

Alege limba în Setări → Limbă. O pictogramă drapel se arată lângă fiecare opțiune (încărcat din assets/flags/<code>.svg). Selecția se salvează în [settings] language din config.ini.

18. Supervisor VSCode

Un serviciu Windows (CBEVSCodeSupervisor) înfășoară scriptul tools/vscode_supervisor.ps1 prin NSSM și leagă un HttpListener pe http://127.0.0.1:3434/. Butonul monitor panelului se luminează albastru când punctul final /status al supervisorului răspunde 200 OK.

Dacă sonda HTTP eșuează dar serviciul este instalat, watchdog-ul panelului repornește automat serviciul (cool-down 30 secunde deci nu se reapor de furtună).

Clic stânga pe butonul monitor pentru a instala / porni / opri. Clic dreapta pentru a deschide canalul de urmărire.

19. Actualizare automată (pull)

4 secunde după activarea extensiei, panoul preiau https://trentontompkins.com/cbe/manifest.xml.php — o manifestă MD5+mărime a fișierelor publicate mai recent. Pentru fiecare fișier la distanță, MD5 copiei locale este comparat; doar fișierele modificate/lipsă sunt descărcate prin HTTPS.

Starea locală utilizatorului (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) este pe lista de excludere a pull și nu este niciodată suprascrisă.

20. Trimitere admin

Doar clienți cu [updates] is_admin = true trimit vreodată către server. Declanșat prin:

  • Paleta de comenzi → Claude Codex Black: Push update
  • Comanda slash /push

Folosește sesiunea WinSCP salvată denumită în [updates] winscp_session (implicit vps). Trimite prin /script=… cu comanda sincronizare și o mască de fișier care exclud secrete & stare per-mașină.

21. Piață de extensii

Clic pe butonul 🧩 Extensii. O modală iframe se deschide la https://trentontompkins.com/cbe/extension/extension_marketplace.php, care preia catalogul la extensions.xml.php și redă fiecare extensie disponibilă ca card cu descriere, etichete, versiune, mărime fișier, MD5, și un buton Install.

O extensie este ambalată ca <id>.ext — o arhivă zip cu manifest.xml plus codul extensiei (de obicei o singură extension.html). Când clic pe Install, iframe-ul pieței trimite un postMessage înapoi la panou; panoul descarcă fișierul .ext direct de pe server și îl extrage sub extensions/ în dosarul extensiei.

Trei extensii demo se livrează cu catalogul de lansare: Calculator, Minesweeper, și un Emoji Picker.

22. Comenzi cu slash

Tastează / în caseta promptului pentru a deschide paleta de comenzi cu slash. Clic pe un rând pentru a insera textul de comandă în prompt (editabil), sau apasă Enter pe un rând rulabil pentru a-l declanșa imediat.

23. Meniu clic dreapta

Clic dreapta oriunde în panou pentru un meniu contextual (definit ca o singură sală XML în panel.js). Intrările includ Refresh (reîncarcă panoul fără a atinge gazda extensiei — nu folosi niciodată reloadWindow), Șterge conversație, Deschide setări, și Inspect (DevTools, doar compilări debug).

24. Canal de urmărire

Extensia scrie o cronologie granulară în debug.log lângă extensie. Tot ceea ce este remarcabil ajunge acolo: comutări furnizor, ciclu viață STT, sonde supervisor, coduri răspuns NameSilo, mesaje pod panou↔gazdă, numărări manifest push/pull.

Clic dreapta pe butonul monitor pentru a deschide canalul de urmărire cu un clic.

25. Depanare

SimptomCauză probabilă
Caseta prompt arată proporțional, nu monospațiu --vscode-editor-font-family nu este aplicat; verifică variabilele :root
Spinner Prompt automat este un punct negru Activ SVG greșit; ar trebui să fie auto_read_spinner.svg cu halo drop-shadow
Butonul Compact nu face nimic Handler gazdă lipsă — case 'compactConversation' în router extension.js
"0 domenii" în modala Domenii NameSilo reply.code != 300 (canalul de urmărire o are), sau domains.txt vechi
STT "no speech detected" imediat Ai oprit înainte ca SAPI să lege microfonul. Pre-încălzirea omite acum acea așteptare — verifică cu stt: using pre-warmed SAPI în debug.log
Push eșuează pe cale cu spații Folosind /command= inline; folosește întotdeauna /script=tempfile.winscp
Strălucire albastră supervisor nu se aprinde Serviciu nu rulează. Clic stânga pe monitorBtn pentru a instala/porni, sau rulează Start-Service CBEVSCodeSupervisor
Reload "repară" ceva Nu a reparat. Nu folosi niciodată reloadWindow. Folosește intrarea meniu context Refresh în loc.
