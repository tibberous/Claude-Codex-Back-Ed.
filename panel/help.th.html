Codex Black Ed.

แผงแชท AI แบบออฟไลน์ก่อนหลัก พร้อมหลายผู้ให้บริการสำหรับ VSCode กด Ctrl+Alt+B เพื่อสลับ

1. ยินดีต้อนรับ

Codex Black คือ webview ของ VSCode ที่ให้คุณแชทกับหลายผู้ให้บริการ AI (Claude, OpenAI, Gemini, Grok, Azure, Ollama ในเครื่อง) จากแผงเดียวที่สามารถปรับตัวได้ ทุกสิ่งที่ต้องการคีย์จะอ่านจาก config.ini ที่รากส่วนขยาย — ไม่จำเป็นต้องมี UI การตั้งค่าส่วนขยาย แต่โมดัลการตั้งค่าสะท้อนฟิลด์ที่มีประโยชน์มากที่สุดสำหรับการแก้ไขด้วยการคลิกเท่านั้น

ใหม่ที่นี่? เริ่มต้นด้วยการเปิด การตั้งค่า (ไอคอนเฟืองหา) เลือกผู้ให้บริการของคุณ วางคีย์ API ของคุณ จากนั้นพิมพ์พรอมพ์และกด Enter ทุกฟีเจอร์อื่น ๆ ในคู่มือนี้เป็นทางเลือก

3. กล่องพรอมพ์

textarea ที่ใหญ่และแก้ไขได้ที่ด้านล่าง พิมพ์ วาง ลากไฟล์ แนบผ่านคลิป — สิ่งใดที่คุณใส่ไว้ที่นี่คือผู้ใช้เปลี่ยนแปลงของการโทร API ถัดไป

แบบอักษรจะถูกล็อกไปยังแบบอักษรโมโนสเปซของเอดิเตอร์ VSCode ของคุณ (ผ่านตัวแปร CSS --vscode-editor-font-family) เพื่อให้แผงดูคล้ายกับการใช้งานในเอดิเตอร์

5. โมเดลและผู้ให้บริการ

CBE มีการส่ง 11 สะพาน เป็นปลั๊กอิน .bridge ที่แทรกได้ใต้ bridges/ แต่ละอันเป็น zip ที่มีตัวเองซึ่งมี manifest.xml + bridge.py + ไอคอน วางไฟล์ .bridge ใหม่เข้าไป และมันจะปรากฏในเมนูดรอปดาวน์ตลับ — ไม่มีการเปลี่ยนแปลงรหัสส่วนขยาย

สะพาน text-chat (7)

  • ChatGPT — chatgpt.com สมาชิก Plus/Pro
  • Grok — grok.com การเข้าสู่ระบบ xAI แบบเนทีฟ (ชั้น anonymous ถูก gated อย่างมาก; เข้าสู่ระบบก่อน)
  • Gemini — gemini.google.com บัญชี Google
  • Claude — claude.ai การเข้าสู่ระบบลิงก์มหัศจรรย์ (เรียกใช้ tools/sign_in_helper.py claude ครั้งเดียว)
  • Copilot — copilot.microsoft.com บัญชี Microsoft ฟรี
  • DeepSeek — chat.deepseek.com อีเมล/รหัสผ่านแบบเนทีฟ (ห้ามใช้ Google SSO)
  • Ollama — 127.0.0.1:11434 ในเครื่อง ไม่ต้องเข้าสู่ระบบ

สะพานสร้างวิดีโอ (4)

  • Sora 2 — sora.com นำเสนอการเข้าสู่ระบบ ChatGPT Plus/Pro ของคุณ
  • Google Veo — gemini.google.com (โหมด Veo) สมาชิก Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com สมาชิก Runway แยกต่างหาก
  • Bing Video Creator — bing.com/videos/create Sora-2 ฟรี ด้วยบัญชี Microsoft

วิดีโอที่สร้างขึ้นจะบันทึกไปยัง videos/<bridge>/<timestamp>_<prompt-slug>.mp4 และเล่นอัตโนมัติในแผง Video Library (ดู §Video Library ด้านล่าง)

เลือกสะพาน + โมเดลจากเมนูดรอปดาวน์ตลับถัดจากกล่องพรอมพ์ หรือผ่าน การตั้งค่า → ทั่วไป การเลือกนี้คือต่อพื้นที่ทำงานและคงอยู่ใน workspaceState ในการเพิ่มสะพานใหม่ ดู docs/WRITING_BRIDGES.md

5a. ห้องเก็บวิดีโอ

แผงเฉพาะสำหรับการท่องและดูวิดีโอที่สร้างโดยสะพานวิดีโอ (Sora, Veo, Runway, Bing Video Creator) เปิดผ่าน Command Palette: Codex Black: Open Video Library หรือคำสั่ง codexBlackEd.openVideoPlayer

  • Sidebar จดหมายการ .mp4 / .webm / .mov ที่อยู่ใต้ videos/<bridge>/ จัดกลุ่มตามสะพานและจัดเรียงใหม่-สุดท้าย
  • วิดีโอล่าสุดจะเล่นอัตโนมัติที่เปิดครั้งแรก
  • แผงดูอักษร videos/ ในการเฉพาะ 2 วินาที — วิดีโอที่สร้างใหม่ใด ๆ ปรากฏขึ้นพร้อมกับ ✨ "เพิ่งสร้าง" ป้ายและเล่นอัตโนมัติ (สลับปิดผ่าน อัตโนมัติ ▶ ใหม่)
  • คลิก 📂 เปิด เพื่อเปิดเผยโฟลเดอร์ videos/ ในตัวจัดการไฟล์ OS ของคุณ

6. แปลงเสียงเป็นข้อความ

คลิกไมค์ พูด คลิกอีกครั้งเพื่อหยุด (หรือรอหมดเวลาความเงียบ) เครื่องยนต์สองเครื่องจะลองตามลำดับ:

  1. Web Speech API — ตัวจดจำเสียงของ Google ที่ทำงานใน webview ใช้เซสชัน Gmail/Google ของคุณ ไม่ต้องใช้คีย์เพิ่มเติม
  2. Windows SAPI (fallback) — กระบวนการ PowerShell ที่อุ่นอยู่ก่อนเรียกใช้เมื่อ webview บล็อกการเข้าถึงไมค์ ฟังหน้าต่างที่กำหนดได้ผ่าน [voice] listen_seconds ใน config.ini
SAPI คือ อุ่นไว้ที่ส่วนขยายเปิดใช้งาน เพื่อให้การคลิกไมค์ครั้งแรกหลีกเลี่ยง การเริ่มเย็น 2-4 วินาทีที่ใช้จะกลืนคลิกหยุดช่วงแรก

7. พรอมพ์อัตโนมัติ

ปุ่มป้ายที่มี spinner หลังจากไม่ใช้งาน N วินาที แผงจะส่งข้อความปลุกที่กำหนดค่าไว้อัตโนมัติ ตัวเลขการนับถอยหลังจะแสดงในสี --cbe-highlight-color ซึ่งแต่ละสกินกำหนด

แก้ไขข้อความปลุกผ่านปุ่ม 🔁 Wake — มันจะ round-trip wake.txt

8. อ่านอัตโนมัติ (TTS)

ไอคอนปาก เมื่อเปิด การตอบสนองของผู้ช่วยทุกครั้งจะถูกพูดออกมาผ่านตัวสังเคราะห์ Web Speech (Google) หรือ SAPI fallback จะมีอาภรณ์สีน้ำเงินรอบไอคอนขณะที่เสียงกำลังเล่น

9. การสรุปและการใช้บริบท

แถวการสนทนาที่ส่งไปยังโมเดลจะเพิ่มขึ้นในทุกเทิร์น ลูปรอบไอคอน Compact แสดงการใช้ context-window ปัจจุบัน เป็นการไล่ระดับสี conic — ว่างเมื่อสดใหม่ เต็มเมื่อเข้าใกล้ขีดจำกัด context ของโมเดล

คลิก Compact เพื่อตัดทอนประวัติลงเหลือเพียงสี่เทิร์นล่าสุด การเรียก API ถัดไป ใช้อาร์เรย์ที่เล็กกว่า

10. ตอบสนองการปลุก

เก็บไว้ใน wake.txt ที่รากส่วนขยาย ใช้โดย Auto Prompt เป็นข้อความที่ส่งเมื่อ ตัวจับเวลาไม่ใช้งานจะเหลือ แก้ไขผ่านปุ่ม 🔁 toolbar

11. การแนบไฟล์

คลิก 📎 เพื่อเลือกไฟล์หนึ่งไฟล์หรือมากกว่า ค้างไว้ Ctrl หรือ Shift ในเครื่องเลือก เพื่อเลือกหลายรายการ แต่ละไฟล์จะแทรกเข้าไปในพรอมพ์เป็นบล็อกรหัสที่แยกออกจากกันพร้อมชื่อไฟล์และภาษา ไฟล์ไบนารีขนาดเกิน 1 MB จะข้ามไปพร้อมกับประกาศ

12. โมดัล Git

คลิก 📁 Git ถ้าไม่มีการกำหนดค่าโฟลเดอร์โครงการ คุณจะได้รับเครื่องเลือกโฟลเดอร์ก่อน — เส้นทางที่เลือกจะเขียนไปยัง [project] path ใน config.ini การเรียกใช้ git ที่ตามมาจะทำงานโดยตั้งค่า cwd เป็นเส้นทางนั้น

13. พื้นที่เก็บ GitHub

จดหมายการทุก repo ที่สามารถเข้าถึงได้ของคุณ [github] pat คลิกแถวเพื่อแทรก URL โคลนของมันเข้าไปในพรอมพ์ รายการจะเพจเนทและแคช

14. โดเมน NameSilo

ดึงทุกโดเมนในบัญชี NameSilo ของคุณโดยใช้ [namesilo] api_key (หรือ [api_keys] namesilo_api_key เป็น fallback) ที่เปิดครั้งแรก ผลลัพธ์จะแคช ไปยัง domains.txt บูทแผงที่ตามมาจะให้บริการจากแคช คลิก โหลดใหม่ ในโมดัลเพื่อบังคับการดึงข้อมูลใหม่

ถ้าคุณเห็น "ไม่มีโดเมน" พร้อมรหัส 300 ตอบ ตรวจสอบช่องติดตาม — แคชว่างเปล่าไม่ปิด การเข้าสู่ระบบอีกต่อไป แต่ domains.txt ที่ล้าสมัยในเส้นทางการติดตั้งอื่น ๆ ก็ได้

15. สกินและธีม

ปุ่ม 🎨 ป๊อปเครื่องเลือกการค้นพบที่สแกน skins/ แบบสด (ไม่ใช่ที่เริ่มต้น) วางโฟลเดอร์ใหม่เข้าไปที่เวลาทำงาน พอ แต่ละสกินมี manifest.xml กำหนด จานสีของมัน — รวมถึง สีไฮไลต์ ซึ่ง Auto Prompt countdown badge วงแหวนโฟกัส และพัลส์ผู้ดูแลทั้งหมดใช้งาน

สกินในตัวรวมถึง: gnome (สีเทา Adwaita) terminal (ดำ/เขียวพร้อมสำเนียงสีชมพูร้อน) tamagotchi (พาสเทลเปลือกไข่พร้อมแผงสไปรต์เจ้าหน้าที่) blocky และอื่น ๆ

16. การตั้งค่า

เปิดจากเฟืองหา ⚙ แท็บ:

  • ทั่วไป — ชื่อแสดง โมเดลเริ่มต้น ส่งจากปีก
  • เสียง — อุปกรณ์ไมค์ listen_seconds เลือกเครื่องยนต์ STT อ่านอัตโนมัติ TTS
  • อัปเดต — แฟล็ก is_admin เซสชัน WinSCP เส้นทางรีโมต
  • คีย์ — คีย์ API ของผู้ให้บริการทุกคน
  • มอนิเตอร์ — สลับผู้ดูแล VSCode พอร์ต ช่วงเวลาการสำรวจ
  • ภาษา — เลือกจากภาษาท้องถิ่น 39 ดู § 17

โมดัลจะจำขนาดและตำแหน่งของมันระหว่างเซสชัน

17. ภาษา

แผงมีการแปล 39 ภาษาที่พูดมากที่สุด ไฟล์ Locale อยู่ที่ languages/<code>.xml และโหลดครั้งเดียวที่ส่วนขยายเปิดใช้งาน คีย์ที่ขาดหายจะกลับไปที่ภาษาอังกฤษ

เลือกภาษาของคุณใน การตั้งค่า → ภาษา ไอคอนธงจะแสดงถัดจากตัวเลือกแต่ละตัว (โหลดจาก assets/flags/<code>.svg) การเลือกจะบันทึกไปยัง [settings] language ใน config.ini

18. ผู้ดูแล VSCode

บริการ Windows (CBEVSCodeSupervisor) ห่อสคริปต์ tools/vscode_supervisor.ps1 ผ่าน NSSM และผูกเข้า HttpListener บน http://127.0.0.1:3434/ ปุ่มมอนิเตอร์ของแผงแสดงสีน้ำเงินเมื่อปลายทาง /status ของผู้ดูแลตอบ 200 OK

ถ้า HTTP probe ล้มเหลว แต่บริการติดตั้งแล้ว เวชฟอรด์ของแผงจะรีสตาร์ทบริการ อัตโนมัติ (ระยะเวลารอ 30 วินาที เพื่อไม่ให้รีสตาร์ท-storm)

คลิกซ้ายที่ปุ่มมอนิเตอร์เพื่อติดตั้ง / เริ่ม / หยุด คลิกขวาเพื่อเปิด ช่องติดตาม

19. อัปเดตอัตโนมัติ (ดึง)

4 วินาทีหลังจากเปิดใช้งานส่วนขยาย แผงจะดึง https://trentontompkins.com/cbe/manifest.xml.php — manifest MD5+size ของไฟล์ที่เผยแพร่ล่าสุด สำหรับแต่ละไฟล์รีโมต MD5 ของสำเนาในเครื่องจะถูก เปรียบเทียบ เฉพาะไฟล์ที่เปลี่ยนแปลง/ขาดหายจะถูกดาวน์โหลดผ่าน HTTPS

สถานะของผู้ใช้ในเครื่อง (config.ini debug.log domains.txt wake.txt prompt_history.txt) อยู่ ในรายชื่อยกเว้นการดึงและไม่เคยถูกเขียนทับ

20. ส่งผ่านไปยังผู้ดูแล

เฉพาะไคลเอ็นต์ที่มี [updates] is_admin = true จะส่งไปยังเซิร์ฟเวอร์เท่านั้น เรียกใช้ผ่าน:

  • Command Palette → Codex Black: Push update
  • คำสั่งเฉือน /push

ใช้เซสชั่นที่บันทึกไว้ WinSCP ที่ตั้งชื่อใน [updates] winscp_session (ค่าเริ่มต้น vps) ส่งผ่าน /script=… ด้วยคำสั่ง synchronize และ filemask ที่ยกเว้นข้อมูลลับและสถานะต่อเครื่อง

21. ตลาดส่วนขยาย

คลิกปุ่ม 🧩 ส่วนขยาย โมดัล iframe จะเปิดไปที่ https://trentontompkins.com/cbe/extension/extension_marketplace.php ซึ่งดึง catalog ที่ extensions.xml.php และแสดงแต่ละส่วนขยายที่มีอยู่เป็นการ์ด พร้อมคำอธิบาย แท็ก เวอร์ชัน ขนาดไฟล์ MD5 และ ติดตั้ง ปุ่ม

ส่วนขยายจะแพ็ก <id>.ext — archive zip ประกอบด้วย manifest.xml บวกรหัสส่วนขยาย (โดยทั่วไป extension.html เดี่ยว) เมื่อคุณคลิกติดตั้ง iframe ตลาดจะส่ง postMessage กลับไปยังแผง แผง ดาวน์โหลดไฟล์ .ext โดยตรงจากเซิร์ฟเวอร์และแยกมันใต้ extensions/ ในโฟลเดอร์ส่วนขยาย

ส่วนขยายการสาธิตสามตัวมีการส่ง catalog เปิดตัว: เครื่องคิดเลข Minesweeper และ Emoji Picker

22. คำสั่งแบบเฉือน

พิมพ์ / ในกล่องพรอมพ์เพื่อเปิดจานสีคำสั่งแบบเฉือน คลิกแถวเพื่อ แทรก ข้อความคำสั่งเข้าไปในพรอมพ์ของคุณ (แก้ไขได้) หรือกด Enter บนแถวที่รันได้เพื่อ เหลวอย่างเสี่ยง

รายการที่ไม่ครบถ้วน:

คำสั่งผล
/helpเปิดเอกสารนี้
/skinป๊อปเครื่องเลือกสกิน
/pushดำเนินการดัน auto-update (admin เท่านั้น)
/licenseแสดง LICENSE.TXT
/clearล้างประวัติการสนทนา
/domainsเปิดโมดัลโดเมน NameSilo
/gitเปิดโมดัล Git
/wakeเปิดตัวแก้ไขปลุก
/memoryเปิดดัชนีหน่วยความจำโครงการ

23. เมนูคลิกขวา

คลิกขวาที่ใดก็ได้ในแผงสำหรับเมนูตามบริบท (กำหนดเป็นสตริง XML เดียวใน panel.js) รายการรวมถึง Refresh (โหลดแผงใหม่โดยไม่สัมผัสโฮสต์ส่วนขยาย — ห้ามใช้ reloadWindow) ล้างการสนทนา เปิดการตั้งค่า และตรวจสอบ (DevTools เฉพาะบิวด์ดีบัก)

24. ช่องทางติดตาม

ส่วนขยายเขียนไทม์ไลน์แบบละเอียดไปยัง debug.log ถัดจากส่วนขยาย ทุกสิ่งที่น่าสังเกตจะอยู่ที่นั่น: สวิตช์ผู้ให้บริการ วงจรชีวิต STT การสำรวจผู้ดูแล รหัสตอบ NameSilo ข้อความสะพาน panel↔host นับ manifest push/pull

คลิกขวาปุ่มมอนิเตอร์เพื่อเปิด one-click ของช่องติดตาม

25. การแก้ไขปัญหา

อาการสาเหตุที่น่าจะเป็น
กล่องพรอมพ์มีลักษณะสัดส่วน ไม่ใช่โมโนสเปซ --vscode-editor-font-family ไม่ได้ใช้ ตรวจสอบตัวแปร :root
spinner Auto Prompt เป็นจุดดำ ทรัพยากร SVG ผิด ควรเป็น auto_read_spinner.svg พร้อม drop-shadow halo
ปุ่ม Compact ไม่ทำอะไร โฮสต์ handler ขาดหายมา — case 'compactConversation' ในเราเตอร์ extension.js
"0 โดเมน" ในโมดัล Domains รหัสตอบ NameSilo != 300 (ช่องติดตามมีมัน) หรือ domains.txt ล้าสมัย
STT "ไม่พบเสียงพูด" ทันที คุณหยุดก่อนที่ SAPI จะผูกมิก การ pre-warm ตอนนี้ข้ามการรอ — ตรวจสอบด้วย stt: using pre-warmed SAPI ใน debug.log
ดันล้มเหลวบนเส้นทางที่มีช่องว่าง ใช้ /command= อินไลน์ เสมอใช้ /script=tempfile.winscp
เรืองแสงสีน้ำเงินผู้ดูแลไม่ส่อง บริการไม่ทำงาน คลิกซ้ายที่ monitorBtn เพื่อติดตั้ง/เริ่ม หรือเรียกใช้ Start-Service CBEVSCodeSupervisor
โหลด "ซ่อม" บางอย่าง มันไม่ได้ ห้ามใช้ reloadWindow เสมอ ใช้รายการเมนู Refresh context-menu แทน
