Claude Codex — Black Edition

VSCode를 위한 오프라인 우선 다중 제공자 AI 채팅 패널입니다. Ctrl+Alt+B를 눌러 토글하세요.

1. 환영합니다

Claude Codex Black은 VSCode 웹뷰로, 여러 AI 제공자(Claude, OpenAI, Gemini, Grok, Azure, 로컬 Ollama)와 단일의 테마 가능한 패널에서 채팅할 수 있습니다. 키가 필요한 모든 것은 확장 루트의 config.ini에서 읽힙니다 — 확장 설정 UI는 필수가 아니지만, 설정 모달은 클릭 전용 편집을 위해 가장 유용한 필드를 미러링합니다.

처음이신가요? 설정을 열고(톱니 아이콘), 제공자를 선택한 후 API 키를 붙여넣고, 프롬프트를 입력한 다음 Enter를 누르세요. 이 가이드의 다른 모든 기능은 선택 사항입니다.

3. 프롬프트 상자

하단의 큰 편집 가능한 텍스트 영역입니다. 입력, 붙여넣기, 파일 드래그, 클립 첨부 — 여기에 입력한 모든 것이 다음 API 호출의 사용자 턴입니다.

글꼴이 VSCode 편집기의 모노스페이스 글꼴로 잠금되어 있습니다 (--vscode-editor-font-family CSS 변수를 통해) 따라서 패널이 편집기 내에서 집에 있는 것처럼 보입니다.

5. 모델 및 제공자

CBE는 bridges/ 아래의 드롭인 .bridge 플러그인으로 11개 브릿지를 제공합니다. 각각은 manifest.xml + bridge.py + 아이콘이 포함된 자체 포함 zip입니다. 새 .bridge 파일을 드롭인하면 카트리지 드롭다운에 나타나며 — 확장 코드 변경이 필요 없습니다.

텍스트 채팅 브릿지 (7개)

  • ChatGPT — chatgpt.com, Plus/Pro 구독
  • Grok — grok.com, 기본 xAI 로그인 (익명 계층은 많이 제한됨; 먼저 로그인하세요)
  • Gemini — gemini.google.com, Google 계정
  • Claude — claude.ai, 매직링크 로그인 (tools/sign_in_helper.py claude 한 번 실행)
  • Copilot — copilot.microsoft.com, 무료 Microsoft 계정
  • DeepSeek — chat.deepseek.com, 기본 이메일/비밀번호 (Google SSO를 사용하지 마세요)
  • Ollama — 로컬 127.0.0.1:11434, 로그인 불필요

비디오 생성 브릿지 (4개)

  • Sora 2 — sora.com, ChatGPT Plus/Pro 로그인 재사용
  • Google Veo — gemini.google.com (Veo 모드), Gemini Advanced 구독
  • Runway Gen-3/4 — app.runwayml.com, 별도 Runway 구독
  • Bing Video Creator — bing.com/videos/create, 무료 Sora-2 (Microsoft 계정 포함)

생성된 비디오는 videos/<bridge>/<timestamp>_<prompt-slug>.mp4에 저장되고 비디오 라이브러리 패널에서 자동 재생됩니다 (아래 §비디오 라이브러리 참조).

프롬프트 상자 옆의 카트리지 드롭다운에서 브릿지 + 모델을 선택하거나 설정 → 일반에서 선택하세요. 선택은 워크스페이스당이며 workspaceState에서 유지됩니다. 새 브릿지를 추가하려면 docs/WRITING_BRIDGES.md를 참조하세요.

5a. 비디오 라이브러리

비디오 브릿지(Sora, Veo, Runway, Bing Video Creator)에 의해 생성된 비디오를 찾아보고 시청하기 위한 전용 패널입니다. 명령 팔레트를 통해 열립니다: Claude Codex Black: Open Video Library 또는 codexBlackEd.openVideoPlayer 명령.

  • 사이드바는 videos/<bridge>/ 아래의 모든 .mp4 / .webm / .mov를 나열하며, 브릿지별로 그룹화되고 최신순으로 정렬됩니다.
  • 가장 최신 비디오는 첫 열기 시 자동으로 재생됩니다.
  • 패널은 2초 틱으로 videos/ 디렉터리를 감시하며 — 새로 생성된 비디오는 ✨ "방금 생성됨" 배지와 함께 나타나고 자동으로 재생됩니다 (자동 ▶ 새것으로 토글 해제).
  • 📂 열기를 클릭하여 OS 파일 매니저에서 videos/ 폴더를 표시합니다.

6. 음성 인식

마이크를 클릭하고 말한 후 다시 클릭하여 중지합니다 (또는 침묵 타임아웃을 기다립니다). 두 개의 엔진이 순서대로 시도됩니다:

  1. Web Speech API — 웹뷰에서 실행되는 Google의 클라우드 인식기. Gmail/Google 세션을 사용하며 추가 키는 필요하지 않습니다.
  2. Windows SAPI (폴백) — 웹뷰가 마이크 접근을 차단할 때 호출되는 사전 가열된 PowerShell 프로세스. config.ini의 [voice] listen_seconds를 통해 구성 가능합니다.
SAPI는 확장 활성화 시 사전 가열되므로 첫 마이크 클릭은 이전에 초기 중지 클릭을 삼켰던 2-4초 콜드 스타트를 피합니다.

7. 자동 프롬프트

배지가 있는 스피너 버튼입니다. ON일 때, N초의 비활성 후 패널은 구성된 시작 텍스트를 자동으로 전송합니다. 카운트다운 숫자는 --cbe-highlight-color에 렌더링되며, 각 스킨이 이를 정의합니다.

🔁 Wake 버튼을 통해 시작 텍스트를 편집합니다 — wake.txt로 왕복합니다.

8. 자동 읽기 (TTS)

입 아이콘입니다. ON일 때, 모든 어시스턴트 응답은 Web Speech 합성기(Google) 또는 SAPI 폴백을 통해 음성으로 표현됩니다. 오디오 재생 중에 아이콘 주위에 파란색 후광이 빛납니다.

9. 컴팩트 및 컨텍스트 사용

모델로 전송되는 대화 배열은 모든 턴마다 커집니다. Compact 아이콘 주변의 링은 현재 컨텍스트 윈도우 사용량을 원뿔형 그래디언트로 표시합니다 — 새로울 때는 비어 있고, 모델의 컨텍스트 제한에 가까워질 때 꽉 찹니다.

Compact를 클릭하여 기록을 마지막 네 턴으로 자릅니다. 다음 API 호출은 더 작은 배열을 사용합니다.

10. 시작 응답

확장 루트의 wake.txt에 저장됩니다. 비활성 타이머가 실행될 때 전송할 메시지로 자동 프롬프트에서 사용됩니다. 🔁 도구 모음 버튼을 통해 편집하세요.

11. 파일 첨부

📎를 클릭하여 하나 이상의 파일을 선택합니다. 픽커에서 Ctrl 또는 Shift를 누른 채로 다중 선택합니다. 각 파일은 파일명과 언어가 있는 울타리 친 코드 블록으로 프롬프트에 인라인됩니다. 1MB 이상의 이진 파일은 알림과 함께 건너뜁니다.

12. Git 모달

📁 Git을 클릭합니다. 프로젝트 폴더가 구성되지 않으면 먼저 폴더 픽커를 얻습니다 — 선택한 경로는 config.ini의 [project] path에 작성됩니다. 후속 git 호출은 해당 경로로 cwd를 설정하여 실행됩니다.

13. GitHub 저장소

[github] pat에 접근 가능한 모든 저장소를 나열합니다. 행을 클릭하여 클론 URL을 프롬프트에 삽입합니다. 목록은 페이지 매김되고 캐시됩니다.

14. NameSilo 도메인

[namesilo] api_key (또는 폴백으로 [api_keys] namesilo_api_key)를 사용하여 NameSilo 계정의 모든 도메인을 가져옵니다. 처음 열 때 결과는 domains.txt로 캐시됩니다; 후속 패널 부팅은 캐시에서 제공합니다. 모달에서 다시 로드를 클릭하여 강제로 새로 가져오기합니다.

300 응답 코드와 함께 "도메인 없음"이 표시되면 추적 채널을 확인하세요 — 빈 캐시는 더 이상 향후 패널 부팅을 손상시키지 않지만, 다른 설치 경로의 오래된 domains.txt가 손상될 수 있습니다.

15. 스킨 및 테마

🎨 버튼은 skins/를 라이브로 스캔하는 발견 픽커를 팝합니다 (시작 시 아님), 따라서 런타임에 새 폴더를 드롭하기만 하면 충분합니다. 각 스킨에는 팔레트를 정의하는 manifest.xml이 있습니다 — 자동 프롬프트 카운트다운 배지, 포커스 링, 감시자 펄스가 모두 키를 사용하는 하이라이트 색상을 포함합니다.

기본 스킨에는 다음이 포함됩니다: gnome (Adwaita 회색), terminal (검은색/녹색, 핫핑크 악센트), tamagotchi (계란껍질 파스텔, 스프라이트 마스코트 패널), blocky 및 기타.

16. 설정

⚙ 톱니에서 엽니다. 탭:

  • 일반 — 표시 이름, 기본 모델, 엔터 시 전송
  • 음성 — 마이크 장치, listen_seconds, STT 엔진 선택, TTS 자동 읽기
  • 업데이트 — is_admin 플래그, WinSCP 세션, 원격 경로
  • 키 — 모든 제공자의 API 키
  • 모니터 — VSCode 감시자 토글, 포트, 폴링 간격
  • 언어 — 39개 로케일 중에서 선택; § 17 참조

모달은 세션 간 크기와 위치를 기억합니다.

17. 언어

패널은 39개의 가장 널리 사용되는 언어에 대한 번역과 함께 제공됩니다. 로케일 파일은 languages/<code>.xml에 있으며 확장 활성화 시 한 번 로드됩니다. 누락된 키는 영어로 폴백합니다.

설정 → 언어에서 언어를 선택합니다. 각 옵션 옆에 국기 아이콘이 표시됩니다 (assets/flags/<code>.svg에서 로드). 선택은 config.ini의 [settings] language에 저장됩니다.

18. VSCode 감시자

Windows 서비스 (CBEVSCodeSupervisor)는 tools/vscode_supervisor.ps1 스크립트를 NSSM을 통해 래핑하고 http://127.0.0.1:3434/에서 HttpListener를 바인딩합니다. 감시자의 /status 끝점이 200 OK로 응답할 때 패널의 모니터 버튼이 파란색으로 빛납니다.

HTTP 프로브가 실패하지만 서비스가 설치된 경우, 패널의 워치독이 서비스를 자동으로 다시 시작합니다 (재시작 폭주를 방지하기 위해 30초 쿨다운).

모니터 버튼을 왼쪽 클릭하여 설치/시작/중지합니다. 우클릭하여 추적 채널을 엽니다.

19. 자동 업데이트 (pull)

확장 활성화 후 4초 후, 패널은 https://trentontompkins.com/cbe/manifest.xml.php를 가져옵니다 — 최신 게시된 파일의 MD5+크기 매니페스트입니다. 각 원격 파일에 대해 로컬 사본의 MD5가 비교됩니다; 변경/누락된 파일만 HTTPS를 통해 다운로드됩니다.

사용자 로컬 상태(config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt)는 pull 제외 목록에 있으며 절대 덮어쓰여지지 않습니다.

20. 관리자 푸시

[updates] is_admin = true인 클라이언트만 서버에 푸시합니다. 다음을 통해 트리거됩니다:

  • 명령 팔레트 → Claude Codex Black: Push update
  • 슬래시 명령 /push

[updates] winscp_session에 명명된 WinSCP 저장 세션을 사용합니다 (기본값 vps). /script=…를 통해 푸시하고 동기화 명령과 비밀 및 머신당 상태를 제외하는 파일 마스크를 사용합니다.

21. 확장 마켓플레이스

🧩 확장 버튼을 클릭합니다. iframe 모달이 https://trentontompkins.com/cbe/extension/extension_marketplace.php로 열리며, extensions.xml.php에서 카탈로그를 가져오고 각 사용 가능한 확장을 설명, 태그, 버전, 파일 크기, MD5 및 설치 버튼이 있는 카드로 렌더링합니다.

확장은 <id>.ext로 패키징됩니다 — manifest.xml 및 확장 코드(일반적으로 단일 extension.html)를 포함하는 zip 아카이브입니다. 설치를 클릭하면, 마켓플레이스 iframe은 패널에 postMessage를 보냅니다; 패널은 서버에서 직접 .ext 파일을 다운로드하고 확장 폴더의 extensions/ 아래에 추출합니다.

세 개의 데모 확장이 출시 카탈로그와 함께 제공됩니다: 계산기, 지뢰찾기 및 이모지 피커.

22. 슬래시 명령

프롬프트 상자에서 /를 입력하여 슬래시 명령 팔레트를 엽니다. 행을 클릭하여 프롬프트에 명령 텍스트를 삽입합니다 (편집 가능) 또는 실행 가능한 행에서 Enter를 눌러 즉시 실행합니다.

완전하지는 않지만 사용 가능한 목록:

명령효과

/skin스킨 픽커 팝

23. 우클릭 메뉴

패널의 아무 곳이나 우클릭하여 상황별 메뉴를 표시합니다 (panel.js의 단일 XML 문자열로 정의). 항목에는 새로 고침(확장 호스트를 건드리지 않고 패널 다시 로드 — 절대 reloadWindow 사용 금지), 대화 지우기, 설정 열기 및 검사 (DevTools, 디버그 빌드만 해당)가 포함됩니다.

24. 추적 채널

확장은 확장 옆의 debug.log에 세밀한 타임라인을 작성합니다. 주목할 만한 모든 것이 거기에 도착합니다: 제공자 전환, STT 라이프사이클, 감시자 프로브, NameSilo 응답 코드, 패널↔호스트 브릿지 메시지, 푸시/pull 매니페스트 수.

모니터 버튼을 우클릭하여 추적 채널을 한 번 클릭으로 엽니다.

25. 문제 해결

증상가능한 원인
프롬프트 상자가 비례로 보이고 모노스페이스가 아님 --vscode-editor-font-family가 적용되지 않음; :root 변수 확인
자동 프롬프트 스피너가 검은 점 잘못된 SVG 자산; auto_read_spinner.svg (드롭 섀도우 후광 포함)여야 함
컴팩트 버튼이 작동하지 않음 호스트 핸들러 누락 — extension.js 라우터의 case 'compactConversation'
도메인 모달의 "0개 도메인" NameSilo reply.code != 300 (추적 채널에 있음) 또는 오래된 domains.txt
STT "음성 감지 안 됨" 즉시 SAPI가 마이크를 바인드하기 전에 중지했습니다. 사전 가열이 이제 해당 대기를 건너뜁니다 — debug.log의 stt: using pre-warmed SAPI로 확인
공백이 있는 경로에서 푸시 실패 /command= 인라인 사용; 항상 /script=tempfile.winscp 사용
감시자 파란색 후광이 밝혀지지 않음 서비스가 실행되지 않음. 모니터Btn을 왼쪽 클릭하여 설치/시작하거나 Start-Service CBEVSCodeSupervisor 실행
새로 고침이 뭔가 "수정"함 그렇지 않습니다. 절대 reloadWindow를 사용하지 마세요. 대신 우클릭 메뉴 항목 새로 고침을 사용하세요.
