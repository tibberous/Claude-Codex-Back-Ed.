Claude Codex — Black Edition

VSCode க்கான ஆப்-லைன் முதல் பல-வழங்குநர் AI சட்டச் பேனல். நিற்கவும் Ctrl+Alt+B பயன்படுத்தவும்.

1. வரவேற்பு

Claude Codex Black ஒரு VSCode webview ஆகும் இது ஒரு தனிப்பட்ட, பொருளாக்கக்கூடிய பேனலில் இருந்து பல AI வழங்குநர்கள் (Claude, OpenAI, Gemini, Grok, Azure, உள்ளூர் Ollama) உடன் சாட் செய்ய அனுமதிக்கிறது. விசையை தேவைப்படும் எல்லாம் config.ini இல் தொடக்க விரிவாக்கத்திலிருந்து வாசிக்கும் — விரிவாக்க அமைப்புகள் UI தேவையில்லை, ஆனால் ஒரு அமைப்புகள் மாடல் கிளிக்-மட்டுமே திருத்தத்திற்கான மிகவும் பயனுள்ள புலங்களை பிரதிபலிக்கிறது.

புதியவரா? அமைப்புகளைத் திறந்து (கியர் ஐகான்), உங்கள் வழங்குநரைத் தேர்ந்தெடுக்கவும், உங்கள் API விசை ஒட்டவும், பின்னர் ஒரு உத்தரவு வகை செய்து Enter அழுத்தவும். இந்த வழிகாட்டலில் ஆறு மற்ற அம்சமும் விருப்பமாகவே உள்ளன.

3. உத்தரவு பெட்டி

கீழே பெரிய திருத்தக்கூடிய textarea. வகை, ஒட்டு, ஒரு ஆவணத்தை இழு, paperclip மூலம் இணைக்கவும் — இங்கே நீங்கள் என்ன வைக்கிறீர்கள் என்பது அடுத்த API அழைப்பின் பயனரின் முறைவதாகும்.

எழுத்துரு உங்கள் VSCode தொరணி இன் monospace எழுத்துரு (வழியாக --vscode-editor-font-family CSS மாறி) பூட்டப்பட்டது ஆக பேனல் திருத்தியளில் வீட்டுள் தோன்றுகிறது.

4. கருவிப்பட்டை பொத்தான்கள்

கீழே வரி, இடமிருந்து வலம். ToolTips மீது தோன்றும்; பேனல் அவற்றை உங்கள் தேர்ந்தெடுக்கப்பட்ட மொழিতে நிரல் பாடும் (பார்க்கவும் மொழி).

வீடியோ பாலங்களால் உற்பத்தி வீடியோ உலாவுதல் + பார்ப்பதற்கான ஒரு பெறுபத்திய பேனல் (Sora, Veo, Runway, Bing வீடியோ Creator). Command Palette வழியாக திறக்கவும்: Claude Codex Black: Open வீடியோ Library அல்லது codexBlackEd.openVideoPlayer கட்டளை.

6. பேச்சு முதல் உரை வரை

நிமிடம் கிளிக், பேசவும், நிறுத்ததை கிளிக் (அல்லது மென்மையான மூடல்-டைம்அவுட் கோ). இரண்டு ஏவு வரிசை ஈ:

  1. Web Speech API — webview இல் இயங்கும் Google உறுதிம் recognizer. உங்கள் Gmail/Google அமர்ந்து பயன்படுத்துகிறது; எந்த விசை தேவையில்லை.
  2. Windows SAPI (fallback) — [voice] listen_seconds உல் உল்টம்-வெப்பப் PowerShell செயல்பாடு webview நிறுத்து அணுக்கத் invoked. உல் உள்ளூர் config.ini.
SAPI ஆ விரிவாக்க செயல்படுத்த பூர்வ-வெப்பம் எனவே முதல் நிமிச் கிளிக் 2-4 விநாடி குளிர் ப்தக் என்று வெளிசுவு வெளி சரவளி தவிர்க்கவும்.

7. தானியங்கி உத்தரவு

தாளக்-உடன்-spinner பொத்தான். உள், N விநாடி பூமிப்பின் பின் பேனல் தனித்த-அனுப்பப்பட்ட உங்கள் ஆ விழிப்பு உரை. அக்ர மாற்றி --cbe-highlight-color சுமந்து, ஒவ்வொரு தோல் வரையறுக்கிறது.

🔁 Wake பொத்தான் வழியாக விழிப்பு உரைத் திருத்தவும் — இது வெளியாய் wake.txt.

8. தானியங்கி வாசிப்பு (TTS)

வாய় ஐகான். உள், ஒவ்வொரு உதவியாளர் பதில் Web Speech synthesizer (Google) அல்லது SAPI fallback மூலம் பேசப்படுகிறது. நீல halo ஆ ஐ சுற்றி எல் ஆக்கு ஆக்கப் முறையமாயே.

9. சுருக்கம் & சூழல் பயன்பாடு

உரையாடல் அடை பன்மொழி மாதிரிக்கு மாடல் உடன் ஒவ்வொரு சழ்சி வளர்கிறது. compact icon சுற்றில் வளையம் தெளிதல் சூழல்-சாளரம் பயன்பாட் ஒரு conic gradient — கொத்து புதிய, ஆக்க மாடல் சூழல் தெட்ட அதிக தகவ்று கொத்திப் போர்.",

Compact கிளிக் வெட்டி வரலாற்றை கடைசி நான்கு திருப்பங்களுக்கு கீழ். அடுத்த API அழைப்பு சிறிய அডை பயன்படுத்துகிறது.

10. விழிப்பு பதில்

wake.txt ஆ விரிவாக்கம் மூல. தானியங்கி உத்தரவு பயன்படுத்தப்பட் செய்திப் அனுப்பதற்கு பூமிப்பு டைமர் தீ. 🔁 கருவிப்பட்டை பொத்தான் மூலம் திருத்தவும்.

11. ஆவண இணைப்புகள்

📎 கிளிக் ஒன்று அல்லது ஒன்றாக் அதிக ஆவணங்களைத் தேர்ந்தெடுக்க. Ctrl அல்லது Shift தேர்வித் பல-தேர்ந்தெடுக்க. ஒவ்வொரு ஆவணம் தன் ஆவணமாயம் மற்றும் மொழிக் உடன் ஒரு fenced குறிப்பு தொகுக்க உத்தரவ உள் வரிசை. வீட்ட ஆவணங்கள் 1 MB மேல் স் கொண்டு ஒரு நோட் உடன் தவிர்க்கப்পட்ட.

12. Git மாடல்

📁 Git கிளிக். எந்த திருட்டின் பாக்கெட் கட்டமைக்கப்படின்றால், நீங்கள் முதல் ஒரு பாக்கெட் தேர்வית் பெறுக — தேர்ந்தெடுக்கப்பட்ட பாக்கெட் [project] path ஆக config.ini இல் எழுதப்பட்ட. அடுத்த git invocations கட்ட cwd உடன் வரிசை இயக்குகிறது.

13. GitHub களஞ்சியங்கள்

ஒவ்வொரு repos அணுக்கத் [github] pat வரிசை. ஒரு வரி கிளிக் அதி clone URL உத்தரவ உள் உறிஞ்சு. பட்டியல் paginated மற்றும் cached.

14. NameSilo களங்கள்

ஒவ்வொரு களம் உங்கள் NameSilo கணக்கு [namesilo] api_key (அல்லது [api_keys] namesilo_api_key fallback ஆ). முதல் திறக், முடிவு domains.txt cached; அடுத்த பேனல் பூட்ட cached ஆக திசை. Reload மாடல் உல் கிளிக் ஒரு புதிய fetch வலுச்சேயவ.

நீங்கள் எவ்வொழுது "எந்த களங்கள்" 300 பதில் குறிப்பு கொண்டு பார்த்தேல், பிற்படி சேனல் நிரல் — வெறும் caches எந்த இனிமை மாற்று பூட்ட வாழ், ஆனால் மற்ற ஆக ப மாற்றி domains.txt அமர்ந்து வேணுபட்டு.

15. தோல்கள் & கருப்பொருள்கள்

🎨 பொத்தான் ஒரு தேர்வு தேர்வித் தோல் தேடுகிறது skins/ உயிரோடு (தொடக் அ), இதனால் ஒரு புதிய பாக்கெட் drop செயல்பாডு-டைம் இயங்கு போதுமான. ஒவ்வொரு தோல் ஒ manifest.xml அதி பேலட் வரையறுக்கும் — பொதுவுமை வண்ணம் உடன், தானியங்கி உத்தரவ அக்ர தாளக், கேள்வி வளையங்கள், மற்றும் மேற்பார்வையாளர் pulses அனைத்து விசை அ.

கட்டப்பட்ட தோல்கள் அடங்க: gnome (Adwaita வேளெள்), terminal (கறு/பச்சை வெ வெ-பிங்க் பொதுவுமை), tamagotchi (முட்டை-குண்ட் pastels ஒ sprite mascot பேனல் உடன்), blocky, மற்றும் மாயங்கள்.

16. அமைப்புகள்

⚙ கியர் மூலம் திறக்கவும். தாள்களை:

  • பொது — கண்காட்சி மாடல், அவாக্க மாதிரி, அனுப்பு-ஆ-enter
  • வாய்ச் — பாக் கருவி, listen_seconds, STT ஏவு தேர்வு, TTS தனித்த-வாசிப்பு
  • பதுக்কங்கள் — is_admin குறி, WinSCP அமர்ந்து, தொலக் பாக்கெட்
  • விசைகள் — ஒவ்வொரு வழங்குநர் API விசை
  • மேற்பார்வை — VSCode மேற்பார்வையாளர் இறக்கி, தைरь, poll இடைவெளி

மாடல் அறி அதি அளவு மற்றும் அமர்ந்து முதல் அமர்ந்து.

17. மொழி

பேனல் கப்பல் 39 மிகவும் பேசிய மொழிகள் மொழிபெயர்ப்புகள் உடன். Locale ஆவணங்கள் languages/<code>.xml இல் உயிரோடு முறியாய் மற்று ஒரு எக்ஸ் activate முதல் எல்டு. மிதைஇழிய விசைகள் ஆங்கிலம் வாழ்க.

அமைப்புகள் → மொழி உற்தி மொழிப் தேர்ந்தெடுக்கவும். ஒரு கொடி ஐகான் ஒவ்வொரு விரைவு அருகிலுள் (assets/flags/<code>.svg மூலம் எல்टு). தேர்வு [settings] language ஆ config.ini இல் சேமிக்கப்பட்ட.

18. VSCode மேற்பார்வையாளர்

ஒரு Windows உதவ (CBEVSCodeSupervisor) tools/vscode_supervisor.ps1 குறி NSSM வழியாக மூறி மற்றும் ஒ HttpListener இணைக்கவும் http://127.0.0.1:3434/. பேனல் மேற்பார்வை பொத்தான் கொடெய் மேற்பார்வையாளர் /status endpoint பதில் 200 முத்த ஆ.

HTTP probe பசையான ஆனால் உதவ எல்டு, பேனல் watchdog தனித்த-பெறு உதவ (30-விநாடி कूल்-பாய் இதனால் இ prot restart-புயல் என்ற).

இடக்-கிளிக் மேற்பார்வை பொத்தான் முறி / ஆ / நிறுத்து. வலக்-கிளிக் பிற்படி சேனல் திறக்க.

19. தானியங்கி-புதுப்பிப்பு (இழு)

4 விநாடி பிறகு விரிவாக்கம் activate, பேனல் fetches https://trentontompkins.com/cbe/manifest.xml.php — ஒ MD5+அளவு manifest புதியவர் வெளியிடப்பட்ட ஆவணங்கள். ஒவ்வொரு தொலக ஆவணம், உள்ளூர் நকல் MD5 ஒப்பிடு; மட்டும் மாற்றிய/விலக ஆவணங்கள் HTTPS மேல் பதிவிறக்குப் பட।

பயனர்-உள்ளூர் நிலை (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) இழு விலக்குவு பட்டியல் உள் மற்றும் எப்போதுமே மாற்றியதுமில்லை.

21. நீட்டிப்புகள் சந்தை

🧩 நீட்டிப்புகள் பொத்தான் கிளிக். ஒ iframe மாடல் திறக்கவும் https://trentontompkins.com/cbe/extension/extension_marketplace.php, ஒ extensions.xml.php மூலம் fetches கேட்டேலாக மற்று ஒவ்வொரு கிடைக்கும் நீட்டிப் ஒ வர்ணனை, தாள்களை, பதிப்பு, ஆவணம் அளவு, MD5, மற்றும் ஒ Install பொத்தான் உடன் கார்டு ஆக.

ஒ நீட்டிப் <id>.ext உல் — ஒ ஜிப் அடை manifest.xml மற்றும் நீட்டிப் குறி (ஒextension.html). நீங்கள் Install கிளிக் ஆ, சந்தை iframe வரி postMessage பேனலுக்கு; பேனல் பதிவிறக்குப் .ext ஆவணம் directly சேவக் மூலம் மற்று extract extensions/ கீழ் விரிவாக்கம் பாக்கெட்.

மூன்று demo நீட்டிப்புகள் உடன் ஆ வாழ்க வாசக, Minesweeper, மற்றும் ஒ Emoji தேர்வி.
