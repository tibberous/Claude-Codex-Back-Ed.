விரைவு தொடக்கம் ↑ top

  1. Setup (wand icon) கிளிக் செய்து உங்கள் API keys ஐ உள்ளிட wizard வழியாக செல்லுங்கள். அவை config.ini ஆக save செய்யப்படும் (which is gitignored — never committed).
  2. Bottom-left இல் provider pill கிளிக் செய்யுங்கள் (currently labeled "Codex Black Ed.") எந்த AI உடன் பேசுகிறீர்கள் என்பதை மாற்ற.
  3. Textarea இல் type செய்து Enter அழுத்தி அனுப்புங்கள். Shift+Enter newline செருகுகிறது.
  4. Empty textarea இல் ↑ அழுத்தி முந்தைய prompts ஐ recall செய்யுங்கள் (PowerShell-style history).

ஒவ்வொரு bridge ஓ ஒரு சிறிய C++ tray exe at bin/CBE-Bridge-<Target>.exe இது logged-in Chrome profile ஐ திறக்கிறது, உங்கள் prompt ஐ intercept செய்து, model ன் reply ஐ திருப்பி கொடுக்கிறது. Settings இல் bridge provider தேர்ந்தெடுப்பது matching exe ஐ auto-launch செய்கிறது. நீங்கள் bridge ஐ முதல் முறை பயன்படுத்தும் போது அதன் Chrome window இல் site க்கு log in செய்ய வேண்டும்.

Bridge chat speaks a line-protocol on TCP: one JSON line in ({action:"chat", target, message, model}), one JSON line out. No api key required.

செய்திகளை அனுப்புதல் ↑ top

Textarea
உங்கள் prompt type செய்யுங்கள். Enter அனுப்புகிறது, Shift+Enter newline செருகுகிறது. Reply stream செய்யும் போது, கூடுதல் prompts queued மற்றும் order இல் அனுப்பப்படும் — placeholder இந்த state இல் "Queue another message…" காட்டுகிறது.
Send button (orb)
Textarea ன் வலது edge இல் round button. Enter போன்றது. Visually மூன்று states காட்டுகிறது (idle / hover / active).
Stop button
Composer ன் bottom-right. Currently-streaming reply மற்றும் queued messages ஐ cancel செய்கிறது. Streamed text keep செய்யப்படும்; only in-flight request abort செய்யப்படும்.
Provider pill
Composer ன் bottom-left. ஒவ்வொரு configured provider இன் dropdown க்கு click செய்யுங்கள். புதிய ஒன்றை pick செய்வது auto-start செய்கிறது அதன் bridge (if applicable) மற்றும் confirmation toast post செய்கிறது.
Prompt history
↑ / ↓ empty textarea இல் கடந்த 500 prompts வழியாக backward / forward walk செய்யுங்கள் (PowerShell-style). History stored at prompt_history.txt extension folder இல் மற்றும் panel reloads ஐ survive செய்கிறது.

Toolbar buttons ↑ top

Toolbar order இல் listed. All tooltips are localizable per-language via languages/*.xml.

New conversation addBtn
Current thread ஐ clear செய்கிறது, in-memory conversation state ஐ wipe செய்கிறது, மற்றும் fresh start செய்கிறது. Previous thread disk இல் preserved chats/<UTC-date>.log under so nothing is lost. Equivalent to /clear.
Stored prompts storedPromptsBtn
Every saved prompt template listing modal open செய்கிறது stored_prompts/ under. Textarea இல் insert செய்ய ஒன்றை click செய்யுங்கள்; "+" button புதிய template add செய்கிறது. Templates support variable substitution.
Chat history chatHistoryBtn
On-disk chat log browse செய்கிறது (one file per UTC date under chats/). Past conversations through scroll back செய்ய date pick செய்யுங்கள்.
Attach file attachFileBtn
File picker open செய்கிறது. Selected file next prompt உடன் upload செய்யப்படும் — images inline go (vision), text/code files fenced block ஆக உங்கள் prompt இல் ஆகும். Supports multi-attach.
Read aloud (TTS) ttsBtn
Most recent assistant reply ஐ aloud speak செய்கிறது. ElevenLabs (if [elevenlabs] api_key is set) அல்லது Windows SAPI க்கு fallback. Right-click toggles auto-read mode which every new reply automatically spoken — button animated indicator gets while active.
Speech to text (STT) sttBtn
Microphone audio record செய்து textarea இல் transcribe செய்கிறது. Webview ன் Web Speech API முதல் try செய்கிறது; that fails (not-allowed, common in VSCode sandboxes), Windows SAPI க்கு fallback (System.Speech.Recognition) host via PowerShell launch செய்யப்படும். Again stop செய்ய click செய்யுங்கள்.
Auto Prompt autoReplyBtn
Auto Prompt modal open செய்கிறது. Prompt + countdown interval define செய்யுங்கள்; ஒவ்வொரு assistant reply க்குப் பிறகு countdown tick மாடும் மற்றும் zero hit செய்யும் போது auto-prompt automatically re-send செய்யும். Useful for "keep going", "next step", repeated tool sessions. Again disable செய்ய click செய்யுங்கள்.
Wake-up response wakeUpBtn
Wake-up message stored at wake.txt edit செய்கிறது. Wake-up என்பது Auto Prompt அனுப்புவது model stalled detect செய்தால் — generally short ping like "Hey! Continue."
Show command menu showCommandsBtn
Slash-command palette modal இல் open செய்கிறது. Full list க்கு Slash commands பார்க்கவும். Textarea ன் start இல் / type செய்வதற்கு same.
Compact conversation compactBtn
Summarize-and-prune request post செய்கிறது current thread ஐ condensed recap உடன் replace செய்கிறது. Equivalent to /compact. Conversation long grow செய்யும் போது context keep செய்ய ஆனால் re-sending whole history பற்றிய tokens burn stop செய்ய விரும்பும் போது useful.
Handbook handbookBtn
Employee/project handbook modal open செய்கிறது. handbook.html அல்லது configured document load செய்கிறது. Used as system-prompt reference model consult செய்யக் கூறப்படாம்.
Settings settingsBtn
Settings modal open செய்கிறது (provider, model, skin, language, SFX). Settings பார்க்கவும்.
Accounts accountsBtn
Multi-account manager open செய்கிறது. Add / edit / remove API keys per provider, per session between switch செய்யுங்கள். Accounts பார்க்கவும்.
Extensions extensionsBtn
In-panel extensions browser open செய்கிறது. extensions/ under what's installed list செய்கிறது (ஒவ்வொரு manifest.xml + entry HTML உடன்), extensions toolbar இல் pin செய்ய விடுகிறது, public catalog இலிருந்து புதியவை install செய்யவும் அல்லது remove செய்யவும்.
Project folder projectFolderBtn
Working directory pick செய்கிறது Attach File, Terminal, Git, மற்றும் project root தேவைப்படும் tools பயன்படுத்தப்படும். Current folder shown provider pill ன் அடுத்து.
Browser browserBtn
Side-by-side QtWebEngine browser pane open செய்கிறது quick lookups க்கு panel छोडना இல்லாமல்.
VSCode monitor monitorBtn
VSCode supervisor watchdog toggle செய்கிறது — background process which restarts VSCode if crashes. Left-click run/stop toggle செய்கிறது, right-click supervisor ன் trace channel open செய்கிறது.
Terminal terminalBtn
VSCode integrated terminal open செய்கிறது project folder இல். Project folder set இல்லை, Desktop க்கு fallback. One persistent terminal reuses labeled "CBE".
Setup wizard setupBtn
ஒவ்வொரு API key + integration walk செய்கிறது extension knows about (~12 steps). Setup wizard பார்க்கவும்.
Git gitBtn

Domains (NameSilo) domainsBtn

Modals & dialogs ↑ top

Settings modal — provider / model / skin / language / SFX
  • Provider: ஒவ்வொரு direct-API + bridge provider ன் full dropdown. Picking one active session switch செய்கிறது AND matching bridge exe auto-start செய்கிறது (if applicable).
  • Model: per-provider list allowed models ன் (e.g. claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 for Anthropic).
  • Skin: visual theme. Skins பார்க்கவும்.
  • Language: 39 locales available. Switching re-pulls strings map மற்றும் ஒவ்வொரு tooltip / label / help button live re-translates.
  • SFX enabled: UI sound effects toggle (clicks, ticks, modal open/close, etc.).
  • SFX volume: 0–100 slider. Previewed live as drag.
  • Cancel reverts any live previews (SFX/skin) tried; Save persists மற்றும் setProvider emits.
Setup wizard — multi-step API key entry

ஒவ்வொரு integration ன் walk-through. ஒவ்வொரு step credentials ask செய்து config.ini இல் write செய்கிறது. Skip without advancing; Next writes மற்றும் advances; final step ன் Done closes. Steps include: Anthropic, OpenAI, Gemini, xAI/Grok, GitHub PAT, Email/SMTP (Gmail app password), Cloudflare, Twilio, ElevenLabs, Stability AI, Runway, SendGrid, NameSilo, மற்றும் more.

Accounts modal — multi-account API key manager

ஒவ்வொரு provider க்கு, multiple labeled accounts manage செய்யுங்கள் (e.g. "personal", "work"). Per-session which one active switch செய்யுங்கள் without overwriting others. Keys masked end-to-end மற்றும் saved per-provider in config.ini.

Domains modal — NameSilo

NameSilo account ன் ஒவ்வொரு domain list செய்கிறது nameservers + registration dates உடன். Reload button fresh API fetch force செய்கிறது (otherwise caches in domains.txt).

Handbook modal

Project handbook HTML render செய்கிறது (intended as system-prompt reference model consult செய்யக் கூறப்படாம்). Per-project configurable.

Stored prompts modal

Insertable prompt templates from stored_prompts/. ஒவ்வொரு file ஒன்று template; filename prefix NN- sort order control செய்கிறது. "+" button புதிய ஒன்று create செய்கிறது.

Chat history modal

UTC date pick செய்து chats/<date>.log chat log load செய்யுங்கள். Read-only.

Extensions modal

ஒவ்வொரு installed extension க்கு cards. Pin to toolbar / unpin, public catalog (extensions.xml.php on server) இலிருந்து install, அல்லது disk இலிருந்து remove.

Change log modal

panel/change_log.html render செய்கிறது — bundled release notes. tools/build_changelog.py via generated.

View Source modal

Any code block அல்லது panel ன் full HTML pretty-print செய்கிறது, Prism syntax highlighting மற்றும் Copy button உடன். Right-click → View Source via reached.

Auto Prompt modal

Prompt string + countdown interval configure செய்யுங்கள். ஒவ்வொரு assistant reply க்குப் பிறகு countdown decrements; zero hit செய்யும் போது CBE configured prompt auto-send செய்கிறது. Toggled on/off via Auto Prompt toolbar button.

Settings ↑ top

All settings live ஓ இரண்டு places ன்:

  • workspaceState (VSCode-managed, per-workspace) — provider, model, skin, language, sfx enabled/volume, font size.
  • config.ini (extension root, gitignored) — API keys + per-integration credentials.

Settings persist across panel reloads automatically. Settings modal safe way anything change செய்ய; editing config.ini directly works too.

Accounts & API keys ↑ top

Skins ↑ top

Whole panel — buttons, modals, code blocks, even font — visual themes. Settings → Skin இல் ஒன்றை pick. ஒவ்வொரு skin lives in skins/<id>/ with manifest.xml (declares colors + accent) மற்றும் styles.css (overrides CSS variables).

  • codex-black (default) — dark, monospace, neon-cyan accent
  • glassy — frosted-glass surfaces soft backdrop over
  • tamagotchi — lime-green LCD handheld; auto-show pet widget docked composer corner இல்

Extensions ↑ top

Mini-apps which live inside CBE. ஒவ்வொரு ஓ folder under extensions/<id>/ with:

  • manifest.xml — id, name, version, author, description, entry HTML, icon (emoji அல்லது icon.svg)
  • extension.html (அல்லது manifest ன் <entry> says) — actual app

Extensions click செய்து browse installed, pin to toolbar, public catalog இலிருந்து புதியவை install, அல்லது disk இலிருந்து remove. Pinned IDs live in extensions/_pinned.json.

Auto-update (push / pull) ↑ top

CBE syncs source between machines via WinSCP push + HTTPS pull channel.

Push (admin only)

If [updates] is_admin = true in config.ini, ஒவ்வொரு activation runs background WinSCP synchronize remote -mirror which pushes extension folder to /home/trentontompkins.com/cbe on server. Manual trigger: /push slash command. Excludes per-machine state: data/ (1.74 GB Chrome profiles), bridges/, node_modules/, .git/, logs/, chats/, config.ini, prompt_history.txt, domains.txt, wake.txt.

Pull (every client)

4 seconds பிறகு activation, ஒவ்வொரு client fetches https://trentontompkins.com/cbe/manifest.xml.php மற்றும் MD5-compare per-file against local copies. Only changed/missing files downloaded plain HTTPS GET over. Excluded paths NEVER pulled: config.ini, data/, bridges/, extension.js, panel/panel.js, panel/index.html, package.json, build tools — rationale being which source ships via .vsix மற்றும் server ன் older copy mustn't clobber in-progress dev work.

Hot reload ↑ top

Two reload paths exposed via right-click menu:

  • Reload Panel — re-reads panel/index.html + every JS/CSS asset with per-file ?v=<mtime> cache-buster மற்றும் reassigns panel.webview.html. Picks up panel.js / skin CSS / dotmatrix edits without VSCode reboot. Extension host stays alive (terminal, supervisor, message handlers, chat history all persist).
  • Reload Window — fires workbench.action.reloadWindow. Use only when extension.js (host-side code) edited மற்றும் Reload Panel பர்யாப்தம் இல்லை.

Skin CSS edits also auto-apply via panel ன் existing skin watcher — menu click need.

Troubleshooting ↑ top

"bridge X chat failed: api key empty in config.ini"

Smart_bridge.py daemon ஓ caching old gating check in memory. Fixed C++-exe routing pivot இல். Still see, stale daemons kill:

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
"copilot has no public REST API — use the browser bridge"

Old extension.js ஓ routing bridge chat through REST router instead actual C++ tray exe. Reload Window to pick up fixed extension.js, then chat goes straight bin/CBE-Bridge-Copilot.exe to.

HTTP 404 model: sonnet-4.6

Outdated short alias Claude bridge config இல். Fixed — full IDs (claude-sonnet-4-6, claude-opus-4-7, claude-haiku-4-5) now used.

I edited a file but the panel doesn't show the change
  1. If it's panel.js / skins/*.css / index.html → right-click → Reload Panel.
  2. If it's extension.js / bridges_cpp/*.py → right-click → Reload Window.
  3. If menu reach can't (e.g. menu itself isn't loaded yet), launch fresh VSCode instance isolated user-data-dir உடன்:
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Codex Black"
STT fails with "not-allowed"

VSCode sandboxes webview microphone permission இலிருந்து. CBE auto-falls-back Windows SAPI (System.Speech.Recognition) PowerShell via launched. Mic access OS level grant need (Settings → Privacy → Microphone).

Bridge exe missing

Trace log shows BRIDGE:MISSING target=<t> expected=<path>. C++ tray exes live in bin/CBE-Bridge-<Pretty>.exe. Yours exist don't, rebuild from bridges_cpp/ source (MSVC) அல்லது pull fresh .vsix.
