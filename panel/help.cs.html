Codex Black Ed.

Samostatný AI panel pro VSCode. Chatujte s jakýmkoli poskytovatelem LLM (přímé API nebo přemostění v prohlížeči) s vestavěným TTS, STT, přílohami k souborům, paletou příkazů, správou více účtů, skiny a pixel-pet Tamagotchi.

Rychlý start ↑ nahoru

  1. Klikněte na Setup (ikona čarodějky) a projděte průvodcem, abyste zadali své klíče API. Ty se uloží do config.ini (který je v .gitignore — nikdy se nepotvrzuje).
  2. Klikněte na pill poskytovatele v levém dolním rohu (aktuálně označený „Codex Black Ed.") a přepněte se na to, s kterou AI si chcete povídat.
  3. Zadejte text do textové oblasti a stiskněte Enter pro odeslání. Shift+Enter vloží nový řádek.
  4. Stiskněte ↑ v prázdné textové oblasti, abyste si vzpomněli na předchozí prompty (historie ve stylu PowerShellu).

Každý most je malý exe v C++ v systému bin/CBE-Bridge-<Target>.exe, který otevře přihlášený profil Chrome, zachytí váš prompt a vrátí odpověď modelu. Výběr poskytovatele mostu v Nastavení automaticky spustí příslušný exe. Poprvé, když použijete most, se musíte přihlásit na stránce v jeho okně Chrome.

Mostní chat používá line-protocol na TCP: jeden JSON řádek vstup ({action:"chat", target, message, model}), jeden JSON řádek výstup. Není vyžadován žádný api klíč.

Posílání zpráv ↑ nahoru

Textová oblast
Zadejte svůj prompt. Enter odešle, Shift+Enter vloží nový řádek. Během streamování odpovědi jsou další prompty zařazeny do fronty a poslány postupně — zástupný text během tohoto stavu ukazuje „Zařadit další zprávu do fronty…".
Tlačítko Odeslat (koule)
Kulaté tlačítko na pravém okraji textové oblasti. Stejné jako Enter. Vizuálně zobrazuje tři stavy (nečinný / přesun / aktivní).
Tlačítko Zastavit
Vpravo dole od autora. Zruší aktuálně streamovanou odpověď a všechny zařazené zprávy. Streamovaný text se zachovává; pouze letící požadavek se přeruší.
Pill poskytovatele
Vlevo dole od autora. Klikněte pro rozbalovací seznam každého poskytovatele, kterého jste nakonfigurovali. Výběr nového automaticky spustí jeho most (je-li k dispozici) a odešle potvrzovací toast.
Historie promptů
↑ / ↓ v prázdné textové oblasti se pohybuje zpět / vpřed posledních 500 promptů, které jste poslali (ve stylu PowerShellu). Historie se ukládá na prompt_history.txt ve složce rozšíření a přežije opětovné načtení panelu.

Tlačítka nástrojů ↑ nahoru

Uvedeno v pořadí nástrojů. Všechny popisy nástrojů jsou lokalizovatelné podle jazyka přes languages/*.xml.

Nová konverzace addBtn
Vymaže aktuální vlákno, smaže stav konverzace v paměti a začne znovu. Předchozí vlákno se uloží na disk pod chats/<UTC-date>.log, takže se nic neztratí. Ekvivalent /clear.
Uložené prompty storedPromptsBtn
Otevře modální okno se seznamem každé uložené šablony promptu pod stored_prompts/. Klikněte na jednu, aby se vložila do textové oblasti; tlačítko „+" přidá novou šablonu. Šablony podporují nahrazení proměnných.
Historie chatu chatHistoryBtn
Prochází protokol chatu na disku (jeden soubor na UTC datum pod chats/). Vyberte datum, abyste se podívali zpět na minulé konverzace.
Připojit soubor attachFileBtn
Otevře výběr souborů. Vybraný soubor se nahraje s dalším promptem — obrázky budou vloženy (vision), textové/kódové soubory se stanou blok v ohradě ve vašem promptu. Podporuje vícenásobné připojení.
Čtení nahlas (TTS) ttsBtn
Vysloví poslední odpověď asistenta. Používá ElevenLabs (je-li nastaven [elevenlabs] api_key) nebo se vrátí k Windows SAPI. Kliknutí pravým tlačítkem přepíná režim automatického čtení, kde je každá nová odpověď automaticky vyslovena — tlačítko během aktivního stavu získá animovaný indikátor.
Převod řeči na text (STT) sttBtn
Nahraje zvuk mikrofonu a přepíše jej do textové oblasti. Nejprve se pokusí o Web Speech API webového zobrazení; pokud to selže (not-allowed, běžné v izolovaných prostředích VSCode), vrátí se k Windows SAPI (System.Speech.Recognition) spuštěné na hostiteli přes PowerShell. Klikněte znovu, abyste zastavili.
Automatický prompt autoReplyBtn
Otevře modální okno Automatický prompt. Definujte prompt a interval odpočtu; po každé odpovědi asistenta se odpočet snižuje a po dosažení nuly automaticky znovu odešle automatický prompt. Užitečné pro „pokračuj", „další krok", opakované relace nástrojů. Klikněte znovu, abyste vypnuli.
Odpověď na probuzení wakeUpBtn
Upravuje zprávu probuzení uloženou na wake.txt. Probuzení je to, co Automatický prompt pošle, pokud zjistí, že se model zasekl — obecně krátký ping jako „Hej! Pokračuj."
Zobrazit nabídku příkazů showCommandsBtn
Otevře paletu slash-příkazů v modálním okně. Podívejte se na Slash příkazy pro úplný seznam. Stejné jako zadání / na začátek textové oblasti.
Komprimovat konverzaci compactBtn
Odešle požadavek na shrnutí a prořezávání, který nahradí aktuální vlákno kondenzovaným souhrnem. Ekvivalent /compact. Užitečné, když se konverzace prodloužila a chcete si ponechat kontext, ale přestat spalovat tokeny na opětovné odesílání celé historie.
Příručka handbookBtn
Otevře modální okno příručky zaměstnance/projektu. Načte handbook.html nebo jakýkoli nakonfigurovaný dokument. Používá se jako reference systémového promptu, kterou je model požádán, aby konzultoval.
Nastavení settingsBtn

Účty accountsBtn
Otevře správce více účtů. Přidejte / upravte / odeberte klíče API na poskytovatele, přepínejte mezi nimi za relaci. Podívejte se na Účty.
Rozšíření extensionsBtn
Otevře prohlížeč rozšíření v panelu. Uvádí, co je nainstalováno pod extensions/ (každé s manifest.xml + vstupem HTML), umožňuje připnout rozšíření na nástrojovou lištu, nainstalovat nové z veřejného katalogu nebo je odebrat.
Složka projektu projectFolderBtn

Prohlížeč browserBtn
Otevře vedle sebe panel prohlížeče QtWebEngine pro rychlé vyhledávání bez opuštění panelu.
Monitor VSCode monitorBtn
Přepíná strážce dozoru VSCode — proces na pozadí, který restartuje VSCode, pokud se zhroutí. Levé kliknutí přepíná spuštění/zastavení, pravé kliknutí otevře kanál trasování supervizora.
Terminál terminalBtn
Otevře integrovaný terminál VSCode ve složce projektu. Pokud složka projektu není nastavena, vrátí se k vašему Počítači. Znovu používá jeden trvalý terminál označený „CBE".
Průvodce nastavením setupBtn

Kontextová nabídka ↑ nahoru

Klikněte pravým tlačítkem na text chatu nebo blok kódu, abyste dostali kontextovou nabídku CBE. Kliknutí pravým tlačítkem na textovou oblast promptu nyní otevře nativní nabídku prohlížeče (Kopírovat / Vyjmout / Vložit / Smazat / Vybrat vše).

Kopírovat / Kopírovat blok kódu
Kopíruje aktuální výběr. Pokud není výběr, ale klikli jste pravým tlačítkem na <pre><code>, zkopíruje celý blok kódu.
Zobrazit zdroj
Zobrazuje surový HTML/markdown kliknuté oblasti — buď blok kódu nebo celý DOM panelu. Užitečné pro ladění problémů s skinem/CSS.
Otevřít DevTools
Požádá VSCode, aby otevřel Developer Tools, abyste mohli živě kontrolovat webové zobrazení.
Nastavení nové
Otevře stejné modální okno Nastavení, které otevírá tlačítko nástrojů Nastavení (poskytovatel / model / skin / jazyk / SFX). Stejné jako /settings.
Informace nové
Malý dialog v panelu s verzí, autorem, licencí, odkazem na repo, portfoliem a kontaktním telefonem. Zavře se kliknutím na pozadí, tlačítkem × nebo Esc.
Načíst panel znovu nové
Znovu přečte panel/index.html + panel.js + skins/* s ?v=<mtime> cache-busterem pro jednotlivé soubory a znovu přiřadí panel.webview.html. Vybere CSS/JS úpravy bez restartování VSCode. Hostitele rozšíření zůstane naživu — terminál, supervizor, historie chatu všechno přetrvává.
Načíst okno znovu nové
Spustí workbench.action.reloadWindow. Použijte to pouze, když jste upravili extension.js (kód na straně hostitele) a opětovné načtení panelu není dostatečné. Je to úplné opětovné načtení okna VSCode.

Modální okna a dialogy ↑ nahoru

Modální okno Nastavení — poskytovatel / model / skin / jazyk / SFX
  • Poskytovatel: úplný rozbalovací seznam každého poskytovatele přímého API a mostu. Výběr jednoho přepíná aktivní relaci A automaticky spustí odpovídající exe mostu (je-li to vhodné).
  • Model: seznam povolených modelů pro jednotlivé poskytovatele (např. claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 pro Anthropic).
  • Skin: vizuální motiv. Podívejte se na Skiny.
  • Jazyk: 39 dostupných jazyků. Přepínání znovu načte mapu řetězců a live přeloží každý popis nástroje / popis / tlačítko nápovědy.
  • SFX povoleno: přepnutí zvukových efektů UI (kliknutí, tikání, otevření/zavření modálu atd.).
  • Hlasitost SFX: posuvník 0–100. Náhled živě při přetahování.
  • Zrušit vrátí zpět všechny živé náhledy (SFX/skin), které jste vyzkoušeli; Uložit trvale zachová a vydá setProvider.
Průvodce nastavením — vícekrokový vstup klíče API

Procházka přes každou integraci. Každý krok požádá o přihlašovací údaje a zapíše je do config.ini. Přeskočit postupuje bez zápisu; Další zapíše a postupuje; poslední krok Hotovo zavře. Kroky zahrnují: Anthropic, OpenAI, Gemini, xAI/Grok, GitHub PAT, Email/SMTP (heslo aplikace Gmail), Cloudflare, Twilio, ElevenLabs, Stability AI, Runway, SendGrid, NameSilo a další.

Modální okno Účty — správce klíčů API více účtů

Pro každého poskytovatele spravujte více účtů s popisky (např. „osobní", „pracovní"). Bez přepsání ostatních přepínejte, který je aktivní za relaci. Klíče jsou maskované end-to-end a uložené na poskytovatele v config.ini.

Modální okno Domény — NameSilo

Uvádí každou doménu v účtu NameSilo s nameservery a daty registrace. Tlačítko Načíst znovu vynutí nové načtení rozhraní API (jinak se ukládá do mezipaměti v domains.txt).

Modální okno Příručka

Vykresluje projekt příručku HTML (určený jako reference systémového promptu, který může model konzultovat). Konfigurovat pro jednotlivé projekty.

Modální okno Uložené prompty

Vložitelné šablony promptů z stored_prompts/. Každý soubor je jedna šablona; předpona názvu souboru NN- řídí pořadí řazení. Tlačítko „+" vytvoří novou.

Modální okno Historie chatu

Vyberte UTC datum, aby se načetl protokol chatu z chats/<date>.log. Pouze pro čtení.

Modální okno Rozšíření

Karty pro každé nainstalované rozšíření. Připnout na nástrojovou lištu / odepnout, nainstalovat z veřejného katalogu (extensions.xml.php na serveru) nebo odebrat z disku.

Modální okno Protokol změn

Vykresluje panel/change_log.html — poznámky k vydané verzi. Generuje se přes tools/build_changelog.py.

Modální okno Zobrazit zdroj

Pěkně formátuje jakýkoli blok kódu nebo plný HTML panelu se zvýrazněním syntaxe Prism a tlačítkem Kopírovat. Dostupné přes pravé kliknutí → Zobrazit zdroj.

Modální okno Automatický prompt

Nakonfigurujte řetězec promptu a interval odpočtu. Po každé odpovědi asistenta se odpočet snižuje; když dosáhne nuly, CBE automaticky odešle nakonfigurovaný prompt. Přepíná se zapnuto/vypnuto přes tlačítko nástrojů Automatický prompt.

Nastavení ↑ nahoru

Všechna nastavení se nacházejí na jednom ze dvou míst:

  • workspaceState (spravováno VSCode, na pracovní prostor) — poskytovatel, model, skin, jazyk, sfx povoleno/hlasitost, velikost písma.
  • config.ini (kořen rozšíření, gitignored) — klíče API a pověřovací údaje na integraci.

Nastavení se automaticky uchovávají při opětovném načtení panelu. Modální okno Nastavení je bezpečný způsob, jak cokoliv změnit; přímá úprava config.ini také funguje.

Účty a API klíče ↑ nahoru

Každý poskytovatel může mít více účtů s popisky — užitečné, pokud chcete přepínat mezi osobními a pracovními klíči nebo testovat jinou úroveň. Modální okno Účty vám umožňuje:

  • Přidat nový účet s popiskem a klíčem
  • Upravit stávající účet (přepopsat popis, nahradit klíč)
  • Nastavit, který účet je aktivní pro aktuální relaci
  • Odebrat účet

Klíče se uchovávají maskované (viditelné pouze poslední čtyři) v config.ini. V workspaceState není žádná kopie ve formátu prostého textu.

Tamagotchi pet ↑ nahoru

Tamagotchi je pixel-artový pet, který žije v panelu pod skinem tamagotchi. Stárne, cítí hlad/špinu, lze si s ním hrát a umírá, pokud je dostatečně dlouho zanedbáván. Stav se uchovává v workspaceState.

Statistiky (horní část widgetu)

StatistikaCo sleduje
🥚 FázeŽivotní cyklus: vejce → miminko → dítě → teenager → dospělý → senior → mrtvý. Stárne v reálném čase minut.
🍖 Hlad0–100. Klesá v čase; Krmit to zvyšuje. Když dosáhne 0 → zdraví klesá.
😀 Štěstí0–100. Klesá v čase; Hrát si to zvyšuje.
❤️ Zdraví0–100. Klesá, když je nemocný nebo hladoví. Injekce to vyléčí.
✨ Čistota0–100. Klesá, když pet zmrská. Čistit to zvyšuje.
⏱ VěkMinuty od vylíhnutí.

Tlačítka akcí v LCD (dolní část widgetu)

IkonaAkce
🍖Krmit — cyklus maso ↔ baklažán. Vybrat, aby se skutečně nakrmil.
🧹Čistit — zametat zmrsku.
⚾Hrát si — minihra; zvyšuje štěstí.
💉Injekce — vyléčí, když je nemocný.
💡Světlo — přepnout lampu LCD; pet spí v temnu.
✅Vybrat — potvrdit / pokračovat (ekvivalent původního středního tlačítka Bandai).

Sprite petu se kreslí do plátna 240×240 (kompakt: 138×116). Sprity a logika životního cyklu se nacházejí v panel/dotmatrix-tamagotchi-sprites.js a panel/dotmatrix-tamagotchi-game.js.

Skiny ↑ nahoru

Vizuální motivy pro celý panel — tlačítka, modály, bloky kódu, dokonce i písmo. Vyberte si jeden v Nastavení → Skin. Každý skin se nachází v skins/<id>/ s manifest.xml (deklaruje barvy a akcent) a styles.css (přepíše proměnné CSS).

  • codex-black (výchozí) — tmavý, monospace, neonově-azurový akcent
  • glassy — zamrzlé povrchy přes měkké pozadí
  • tamagotchi — limetko-zelené LCD handheld; automaticky zobrazuje widget petu zakotveného v rohu autora
  • office — styl Wordu krém/modrý chrom
  • macos-color-dock / mint-dock — dolní lišty panelu nástrojů se skleněnými ikonami
  • terminal / arch / kde / gnome / xfce / ubuntu / redhat — témata linuxového desktopového prostředí

Barvy modálu vycházejí z položek <colors> v manifestu každého skinu a jsou vloženy do :root jako proměnné --cbe-modal-*, takže se každý modál (včetně této nápovědy) vykresluje v motivu.

Rozšíření ↑ nahoru

Mini-aplikace, které se nacházejí uvnitř CBE. Každá je složka pod extensions/<id>/ s:

  • manifest.xml — id, název, verze, autor, popis, vstupní HTML, ikona (emoji nebo icon.svg)
  • extension.html (nebo cokoli, co manifest říká <entry>) — skutečná aplikace

Klikněte na Rozšíření, abyste procházeli co je nainstalováno, připnuli na nástrojovou lištu, nainstalovali nové z veřejného katalogu nebo odebrat z disku. Připnuté ID se nacházejí v extensions/_pinned.json.

Automatická aktualizace (push / pull) ↑ nahoru

CBE synchronizuje svůj zdroj mezi stroji přes kanál push WinSCP + HTTPS pull.

Push (pouze správce)

Pokud je [updates] is_admin = true v config.ini, každá aktivace spustí na pozadí WinSCP synchronize remote -mirror, která odešle složku rozšíření na /home/trentontompkins.com/cbe na serveru. Ruční spuštění: /push slash příkaz. Vyloučeno stav na jednotlivých strojích: data/ (1,74 GB profily Chrome), bridges/, node_modules/, .git/, logs/, chats/, config.ini, prompt_history.txt, domains.txt, wake.txt.

Pull (každý klient)

4 sekundy po aktivaci každý klient načte https://trentontompkins.com/cbe/manifest.xml.php a MD5-porovnává soubory proti místním kopiím. Pouze změněné/chybějící soubory se stahují přes prostý HTTPS GET. Vyloučené cesty se NIKDY nestahuní: config.ini, data/, bridges/, extension.js, panel/panel.js, panel/index.html, package.json, nástroje pro vytváření — důvod je, že zdroj se dodává přes .vsix a starší kopie serveru nesmí přepsat průběžné vývojové práce.

Hot reload ↑ nahoru

Dvě cesty opětovného načtení jsou vystaveny přes kontextovou nabídku:

  • Načíst panel znovu — znovu přečte panel/index.html + každý prostředek JS/CSS s ?v=<mtime> cache-busterem pro jednotlivé soubory a znovu přiřadí panel.webview.html. Vybere úpravy panel.js / skin CSS / dotmatrix bez restartování VSCode. Hostitel rozšíření zůstane naživu (váš terminál, supervizor, obslužné programy zpráv, historie chatu všechno zůstane).
  • Načíst okno znovu — spustí workbench.action.reloadWindow. Použijte pouze, když jste upravili extension.js (kód na straně hostitele) a Načíst panel znovu nestačí.

Úpravy CSS skinu se také automaticky aplikují přes stávajícího sledovače skinu panelu — není potřeba kliknutí na nabídku.

Řešení problémů ↑ nahoru

„bridge X chat failed: api key empty in config.ini"

Daemon smart_bridge.py uchovával starou kontrolu brány v paměti. Opraveno v otočení C++-exe. Pokud ji stále vidíte, zabijte zastaralé demony:

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
„copilot has no public REST API — use the browser bridge"

Staré extension.js směrovalo mostní chat přes router REST místo skutečného exe tray. Načtěte okno znovu, aby se vyzvedlo opravené extension.js, pak bude chat jít přímo na bin/CBE-Bridge-Copilot.exe.

HTTP 404 model: sonnet-4.6

Zastaralý krátký alias v konfiguraci Claude mostu. Opraveno — nyní se používají úplné ID (claude-sonnet-4-6, claude-opus-4-7, claude-haiku-4-5).

Upravil jsem soubor, ale panel nezobrazuje změnu
  1. Pokud je to panel.js / skins/*.css / index.html → kliknutí pravým tlačítkem → Načíst panel znovu.
  2. Pokud je to extension.js / bridges_cpp/*.py → kliknutí pravým tlačítkem → Načíst okno znovu.
  3. Pokud nemůžete dosáhnout nabídky (např. nabídka sama se ještě nenačetla), spusťte novou instanci VSCode s izolovaným uživatelským datovým adresářem:
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Codex Black"
STT se nezdaří s „not-allowed"

VSCode izoluje webové zobrazení od povolení mikrofonu. CBE se automaticky vrátí k Windows SAPI (System.Speech.Recognition) spuštěnému přes PowerShell. Možná bude nutné udělit přístup k mikrofonu na úrovni OS (Nastavení → Soukromí → Mikrofon).

Most exe chybí

Protokol trasování zobrazuje BRIDGE:MISSING target=<t> expected=<path>. Exe tray v C++ se nacházejí v bin/CBE-Bridge-<Pretty>.exe. Pokud vaše neexistují, přestavte ze zdroje bridges_cpp/ (MSVC) nebo stáhněte nový .vsix.
