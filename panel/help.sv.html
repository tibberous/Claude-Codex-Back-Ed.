Claude Codex — Black Edition

Fristående AI-panel för VSCode. Chatta med vilken LLM-leverantör som helst (direkt API eller webbläsarbro), med inbyggd TTS, STT, bifoga-till-fil, kommandopallett, multi-konto, skinnor och en pixel-husdjur Tamagotchi.

Snabbstart ↑ topp

  1. Klicka på Setup (trollstav-ikon) och gå igenom guiden för att ange dina API-nycklar. De sparas i config.ini (som är gitignorerad — aldrig committad).
  2. Klicka på leverantörspillret i nedre vänstra hörnet (för närvarande märkt "Claude Codex — Black Edition") för att växla vilken AI du chattar med.
  3. Skriv i textarean och tryck Enter för att skicka. Shift+Enter infogar en ny rad.
  4. Tryck ↑ i en tom textarea för att hämta tidigare prompter (PowerShell-stilhistorik).

Varje bro är en liten C++-bricka-exe på bin/CBE-Bridge-<Target>.exe som öppnar en inloggad Chrome-profil, avlyssnar din prompt och returnerar modellens svar. Att välja en broleverantör i Inställningar startar automatiskt motsvarande exe. Första gången du använder en bro måste du logga in på webbplatsen i dess Chrome-fönster en gång.

Bridge-chatt använder ett radprotokoll över TCP: en JSON-rad in ({action:"chat", target, message, model}), en JSON-rad ut. Ingen API-nyckel krävs.

Skicka meddelanden ↑ topp

Textarea
Skriv din prompt. Enter skickar, Shift+Enter infogar en ny rad. Medan ett svar strömmas är ytterligare prompter köade och skickas i ordning — platshållaren visar "Köa ett annat meddelande…" i det här tillståndet.
Skicka-knapp (orb)
Den runda knappen på höger kant av textarean. Samma som Enter. Visar visuellt tre tillstånd (vilande / hovra / aktiv).
Stoppknapp
Nedre höger i komponisten. Avbryter det för närvarande strömade svaret och alla köade meddelanden. Strömmat text behålls; endast förfrågan i flygning avbryts.
Leverantörspill
Nedre vänster i komponisten. Klicka för en listruta med varje leverantör du har konfigurerat. Att välja en ny startar automatiskt dess bro (om tillämpligt) och postar ett bekräftelsemeddelande.
Prompthistorik
↑ / ↓ i en tom textarea går bakåt / framåt genom de senaste 500 prompterna du har skickat (PowerShell-stil). Historiken lagras på prompt_history.txt i tilläggets mapp och överlever panelomläsningar.

Väckningssvar wakeUpBtn

Högerklicka på chatttext eller ett kodblock för att få CBE-sammanhangsmeny. Högerklicka på prompttextarean öppnar nu istället den inbyggda webbläsarmenyn (Kopiera / Klipp ut / Klistra in / Ta bort / Markera allt).

Kopiera / Kopiera kodblock
Kopierar det aktuella urvalet. Om inget urval men du högerklickade på en <pre><code>, kopieras hela kodblocket.
Visa källa
Visar raw HTML/markdown för den klickade regionen — antingen ett kodblock eller hela panel-DOM:en. Användbar för att felsöka skinne/CSS-problem.
Öppna DevTools
Frågar VSCode att öppna sina Developer Tools så du kan inspektera webbutsikten live.
Inställningar ny
Öppnar samma Inställnings-modal som verktygsfältsknappen Inställningar öppnar (leverantör / modell / skinn / språk / SFX). Samma som /settings.
Om ny
Liten dialog i panelen med version, författare, licens, repo-länk, portfölj och kontakttelefon. Stängs när backgrundsklick, ×-knapp eller Esc.
Läs in panel ny
Läser om panel/index.html + panel.js + skins/* med en per-fil ?v=<mtime> cache-buster och omtilldelar panel.webview.html. Plockar upp CSS/JS-redigeringar utan att starta om VSCode. Tilläggets värd förblir levande — terminal, övervakare, chatthistorik bevaras alla.

Utlöser workbench.action.reloadWindow. Använd detta endast när du har redigerat extension.js (värdkod) och panelomläsningen inte räcker. Det är en fullständig VSCode-fönsteromläsning.

Modaler & dialoger ↑ topp

Inställnings-modal — leverantör / modell / skinn / språk / SFX
  • Leverantör: fullständig listruta för varje direkt-API + broleverantör. Att välja en växlar den aktiva sessionen OCH startar automatiskt motsvarande bro-exe (om tillämpligt).
  • Modell: per-leverantörlista över tillåtna modeller (t.ex. claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 för Anthropic).
  • Skinn: visuellt tema. Se Skinnor.
  • Språk: 39 språk tillgängliga. Att växla drar om strängar-kartan och översätter om varje verktygstips / etikett / hjälpknapp live.
  • SFX aktiverad: växla gränssnittets ljudeffekter (klick, bockar, modal öppna/stänga, osv.).
  • SFX-volym: 0–100-reglage. Förhandsvisas live när du drar.
  • Avbryt återställer eventuella live-förhandsvisningar (SFX/skinn) du provade; Spara bevarar och sänder setProvider.
Installationsguide — stegvis API-nyckelanmälan

Genomgång för varje integration. Varje steg frågar efter autentiseringsuppgifter och skriver dem till config.ini. Hoppa över går vidare utan att skriva; Nästa skriver och går vidare; sista stegets Klar stänger. Stegen inkluderar: Anthropic, OpenAI, Gemini, xAI/Grok, GitHub PAT, E-post/SMTP (Gmail-applösenord), Cloudflare, Twilio, ElevenLabs, Stability AI, Runway, SendGrid, NameSilo och mer.

För varje leverantör, hantera flera märkta konton (t.ex. "personligt", "arbete"). Växla vilket som är aktivt per session utan att skriva över de andra. Nycklar maskeras från slutpunkt till slutpunkt och sparas per leverantör i config.ini.

Domäner-modal — NameSilo

Listar varje domän på ditt NameSilo-konto med namnservrar + registreringsdatum. Knappen Läs in tvingar en ny API-hämtning (annars cachelagrar den i domains.txt).

Handbok-modal

Renderar en projekthandbok HTML (avsedd som en systemprompt-referens som modellen kan konsultera). Konfigurerbar per projekt.

Sparade prompter-modal

Insättbara promptmallar från stored_prompts/. Varje fil är en mall; filnamnsprefixet NN- styr sorteringsordning. Knappen "+" skapar en ny.

Chatthistorik-modal

Välj ett UTC-datum för att läsa in chattloggen från chats/<date>.log. Skrivskyddad.

Tillägg-modal

Kort för varje installerat tillägg. Fäst på verktygsfältet / lösgör, installera från den offentliga katalogen (extensions.xml.php på servern) eller ta bort från disk.

Ändringslogg-modal

Renderar panel/change_log.html — de paketerade versionsnota. Genererad via tools/build_changelog.py.

Visa källkods-modal

Pretty-skriver ut vilket kodblock som helst eller panelens fullständiga HTML, med Prism-syntaxmarkering och en Kopiera-knapp. Nådd via högerklick → Visa källa.

Auto Prompt-modal

Konfigurera en promptsträng + nedräkningsintervall. Efter varje assistentsvar minskar nedräkningen; när den når noll skickar CBE automatiskt den konfigurerade prompten. Växlad på/av via knappen Auto Prompt i verktygsfältet.

Inställningar ↑ topp

Alla inställningar bor på en av två platser:

  • workspaceState (VSCode-hanterat, per-arbetsyta) — leverantör, modell, skinn, språk, sfx aktiverad/volym, teckenstorlek.
  • config.ini (tilläggets rot, gitignorerad) — API-nycklar + per-integrations-autentiseringsuppgifter.

Inställningar bevaras automatiskt över panelomläsningar. Modalern Inställningar är det säkra sättet att ändra något; att redigera config.ini direkt fungerar också.

Konton & API-nycklar ↑ topp

Varje leverantör kan ha flera märkta konton — användbar om du vill växla mellan personliga och arbetsnyckar eller testa ett annat lager. Konton-modalen låter dig:

  • Lägg till ett nytt konto med etikett + nyckel
  • Redigera ett befintligt konto (omärka, ersätt nyckeln)
  • Ställ in vilket konto som är aktivt för den aktuella sessionen
  • Ta bort ett konto

Nycklar lagras maskerade (endast sista fyra synlig) i config.ini. Det finns ingen oformaterad kopia i workspaceState.

Tamagotchi-husdjur ↑ topp

Tamagotchi är ett pixel-husdjur som bor i panelen under tamagotchi-skinnet. Det åldras, blir hungrig/smutsigt, kan leka med och dör om det försummas tillräckligt länge. Tillståndet bevaras i workspaceState.

Statistik (topp av widget)

StatistikVad den spårar
🥚 StadiumLivscykel: ägg → baby → barn → tonåring → vuxen → senior → död. Åldras med riktiga minuter.
🍖 Hunger0–100. Sjunker över tid; Mata höjer det. Når 0 → hälsa sjunker.
😀 Lycka0–100. Sjunker över tid; Leka höjer det.
❤️ Hälsa0–100. Sjunker när sjuk eller svält. Spruta läker.
✨ Renlighet0–100. Sjunker när husdjuret bajjar. Rengör höjer det.
⏱ ÅlderMinuter sedan kläckning.

In-LCD åtgärdsknappar (botten av widget)

IkonÅtgärd
🍖Mata — växlar mellan kött ↔ aubergine. Välj för att faktiskt mata.
🧹Rengör — sopa upp bajset.
⚾Leka — minispel; höjer lycka.
💉Spruta — läker när sjuk.
💡Ljus — växla LCD-lampan; husdjuret sover i mörkret.

Hussdjurets sprite ritas in i en 240×240 (kompakt: 138×116) canvas. Sprites + livscyklar finns i panel/dotmatrix-tamagotchi-sprites.js och panel/dotmatrix-tamagotchi-game.js.

Skinnor ↑ topp

Visuella teman för hela panelen — knappar, modaler, kodblock, även typsnitt. Välj en i Inställningar → Skinn. Varje skinn bor i skins/<id>/ med en manifest.xml (förklarar färger + accent) och en styles.css (åsidosätter CSS-variabler).

  • codex-black (standard) — mörk, monospace, neon-cyan accent
  • glassy — frostat-glasytor över en mjuk bakgrund
  • tamagotchi — lime-grön LCD-handhållen; visar automatiskt hussdjurspanelen dockad i komponistens hörn
  • office — Word-stil cream/blue-krom
  • macos-color-dock / mint-dock — botten-dockar med glasiga ikoner
  • terminal / arch / kde / gnome / xfce / ubuntu / redhat — Linux-skrivbordsteman

Modal-färger kommer från <colors>-poster i varje skinns manifest och pushes på :root som --cbe-modal-*-variabler så varje modal (inklusive denna hjälp) renderas i-tema.

Tillägg ↑ topp

Mini-appar som bor inuti CBE. Var och en är en mapp under extensions/<id>/ med:

  • manifest.xml — id, namn, version, författare, beskrivning, entry HTML, ikon (emoji eller icon.svg)
  • extension.html (eller vad manifesten <entry> än säger) — själva appen

Klicka på Tillägg för att bläddra vad som är installerat, fästa på verktygsfältet, installera nya från den offentliga katalogen eller ta bort från disk. Fästa ID:n bor i extensions/_pinned.json.

Auto-uppdatering (push / pull) ↑ topp

CBE synkroniserar sin källa mellan maskiner via en WinSCP-push + HTTPS-pull-kanal.

Push (endast admin)

Om [updates] is_admin = true i config.ini, kör varje aktivering en bakgrund WinSCP synchronize remote -mirror som pushar tilläggets mapp till /home/trentontompkins.com/cbe på servern. Manuell utlösare: /push snedstrek-kommando. Utesluter per-maskin tillstånd: data/ (1.74 GB Chrome-profiler), bridges/, node_modules/, .git/, logs/, chats/, config.ini, prompt_history.txt, domains.txt, wake.txt.

Pull (varje klient)

4 sekunder efter aktivering, hämtar varje klient https://trentontompkins.com/cbe/manifest.xml.php och MD5-jämför per-fil mot lokala kopior. Endast ändrade/saknade filer laddas ner över vanlig HTTPS GET. Uteslutna sökvägar är ALDRIG pulled: config.ini, data/, bridges/, extension.js, panel/panel.js, panel/index.html, package.json, build-verktyg — anledningen är att källan levereras via .vsix och serverns äldre kopia måste inte klirra i-progress dev-arbete.

Hot reload ↑ topp

Två omladdningsvägar exponeras via högerklick-menyn:

  • Läs in panel — läser om panel/index.html + varje JS/CSS-tillgång med en per-fil ?v=<mtime> cache-buster och omtilldelar panel.webview.html. Plockar upp panel.js / skin-CSS / dotmatrix-redigeringar utan att starta om VSCode. Tilläggets värd förblir levande (din terminal, övervakare, meddelandehanterare, chatthistorik bevaras alla).
  • Läs in fönster — eldas workbench.action.reloadWindow. Använd endast när du har redigerat extension.js (värdkod) och panelomläsningen inte räcker.

Skin-CSS-redigeringar tillämpas också automatiskt via panelens befintliga skinn-watchdog — ingen meny-klick behövs.

Felsökning ↑ topp

"bridge X chat failed: api key empty in config.ini"

Smart_bridge.py-demonen cachelagrar en gammal gatingkontroll i minnet. Fixad i C++-exe-routingpivoten. Om du fortfarande ser det, döda löst daemons:

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
"copilot has no public REST API — use the browser bridge"

Gammal extension.js routade bridge-chatt genom REST-routern istället för den faktiska C++-bricka-exen. Läs in Window för att plocka upp fixed extension.js, då går chatt direkt till bin/CBE-Bridge-Copilot.exe.

HTTP 404 modell: sonnet-4.6

Föråldrad kort alias i Claude-bro-config. Fixad — full ID:n (claude-sonnet-4-6, claude-opus-4-7, claude-haiku-4-5) används nu.

Jag redigerade en fil men panelen visar inte ändringen
  1. Om det är panel.js / skins/*.css / index.html → högerklick → Läs in panel.
  2. Om det är extension.js / bridges_cpp/*.py → högerklick → Läs in fönster.
  3. Om du inte kan nå menyn (t.ex. menyn själv är inte laddad ännu), starta en ny VSCode-instans med en isolerad user-data-dir:
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Claude Codex Black"
STT misslyckas med "not-allowed"

VSCode sandboxar webbutsikten från mikrofontillstånd. CBE auto-faller tillbaka till Windows SAPI (System.Speech.Recognition) lanserad via PowerShell. Du kan behöva ge mic-åtkomst på OS-nivå (Inställningar → Integritet → Mikrofon).

Bridge-exe saknas

Trace-logg visar BRIDGE:MISSING target=<t> expected=<path>. C++-bricka-exen bor i bin/CBE-Bridge-<Pretty>.exe. Om dina inte finns, bygg om från bridges_cpp/ källa (MSVC) eller pull en ny .vsix.
