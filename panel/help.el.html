Claude Codex — Black Edition

Ένα δοχείο συνομιλίας AI πολλαπλών παρόχων χωρίς σύνδεση για το VSCode. Πατήστε Ctrl+Alt+B για εναλλαγή.

1. Καλώς ήρθατε

Το Claude Codex Black είναι ένα webview του VSCode που σας επιτρέπει να συνομιλείτε με πολλαπλούς παρόχους AI (Claude, OpenAI, Gemini, Grok, Azure, τοπικό Ollama) από ένα μόνο, θεματοποιήσιμο πάνελ. Όλα όσα χρειάζονται ένα κλειδί διαβάζουν από το config.ini στη ρίζα της επέκτασης — δεν απαιτείται UI ρυθμίσεων επέκτασης, αλλά ένα μοντέλο Ρυθμίσεων αντιπροσωπεύει τα πιο χρήσιμα πεδία για επεξεργασία μόνο με κλικ.

Είστε νέοι εδώ; Ξεκινήστε ανοίγοντας τις Ρυθμίσεις (εικονίδιο γραναζιού), επιλέξτε τον πάροχό σας, επικολλήστε το κλειδί API σας και, στη συνέχεια, πληκτρολογήστε ένα prompt και πατήστε Enter. Κάθε άλλη λειτουργία σε αυτόν τον οδηγό είναι προαιρετική.

3. Το πλαίσιο prompt

Το μεγάλο επεξεργάσιμο textarea στο κάτω μέρος. Πληκτρολογήστε, επικολλήστε, σύρετε ένα αρχείο, επισυνάψτε μέσω του συνδέσμου — όποιο κείμενο τοποθετείτε εδώ είναι το χρήστη σειρά της επόμενης κλήσης API.

Η γραμματοσειρά κλειδώνεται στη γραμματοσειρά monospace του επεξεργαστή σας στο VSCode (μέσω της --vscode-editor-font-family CSS variable) έτσι ώστε το πάνελ να μοιάζει σπίτι μέσα στον επεξεργαστή.

5. Μοντέλα & πάροχοι

Το CBE διακινεί 11 γέφυρες ως drop-in .bridge plugins κάτω από bridges/. Κάθε ένα είναι ένα αυτόνομο zip με manifest.xml + bridge.py + εικόνες. Απλώς ρίξτε ένα νέο .bridge αρχείο και εμφανίζεται στο αναπτυσσόμενο κέρμα — δεν απαιτείται αλλαγή κώδικα επέκτασης.

Γέφυρες κειμένου-συνομιλίας (7)

  • ChatGPT — chatgpt.com, συνδρομή Plus/Pro
  • Grok — grok.com, εγγραφή xAI native (το ανώνυμο επίπεδο είναι πολύ περιορισμένο · εισάγετε πρώτα)
  • Gemini — gemini.google.com, λογαριασμός Google
  • Claude — claude.ai, σύνδεση με μαγικό σύνδεσμο (εκτελέστε tools/sign_in_helper.py claude μία φορά)
  • Copilot — copilot.microsoft.com, δωρεάν λογαριασμός Microsoft
  • DeepSeek — chat.deepseek.com, εγγραφή email/password native (ΜΗ χρησιμοποιείτε Google SSO)
  • Ollama — τοπικό 127.0.0.1:11434, χωρίς σύνδεση

Γέφυρες παραγωγής βίντεο (4)

  • Sora 2 — sora.com, επαναχρησιμοποίηση της σύνδεσης ChatGPT Plus/Pro
  • Google Veo — gemini.google.com (Veo mode), συνδρομή Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, ξεχωριστή συνδρομή Runway
  • Bing Video Creator — bing.com/videos/create, δωρεάν Sora-2 με λογαριασμό Microsoft

Τα δημιουργημένα βίντεο αποθηκεύονται σε videos/<bridge>/<timestamp>_<prompt-slug>.mp4 και αυτόματη αναπαραγωγή στο πάνελ Video Library (δείτε §Video Library παρακάτω).

Επιλέξτε μια γέφυρα + μοντέλο από το αναπτυσσόμενο κέρμα δίπλα στο πλαίσιο prompt, ή μέσω Ρυθμίσεις → Γενικά. Η επιλογή είναι ανά χώρο εργασίας και διατηρείται στο workspaceState. Για να προσθέσετε μια νέα γέφυρα, δείτε docs/WRITING_BRIDGES.md.

5a. Βιβλιοθήκη βίντεο

Ένα αποκλειστικό πάνελ για περιήγηση + παρακολούθηση βίντεο που δημιουργήθηκαν από τις γέφυρες βίντεο (Sora, Veo, Runway, Bing Video Creator). Ανοίγει μέσω της Παλέτας Εντολών: Claude Codex Black: Open Video Library ή την εντολή codexBlackEd.openVideoPlayer.

  • Η πλευρική στήλη παραθέτει κάθε .mp4 / .webm / .mov κάτω από videos/<bridge>/, ομαδοποιημένα κατά γέφυρα και ταξινομημένα ως νεότερα πρώτα.
  • Το πιο φρέσκο βίντεο αναπαράγεται αυτόματα κατά το πρώτο άνοιγμα.
  • Το πάνελ παρακολουθεί τον κατάλογο videos/ σε ένα τικ 2 δευτερολέπτων — οποιοδήποτε νέο κατασκευασμένο βίντεο εμφανίζεται με ένα ✨ badge «Μόλις δημιουργήθηκε» και αυτόματη αναπαραγωγή (απενεργοποίηση μέσω Auto ▶ new).
  • Κάντε κλικ στο 📂 Ανοίξτε για να αποκαλύψετε τον φάκελο videos/ στη διαχείριση αρχείων OS σας.

6. Ομιλία σε κείμενο

Κάντε κλικ στο μικρόφωνο, μιλήστε, κάντε κλικ ξανά για να σταματήσετε (ή περιμένετε τον χρόνο σιωπής). Δύο κινητήρες δοκιμάζονται με σειρά:

  1. Web Speech API — Αναγνωριστής νέφους της Google που τρέχει στο webview. Χρησιμοποιεί την περίοδό σας Gmail/Google · δεν απαιτείται επιπλέον κλειδί.
  2. Windows SAPI (fallback) — Διαδικασία PowerShell προ-θερμαμένη κατά την κλήση της κατά την ενεργοποίηση της επέκτασης. Προστιθέμενο παράθυρο ακρόασης μέσω [voice] listen_seconds στο config.ini.
Το SAPI είναι προ-θερμαμένο κατά την ενεργοποίηση της επέκτασης έτσι ώστε το πρώτο κλικ μικρόφωνου να αποφεύγει την ψυχρή εκκίνηση 2-4 δευτερολέπτων που ήταν δάγκωμα των πρώιμων κλικ σταματήματος.

7. Αυτόματο Prompt

Το κουμπί σήμα-με-spinner. Όταν είναι ΕΝΕΡΓΟΠΟΙΗΜΕΝΟ, μετά από N δευτερόλεπτα αδράνειας το πάνελ αυτό-αποστέλλει το ρυθμισμένο κείμενο ξύπνησης. Το ψηφίο αντίστροφης μέτρησης αποδίδεται σε --cbe-highlight-color, το οποίο κάθε skin ορίζει.

Επεξεργασία του κειμένου ξύπνησης μέσω του κουμπιού 🔁 Wake — κάνει round-trips wake.txt.

8. Αυτόματη ανάγνωση (TTS)

Το εικονίδιο του στόματος. Όταν είναι ΕΝΕΡΓΟΠΟΙΗΜΕΝΟ, κάθε απάντηση βοηθού ομιλίας μέσω του συνθέτη Web Speech (Google) ή fallback SAPI. Ένας μπλε oreol λάμπει γύρω από το εικονίδιο ενώ αναπαράγεται ήχος.

9. Συμπαγής & χρήση περιεχομένου

Ο πίνακας συνομιλίας που αποστέλλεται στο μοντέλο μεγαλώνει με κάθε σειρά. Ο δακτύλιος γύρω από το εικονίδιο Compact δείχνει τη τρέχουσα χρήση παραθύρου περιεχομένου ως κωνική κλίση — άδειο όταν φρέσκο, πλήρες όταν κοντά στο όριο περιεχομένου του μοντέλου.

Κάντε κλικ στο Compact για περικοπή ιστορικού κάτω στις τελευταίες τέσσερις σειρές. Η επόμενη κλήση API χρησιμοποιεί τον μικρότερο πίνακα.

10. Απάντηση ξύπνησης

Αποθηκευμένο στο wake.txt στη ρίζα της επέκτασης. Χρησιμοποιείται από το Auto Prompt ως το μήνυμα που θα αποσταλεί όταν ξυπνήσει το χρονόμετρο αδράνειας. Επεξεργασία μέσω του κουμπιού 🔁.

11. Συνημμένα αρχεία

Κάντε κλικ 📎 για να επιλέξετε ένα ή περισσότερα αρχεία. Κρατήστε Ctrl ή Shift στο επιλογέα για πολλαπλή επιλογή. Κάθε αρχείο είναι ενσωματωμένο στο prompt ως περιφραγμένο κενό κείμενο με το όνομα αρχείου και γλώσσα. Δυαδικά αρχεία πάνω από 1 MB παραλείπονται με ειδοποίηση.

12. Μοντέλο Git

Κάντε κλικ 📁 Git. Εάν δεν έχει ρυθμιστεί φάκελος έργου, λαμβάνετε πρώτα έναν επιλογέα φακέλου — η επιλεγμένη διαδρομή γράφεται στο [project] path στο config.ini. Οι επόμενες κλήσεις git εκτελούνται με cwd ορίστε σε αυτή τη διαδρομή.

13. Αποθετήρια GitHub

Παραθέτει κάθε αποθετήριο προσβάσιμο στο [github] pat σας. Κάντε κλικ σε μια σειρά για εισαγωγή της διεύθυνσης URL κλώνου της σε ένα prompt. Ο κατάλογος είναι σελιδοποιημένος και αποθηκευμένος.

14. Τομείς NameSilo

Τραβάει κάθε τομέα στο λογαριασμό σας NameSilo χρησιμοποιώντας [namesilo] api_key (ή [api_keys] namesilo_api_key ως fallback). Κατά το πρώτο άνοιγμα, τα αποτελέσματα είναι αποθηκευμένα σε domains.txt · τις επόμενες εκκινήσεις πάνελ χρησιμοποιούν την προσωρινή μνήμη. Κάντε κλικ Ανανέωση στο μοντέλο για την εξαναγκασμένη ανάκτηση.

Εάν δείτε ποτέ «χωρίς τομέα» με κωδικό απάντησης 300, ελέγξτε το κανάλι ιχνών — τα κενά αποθέματα δεν δηλητηρίαζουν πλέον τις μελλοντικές εκκινήσεις πάνελ, αλλά ένα σταθερό domains.txt σε άλλη διαδρομή εγκατάστασης θα μπορούσε να.

15. Skins & θέματα

Το κουμπί 🎨 ανοίγει έναν επιλογέα ανακάλυψης που σαρώνει skins/ ζωντανά (όχι κατά την εκκίνηση), έτσι η ρίψη ενός νέου φακέλου κατά τη διάρκεια εκτέλεσης είναι αρκετή. Κάθε skin έχει manifest.xml που ορίζει την παλέτα του — συμπεριλαμβανομένου του χρώματος ύψους, το οποίο το Auto Prompt countdown badge, δακτύλιοι εστίασης, και όλα τα κλειδιά εποπτείας σπιν.

Τα ενσωματωμένα skins περιλαμβάνουν: gnome (Adwaita gray), terminal (μαύρο/πράσινο με hot-pink accent), tamagotchi (ανοικτόχρωμα αγόρια με πάνελ mascot sprite), blocky, και άλλα.

16. Ρυθμίσεις

Ανοίγει από το ⚙ γραναζί. Καρτέλες:

  • Γενικά — όνομα εμφάνισης, προεπιλεγμένο μοντέλο, αποστολή στο enter
  • Φωνή — συσκευή μικρόφωνου, listen_seconds, επιλογή κινητήρα STT, αυτόματη ανάγνωση TTS
  • Ενημερώσεις — σημαία is_admin, περίοδος WinSCP, απομακρυσμένη διαδρομή
  • Κλειδιά — κάθε κλειδί API παρόχου
  • Επιβλέπων — εναλλαγή εποπτείας VSCode, θύρα, διάστημα δημοσκόπησης
  • Γλώσσα — επιλογή από 39 γλώσσες · δείτε § 17

Το μοντέλο θυμάται το μέγεθος και τη θέση του μεταξύ των συνεδριών.

17. Γλώσσα

Το πάνελ διακινεί με μεταφράσεις για τις 39 πιο συνομιλητές γλώσσες. Τα αρχεία γλώσσας ζουν στο languages/<code>.xml και φορτώνονται μία φορά κατά την ενεργοποίηση της επέκτασης. Τα εξουσιοδοτημένα κλειδιά επιστρέφονται στα αγγλικά.

Επιλέξτε τη γλώσσα σας στο Ρυθμίσεις → Γλώσσα. Ένα εικονίδιο σημαία εμφανίζεται δίπλα σε κάθε επιλογή (φορτωμένο από assets/flags/<code>.svg). Η επιλογή αποθηκεύεται στο [settings] language στο config.ini.

18. Επιβλέπων VSCode

Μια υπηρεσία Windows (CBEVSCodeSupervisor) τυλίγει το tools/vscode_supervisor.ps1 script μέσω NSSM και δεσμεύει έναν HttpListener στο http://127.0.0.1:3434/. Το κουμπί monitor του πάνελ λάμπει μπλε όταν ο τελικός σημείο /status του εποπτείου απαντά 200 OK.

Εάν η δοκιμή HTTP αποτύχει αλλά η υπηρεσία έχει εγκατασταθεί, ο σκύλος παρακολούθησης του πάνελ αυτό-ξεκινά ξανά την υπηρεσία (ψύχος 30 δευτερολέπτων έτσι δεν restart-storm).

Left-click το κουμπί monitor για εγκατάσταση / έναρξη / σταματήστε. Right-click για ανοίγμα του καναλιού ιχνών.

19. Αυτόματη ενημέρωση (pull)

4 δευτερόλεπτα μετά την ενεργοποίηση της επέκτασης, το πάνελ ανακτά https://trentontompkins.com/cbe/manifest.xml.php — μια δήλωση MD5+size των τελευταίων δημοσιευμένων αρχείων. Για κάθε απομακρυσμένο αρχείο, το τοπικό αντίγραφο MD5 είναι σε σύγκριση · μόνο αλλαγμένα/λειπόμενα αρχεία λαμβάνονται κατάληψης HTTPS.

Κατάσταση τοπική χρήστη (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) είναι στη λίστα αποκλεισμού ανάληψης και δεν αντιγράφεται ποτέ.

20. Ώθηση διαχειριστή

Μόνο οι πελάτες με [updates] is_admin = true ποτέ δεν ωθούν στο διακομιστή. Ενεργοποιημένο μέσω:

  • Παλέτα εντολών → Claude Codex Black: Push update
  • Εντολή κάθετου /push

Χρησιμοποιεί την περίοδο WinSCP που έχει αποθηκευτεί στο [updates] winscp_session (προεπιλογή vps). Ωθήσεις μέσω /script=… με την εντολή συγχρονισμού και ένα filemask που αποκλείει τα μυστικά & κατάσταση ανά μηχάνημα.

21. Αγορά επεκτάσεων

Κάντε κλικ στο κουμπί 🧩 Extensions. Ένα μοντέλο iframe ανοίγει στο https://trentontompkins.com/cbe/extension/extension_marketplace.php, το οποίο ανακτά τον κατάλογο στο extensions.xml.php και αποδίδει κάθε διαθέσιμη επέκταση ως κάρτα με περιγραφή, ετικέτες, έκδοση, μέγεθος αρχείου, MD5, και ένα κουμπί Εγκατάστασης.

Μια επέκταση είναι συσκευασμένη ως <id>.ext — ένα αρχείο zip που περιέχει manifest.xml συν κώδικας επέκτασης (συνήθως ένα μόνο extension.html). Όταν κάνετε κλικ Εγκατάσταση, το iframe της αγοράς στέλνει ένα postMessage πίσω στο πάνελ · το πάνελ ανακτά απευθείας το .ext αρχείο από το διακομιστή και το εξάγει κάτω extensions/ στο φάκελο επέκτασης.

Τρεις επιδείξεις επεκτάσεις διακινούν την εκκίνηση καταλόγου: Αριθμομηχανή, Minesweeper, και ένας Επιλογέας Emoji.

22. Εντολές κάθετου

Πληκτρολογήστε / στο πλαίσιο prompt για ανοίγμα της παλέτας εντολών κάθετου. Κάντε κλικ σε μια σειρά για εισαγωγή του κειμένου εντολής στο prompt σας (επεξεργάσιμο), ή πατήστε Enter σε μια εκτελέσιμη σειρά για πυροδότηση άμεσα.

Μια μη εξαντλητική λίστα:

23. Μενού δεξιού κλικ

Δεξί κλικ οπουδήποτε στο πάνελ για ένα σχετικό μενού (ορίστε ως μια μόνο συμβολοσειρά XML στο panel.js). Οι εγγραφές περιλαμβάνουν Ανανέωση (ανακατάσταση πάνελ χωρίς θίγει τον κεντρικό υπολογιστή — ποτέ μην χρησιμοποιείτε reloadWindow), Εκκαθάριση συνομιλία, Ανοίξτε ρυθμίσεις, και Επιθεώρηση (DevTools, αποσφαλμάτωση κατασκευών μόνο).

24. Κανάλι ιχνών

Η επέκταση γράφει έναν κοκκώδη χρονοδιάγραμμα στο debug.log δίπλα στην επέκταση. Όλα τα αξιοσημείωτα προορίζονται εκεί: αλλαγές παρόχου, κύκλος ζωής STT, δοκιμές εποπτείας, κώδικες απάντησης NameSilo, πάνελ↔κεντρικό μήνυμα γέφυρας, push/pull μέτρηση δηλώσεων.

Right-click το κουμπί monitor για one-click ανοίγμα του καναλιού ιχνών.

Το Auto Prompt spinner είναι μια μαύρη τελεία Λάθος SVG asset · πρέπει να είναι auto_read_spinner.svg με drop-shadow halo
Το κουμπί Compact δεν κάνει τίποτα Χειριστής κεντρικού υπολογιστή που λείπει — case 'compactConversation' στο δρομολογητή extension.js
«0 τομέα» στο μοντέλο τομέων Η απάντηση NameSilo.code != 300 (το κανάλι ιχνών την έχει), ή σταθερό domains.txt
STT «κανένα ομιλίας που ανιχνεύεται» αμέσως Σταματήσατε πριν το SAPI δέσει το μικρόφωνο. Η προ-θέρμανση τώρα παραλείπει αυτή την αναμονή — επαληθεύστε με stt: using pre-warmed SAPI σε debug.log
Η ώθηση αποτυγχάνει σε διαδρομή με κενά Χρησιμοποιώντας /command= inline · πάντα χρησιμοποιήστε /script=tempfile.winscp
Η μπλε αίγλη επιβλέπων δεν ανάβει Υπηρεσία δεν τρέχει. Left-click monitorBtn για εγκατάσταση/έναρξη, ή εκτελέστε Start-Service CBEVSCodeSupervisor
Η ανανέωση «διορθώνει» κάτι Δεν το έκανε. Ποτέ μην χρησιμοποιείτε reloadWindow. Χρησιμοποιήστε την Ανανέωση καταχώρηση menu context αντί αυτού.
