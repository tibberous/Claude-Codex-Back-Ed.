Claude Codex — Black Edition

VSCode کے لیے آفلائن-فرسٹ ملٹی-فراہم کنندہ AI چیٹ پینل۔ ٹوگل کرنے کے لیے Ctrl+Alt+B دبائیں۔

1. خوش آمدید

Claude Codex Black ایک VSCode ویب ویو ہے جو آپ کو ایک ہی، تھیم کے قابل پینل سے متعدد AI فراہم کنندگان (Claude, OpenAI, Gemini, Grok, Azure, مقامی Ollama) کے ساتھ چیٹ کرنے دیتا ہے۔ سب کچھ جس کے لیے کلید کی ضرورت ہے وہ config.ini سے پڑھی جاتی ہے جو توسیع کی جڑ پر ہے — کوئی توسیع سیٹنگز UI کی ضرورت نہیں ہے، لیکن ایک سیٹنگز ماڈل سب سے زیادہ مفید فیلڈز کو صرف کلک کے لیے ترمیم کے لیے منعکس کرتا ہے۔

یہاں نیا ہیں؟ سیٹنگز (گیئر آئیکن) کھول کر شروع کریں، اپنا فراہم کنندہ منتخب کریں، اپنی API کلید پیسٹ کریں، پھر ایک پروں پٹ ٹائپ کریں اور Enter دبائیں۔ اس گائیڈ میں ہر دوسری خصوصیت اختیاری ہے۔

3. پروں پٹ باکس

نیچے بڑا ترمیم کے قابل textarea۔ ٹائپ کریں، پیسٹ کریں، ایک فائل کو ڈریگ کریں، کاغذی کلپ کے ذریعے منسلک کریں — جو کچھ بھی آپ یہاں ڈالتے ہیں وہ اگلی API کال کا صارف موڑ ہے۔

فانٹ آپ کے VSCode ایڈیٹر کے monospace فانٹ کے لیے بند ہے ( --vscode-editor-font-family CSS متغیر کے ذریعے) لہذا پینل ایڈیٹر کے اندر گھر جیسا لگتا ہے۔

4. ٹول بار بٹن

نیچے کی صف، بائیں سے دائیں۔ ٹول ٹپس ماؤس کی بروکی پر ظاہر ہوتے ہیں؛ پینل انہیں آپ کی منتخب شدہ زبان میں بھی پڑھتا ہے (زبان دیکھیں)۔

5. ماڈلز اور فراہم کنندگان

CBE 11 برجز کے ساتھ شپ کرتا ہے bridges/ کے تحت drop-in .bridge پلگ ان کے طور پر۔ ہر ایک ایک self-contained zip ہے manifest.xml + bridge.py کے ساتھ + آئیکنز۔ bridges/ میں نیا .bridge فائل ڈراپ کریں اور یہ کارتوس ڈراپ ڈاؤن میں ظاہر ہوتا ہے — کوئی توسیع کوڈ کی تبدیلی کی ضرورت نہیں۔

ٹیکسٹ چیٹ برجز (7)

  • ChatGPT — chatgpt.com، Plus/Pro سبسکرپشن
  • Grok — grok.com، نیٹیو xAI لاگ ان (بے نام ٹائر بہت سے گیٹ کے ساتھ؛ پہلے لاگ ان کریں)
  • Gemini — gemini.google.com، Google اکاؤنٹ
  • Claude — claude.ai، جادو لنک لاگ ان (tools/sign_in_helper.py claude ایک بار چلائیں)
  • Copilot — copilot.microsoft.com، Microsoft اکاؤنٹ مفت
  • DeepSeek — chat.deepseek.com، نیٹیو ای میل/پاس ورڈ (Google SSO استعمال نہ کریں)
  • Ollama — مقامی 127.0.0.1:11434، کوئی لاگ ان درکار نہیں

ویڈیو تخلیق برجز (4)

  • Sora 2 — sora.com، آپ کے ChatGPT Plus/Pro لاگ ان کو دوبارہ استعمال کرتا ہے
  • Google Veo — gemini.google.com (Veo موڈ)، Gemini Advanced سبسکرپشن
  • Runway Gen-3/4 — app.runwayml.com، علیحدہ Runway سبسکرپشن
  • Bing Video Creator — bing.com/videos/create، Microsoft اکاؤنٹ کے ساتھ مفت Sora-2

تیار شدہ ویڈیوز videos/<bridge>/<timestamp>_<prompt-slug>.mp4 میں محفوظ ہوتی ہیں اور ویڈیو لائبریری پینل میں خودکار طور پر چلتی ہیں (نیچے ویڈیو لائبریری دیکھیں)۔

پروں پٹ باکس کے ساتھ کارتوس ڈراپ ڈاؤن سے ایک برج + ماڈل منتخب کریں، یا ترتیبات → عمومی کے ذریعے۔ منتخب کی جانے والی چیز فی workspace ہے اور workspaceState میں محفوظ ہے۔ نیا برج شامل کرنے کے لیے، docs/WRITING_BRIDGES.md دیکھیں۔

5a. ویڈیو لائبریری

ویڈیو برجز (Sora، Veo، Runway، Bing Video Creator) کے ذریعے تیار کی گئی ویڈیوز کو براؤز کرنے + دیکھنے کے لیے ایک خصوصی پینل۔ کمانڈ پیلیٹ کے ذریعے کھولیں: Claude Codex Black: Open Video Library یا codexBlackEd.openVideoPlayer کمانڈ۔

  • سائڈ بار videos/<bridge>/ کے تحت ہر .mp4 / .webm / .mov فہرست برج کے لحاظ سے گروپ بند اور نئے ترتیب سے۔
  • تازہ ترین ویڈیو پہلے کھولنے پر خودکار چلتی ہے۔
  • پینل videos/ ڈائریکٹری کو 2 سیکنڈ کے ٹک پر دیکھتا ہے — کوئی بھی نئی تیار شدہ ویڈیو ایک ✨ "صرف تیار شدہ" بیج کے ساتھ ظاہر ہوتی ہے اور خودکار چلتی ہے (٪ "Auto ▶ new" کے ذریعے بند کریں)۔
  • 📂 کھولیں پر کلک کریں تاکہ videos/ فولڈر آپ کے OS فائل منیجر میں ظاہر ہو۔

6. تقریر سے ٹیکسٹ

مائک پر کلک کریں، بات کریں، دوبارہ کلک کریں رکنے کے لیے (یا خاموشی کے وقت کے ختم ہونے کا انتظار کریں)۔ دو انجن بالترتیب کوشش کی جاتی ہیں:

  1. Web Speech API — Google کی کلاؤڈ recognizer ویب ویو میں چل رہی ہے۔ آپ کے Gmail/Google سیشن کا استعمال کرتا ہے؛ کوئی اضافی کلید کی ضرورت نہیں۔
  2. Windows SAPI (fallback) — pre-warmed PowerShell عمل جب ویب ویو مائک تک رسائی کو روکتا ہے۔ [voice] listen_seconds config.ini میں قابل ترتیب سن رہے ہوئے دریچے کے ساتھ۔
SAPI توسیع کو فعال کرتے وقت pre-warmed ہے لہذا پہلی مائک کلک 2-4 سیکنڈ کے سردی کے آغاز سے بچتا ہے جو پہلے شروعاتی سٹاپ کلک کو نگل جاتا تھا۔

7. آٹو پروں پٹ

سپنر والا بیج بٹن۔ ON ہونے پر، N سیکنڈ کی بے کاری کے بعد پینل آپ کے ترتیب شدہ جاگنے کا متن خودکار بھیجتا ہے۔ کاؤنٹ ڈاؤن ہندسہ --cbe-highlight-color میں درج ہے، جو ہر اسکن بیان کرتا ہے۔

🔁 Wake بٹن کے ذریعے جاگنے کا متن ترمیم کریں — یہ wake.txt round-trip کرتا ہے۔

8. خودکار پڑھنا (TTS)

منہ کا آئیکن۔ ON ہونے پر، ہر معاون جواب Web Speech synthesizer (Google) یا SAPI fallback کے ذریعے بولا جاتا ہے۔ نیلا ہیلو آئیکن کے ارد گرد جھکتا ہے جب ائیڈیو چل رہا ہو۔

9. کمپیکٹ اور سیاق کا استعمال

ماڈل کو بھیجی جانے والی گفتگو کی صف ہر موڑ کے ساتھ بڑھتی ہے۔ کمپیکٹ آئیکن کے ارد گرد کا رنگ موجودہ سیاق کے دریچے کو conic gradient کے طور پر دکھاتا ہے — تازہ ہونے پر خالی، ماڈل کی سیاق حد کے قریب ہونے پر مکمل۔

تاریخ کو آخری چار موڑوں تک کاٹنے کے لیے کمپیکٹ پر کلک کریں۔ اگلی API کال چھوٹی صف استعمال کرتی ہے۔

10. جاگنے کا جواب

wake.txt میں توسیع کی جڑ پر محفوظ۔ Auto Prompt کے ذریعے بے کاری ٹائمر کے فائر ہونے پر بھیجنے کے لیے پیغام کے طور پر استعمال ہوتا ہے۔ 🔁 ٹول بار بٹن کے ذریعے ترمیم کریں۔

11. فائل منسلکات

📎 پر کلک کریں ایک یا زیادہ فائلیں منتخب کریں۔ منتخب کنندہ میں متعدد منتخب کرنے کے لیے Ctrl یا Shift رکھیں۔ ہر فائل اپنی فائل نام اور زبان کے ساتھ ایک fenced کوڈ بلاک کے طور پر پروں پٹ میں درج ہے۔ 1 MB سے زیادہ بائنری فائلیں نوٹس کے ساتھ چھوڑی جاتی ہیں۔

12. Git ماڈل

📁 Git پر کلک کریں۔ اگر کوئی پروجیکٹ فولڈر ترتیب نہیں دیا جاتا تو آپ کو پہلے فولڈر منتخب کنندہ ملتا ہے — منتخب شدہ پاتھ [project] path میں لکھا جاتا ہے config.ini میں۔ بعد میں git invocations cwd کو اس پاتھ پر سیٹ کے ساتھ چلتی ہے۔

13. GitHub ذخائر

ہر repo فہرست دیتا ہے جو آپ کے [github] pat کے لیے accessible ہے۔ اس کے clone URL کو پروں پٹ میں ڈالنے کے لیے ایک صف پر کلک کریں۔ فہرست paginated اور cached ہے۔

14. NameSilo ڈومینز

[namesilo] api_key استعمال کرتے ہوئے آپ کے NameSilo اکاؤنٹ میں ہر ڈومین کھینچتا ہے (یا [api_keys] namesilo_api_key fallback کے طور پر)۔ پہلے کھولنے پر، نتائج domains.txt میں cached ہوتے ہیں؛ بعد میں پینل بوٹ cache سے سیوا کرتے ہیں۔ تازہ fetch کو فورس کرنے کے لیے ماڈل میں دوبارہ لوڈ کریں پر کلک کریں۔

اگر آپ کو "کوئی ڈومینز نہیں" 300 reply کوڈ کے ساتھ کبھی دیکھتے ہیں تو ٹریس چینل چیک کریں — خالی caches اب مستقبل کے پینل بوٹ کو زہر دیتے ہیں، لیکن اگر دوسرے install path میں stale domains.txt ہو۔

15. سکن اور تھیمز

🎨 بٹن ایک دریافت منتخب کنندہ پاپ کرتا ہے جو skins/ کو براہ راست (شروعات پر نہیں) سکین کرتا ہے، لہذا runtime میں ایک نیا فولڈر ڈالنا کافی ہے۔ ہر skin میں manifest.xml اپنے palette کو بیان کرتے ہوئے ہے — بشمول highlight رنگ، جو Auto Prompt کاؤنٹ ڈاؤن بیج، فوکس rings، اور supervisor نبض سب کلیدی۔

بلٹ ان skins میں شامل ہیں: gnome (Adwaita سرمئی)، terminal (سیاہ/سبز گرم گلابی accent کے ساتھ)، tamagotchi (انڈے کے پوسته کے pastels ایک sprite mascot پینل کے ساتھ)، blocky، اور دیگر۔

17. زبان

پینل 39 سب سے زیادہ بولی جانے والی زبانوں کے لیے ترجمے کے ساتھ شپ کرتا ہے۔ Locale فائلیں languages/<code>.xml پر رہتی ہیں اور توسیع کو فعال کرتے وقت ایک بار لوڈ ہوتی ہیں۔ غائب کلیدز انگلش میں واپس جاتی ہیں۔

اپنی زبان ترتیبات → زبان میں منتخب کریں۔ ہر آپشن کے ساتھ ایک flag آئیکن دکھایا جاتا ہے (assets/flags/<code>.svg سے لوڈ)۔ منتخب [settings] language میں محفوظ کی جاتی ہے config.ini میں۔

18. VSCode سپروائزر

ایک Windows سروس (CBEVSCodeSupervisor) tools/vscode_supervisor.ps1 اسکرپٹ کو NSSM کے ذریعے لپیٹتا ہے اور http://127.0.0.1:3434/ پر HttpListener بند کرتا ہے۔ پینل کا monitor بٹن نیلا ہوتا ہے جب supervisor کا /status endpoint 200 OK جواب دے۔

اگر HTTP تحقیق ناکام ہو لیکن سروس انسٹال ہو تو پینل کی watchdog سروس کو خودکار دوبارہ شروع کرتی ہے (30 سیکنڈ cool-down تاکہ یہ restart-storm نہ ہو)۔

monitor بٹن کو بائیں کلک کریں تاکہ انسٹال / شروع / بند کریں۔ ٹریس چینل کھولنے کے لیے دائیں کلک کریں۔

19. خودکار اپ ڈیٹ (pull)

توسیع کو فعال کرنے کے 4 سیکنڈ بعد، پینل https://trentontompkins.com/cbe/manifest.xml.php — تازہ ترین شائع شدہ فائلوں کا MD5+size manifest کو fetch کرتا ہے۔ ہر دور کی فائل کے لیے، مقامی copy کا MD5 موازنہ کیا جاتا ہے؛ صرف تبدیل شدہ/غائب فائلیں HTTPS پر ڈاؤن لوڈ کی جاتی ہیں۔

صارف مقامی state (config.ini، debug.log، domains.txt، wake.txt، prompt_history.txt) pull exclusion فہرست پر ہے اور کبھی overwrite نہیں ہوتے۔

20. ایڈمن پش

صرف [updates] is_admin = true والے کلائنٹس سروقت سرور پر کبھی پش کرتے ہیں۔ ٹریگر ہوا:

  • کمانڈ پیلیٹ → Claude Codex Black: Push update
  • سلیش کمانڈ /push

[updates] winscp_session میں نام دیے گئے WinSCP محفوظ سیشن کا استعمال کرتا ہے (ڈیفالٹ vps)۔ /script=… کے ذریعے push کرتا ہے synchronize کمانڈ اور اسرار اور per-machine state کو exclude کرنے والا filemask کے ساتھ۔

21. ایکسٹینشنز مارکیٹ

🧩 Extensions بٹن پر کلک کریں۔ ایک iframe ماڈل https://trentontompkins.com/cbe/extension/extension_marketplace.php کھولتا ہے، جو extensions.xml.php پر کیٹلاگ کو fetch کرتا ہے اور ہر دستیاب توسیع کو بیان، tags، version، فائل سائز، MD5، اور ایک انسٹال بٹن کے ساتھ کارڈ کے طور پر درج کرتا ہے۔

ایک توسیع <id>.ext — ایک zip archive manifest.xml + توسیع کوڈ کے ساتھ کے طور پر پیکیج دیا جاتا ہے (عام طور پر ایک واحد extension.html)۔ جب آپ انسٹال پر کلک کرتے ہیں، تو مارکیٹ pane iframe postMessage پینل کو بھیجتا ہے؛ پینل سروقت سے براہ راست .ext فائل ڈاؤن لوڈ کرتا ہے اور اسے extensions/ کے تحت توسیع فولڈر میں نکالتا ہے۔

تین ڈیمو توسیع launch کیٹلاگ کے ساتھ شپ کرتے ہیں: کیلکولیٹر، Minesweeper، اور ایک Emoji Picker۔

22. سلیش کمانڈز

23. دائیں کلک کا مینو

پینل میں کہیں بھی دائیں کلک کریں ایک contextual مینو کے لیے (panel.js میں ایک واحد XML سٹرنگ کے طور پر بیان)۔ اندراجات میں شامل ہیں Refresh (توسیع host کو چھوئے بغیر پینل کو دوبارہ لوڈ کریں — reloadWindow کبھی استعمال نہ کریں)، گفتگو صاف کریں، ترتیبات کھولیں، اور Inspect (DevTools، صرف debug builds)۔

24. ٹریس چینل

توسیع debug.log میں ایک granular timeline لکھتا ہے توسیع کے ساتھ۔ سب کچھ قابل غور وہاں جاتا ہے: فراہم کنندہ سوئچ، STT lifecycle، supervisor probes، NameSilo جواب codes، panel↔host bridge پیغامات، push/pull manifest counts۔

monitor بٹن کو دائیں کلک کریں تاکہ ٹریس چینل کی ایک کلک کھولی ہو۔
