Claude Codex — Black Edition

VSCode-এর জন্য একটি অফলাইন-প্রথম মাল্টি-প্রদানকারী AI চ্যাট প্যানেল। টগল করতে Ctrl+Alt+B চাপুন।

১. স্বাগতম

Claude Codex Black একটি VSCode ওয়েবভিউ যা আপনাকে একটি একক, থিমযোগ্য প্যানেল থেকে একাধিক AI প্রদানকারীর (Claude, OpenAI, Gemini, Grok, Azure, স্থানীয় Ollama) সাথে চ্যাট করতে দেয়। যে সবকিছুর একটি কী প্রয়োজন তা এক্সটেনশন রুট-এর config.ini থেকে পড়ে — কোনো এক্সটেনশন সেটিংস UI প্রয়োজন নেই, তবে একটি সেটিংস মডেল ক্লিক-শুধু সম্পাদনার জন্য সবচেয়ে দরকারী ক্ষেত্রগুলি প্রতিফলিত করে।

নতুন এখানে? সেটিংস খুলে শুরু করুন (গিয়ার আইকন), আপনার প্রদানকারী চয়ন করুন, আপনার API কী পেস্ট করুন, তারপর একটি প্রম্পট টাইপ করুন এবং Enter চাপুন। এই গাইডের অন্য প্রতিটি বৈশিষ্ট্য ঐচ্ছিক।

३. প্রম্পট বক্স

নীচের বড় সম্পাদনাযোগ্য টেক্সটএরিয়া। টাইপ করুন, পেস্ট করুন, একটি ফাইল ড্র্যাগ করুন, ক্লিপে সংযুক্ত করুন — যা কিছু আপনি এখানে রাখেন তা পরবর্তী API কল-এর ব্যবহারকারী টার্ন।

ফন্টটি আপনার VSCode সম্পাদকের মোনোস্পেস ফন্টে লক করা হয়েছে ( --vscode-editor-font-family CSS ভেরিয়েবলের মাধ্যমে) তাই প্যানেলটি সম্পাদকের ভিতরে বাড়িতে দেখায়।

५. মডেল এবং প্রদানকারী

CBE bridges/-এর অধীনে ড্রপ-ইন .bridge প্লাগইন হিসাবে 11টি ব্রিজ শিপ করে। প্রতিটিটি একটি স্ব-অন্তর্ভুক্ত zip যা manifest.xml + bridge.py + আইকন সহ আসে। একটি নতুন .bridge ফাইল ড্রপ করুন এবং এটি কার্ট্রিজ ড্রপডাউনে উপস্থিত হয় — কোনো এক্সটেনশন কোড পরিবর্তন প্রয়োজন নেই।

টেক্সট-চ্যাট ব্রিজ (7)

  • ChatGPT — chatgpt.com, Plus/Pro সাবস্ক্রিপশন
  • Grok — grok.com, নেটিভ xAI লগইন (অ্যানোনিমাস টায়ার ভারীভাবে গেট করা হয়েছে; প্রথম লগইন করুন)
  • Gemini — gemini.google.com, গুগল অ্যাকাউন্ট
  • Claude — claude.ai, ম্যাজিক-লিংক লগইন (tools/sign_in_helper.py claude একবার চালান)
  • Copilot — copilot.microsoft.com, বিনামূল্যে মাইক্রোসফ্ট অ্যাকাউন্ট
  • DeepSeek — chat.deepseek.com, নেটিভ ইমেল/পাসওয়ার্ড (Google SSO ব্যবহার করবেন না)
  • Ollama — স্থানীয় 127.0.0.1:11434, কোনো লগইন প্রয়োজন নেই

ভিডিও-জেনারেশন ব্রিজ (4)

  • Sora 2 — sora.com, আপনার ChatGPT Plus/Pro লগইন পুনরায় ব্যবহার করে
  • Google Veo — gemini.google.com (Veo মোড), Gemini Advanced সাবস্ক্রিপশন
  • Runway Gen-3/4 — app.runwayml.com, পৃথক Runway সাবস্ক্রিপশন
  • Bing ভিডিও সৃষ্টিকারী — bing.com/videos/create, বিনামূল্যে Sora-2 মাইক্রোসফ্ট অ্যাকাউন্ট সহ

উৎপাদিত ভিডিওগুলি videos/<bridge>/<timestamp>_<prompt-slug>.mp4-এ সংরক্ষণ করে এবং ভিডিও লাইব্রেরি প্যানেলে স্বয়ংক্রিয় খেলায় (নিচে § ভিডিও লাইব্রেরি দেখুন)।

প্রম্পট বক্সের পাশে কার্ট্রিজ ড্রপডাউন থেকে একটি ব্রিজ + মডেল চয়ন করুন, বা সেটিংস → সাধারণ-এর মাধ্যমে। নির্বাচনটি প্রতি-কর্মক্ষেত্র এবং workspaceState-তে স্থিত। একটি নতুন ব্রিজ যোগ করতে, docs/WRITING_BRIDGES.md দেখুন।

५a. ভিডিও লাইব্রেরি

ভিডিও ব্রিজ দ্বারা উৎপাদিত ভিডিওগুলি ব্রাউজ এবং দেখার জন্য একটি নিবেদিত প্যানেল (Sora, Veo, Runway, Bing ভিডিও সৃষ্টিকারী)। কমান্ড প্যালেটের মাধ্যমে খোলে: Claude Codex Black: Open Video Library বা codexBlackEd.openVideoPlayer কমান্ড।

  • সাইডবার videos/<bridge>/-এর অধীনে প্রতিটি .mp4 / .webm / .mov তালিকাভুক্ত করে, ব্রিজ দ্বারা গ্রুপ করা এবং সর্বশেষ-প্রথম সাজানো।
  • তাজা ভিডিও প্রথম খোলার সময় স্বয়ংক্রিয়-খেলায় চলে।
  • প্যানেল 2-সেকেন্ড টিকে videos/ ডিরেক্টরি দেখে — যেকোনো নতুন উৎপাদিত ভিডিও একটি ✨ "শুধু উৎপাদিত" ব্যাজ সহ পপ আপ করে এবং স্বয়ংক্রিয়-খেলায় চলে (Auto ▶ নতুন-এর মাধ্যমে বন্ধ করুন)।
  • 📂 খুলুন-এ ক্লিক করুন আপনার OS ফাইল ম্যানেজারে videos/ ফোল্ডার প্রকাশ করতে।

६. বক্তৃতা থেকে পাঠ্য

মাইক ক্লিক করুন, কথা বলুন, আবার ক্লিক করুন থামাতে (বা নীরবতা-সময়সীমার জন্য অপেক্ষা করুন)। দুটি ইঞ্জিন ক্রমে চেষ্টা করা হয়:

  1. Web Speech API — ওয়েবভিউতে চলমান Google-এর ক্লাউড স্বীকৃতিকারী। আপনার Gmail/Google সেশন ব্যবহার করে; কোনো অতিরিক্ত কী প্রয়োজন নেই।
  2. Windows SAPI (ফলব্যাক) — ওয়েবভিউ মাইক অ্যাক্সেস ব্লক করলে আহ্বান করা পূর্ব-উষ্ণ PowerShell প্রক্রিয়া। [voice] listen_seconds শ্রবণ উইন্ডো config.ini-এ কনফিগারযোগ্য।
SAPI এক্সটেনশন সক্রিয়করণে পূর্ব-উষ্ণ করা হয় তাই প্রথম মাইক ক্লিক 2-4 সেকেন্ডের ঠান্ডা স্টার্ট এড়ায় যা আগে তাড়াতাড়ি থামা-ক্লিক গিলে দিত।

७. স্বয়ংক্রিয় প্রম্পট

স্পিনার সহ ব্যাজ বোতাম। যখন চালু থাকে, নিষ্ক্রিয়তার N সেকেন্ড পরে প্যানেল স্বয়ংক্রিয়ভাবে আপনার কনফিগার করা জাগ্রত পাঠ্য পাঠায়। কাউন্টডাউন অঙ্ক --cbe-highlight-color-এ রেন্ডার করা হয়, যা প্রতিটি স্কিন সংজ্ঞায়িত করে।

জাগ্রত পাঠ্য 🔁 জাগান বোতামের মাধ্যমে সম্পাদনা করুন — এটি wake.txt রাউন্ড-ট্রিপ করে।

८. স্বয়ংক্রিয় পড়া (TTS)

মুখ আইকন। যখন চালু থাকে, প্রতিটি সহায়ক উত্তর Web Speech সংশ্লেষণকারী (Google) বা SAPI ফলব্যাকের মাধ্যমে বলা হয়। একটি নীল হালো আইকনের চারপাশে জ্বলে যখন অডিও খেলা হয়।

९. কমপ্যাক্ট এবং প্রসঙ্গ ব্যবহার

মডেলে পাঠানো কথোপকথন অ্যারে প্রতিটি টার্নের সাথে বৃদ্ধি পায়। কমপ্যাক্ট আইকনের চারপাশের রিং শঙ্কু গ্রেডিয়েন্ট হিসাবে বর্তমান প্রসঙ্গ-উইন্ডো ব্যবহার দেখায় — তাজা হলে খালি, মডেলের প্রসঙ্গ সীমার কাছাকাছি থাকলে পূর্ণ।

ইতিহাস শেষ চার টার্নে ট্রাংকেট করতে কমপ্যাক্ট ক্লিক করুন। পরবর্তী API কল ছোট অ্যারে ব্যবহার করে।

१०. জেগে ওঠার প্রতিক্রিয়া

এক্সটেনশন রুটের wake.txt-এ সংরক্ষিত। নিষ্ক্রিয়তা টাইমার ফায়ার হলে পাঠানোর বার্তা হিসাবে স্বয়ংক্রিয় প্রম্পট দ্বারা ব্যবহৃত। 🔁 টুলবার বোতামের মাধ্যমে সম্পাদনা করুন।

११. ফাইল সংযোজন

📎 ক্লিক করুন এক বা একাধিক ফাইল চয়ন করতে। পিকারে Ctrl বা Shift ধরে রাখুন মাল্টি-নির্বাচনের জন্য। প্রতিটি ফাইল প্রম্পটে একটি ফেন্সড কোড ব্লক হিসাবে ইনলাইন করা হয় এর ফাইলনাম এবং ভাষা সহ। 1 MB-এর বেশি বাইনারি ফাইলগুলি নোটিস সহ স্কিপ করা হয়।

१२. গিট মডেল

📁 গিট ক্লিক করুন। যদি কোনো প্রকল্প ফোল্ডার কনফিগার করা না হয় তবে আপনি প্রথমে একটি ফোল্ডার পিকার পান — নির্বাচিত পথ config.ini-এ [project] path-এ লেখা হয়। পরবর্তী গিট আহ্বানগুলি সেই পথে cwd সেট করে চলে।

१३. গিটহাব সংগ্রহ

আপনার [github] pat-এর কাছে অ্যাক্সেসযোগ্য প্রতিটি রিপোজিটরি তালিকাভুক্ত করে। প্রম্পটে এর ক্লোন URL সন্নিবেশ করতে একটি সারি ক্লিক করুন। তালিকা পেজিনেট করা এবং ক্যাশ করা হয়।

१४. NameSilo ডোমেইন

[namesilo] api_key ব্যবহার করে আপনার NameSilo অ্যাকাউন্টে প্রতিটি ডোমেইন টানে (বা [api_keys] namesilo_api_key ফলব্যাক হিসাবে)। প্রথম খোলার সময়, ফলাফল domains.txt-এ ক্যাশ করা হয়; পরবর্তী প্যানেল বুট ক্যাশ থেকে পরিবেশন করে। মডেলে পুনরায় লোড ক্লিক করুন তাজা ফেচ জোর করতে।

আপনি যদি কখনও "কোনো ডোমেইন নেই" 300 উত্তর কোড দিয়ে দেখেন তবে ট্রেস চ্যানেল চেক করুন — খালি ক্যাশ আর ভবিষ্যত প্যানেল বুটে বিষ দেয় না, তবে অন্য ইনস্টল পথে একটি পুরানো domains.txt পারতে পারে।

१५. স্কিন এবং থিম

🎨 বোতাম একটি আবিষ্কার পিকার পপ করে যা skins/ লাইভ স্ক্যান করে (স্টার্টআপে নয়), তাই রানটাইমে নতুন ফোল্ডার ড্রপ করা যথেষ্ট। প্রতিটি স্কিনের একটি manifest.xml আছে যা এর প্যালেট সংজ্ঞায়িত করে — হাইলাইট রঙ সহ, যা স্বয়ংক্রিয় প্রম্পট কাউন্টডাউন ব্যাজ, ফোকাস রিং এবং তদারকি নাড়ি সব কী করে।

বিল্ট-ইন স্কিন অন্তর্ভুক্ত: gnome (Adwaita ধূসর), terminal (কালো/সবুজ গরম-গোলাপী উচ্চার সহ), tamagotchi (ডিম-শেল পেস্টেল একটি স্প্রাইট মাস্কট প্যানেল সহ), blocky, এবং অন্যদের।

१६. সেটিংস

⚙ গিয়ার থেকে খোলে। ট্যাব:

  • সাধারণ — প্রদর্শন নাম, ডিফল্ট মডেল, এন্টারে পাঠান
  • ভয়েস — মাইক ডিভাইস, listen_seconds, STT ইঞ্জিন পিক, TTS স্বয়ংক্রিয় পড়া
  • আপডেট — is_admin ফ্ল্যাগ, WinSCP সেশন, রিমোট পথ
  • কী — প্রতিটি প্রদানকারীর API কী
  • মনিটর — VSCode তদারকি টগল, পোর্ট, পোল ইন্টারভাল
  • ভাষা — 39 লোকেল থেকে চয়ন করুন; § 17 দেখুন

মডেল সেশনের মধ্যে এর আকার এবং অবস্থান মনে রাখে।

१७. ভাষা

প্যানেল 39টি সবচেয়ে-কথ্য ভাষার অনুবাদ সহ আসে। লোকেল ফাইলগুলি languages/<code>.xml-এ থাকে এবং এক্সটেনশন সক্রিয়করণে একবার লোড করা হয়। অনুপস্থিত কী ইংরেজিতে ফল করে।

সেটিংস → ভাষা-এ আপনার ভাষা চয়ন করুন। প্রতিটি বিকল্পের পাশে একটি ফ্ল্যাগ আইকন দেখানো হয় (assets/flags/<code>.svg থেকে লোড করা)। নির্বাচন config.ini-এ [settings] language-এ সংরক্ষিত হয়।

१८. VSCode তদারকি

একটি Windows সেবা (CBEVSCodeSupervisor) NSSM-এর মাধ্যমে tools/vscode_supervisor.ps1 স্ক্রিপ্ট মোড়ানো এবং http://127.0.0.1:3434/-এ একটি HttpListener বাঁধে। প্যানেলের মনিটর বোতাম নীল জ্বলে যখন তদারকির /status এন্ডপয়েন্ট 200 OK উত্তর দেয়।

যদি HTTP প্রোব ব্যর্থ হয় কিন্তু সেবা ইনস্টল করা হয়, প্যানেলের ওয়াচডগ স্বয়ংক্রিয়ভাবে সেবা পুনরায় শুরু করে (30-সেকেন্ড শীতল-ডাউন যাতে এটি পুনরায় শুরু-ঝড় না করে)।

মনিটর বোতাম বাম-ক্লিক করুন ইনস্টল / শুরু / থামাতে। ট্রেস চ্যানেল খুলতে ডান-ক্লিক করুন।

१९. স্বয়ংক্রিয় আপডেট (পুল)

এক্সটেনশন সক্রিয়করণের 4 সেকেন্ড পরে, প্যানেল https://trentontompkins.com/cbe/manifest.xml.php থেকে সর্বশেষ প্রকাশিত ফাইলগুলির একটি MD5+সাইজ প্রকাশ সংগ্রহ করে। প্রতিটি রিমোট ফাইলের জন্য, স্থানীয় কপির MD5 তুলনা করা হয়; শুধুমাত্র পরিবর্তিত/অনুপস্থিত ফাইলগুলি HTTPS-এর উপর ডাউনলোড করা হয়।

ব্যবহারকারী-স্থানীয় অবস্থা (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) পুল বর্জন তালিকায় আছে এবং কখনই অতিলিখিত হয় না।

२१. এক্সটেনশন মার্কেটপ্লেস

🧩 এক্সটেনশন বোতাম ক্লিক করুন। একটি iframe মডেল https://trentontompkins.com/cbe/extension/extension_marketplace.php-এ খোলে, যা extensions.xml.php থেকে ক্যাটালগ সংগ্রহ করে এবং প্রতিটি উপলব্ধ এক্সটেনশন একটি বর্ণনা, ট্যাগ, সংস্করণ, ফাইল আকার, MD5 এবং একটি ইনস্টল বোতাম সহ কার্ড হিসাবে রেন্ডার করে।

একটি এক্সটেনশন <id>.ext হিসাবে প্যাকেজ করা হয় — একটি জিপ আর্কাইভ যা manifest.xml এবং এক্সটেনশন কোড ধারণ করে (সাধারণত একটি একক extension.html)। যখন আপনি ইনস্টল ক্লিক করেন, মার্কেটপ্লেস iframe একটি postMessage প্যানেলে ফেরত পাঠায়; প্যানেল সার্ভার থেকে সরাসরি .ext ফাইল ডাউনলোড করে এবং এক্সটেনশন ফোল্ডারে extensions/-এর অধীনে বের করে।

তিনটি ডেমো এক্সটেনশন লঞ্চ ক্যাটালগের সাথে আসে: ক্যালকুলেটর, মাইনসুইপার এবং একটি ইমোজি পিকার।
