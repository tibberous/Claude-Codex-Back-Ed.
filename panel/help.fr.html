Codex Black Ed.

Un panel de chat IA multi-fournisseur hors ligne pour VSCode. Appuyez sur Ctrl+Alt+B pour basculer.

1. Bienvenue

Codex Black est une webview VSCode qui vous permet de discuter avec plusieurs fournisseurs d'IA (Claude, OpenAI, Gemini, Grok, Azure, Ollama local) à partir d'un panneau unique et personnalisable. Tout ce qui nécessite une clé est lu à partir de config.ini à la racine de l'extension — aucune interface de paramètres d'extension n'est requise, mais un modal Paramètres reflète les champs les plus utiles pour l'édition au clic uniquement.

Vous débuter ? Commencez par ouvrir Paramètres (icône d'engrenage), choisissez votre fournisseur, collez votre clé API, puis tapez un prompt et appuyez sur Entrée. Chaque autre fonctionnalité dans ce guide est optionnelle.

3. Boîte de prompt

La grande textarea éditable au bas. Tapez, collez, glissez un fichier, attachez via le trombone — tout ce que vous mettez ici est le tour utilisateur du prochain appel API.

La police est verrouillée sur la police monospace de l'éditeur VSCode (via la variable CSS --vscode-editor-font-family) pour que le panel s'intègre bien à l'éditeur.

5. Modèles et fournisseurs

CBE est livré avec 11 bridges en tant que plugins .bridge prêts à l'emploi sous bridges/. Chacun est une archive zip autonome avec manifest.xml + bridge.py + icônes. Déposez un nouveau fichier .bridge et il apparaît dans le menu déroulant de cartouche — aucun changement de code d'extension nécessaire.

Bridges de chat textuel (7)

  • ChatGPT — chatgpt.com, abonnement Plus/Pro
  • Grok — grok.com, connexion native xAI (le niveau anonyme est fortement limité ; connectez-vous d'abord)
  • Gemini — gemini.google.com, compte Google
  • Claude — claude.ai, connexion par lien magique (exécutez tools/sign_in_helper.py claude une fois)
  • Copilot — copilot.microsoft.com, compte Microsoft gratuit
  • DeepSeek — chat.deepseek.com, email/mot de passe natif (N'utilisez PAS Google SSO)
  • Ollama — local 127.0.0.1:11434, aucune connexion requise

Bridges de génération vidéo (4)

  • Sora 2 — sora.com, réutilise votre connexion ChatGPT Plus/Pro
  • Google Veo — gemini.google.com (mode Veo), abonnement Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, abonnement Runway séparé
  • Bing Video Creator — bing.com/videos/create, Sora-2 gratuit avec compte Microsoft

Les vidéos générées sont enregistrées dans videos/<bridge>/<timestamp>_<prompt-slug>.mp4 et sont lues automatiquement dans le panel Bibliothèque vidéo (voir §Bibliothèque vidéo ci-dessous).

Sélectionnez un bridge + modèle dans le menu déroulant de cartouche à côté de la boîte de prompt, ou via Paramètres → Général. La sélection est par espace de travail et persistée dans workspaceState. Pour ajouter un nouveau bridge, voir docs/WRITING_BRIDGES.md.

5a. Bibliothèque vidéo

Un panel dédié pour parcourir et regarder les vidéos générées par les bridges vidéo (Sora, Veo, Runway, Bing Video Creator). S'ouvre via la Palette de commandes : Codex Black: Open Video Library ou la commande codexBlackEd.openVideoPlayer.

  • La barre latérale liste chaque .mp4 / .webm / .mov sous videos/<bridge>/, groupés par bridge et triés du plus récent au plus ancien.
  • La vidéo la plus récente est lue automatiquement à la première ouverture.
  • Le panel surveille le répertoire videos/ sur un cycle de 2 secondes — toute vidéo nouvellement générée s'affiche avec un badge ✨ « Vient d'être généré » et est lue automatiquement (désactivez via Auto ▶ nouveau).
  • Cliquez sur 📂 Ouvrir pour révéler le dossier videos/ dans le gestionnaire de fichiers de votre OS.

6. Reconnaissance vocale

Cliquez sur le micro, parlez, cliquez à nouveau pour arrêter (ou attendez le délai d'expiration du silence). Deux moteurs sont essayés dans l'ordre :

  1. Web Speech API — Le reconnaisseur cloud de Google fonctionnant dans la webview. Utilise votre session Gmail/Google ; aucune clé supplémentaire requise.
  2. Windows SAPI (fallback) — Processus PowerShell préchauffé invoqué lorsque la webview bloque l'accès au micro. Fenêtre d'écoute configurable via [voice] listen_seconds dans config.ini.
SAPI est préchauffé lors de l'activation de l'extension donc le premier clic sur le micro évite le démarrage à froid de 2-4 secondes qui avait l'habitude d'engloutir les clics d'arrêt précoces.

7. Auto Prompt

Le bouton avec badge et spinner. Lorsqu'il est ACTIVÉ, après N secondes d'inactivité, le panel envoie automatiquement votre texte de réveil configuré. Le chiffre du compte à rebours est rendu dans --cbe-highlight-color, que chaque skin définit.

Éditer le texte de réveil via le bouton 🔁 Réveil — cela fait un aller-retour avec wake.txt.

8. Lecture automatique (TTS)

L'icône de bouche. Lorsqu'il est ACTIVÉ, chaque réponse de l'assistant est parlée via le synthesizer Web Speech (Google) ou un fallback SAPI. Un halo bleu brille autour de l'icône pendant que l'audio est en cours de lecture.

9. Compact et utilisation du contexte

Le tableau de conversation envoyé au modèle grandit à chaque tour. L'anneau autour de l'icône Compact affiche l'utilisation actuelle de la fenêtre de contexte comme un dégradé conique — vide au démarrage, plein lorsqu'on s'approche de la limite de contexte du modèle.

Cliquez sur Compact pour tronquer l'historique aux quatre derniers tours. Le prochain appel API utilise le tableau plus petit.

10. Réponse de réveil

Stockée dans wake.txt à la racine de l'extension. Utilisée par Auto Prompt comme le message à envoyer lorsque le minuteur d'inactivité se déclenche. Éditer via le bouton 🔁 de la barre d'outils.

11. Pièces jointes de fichiers

Cliquez sur 📎 pour sélectionner un ou plusieurs fichiers. Maintenez Ctrl ou Maj dans le sélecteur pour multi-sélection. Chaque fichier est intégré dans le prompt comme un bloc de code clôturé avec son nom de fichier et son langage. Les fichiers binaires supérieurs à 1 Mo sont ignorés avec un avis.

12. Modal Git

Cliquez sur 📁 Git. Si aucun dossier de projet n'est configuré, vous obtenez d'abord un sélecteur de dossier — le chemin choisi est écrit dans [project] path dans config.ini. Les invocations git ultérieures s'exécutent avec cwd défini sur ce chemin.

13. Dépôts GitHub

Liste chaque dépôt accessible à votre [github] pat. Cliquez sur une ligne pour insérer son URL de clonage dans le prompt. La liste est paginée et mise en cache.

14. Domaines NameSilo

Récupère chaque domaine de votre compte NameSilo en utilisant [namesilo] api_key (ou [api_keys] namesilo_api_key comme fallback). À la première ouverture, les résultats sont mis en cache dans domains.txt ; les démarrages de panel ultérieurs servent à partir du cache. Cliquez sur Recharger dans le modal pour forcer une récupération fraîche.

Si vous voyez jamais « aucun domaine » avec un code de réponse 300, vérifiez le canal de trace — les caches vides ne polluent plus les démarrages de panel futurs, mais un domains.txt obsolète dans un autre chemin d'installation pourrait.

15. Skins et thèmes

Le bouton 🎨 ouvre un sélecteur de découverte qui scanne skins/ en direct (pas au démarrage), donc déposer un nouveau dossier au runtime suffit. Chaque skin a un manifest.xml définissant sa palette — y compris la couleur de surbrillance, sur laquelle le badge de compte à rebours Auto Prompt, les anneaux de focus, et la pulsion du superviseur s'appuient tous.

Les skins intégrés incluent : gnome (gris Adwaita), terminal (noir/vert avec accent rose vif), tamagotchi (pastels coquille d'œuf avec un panel de mascotte sprite), blocky, et autres.

16. Paramètres

S'ouvre depuis l'engrenage ⚙. Onglets :

  • Général — nom d'affichage, modèle par défaut, envoyer à l'entrée
  • Voix — appareil micro, listen_seconds, choix du moteur STT, TTS lecture auto
  • Mises à jour — drapeau is_admin, session WinSCP, chemin distant
  • Clés — clé API de chaque fournisseur
  • Monitor — basculer superviseur VSCode, port, intervalle de sondage
  • Langue — choisir parmi 39 locales ; voir § 17

Le modal se souvient de sa taille et sa position entre les sessions.

17. Langue

Le panel est livré avec des traductions pour les 39 langues les plus parlées. Les fichiers de locale résident dans languages/<code>.xml et sont chargés une fois lors de l'activation de l'extension. Les clés manquantes reviennent à l'anglais.

Choisissez votre langue dans Paramètres → Langue. Une icône de drapeau est affichée à côté de chaque option (chargée depuis assets/flags/<code>.svg). La sélection est enregistrée dans [settings] language dans config.ini.

18. Superviseur VSCode

Un service Windows (CBEVSCodeSupervisor) enveloppe le script tools/vscode_supervisor.ps1 via NSSM et lie un HttpListener sur http://127.0.0.1:3434/. Le bouton de moniteur du panel brille bleu lorsque le point de terminaison /status du superviseur répond 200 OK.

Si la sonde HTTP échoue mais que le service est installé, le watchdog du panel redémarre automatiquement le service (délai de refroidissement de 30 secondes pour éviter une tempête de redémarrage).

Clic gauche sur le bouton de moniteur pour installer / démarrer / arrêter. Clic droit pour ouvrir le canal de trace.

19. Mise à jour automatique (pull)

4 secondes après l'activation de l'extension, le panel récupère https://trentontompkins.com/cbe/manifest.xml.php — un manifeste MD5+size des derniers fichiers publiés. Pour chaque fichier distant, le MD5 de la copie locale est comparé ; seuls les fichiers modifiés/manquants sont téléchargés via HTTPS.

L'état local de l'utilisateur (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) est sur la liste d'exclusion du pull et n'est jamais écrasé.

20. Admin push

Seuls les clients avec [updates] is_admin = true poussent jamais vers le serveur. Déclenché via :

  • Palette de commandes → Codex Black: Push update
  • Commande slash /push

Utilise la session WinSCP sauvegardée nommée dans [updates] winscp_session (défaut vps). Pousse via /script=… avec la commande de synchronisation et un masque de fichier qui exclut les secrets et l'état par machine.

21. Marketplace Extensions

Cliquez sur le bouton 🧩 Extensions. Un modal iframe s'ouvre sur https://trentontompkins.com/cbe/extension/extension_marketplace.php, qui récupère le catalogue sur extensions.xml.php et rend chaque extension disponible comme une carte avec une description, des tags, la version, la taille du fichier, le MD5, et un bouton Installer.

Une extension est emballée comme <id>.ext — une archive zip contenant manifest.xml plus le code de l'extension (généralement un seul extension.html). Lorsque vous cliquez sur Installer, le iframe marketplace envoie un postMessage au panel ; le panel télécharge le fichier .ext directement depuis le serveur et l'extrait sous extensions/ dans le dossier de l'extension.

Trois extensions de démonstration sont livrées avec le catalogue de lancement : Calculatrice, Démineur, et un Sélecteur d'emoji.

22. Commandes slash

Tapez / dans la boîte de prompt pour ouvrir la palette de commandes slash. Cliquez sur une ligne pour insérer le texte de la commande dans votre prompt (éditable), ou appuyez sur Entrée sur une ligne exécutable pour la lancer immédiatement.

Une liste non exhaustive :

23. Menu contextuel

Cliquez avec le bouton droit n'importe où dans le panel pour un menu contextuel (défini comme une seule chaîne XML dans panel.js). Les entrées incluent Actualiser (recharger le panel sans toucher à l'hôte d'extension — n'utilisez jamais reloadWindow), Effacer la conversation, Ouvrir les paramètres, et Inspecter (DevTools, builds de débogage uniquement).

24. Canaux de trace

L'extension écrit une chronologie granulaire dans debug.log à côté de l'extension. Tout ce qui est notable s'y rend : changements de fournisseur, cycle de vie STT, sondes du superviseur, codes de réponse NameSilo, messages de pont panel↔hôte, comptages de manifeste push/pull.

Cliquez avec le bouton droit sur le bouton de moniteur pour une ouverture en un clic du canal de trace.

25. Dépannage

SymptômeCause probable
La boîte de prompt semble proportionnelle, pas monospace --vscode-editor-font-family non appliqué ; vérifiez les variables :root
Le spinner Auto Prompt est un point noir Mauvais asset SVG ; devrait être auto_read_spinner.svg avec halo d'ombre
Le bouton Compact ne fait rien Gestionnaire hôte manquant — case 'compactConversation' dans le routeur extension.js
« 0 domaines » dans le modal Domaines reply.code NameSilo != 300 (le canal de trace l'a), ou domains.txt obsolète
STT « aucune parole détectée » instantanément Vous avez arrêté avant que SAPI ne lie le micro. Le préchauffage saute maintenant cette attente — vérifiez avec stt: using pre-warmed SAPI dans debug.log
Push échoue sur un chemin avec des espaces Utilisation de /command= en ligne ; toujours utiliser /script=tempfile.winscp
La lueur bleue du superviseur ne s'allume pas Service ne fonctionne pas. Cliquez à gauche sur monitorBtn pour installer/démarrer, ou exécutez Start-Service CBEVSCodeSupervisor
Actualiser « corrige » quelque chose Ce n'est pas le cas. N'utilisez jamais reloadWindow. Utilisez plutôt l'entrée du menu contextuel Actualiser.
