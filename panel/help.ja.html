Codex Black Ed.

VSCodeのオフラインファースト、マルチプロバイダーAIチャットパネル。 Ctrl+Alt+Bでトグル。

1. ようこそ

Codex Blackは、複数のAIプロバイダー（Claude、OpenAI、Gemini、Grok、Azure、ローカルOllama）とチャットできるVSCode Webviewパネルです。 APIキーが必要なものはすべて、拡張機能ルートのconfig.iniから読み込まれます。設定UIは不要ですが、Settingsモーダルではクリックのみで編集できる最も便利なフィールドが表示されます。

初めてですか？Settings（歯車アイコン）を開き、プロバイダーを選択してAPIキーを貼り付け、プロンプトを入力してEnterを押してください。このガイド内の他の機能はすべてオプションです。

3. プロンプトボックス

下部の大きな編集可能テキストエリア。ここに入力、貼り付け、ファイルをドラッグ、またはペーパークリップで添付したものはすべて、次のAPI呼び出しのユーザーターンになります。

フォントはVSCodeエディタのモノスペースフォント（--vscode-editor-font-family CSS变量経由）にロックされているため、パネルはエディタ内で自宅のような見た目になります。

5. モデルとプロバイダー

CBEはbridges/下にドロップイン.bridgeプラグインとして11個のブリッジを搭載しています。各ブリッジは、manifest.xml + bridge.py + アイコンを含む自己完結型のzipです。新しい.bridgeファイルをドロップインするだけで、カートリッジドロップダウンに表示されます。拡張機能コードの変更は不要です。

テキストチャットブリッジ（7個）

  • ChatGPT — chatgpt.com、Plus/Proサブスクリプション
  • Grok — grok.com、ネイティブxAIログイン（匿名層は重く制限されているため、まずログインしてください）
  • Gemini — gemini.google.com、Googleアカウント
  • Claude — claude.ai、マジックリンクログイン（tools/sign_in_helper.py claudeを一度実行）
  • Copilot — copilot.microsoft.com、無料Microsoftアカウント
  • DeepSeek — chat.deepseek.com、ネイティブメール/パスワード（Google SSOは使用しないでください）
  • Ollama — ローカル127.0.0.1:11434、ログイン不要

ビデオ生成ブリッジ（4個）

  • Sora 2 — sora.com、ChatGPT Plus/Proログインを再利用
  • Google Veo — gemini.google.com（Veoモード）、Gemini Advancedサブスクリプション
  • Runway Gen-3/4 — app.runwayml.com、個別Runwayサブスクリプション
  • Bing Video Creator — bing.com/videos/create、無料Sora-2（Microsoftアカウント使用）

生成ビデオはvideos/<bridge>/<timestamp>_<prompt-slug>.mp4に保存され、ビデオライブラリパネルで自動再生されます（下記ビデオライブラリを参照）。

プロンプトボックスの横のカートリッジドロップダウンからブリッジ+モデルを選択するか、Settings → Generalから選択してください。選択はワークスペースごとで、workspaceStateに保持されます。新しいブリッジを追加するには、docs/WRITING_BRIDGES.mdを参照してください。

5a. ビデオライブラリ

ビデオブリッジ（Sora、Veo、Runway、Bing Video Creator）で生成されたビデオを閲覧・視聴するための専用パネル。コマンドパレットから開きます： Codex Black: Open Video LibraryまたはcodexBlackEd.openVideoPlayerコマンド。

  • サイドバーはvideos/<bridge>/下のすべての.mp4 / .webm / .movを一覧表示し、ブリッジでグループ化、最新順でソート。
  • 最新ビデオは最初のオープン時に自動再生。
  • パネルはvideos/ディレクトリを2秒間隔で監視し、新しく生成されたビデオは✨「生成されたばかり」バッジで表示され、自動再生されます（Auto ▶ newでオフに切り替え）。
  • 📂 開くをクリックして、videos/フォルダをOSファイルマネージャーで表示。

6. 音声テキスト変換

マイクをクリック、話す、再度クリックして停止（または無音タイムアウトを待つ）。2つのエンジンが順に試行されます：

  1. Web Speech API — Webviewで実行されるGoogleのクラウド認識エンジン。 Gmail/Googleセッションを使用。追加キー不要。
  2. Windows SAPI（フォールバック）— Webviewがマイクアクセスをブロックするときに呼び出される事前ウォーミングPowerShellプロセス。config.iniの[voice] listen_secondsで設定可能。
SAPIは拡張機能アクティベート時に事前ウォーミングされ、最初のマイククリックで以前は早期ストップクリックを飲み込んでいた2～4秒のコールドスタートを回避します。

7. 自動プロンプト

バッジ付きスピナーボタン。ON時、N秒の非アクティブ状態の後、パネルは設定されたウェイクアップテキストを自動送信します。カウントダウン数字は、各スキンが定義する--cbe-highlight-colorでレンダリングされます。

🔁 Wakeボタンでウェイクアップテキストを編集します。wake.txtにラウンドトリップします。

8. 自動読み上げ (TTS)

口のアイコン。ON時、すべてのアシスタント返信はWeb Speech合成（Google）またはSAPIフォールバックで音声化されます。オーディオ再生中、アイコンの周りに青いハロが輝きます。

9. コンパクト＆コンテキスト使用

モデルに送信される会話配列は、ターンごとに成長します。Compactアイコンの周りのリングは、現在のコンテキストウィンドウ使用を円錐勾配として表示します。新規のときは空、モデルのコンテキスト制限に近いときは満杯です。

Compactをクリックして履歴を最後の4ターンに切り詰めます。次のAPI呼び出しは小さい配列を使用します。

10. ウェイクアップレスポンス

拡張機能ルートのwake.txtに保存。非アクティブタイマーが発火したときに自動プロンプトが送信するメッセージとして使用。🔁ツールバーボタンで編集します。

11. ファイル添付

📎をクリックして1つ以上のファイルを選択。ピッカーでCtrlまたはShiftを押して複数選択。各ファイルはプロンプトに、ファイル名と言語を持つフェンスコードブロックとしてインライン化されます。1 MBを超えるバイナリファイルはスキップされます。

12. Gitモーダル

📁 Gitをクリック。プロジェクトフォルダが設定されていない場合は、最初にフォルダピッカーが表示されます。選択したパスはconfig.iniの[project] pathに書き込まれます。その後のgit呼び出しは、そのパスをcwdとして実行されます。

13. GitHubリポジトリ

[github] patでアクセス可能なすべてのリポジトリを一覧表示。行をクリックしてそのクローンURLをプロンプトに挿入。リストはページネーション済みとキャッシュ済み。

14. NameSiloドメイン

[namesilo] api_key（またはフォールバックとして[api_keys] namesilo_api_key）を使用してNameSiloアカウント内のすべてのドメインを取得。最初のオープン時、結果はdomains.txtにキャッシュされます。その後のパネルブートはキャッシュから提供されます。モーダルでReloadをクリックして強制的に新規フェッチします。

「ドメインなし」と300応答コードが表示される場合は、トレースチャネルを確認してください。空キャッシュは以降のパネルブートに悪影響をもたらしなくなりましたが、別のインストールパスの古いdomains.txtが存在する可能性があります。

15. スキン＆テーマ

🎨ボタンがディスカバリーピッカーを開き、skins/をライブスキャン（スタートアップではなく）するため、実行時に新しいフォルダをドロップするだけで十分です。各スキンは、パレット（ハイライトカラーを含む）を定義するmanifest.xmlを持ちます。ハイライトカラーは、自動プロンプトカウントダウンバッジ、フォーカスリング、スーパーバイザーパルスが参照します。

組み込みスキンには：gnome（Adwaitaグレー）、terminal（黒/緑、ホットピンクアクセント）、tamagotchi（卵殻パステル、スプライトマスコットパネル）、blockyなど。

16. 設定

⚙歯車から開きます。タブ：

  • General — 表示名、デフォルトモデル、Enterで送信
  • Voice — マイクデバイス、listen_seconds、STTエンジン選択、TTS自動読み上げ
  • Updates — is_adminフラグ、WinSCPセッション、リモートパス
  • Keys — すべてのプロバイダーのAPIキー
  • Monitor — VSCodeスーパーバイザートグル、ポート、ポーリング間隔
  • Language — 39のロケールから選択。§ 17を参照。

モーダルはセッション間でそのサイズと位置を記憶します。

17. 言語

パネルは39の最も話される言語の翻訳を搭載しています。ロケールファイルはlanguages/<code>.xmlに存在し、拡張機能アクティベート時に一度読み込まれます。不足キーは英語にフォールバックします。

Settings → Languageで言語を選択。各オプションの横に国旗アイコンが表示されます（assets/flags/<code>.svgから読み込み）。選択はconfig.iniの[settings] languageに保存されます。

18. VSCodeスーパーバイザー

Windowsサービス（CBEVSCodeSupervisor）はtools/vscode_supervisor.ps1スクリプトをNSSM経由でラップし、http://127.0.0.1:3434/上のHttpListenerにバインドします。スーパーバイザーの/statusエンドポイントが200 OKで応答するとき、パネルのモニターボタンは青く輝きます。

HTTPプローブが失敗してもサービスがインストールされている場合、パネルのウォッチドッグはサービスを自動再開します（30秒クールダウン、再起動ストームしないように）。

モニターボタンを左クリックしてインストール/開始/停止。右クリックしてトレースチャネルを開く。

19. 自動更新 (プル)

拡張機能アクティベートから4秒後、パネルはhttps://trentontompkins.com/cbe/manifest.xml.phpを取得します。これは最新公開ファイルのMD5+サイズマニフェストです。各リモートファイルについて、ローカルコピーのMD5が比較され、変更/不足ファイルのみHTTPS経由で ダウンロードされます。

ユーザーローカルステート（config.ini、debug.log、domains.txt、wake.txt、prompt_history.txt）はプル除外リストに含まれ、上書きされません。

20. 管理者プッシュ

[updates] is_admin = trueのクライアントのみがサーバーにプッシュできます。トリガー：

  • コマンドパレット → Codex Black: Push update
  • スラッシュコマンド/push

[updates] winscp_sessionで指定されたWinSCP保存セッション（デフォルトvps）を使用。/script=…でプッシュし、synchronizeコマンドを使用し、秘密とマシンごとのステートを除外するfilemaskがあります。

21. 拡張機能マーケットプレイス

🧩 Extensions ボタンをクリック。iframeモーダルがhttps://trentontompkins.com/cbe/extension/extension_marketplace.phpに開き、extensions.xml.phpでカタログを取得し、利用可能な各拡張機能を説明、タグ、バージョン、ファイルサイズ、MD5、Installボタン付きカードとしてレンダリングします。

拡張機能は<id>.extとしてパッケージ化されます。manifest.xmlと拡張機能コード（通常は単一のextension.html）を含むzipアーカイブ。Install をクリックすると、マーケットプレイスiframeはpostMessageでパネルに戻し、パネルはサーバーから直接.extファイルをダウンロードし、拡張機能フォルダ下のextensions/に抽出します。

3つのデモ拡張機能がローンチカタログで提供されます：Calculator、Minesweeper、Emoji Picker。

22. スラッシュコマンド

プロンプトボックスで/を入力してスラッシュコマンドパレットを開きます。行をクリックしてコマンドテキストをプロンプトに挿入（編集可能）するか、実行可能な行でEnterを押して即座に実行。

完全ではないリスト：

コマンド効果
/helpこのドキュメントを開く
/skinスキンピッカーをポップ
/push自動更新プッシュを実行（管理者のみ）
/licenseLICENSE.TXTを表示
/clear会話履歴をクリア
/domainsNameSiloドメインモーダルを開く
/gitGitモーダルを開く
/wakeウェイクアップエディタを開く
/memoryプロジェクトメモリインデックスを開く

23. 右クリックメニュー

パネル内の任意の場所で右クリックしてコンテキストメニューを取得（panel.jsの単一XMLストリングとして定義）。エントリには、リフレッシュ（拡張機能ホストに触れずパネルをリロード。reloadWindowは絶対に使用しないでください）、会話をクリア、設定を開く、インスペクト（DevTools、デバッグビルドのみ）が含まれます。

24. トレースチャネル

拡張機能は拡張機能の隣のdebug.logに細粒度タイムラインを書き込みます。注目すべきことはすべてそこに記録されます：プロバイダー切り替え、STTライフサイクル、スーパーバイザープローブ、NameSilo応答コード、パネル↔ホストブリッジメッセージ、プッシュ/プルマニフェスト数。

モニターボタンを右クリックしてトレースチャネルをワンクリックで開きます。

25. トラブルシューティング

症状考えられる原因
プロンプトボックスが等幅ではなくプロポーショナルに見える --vscode-editor-font-familyが適用されていない。:root変数をチェック
自動プロンプトスピナーが黒い点 SVGアセットが間違っている。auto_read_spinner.svgでドロップシャドウハロが必要
Compactボタンが何もしない ホストハンドラが不足。extension.jsルータでcase 'compactConversation'
ドメインモーダルで「0個のドメイン」 NameSilo reply.code != 300（トレースチャネルに記録）、または古いdomains.txt
STT「音声が検出されない」（即座） SAPIがマイクをバインドする前に停止。事前ウォーミングはこの待機をスキップするようになりました。debug.logでstt: using pre-warmed SAPIを確認
スペース付きパスでプッシュが失敗 /command=インラインを使用。常に/script=tempfile.winscpを使用
スーパーバイザーの青い光が点灯しない サービスが実行されていない。monitorBtn の左クリックでインストール/開始するか、Start-Service CBEVSCodeSupervisorを実行
リロードで「修正」される 修正されていません。reloadWindowは絶対に使用しないでください。代わりにリフレッシュコンテキストメニューエントリを使用。
