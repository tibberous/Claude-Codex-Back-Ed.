Claude Codex — Black Edition

Автономна багатопровайдерна AI панель чату для VSCode. Натисніть Ctrl+Alt+B для вмикання.

1. Привіт

Claude Codex Black — це VSCode webview, який дозволяє спілкуватися з кількома AI провайдерами (Claude, OpenAI, Gemini, Grok, Azure, локальний Ollama) з однієї, налаштовуваної панелі. Все, що потребує ключа, читається з config.ini в корені розширення — UI параметрів розширення не потрібний, але модальне вікно параметрів дублює найзручніші поля для редагування кліком.

Новачок? Почніть з відкриття Параметрів (значок шестерні), виберіть свого провайдера, вставте ваш API ключ, потім введіть запит і натисніть Enter. Усі інші функції в цій інструкції є необов'язковими.

3. Поле запиту

Велика редагована текстова область внизу. Вводьте, вставляйте, перетягуйте файл, вкладіть через скріпку — все, що ви сюди помістите, буде користувацьким повідомленням наступного виклику API.

Шрифт заблокований на моноширинному шрифті вашого редактора VSCode (через --vscode-editor-font-family CSS змінну), тому панель виглядає органічно всередині редактора.

5. Моделі та провайдери

CBE поставляється з 11 мостами як plug-and-play .bridge плагіни у bridges/. Кожен — це автономний zip з manifest.xml + bridge.py + значками. Розмістіть новий .bridge файл і він з'явиться в раскривному меню картриджа — змінювати код розширення не потрібно.

Текстові чат-мости (7)

  • ChatGPT — chatgpt.com, Plus/Pro підписка
  • Grok — grok.com, вхід xAI (анонімний рівень сильно обмежений; спочатку увійдіть)
  • Gemini — gemini.google.com, обліковий запис Google
  • Claude — claude.ai, вхід за магічним посиланням (запустіть tools/sign_in_helper.py claude один раз)
  • Copilot — copilot.microsoft.com, безплатний обліковий запис Microsoft
  • DeepSeek — chat.deepseek.com, вхід за email/паролем (НЕ використовуйте Google SSO)
  • Ollama — локальний 127.0.0.1:11434, вхід не потрібен

Мости генерування відео (4)

  • Sora 2 — sora.com, повторне використання вашого ChatGPT Plus/Pro входу
  • Google Veo — gemini.google.com (режим Veo), підписка Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, окрема підписка Runway
  • Bing Video Creator — bing.com/videos/create, безплатний Sora-2 з обліковим записом Microsoft

Згенеровані відео зберігаються в videos/<bridge>/<timestamp>_<prompt-slug>.mp4 та автоматично відтворюються на панелі Відеотеки (дивіться §Відеотека нижче).

Виберіть мість + модель з раскривного меню картриджа поруч з полем запиту або через Параметри → Основне. Вибір залежить від робочої области і зберігається в workspaceState. Щоб додати новий мість, дивіться docs/WRITING_BRIDGES.md.

5a. Відеотека

Спеціалізована панель для перегляду та просмотру видео, згенерованих мостами для відео (Sora, Veo, Runway, Bing Video Creator). Відкривається через Палітру команд: Claude Codex Black: Open Video Library або команду codexBlackEd.openVideoPlayer.

  • Бічна панель містить кожен .mp4 / .webm / .mov під videos/<bridge>/, згруповані за мостом і відсортовані від новіших.
  • Найсвіжіше відео автоматично відтворюється при першому відкритті.
  • Панель стежить за директорією videos/ з інтервалом у 2 секунди — будь-яке нове згенероване відео з'являється з бейджем ✨ "Щойно згенеровано" та автоматично відтворюється (вимкніть через Авто ▶ новий).
  • Натисніть 📂 Відкрити для відкриття папки videos/ у менеджері файлів ОС.

6. Розпізнавання мовлення

Натисніть мікрофон, говоріть, натисніть знову для зупинки (або чекайте тайм-ауту тишини). Спробовуються два механізми поспіль:

  1. Web Speech API — хмарний розпізнавач Google, що працює у webview. Використовує вашу сесію Gmail/Google; додатковий ключ не потрібен.
  2. Windows SAPI (резервний) — попередньо розігріт процес PowerShell, викликається коли webview блокує доступ до мікрофона. Налаштовуване вікно прослуховування через [voice] listen_seconds у config.ini.
SAPI попередньо розігрівається при активуванні розширення, тому перший клік мікрофона уникає холодного запуску в 2-4 секунди, який раніше проглинав ранні кліки зупинки.

7. Автоматичний запит

Кнопка з бейджем та спінером. Коли УВІМКНЕНО, після N секунд неактивності панель автоматично надсилає ваш налаштований текст активації. Цифра зворотного відліку відображається у --cbe-highlight-color, який визначає кожна тема.

Редагуйте текст активації через кнопку 🔁 Активація — він синхронізується з wake.txt.

8. Автоматичне читання (TTS)

Значок рота. Коли УВІМКНЕНО, кожна відповідь асистента озвучується через Web Speech синтезатор (Google) або резервний SAPI. Синій ореол світиться навколо значка під час відтворення аудіо.

9. Компактний режим та використання контексту

Масив розмови, що надсилається моделі, зростає з кожним повідомленням. Кільце навколо значка Компактне показує поточне використання вікна контексту як конічний градієнт — порожньо на новому, повно при наближенні до обмеження контексту моделі.

Натисніть Компактне для обрізування історії до останніх чотирьох повідомлень. Наступний виклик API використовуватиме менший масив.

10. Відповідь активації

Зберігається у wake.txt в корені розширення. Використовується Автоматичним запитом як повідомлення для надсилання при спрацюванні таймера неактивності. Редагуйте через кнопку 🔁 на панелі інструментів.

11. Вкладення файлів

Натисніть 📎 для вибору одного або більше файлів. Утримуйте Ctrl або Shift у засобі вибору для багатовибору. Кожен файл вставляється в запит як оголошений блок коду з його іменем та мовою. Бінарні файли більше 1 МБ пропускаються із повідомленням.

12. Git модальне вікно

Натисніть 📁 Git. Якщо папка проекту не налаштована, спочатку отримуєте засіб вибору папки — обрана точка записується в [project] path у config.ini. Наступні виклики git запускаються з cwd, встановленим на цю точку.

13. Репозиторії GitHub

Список всіх репозиторіїв, доступних вашому [github] pat. Натисніть рядок для вставлення його URL клону в запит. Список розбивається на сторінки та кешується.

14. Домени NameSilo

Отримує кожен домен у вашому обліковому записі NameSilo за допомогою [namesilo] api_key (або [api_keys] namesilo_api_key як резервна). При першому відкритті результати кешуються до domains.txt; наступні запуски панелі служать з кешу. Натисніть Перезавантажити в модальному вікні для примусового отримання нових даних.

Якщо ви коли-небудь бачите "домени не знайдено" з кодом відповіді 300, перевірте канал трасування — порожні кеші більше не отруюють майбутні запуски панелі, але застарілий domains.txt в іншій точці встановлення міг би.

15. Скіни та теми

Кнопка 🎨 відкриває засіб вибору виявлення, який сканує skins/ в реальному часі (не при запуску), тому розміщення нової папки під час роботи достатньо. Кожна тема має manifest.xml, що визначає її палітру — включаючи колір виділення, на який посилаються бейдж зворотного відліку Автоматичного запиту, кільця фокуса та пульс супервізора.

Вбудовані теми включають: gnome (сірий Adwaita), terminal (чорний/зелений з яскраво-рожевим акцентом), tamagotchi (пастельна шкаралупа яйця з спрайтом маскота на панелі), blocky та інші.

16. Параметри

Відкривається з шестерні ⚙. Вкладки:

  • Основне — іменування дисплея, модель за умовчанням, надсилання при Enter
  • Голос — пристрій мікрофона, listen_seconds, вибір двигуна STT, автоматичне читання TTS
  • Оновлення — прапор is_admin, сесія WinSCP, віддалена точка
  • Ключі — ключ API кожного провайдера
  • Монітор — вмикання супервізора VSCode, порт, інтервал опитування
  • Мова — вибір з 39 локалів; дивіться § 17

Модальне вікно запам'ятовує свій розмір та положення між сеансами.

17. Мова

Панель поставляється з перекладами для 39 найбільш розповсюджених мов. Файли локалей живуть у languages/<code>.xml і завантажуються один раз при активуванні розширення. Відсутні ключі повертаються до англійської.

Виберіть мову у Параметри → Мова. Рядом з кожним варіантом показується значок прапора (завантажується з assets/flags/<code>.svg). Вибір зберігається в [settings] language у config.ini.

18. Супервізор VSCode

Сервіс Windows (CBEVSCodeSupervisor) обгортає tools/vscode_supervisor.ps1 скрипт через NSSM і прив'язує HttpListener на http://127.0.0.1:3434/. Кнопка монітору панелі світить синім, коли кінцева точка /status супервізора відповідає 200 OK.

Якщо HTTP проба не вдається, але сервіс встановлено, сторож панелі автоматично перезапускає сервіс (30-секундне охолодження для запобігання перезапуску).

Лівий клік на кнопку монітору для встановлення / запуску / зупинення. Правий клік для відкриття каналу трасування.

19. Автоматичне оновлення (завантаження)

Через 4 секунди після активуванння розширення, панель завантажує https://trentontompkins.com/cbe/manifest.xml.php — маніфест MD5+розмір останніх опублікованих файлів. Для кожного віддаленого файлу MD5 локальної копії порівнюється; завантажуються лише змінені/відсутні файли через HTTPS.

Стан користувача (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) знаходиться на списку виключення завантаження і ніколи не перезаписується.

20. Адміністративна синхронізація

Тільки клієнти з [updates] is_admin = true коли-небудь синхронізуються з сервером. Спрацьовується через:

  • Палітра команд → Claude Codex Black: Push update
  • Команда з косою рискою /push

Використовує збережену сесію WinSCP, названу у [updates] winscp_session (за умовчанням vps). Синхронізує через /script=… з командою синхронізації та маскою файлів, яка виключає секрети та стан кожної машини.

21. Ринок розширень

Натисніть кнопку 🧩 Розширення. Модальне вікно iframe відкривається на https://trentontompkins.com/cbe/extension/extension_marketplace.php, яке завантажує каталог з extensions.xml.php і відображає кожне доступне розширення як картку з описом, тегами, версією, розміром файлу, MD5 та кнопкою Встановити.

Розширення упакується як <id>.ext — архів zip, що містить manifest.xml плюс код розширення (зазвичай один extension.html). Коли ви натискаєте Встановити, iframe ринку надсилає postMessage назад панелі; панель завантажує .ext файл безпосередньо з сервера й витягує його під extensions/ в папку розширення.

Три демо розширення поставляються з каталогом запуску: Калькулятор, Мінний рядок та Засіб вибору емодзі.

22. Команди з косою рискою

Введіть / у полі запиту для відкриття палітри команд з косою рискою. Натисніть рядок для вставлення тексту команди в ваш запит (редагується), або натисніть Enter на виконуваному рядку для його негайного запуску.

23. Контекстне меню

Правий клік будь-де на панелі для контекстного меню (визначено як єдиний рядок XML у panel.js). Записи включають Оновити (перезавантажити панель без торкання хоста розширення — ніколи не використовуйте reloadWindow), Очистити розмову, Відкрити параметри та Інспектувати (DevTools, тільки складання налагодження).

24. Канал трасування

Розширення записує деталізовану часову шкалу в debug.log поруч з розширенням. Все значуще потрапляє туди: перемикання провайдера, життєвий цикл STT, проби супервізора, коди відповідей NameSilo, повідомлення мосту панелі↔хоста, рахунки маніфестів push/pull.

Правий клік на кнопку монітору для одноразового відкриття каналу трасування.

25. Усунення несправностей

СимптомВірогідна причина
Поле запиту виглядає пропорційно, а не моноширинно --vscode-editor-font-family не застосована; перевірте змінні :root
Спінер Автоматичного запиту — це чорна крапка Невірний ресурс SVG; повинен бути auto_read_spinner.svg з ореолом drop-shadow
Кнопка Компактне нічого не робить Відсутня обробка на хості — case 'compactConversation' в маршрутизаторі extension.js
"0 доменів" у модальному вікні Доменів NameSilo reply.code != 300 (канал трасування має її), або застарілий domains.txt
STT "мовлення не виявлено" миттєво Ви зупинили перед тим, як SAPI прив'язав мікрофон. Попередня розігрівка тепер пропускає це очікування — перевірте stt: using pre-warmed SAPI у debug.log
Push не вдається на точці з пробілами Використовує /command= вбудовану; завжди використовуйте /script=tempfile.winscp
Синій ореол супервізора не світить Сервіс не запущено. Лівий клік на monitorBtn для встановлення/запуску або запустіть Start-Service CBEVSCodeSupervisor
Перезавантаження "виправляє" щось Це не так. Ніколи не використовуйте reloadWindow. Замість цього використовуйте запис контекстного меню Оновити.
