Claude Codex — Black Edition

Окремий AI-панель для VSCode. Чат з будь-яким постачальником LLM (прямий API або мостик браузера), з вбудованими TTS, STT, прикріпленням до файлів, палітрою команд, мультиакаунтом, скінами та цифровим домашнім улюбленцем Tamagotchi.

Швидкий старт ↑ вгору

  1. Натисніть Setup (іконка палички) та пройдіть майстра, щоб введення ключів API. Вони зберігаються у config.ini (який gitignore — ніколи не коммітиться).
  2. Натисніть на таблетку постачальника внизу ліворуч (зараз позначена як "Claude Codex — Black Edition"), щоб перейти до іншого ШІ.
  3. Введіть текст у текстове поле та натисніть Enter для відправлення. Shift+Enter вставляє новий рядок.
  4. Натисніть ↑ в порожньому текстовому полі, щоб повернути попередні запити (історія у стилі PowerShell).

Кожен мостик — це невеликий C++ tray exe у bin/CBE-Bridge-<Target>.exe, який відкриває профіль Chrome, в якому ви увійшли, перехоплює ваш запит і повертає відповідь моделі. Вибір постачальника мостика у параметрах автоматично запускає відповідний exe. Вперше, коли ви використовуєте мостик, ви повинні увійти на сайт у його вікні Chrome один раз.

Чат мостика говорить протоколом лінійної протоколізації на TCP: один рядок JSON на вході ({action:"chat", target, message, model}), один рядок JSON на виході. Ключ API не потрібен.

Відправлення повідомлень ↑ вгору

Текстове поле
Введіть свій запит. Enter відправляє, Shift+Enter вставляє новий рядок. Поки йде потокова передача відповіді, додаткові запити ставляться в чергу і відправляються по черзі — заповнювач показує "Поставити іще одне повідомлення в чергу…" під час цього стану.
Кнопка відправлення (куля)
Круглу кнопку на правому краї текстового поля. Те саме, що Enter. Візуально показує три стани (неактивна / наведення / активна).
Кнопка зупинки
Внизу праворуч композитора. Скасовує потікову передачу відповіді, яка зараз передається, і будь-які повідомлення в черзі. Потікова передача тексту зберігається; скасовується лише активний запит.
Таблетка постачальника
Внизу ліворуч композитора. Натисніть, щоб отримати розкривний список кожного постачальника, який ви налаштували. Вибір нового автоматично запускає його мостик (якщо застосовується) і публікує сповіщення підтвердження.
Історія запитів
↑ / ↓ у порожньому текстовому полі переходять в минулому / вперед останніх 500 запитів, які ви надіслали (у стилі PowerShell). Історія зберігається у prompt_history.txt у папці розширення та зберігається при перезавантаженнях панелі.

Кнопки панелі інструментів ↑ вгору

Перелічені в порядку панелі інструментів. Усі підказки локалізовані для кожної мови через languages/*.xml.

Нова розмова addBtn
Очищує поточний потік, видаляє стан розмови в пам'яті та починає з нуля. Попередній потік зберігається на диску у chats/<UTC-date>.log, тому нічого не втрачається. Еквівалент /clear.
Збережені запити storedPromptsBtn
Відкриває модальне вікно зі списком кожного шаблону збереженого запиту у stored_prompts/. Натисніть на один, щоб вставити його в текстове поле; кнопка "+" додає новий шаблон. Шаблони підтримують підстановку змінних.
Історія чату chatHistoryBtn
Переглядає журнал чату на диску (один файл на дату UTC у chats/). Виберіть дату, щоб прокрутити назад минулих розмов.
Прикріпити файл attachFileBtn
Відкриває вибірник файлів. Вибраний файл завантажується з наступним запитом — зображення переходять вбудовані (бачення), файли текст/код стають огородженим блоком у вашому запиті. Підтримує множинне прикріплення.
Читати вголос (TTS) ttsBtn
Вимовляє найновішу відповідь помічника вголос. Використовує ElevenLabs (якщо встановлено [elevenlabs] api_key) або повертається до Windows SAPI. Натисніть правою кнопкою, щоб перемкнути режим автоматичного читання, де кожна нова відповідь вимовляється автоматично — кнопка отримує анімований індикатор під час активності.
Мова в текст (STT) sttBtn
Записує аудіо з мікрофона та транскрибує у текстове поле. Спочатку спробуйте Web Speech API webview; якщо це не вдається (not-allowed, часто у пісочницях VSCode), повертається до Windows SAPI (System.Speech.Recognition), запущено на хості через PowerShell. Натисніть знову, щоб зупинити.
Автозапит autoReplyBtn
Відкриває модальне вікно Auto Prompt. Визначте запит + інтервал зворотного відліку; після кожної відповіді помічника зворотний відлік відраховується і автоматично повторно надсилає автозапит, коли він досягне нуля. Корисно для "продовжити", "наступний крок", повторні сеанси інструменту. Натисніть знову, щоб вимкнути.
Відповідь на пробудження wakeUpBtn
Редагує повідомлення про пробудження, збережене у wake.txt. Пробудження — це те, що Auto Prompt надсилає, якщо він виявляє, що модель застрягла — загалом короткий пінг на зразок "Привіт! Продовжуй."
Показати меню команд showCommandsBtn
Відкриває палітру команд з косою рискою в модальному вікні. Дивіться Команди косої риски для повного списку. Те саме, що введення / на початку текстового поля.
Компактна розмова compactBtn
Публікує запит на підведення підсумків та видалення, який замінює поточний потік скороченим коротким змістом. Еквівалент /compact. Корисно, коли розмова виросла і ви хочете зберегти контекст, але припинити витрачання токенів на повторну передачу всієї історії.
Довідник handbookBtn
Відкриває модальне вікно довідника для співробітників/проекту. Завантажує handbook.html або будь-який інший налаштований документ. Використовується як довідка системної підказки, яку модель може бути попросена консультуватись.
Параметри settingsBtn
Відкриває модальне вікно параметрів (постачальник, модель, скін, мова, SFX). Див. Параметри.
Акаунти accountsBtn
Відкриває менеджер багатоакаунту. Додавайте / редагуйте / видаляйте ключі API для кожного постачальника, перемикайтеся між ними в сеансі. Див. Акаунти.
Розширення extensionsBtn
Відкриває браузер розширень панелі. Перелічує те, що встановлено у extensions/ (кожне з manifest.xml + HTML entry), дозволяє вам закріпити розширення на панелі інструментів, встановити нові з каталогу, або видалити їх.
Папка проекту projectFolderBtn

Меню правої кнопки ↑ вгору

Показує необроблене HTML/markdown клацаного регіону — або блоку коду, або всього DOM панелі. Корисно для налагодження проблем зі скіном/CSS.

Про програму new
Невелике діалогове вікно панелі з версією, авторством, ліцензією, посиланням на репо, портфоліо та номером контакту. Закривається при натисканні на фон, кнопку × або Esc.
Перезавантажити панель new
Перечитує panel/index.html + panel.js + skins/* з кешем-бастером ?v=<mtime> для кожного файлу та перепризначає panel.webview.html. Підхоплює редагування CSS/JS без перезавантаження VSCode. Хост розширення залишається живим — термінал, розумник, історія чату — все зберігається.
Перезавантажити вікно new
Викликає workbench.action.reloadWindow. Використовуйте це тільки, коли ви відредагували extension.js (код на боці хоста) і перезавантаження панелі недостатньо. Це повне перезавантаження вікна VSCode.

Модальні вікна та діалоги ↑ вгору

Модальне вікно параметрів — постачальник / модель / скін / мова / SFX
  • Постачальник: повний розкривний список кожного прямого API + мостика постачальника. Вибір одного переміщує активний сеанс І автоматично запускає відповідний exe мостика (якщо застосовується).
  • Модель: список дозволених моделей для кожного постачальника (напр. claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 для Anthropic).
  • Скін: візуальна тема. Див. Скіни.
  • Мова: 39 локалей доступні. Переключення повторно витягує карту рядків та перетворює кожен інструмент / мітку / кнопку довідки в реальному часі.
  • SFX увімкнено: перемикати звукові ефекти інтерфейсу (клацання, тики, відкриття/закриття модалей тощо).
  • Гучність SFX: 0–100 повзунок. Переглядається в реальному часі, коли ви перетягуєте.
  • Скасувати відновлює будь-які попередні перегляди (SFX/скін), які ви спробували; Зберегти зберігає та випускає setProvider.
Майстер настройки — ввід ключа API в кілька кроків

Пошаговий процес для кожної інтеграції. Кожен крок запитує облікові дані та записує їх у config.ini. Пропустити переходить без запису; Далі записує та просувається; фінальний крок Готово закриває. Кроки включають: Anthropic, OpenAI, Gemini, xAI/Grok, GitHub PAT, Email/SMTP (пароль застосунку Gmail), Cloudflare, Twilio, ElevenLabs, Stability AI, Runway, SendGrid, NameSilo та інші.

Модальне вікно акаунтів — менеджер ключів API для багатоакаунту

Для кожного постачальника керуйте кількома позначеними акаунтами (напр. "особистий", "робочий"). Переміщуйтеся, який є активним для сеансу, без перезаписування інших. Ключі маскуються від кінця до кінця та зберігаються для кожного постачальника у config.ini.

Модальне вікно доменів — NameSilo

Перелічує кожен домен у вашому акаунті NameSilo з серверами імен + датами реєстрації. Кнопка Перезавантажити примусово отримує свіжу вибірку API (інакше кешує у domains.txt).

Модальне вікно довідника

Відображає HTML довідника проекту (мається на увазі як довідка системної підказки, яку модель може консультуватись). Налаштовується для кожного проекту.

Модальне вікно збережених запитів

Вставні шаблони запитів із stored_prompts/. Кожен файл — один шаблон; префікс імені файлу NN- керує порядком сортування. Кнопка "+" створює новий.

Модальне вікно історії чату

Виберіть дату UTC для завантаження журналу чату із chats/<date>.log. Тільки для читання.

Модальне вікно розширень

Карти для кожного встановленого розширення. Закріпіть до панелі інструментів / видаліть закріплення, встановіть з публічного каталогу (extensions.xml.php на сервері) або видаліть із диску.

Модальне вікно журналу змін

Відображає panel/change_log.html — розповсюджені примітки до випуску. Створюється через tools/build_changelog.py.

Модальне вікно View Source

Красиво виводить будь-який блок коду або повний HTML панелі з підсвічуванням синтаксису Prism та кнопкою копіювання. Доступно через правку → Переглянути джерело.

Модальне вікно Auto Prompt

Налаштуйте рядок запиту + інтервал зворотного відліку. Після кожної відповіді помічника зворотний відлік зменшується; коли він досягає нуля, CBE автоматично надсилає налаштований запит. Перемикається ввімкнено/вимкнено кнопкою Auto Prompt панелі інструментів.

Параметри ↑ вгору

Усі параметри розташовані в одному з двох місць:

  • workspaceState (керується VSCode, для кожного робочого простору) — постачальник, модель, скін, мова, sfx увімкнено/гучність, розмір шрифту.
  • config.ini (корінь розширення, gitignore) — ключі API + облікові дані для кожної інтеграції.

Параметри зберігаються автоматично при перезавантаженнях панелі. Модальне вікно Параметри — безпечний спосіб змінити що-небудь; пряме редагування config.ini також працює.

Акаунти та ключі API ↑ вгору

Кожен постачальник може мати кілька позначених акаунтів — корисно, якщо ви хочете перемикатися між персональними та робочими ключами, або тестувати інший рівень. Модальне вікно акаунтів дозволяє вам:

  • Додати новий акаунт з міткою + ключем
  • Редагувати існуючий акаунт (перемітити, замінити ключ)
  • Встановити, який акаунт активний для поточного сеансу
  • Видалити акаунт

Ключі зберігаються замаскованими (видно тільки останні чотири) у config.ini. Немає копії у звичайному тексті у workspaceState.

Скіни ↑ вгору

Візуальні теми для всієї панелі — кнопки, модалей, блоки коду, навіть шрифт. Виберіть один у параметри → Скін. Кожен скін живе у skins/<id>/ з manifest.xml (оголошує кольори + accent) та styles.css (перекриває змінні CSS).

  • glassy — матові скляні поверхні над м'яким фоном

Розширення ↑ вгору

Мініпрограми, які живуть всередину CBE. Кожна — папка під extensions/<id>/ з:

  • manifest.xml — id, назва, версія, автор, опис, HTML запиту, іконка (емодзі або icon.svg)
  • extension.html (або що б не сказав маніфест <entry>) — сама програма

Натисніть Розширення, щоб переглянути те, що встановлено, закріпіть до панелі інструментів, встановіть нові з публічного каталогу, або видаліть із диску. Закріплені ID живуть у extensions/_pinned.json.

Автоматичне оновлення (push / pull) ↑ вгору

CBE синхронізує його джерело між машинами через канал push WinSCP + pull HTTPS.

Push (тільки адміністратор)

Якщо [updates] is_admin = true у config.ini, кожна активація запускає фоновий WinSCP synchronize remote -mirror, який надсилає папку розширення до /home/trentontompkins.com/cbe на сервері. Ручний запуск: команда /push. Виключає стан для кожної машини: data/ (профілі Chrome 1,74 ГБ), bridges/, node_modules/, .git/, logs/, chats/, config.ini, prompt_history.txt, domains.txt, wake.txt.

Pull (кожен клієнт)

4 секунди після активації кожен клієнт отримує https://trentontompkins.com/cbe/manifest.xml.php та MD5 порівнює для кожного файлу проти локальних копій. Тільки змінені/відсутні файли завантажуються через звичайне отримання HTTPS. Виключені шляхи НІКОЛИ не витягуються: config.ini, data/, bridges/, extension.js, panel/panel.js, panel/index.html, package.json, інструменти складання — причина того, що джерело поставляється через .vsix, а стара копія сервера не повинна затирати роботу, яка знаходиться в процесі розробки.

Гаряче перезавантаження ↑ вгору

Два шляхи перезавантаження викриті через меню правої кнопки:

  • Перезавантажити панель — перечитує panel/index.html + кожен資產 JS/CSS з кешем-бастером ?v=<mtime> для кожного файлу та перепризначає panel.webview.html. Підхоплює редагування panel.js / skin CSS / dotmatrix без перезавантаження VSCode. Хост розширення залишається живим (ваш термінал, розумник, обробники повідомлень, історія чату — все зберігається).
  • Перезавантажити вікно — запускає workbench.action.reloadWindow. Використовуйте тільки, коли ви відредагували extension.js (код на боці хоста) і перезавантаження панелі недостатньо.

Редагування скіна CSS також автоматично застосовується через esistуючий спостерігач скіна панелі — немає клацання меню.

Усунення неполадок ↑ вгору

"мостик X чат не вдався: ключ API порожній у config.ini"

Демон smart_bridge.py кешував стару гейтингову перевірку в пам'яті. Виправлено в C++ exe маршрутизації поворту. Якщо ви все ще це бачите, вбийте застарілі демони:

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
"copilot не має публічного REST API — використовуйте мостик браузера"

Старий extension.js маршрутизував чат мостика через маршрутизатор REST замість фактичного C++ tray exe. Перезавантажте вікно, щоб підхопити виправлений extension.js, потім чат буде йти прямо до bin/CBE-Bridge-Copilot.exe.

HTTP 404 модель: sonnet-4.6

Застаріло коротке псевдоніму в конфігурації Claude мостика. Виправлено — повні ID (claude-sonnet-4-6, claude-opus-4-7, claude-haiku-4-5) тепер використовуються.

Я редагував файл, але панель не показує зміну
  1. Якщо це panel.js / skins/*.css / index.html → правою кнопкою → Перезавантажити панель.
  2. Якщо це extension.js / bridges_cpp/*.py → правою кнопкою → Перезавантажити вікно.
  3. Якщо ви не можете досягти меню (напр. меню ще не завантажено), запустіть новий екземпляр VSCode з ізольованою user-data-dir:
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Claude Codex Black"
STT не вдається з "not-allowed"

VSCode пісочниць webview від дозволу мікрофона. CBE автоматично повертається до Windows SAPI (System.Speech.Recognition), запущено через PowerShell. Вам може знадобитися надати доступ до мікрофона на рівні OS (параметри → конфіденційність → мікрофон).

Бракує мостика exe

Трасування журналу показує BRIDGE:MISSING target=<t> expected=<path>. C++ tray exe живуть у bin/CBE-Bridge-<Pretty>.exe. Якщо вашого не існує, перебудуйте з bridges_cpp/ джерела (MSVC) або витягніть свіжий .vsix.
