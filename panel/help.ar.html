البدء السريع ↑ أعلى

  1. انقر فوق الإعداد (رمز العصا السحرية) واتبع المعالج لإدخال مفاتيح API الخاصة بك. يتم حفظها في config.ini (والذي يتم تجاهله - لم يتم الالتزام به أبداً).
  2. انقر فوق حبة الموفر في أسفل اليسار (حالياً بعنوان "Codex Black Ed.") لتبديل الذكاء الاصطناعي الذي تتحدث معه.
  3. اكتب في منطقة النص واضغط Enter للإرسال. Shift+Enter يدرج سطراً جديداً.
  4. اضغط ↑ في منطقة نص فارغة لاستدعاء الأوامر السابقة (سجل نمط PowerShell).

كل جسر عبارة عن ملف exe صينية C++ صغير في bin/CBE-Bridge-<Target>.exe يفتح ملف تعريف Chrome مسجل الدخول، يعترض أمرك، ويرجع رد النموذج. اختيار موفر جسر في الإعدادات يشغل ملف exe المطابق تلقائياً. المرة الأولى التي تستخدم فيها جسراً يجب عليك تسجيل الدخول إلى الموقع في نافذة Chrome الخاصة به مرة واحدة.

دردشة جسر تتحدث بروتوكول خطي على TCP: سطر JSON واحد للدخول ({action:"chat", target, message, model})، سطر JSON واحد للخروج. لا يلزم مفتاح api.

إرسال الرسائل ↑ أعلى

منطقة النص
اكتب أمرك. Enter يرسل، Shift+Enter يدرج سطراً جديداً. أثناء بث الرد، يتم إدراج الأوامر الإضافية في قائمة الانتظار وإرسالها بالترتيب - العنصر النائب يظهر "قائمة انتظار رسالة أخرى..." خلال هذه الحالة.
زر الإرسال (كرة)
الزر المستدير على الحافة اليمنى من منطقة النص. نفس الشيء مثل Enter. يظهر بصرياً ثلاث حالات (خامل / تحوم / نشط).
زر الإيقاف
أسفل يمين المؤلف. يلغي الرد المتدفق حالياً وأي رسائل في قائمة الانتظار. يتم الاحتفاظ بالنص المبث؛ يتم فقط إيقاف الطلب قيد التنفيذ.
حبة الموفر
أسفل يسار المؤلف. انقر فوق قائمة منسدلة من كل موفر قمت بتكوينه. اختيار موفر جديد يشغل جسره تلقائياً (إن أمكن) وينشر رسالة تأكيد الخبز المحمص.
سجل الأوامر
↑ / ↓ في منطقة نص فارغة يتحرك للخلف / للأمام عبر آخر 500 أمر أرسلته (نمط PowerShell). يتم تخزين السجل في prompt_history.txt في مجلد الامتداد ويستمر عبر إعادات تحميل اللوحة.

أزرار شريط الأدوات ↑ أعلى

مدرجة بترتيب شريط الأدوات. جميع الملخصات قابلة للترجمة لكل لغة عبر languages/*.xml.

محادثة جديدة addBtn
يمسح المؤشر الحالي، ويمسح حالة المحادثة في الذاكرة، ويبدأ من جديد. يتم الاحتفاظ بالمؤشر السابق على القرص تحت chats/<UTC-date>.log حتى لا يتم فقدان أي شيء. يعادل /clear.
الأوامر المخزنة storedPromptsBtn
يفتح نافذة تدرج كل قالب أمر محفوظ تحت stored_prompts/. انقر على واحد لإدراجه في منطقة النص؛ زر "+" يضيف قالب جديد. تدعم القوالب استبدال المتغيرات.
سجل الدردشة chatHistoryBtn
تصفح السجل المحفوظ على القرص (ملف واحد لكل تاريخ UTC تحت chats/). اختر تاريخاً للتمرير للخلف عبر المحادثات السابقة.
إرفاق ملف attachFileBtn
يفتح منتقي الملفات. يتم تحميل الملف المحدد مع الأمر التالي - تنتقل الصور إلى inline (vision)، وتصبح ملفات النص/الكود كتلة محاطة بسياج في أمرك. يدعم الإرفاق المتعدد.
اقرأ بصوت عالٍ (TTS) ttsBtn
ينطق أحدث رد من المساعد بصوت عالٍ. يستخدم ElevenLabs (إذا تم تعيين [elevenlabs] api_key) أو يعود إلى Windows SAPI. انقر بزر الماوس الأيمن لتبديل وضع القراءة التلقائية حيث يتم نطق كل رد جديد تلقائياً - يحصل الزر على مؤشر متحرك أثناء النشاط.
تحويل الكلام إلى نص (STT) sttBtn
يسجل صوت الميكروفون ويحوله إلى نص في منطقة النص. يحاول أولاً واجهة برمجة تطبيقات Web Speech الخاصة بـ webview؛ إذا فشلت (not-allowed، شائعة في رمل VSCode)، تعود إلى Windows SAPI (System.Speech.Recognition) تم إطلاقها على المضيف عبر PowerShell. انقر مرة أخرى للإيقاف.
الأمر التلقائي autoReplyBtn
يفتح نافذة الأمر التلقائي. حدد أمراً + فاصل زمني للعد التنازلي؛ بعد كل رد مساعد، ينقص العد التنازلي ويعيد إرسال الأمر التلقائي تلقائياً عندما يصل إلى الصفر. مفيد لـ "استمر"، "الخطوة التالية"، جلسات الأدوات المتكررة. انقر مرة أخرى للتعطيل.
استجابة الاستيقاظ wakeUpBtn
يحرر رسالة الاستيقاظ المخزنة في wake.txt. الاستيقاظ هو ما يرسله الأمر التلقائي إذا اكتشف أن النموذج قد توقف - عادة ping قصير مثل "مرحبا! استمر."
إظهار قائمة الأوامر showCommandsBtn
يفتح قائمة أوامر الشرطة في نافذة. راجع أوامر الشرطة المائلة للحصول على القائمة الكاملة. نفس الشيء مثل الكتابة / في بداية منطقة النص.
ضغط المحادثة compactBtn
ينشر طلب تلخيص وتنقية يستبدل المؤشر الحالي بملخص مختصر. يعادل /compact. مفيد عندما تكون المحادثة طويلة وتريد الاحتفاظ بالسياق ولكن توقف إحراق الرموز عند إعادة إرسال السجل بالكامل.
دليل المستخدم handbookBtn
يفتح نافذة دليل الموظف/المشروع. يحمل handbook.html أو أي وثيقة مكونة. يستخدم كمرجع موجه النظام يمكن للنموذج الاستفسار عنه.
الإعدادات settingsBtn
يفتح نافذة الإعدادات (الموفر والنموذج والمظهر واللغة وتأثيرات صوتية). راجع الإعدادات.
الحسابات accountsBtn
يفتح مدير الحسابات المتعددة. أضف / عدّل / أزل مفاتيح API لكل موفر، وبدّل بينها لكل جلسة. راجع الحسابات.
الامتدادات extensionsBtn
يفتح متصفح الامتدادات في اللوحة. يسرد ما تم تثبيته تحت extensions/ (كل منها بـ manifest.xml + entry HTML)، يتيح لك تثبيت الامتدادات في شريط الأدوات، تثبيت امتدادات جديدة من الكتالوج العام، أو إزالتها.
مجلد المشروع projectFolderBtn
اختر دليل العمل المستخدم بواسطة إرفاق الملف والطرفية و Git وأي أدوات تحتاج جذر مشروع. يتم عرض المجلد الحالي بجانب حبة الموفر.
المتصفح browserBtn
يفتح جزء متصفح QtWebEngine جنباً إلى جنب للبحث السريع دون مغادرة اللوحة.
مراقب VSCode monitorBtn
يبدل كلب الحراسة المشرف على VSCode - عملية في الخلفية تعيد تشغيل VSCode إذا توقفت. النقر بزر الماوس الأيسر يبدل التشغيل/الإيقاف، النقر بزر الماوس الأيمن يفتح قناة التتبع الخاصة بالمشرف.
الطرفية terminalBtn
يفتح محطة VSCode المدمجة في مجلد المشروع. إذا لم يتم تعيين مجلد المشروع، فسيعود إلى سطح المكتب الخاص بك. يعيد استخدام محطة واحدة دائمة بعنوان "CBE".
معالج الإعداد setupBtn
يمشيك عبر كل مفتاح API + تكامل يعرفه الامتداد (~12 خطوة). راجع معالج الإعداد.
Git gitBtn
يفتح عرض Source Control الخاص بـ VSCode مع التركيز على مجلد المشروع الحالي.
GitHub githubBtn
يسرد مستودعات GitHub الخاصة بك باستخدام [github] token. انقر على مستودع لاستنساخه / فتحه / تصفح المشاكل.
النطاقات (NameSilo) domainsBtn
يسرد كل نطاق على حسابك في NameSilo مع خوادم الأسماء. يتطلب [namesilo] api_key. زر إعادة التحميل يفرض جلب طازج.
حجم الخط fontSizeBtn
يبدل بين الخط العادي والكبير لخيط الدردشة. نفس الشيء مثل /font.
مساعدة helpBtn
يفتح هذه الصفحة. نفس الشيء مثل /help.
Tamagotchi tamaBtn
يبدل لوحة الحيوان الأليف بالبكسل (مرئية فقط على جلد tamagotchi، حيث يرسو في زاوية المؤلف). راجع Tamagotchi.

قائمة النقر بزر الماوس الأيمن ↑ أعلى

انقر بزر الماوس الأيمن على نص الدردشة أو كتلة رمز للحصول على قائمة السياق CBE. انقر بزر الماوس الأيمن على منطقة نص الأمر الآن يفتح قائمة المتصفح الأصلية (نسخ / قص / لصق / حذف / تحديد الكل) بدلاً من ذلك.

نسخ / نسخ كتلة الكود
ينسخ التحديد الحالي. إذا لم يكن هناك تحديد ولكنك نقرت بزر الماوس الأيمن على <pre><code>، فإنها تنسخ كتلة الكود بأكملها.
عرض المصدر
يعرض HTML/markdown الخام للمنطقة المنقورة - إما كتلة كود أو DOM لوحة كاملة. مفيد لاستكشاف مشاكل الجلد/CSS.
فتح DevTools
يطلب من VSCode فتح أدوات المطور حتى تتمكن من فحص webview مباشرة.
الإعدادات new
يفتح نفس نافذة الإعدادات التي يفتحها زر شريط الأدوات الإعدادات (الموفر / النموذج / المظهر / اللغة / تأثيرات صوتية). نفس الشيء مثل /settings.
حول new
حوار صغير في اللوحة يحتوي على الإصدار والمؤلف والترخيص ورابط المستودع والمحفظة ورقم الاتصال. يتم الإغلاق عند النقر على خلفية أو زر ×أو Esc.
إعادة تحميل اللوحة new
إعادة قراءة panel/index.html + panel.js + skins/* مع ?v=<mtime> cache-buster لكل ملف وإعادة تعيين panel.webview.html. التقط تعديلات CSS/JS دون إعادة تشغيل VSCode. يبقى مضيف الامتداد على قيد الحياة - الطرفية والمشرف والسجل والمحادثة جميعها تستمر.
إعادة تحميل النافذة new
يشغل workbench.action.reloadWindow. استخدم هذا فقط عند تحرير extension.js (رمز جانب المضيف) ولا تكفي إعادة تحميل اللوحة. إنها إعادة تحميل نافذة VSCode كاملة.

النوافذ والحوارات ↑ أعلى

نافذة الإعدادات — الموفر / النموذج / المظهر / اللغة / تأثيرات صوتية
  • الموفر: قائمة منسدلة كاملة من كل موفر API مباشر + جسر. اختيار واحد يبدل الجلسة النشطة و يشغل تلقائياً ملف exe الجسر المطابق (إن أمكن).
  • النموذج: قائمة لكل موفر من النماذج المسموحة (مثل claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 لـ Anthropic).
  • المظهر: موضوع بصري. راجع المظاهر.
  • اللغة: 39 لغة متاحة. التبديل يعيد سحب خريطة السلاسل ويعيد ترجمة كل تلميح أداة / تسمية / زر مساعدة مباشرة.
  • تأثيرات صوتية مفعلة: بدّل مؤثرات صوت الواجهة (نقرات وطقات وفتح/إغلاق نافذة إلخ).
  • مستوى صوت تأثيرات صوتية: مشروط 0-100. معاين مباشرة أثناء السحب.
  • إلغاء يعيد معاينات حية جربتها (تأثيرات صوتية/جلد)؛ حفظ يستمر ويصدر setProvider.
معالج الإعداد — إدخال مفتاح API متعدد الخطوات

شرح لكل تكامل. كل خطوة تطلب بيانات اعتماد وتكتبها إلى config.ini. تخطي ينتقل دون الكتابة؛ التالي يكتب ويتقدم؛ تم في الخطوة الأخيرة يغلق. تتضمن الخطوات: Anthropic و OpenAI و Gemini و xAI/Grok و GitHub PAT و Email/SMTP (كلمة مرور تطبيق Gmail) و Cloudflare و Twilio و ElevenLabs و Stability AI و Runway و SendGrid و NameSilo وغيرها.

نافذة الحسابات — مدير مفتاح API متعدد الحسابات

لكل موفر، أدر حسابات متعددة مع تسميات (مثل "شخصي" و "عمل"). بدّل أيها نشط لكل جلسة دون الكتابة فوق الآخرين. يتم إخفاء المفاتيح من طرف إلى طرف وحفظها لكل موفر في config.ini.

نافذة النطاقات — NameSilo

يسرد كل نطاق على حسابك في NameSilo مع خوادم أسماء + تواريخ التسجيل. يفرض زر إعادة التحميل جلب API طازج (وإلا يخزن مؤقتاً في domains.txt).

نافذة الدليل

يرسل HTML دليل مشروع (يُقصد به أن يكون مرجع موجه النظام يمكن للنموذج استشارته). قابل للتخصيص لكل مشروع.

نافذة الأوامر المخزنة

قوالب أوامر قابلة للإدراج من stored_prompts/. كل ملف قالب واحد؛ بادئة اسم الملف NN- تتحكم في ترتيب الفرز. زر "+" ينشئ واحداً جديداً.

نافذة سجل الدردشة

اختر تاريخ UTC لتحميل سجل الدردشة من chats/<date>.log. للقراءة فقط.

نافذة الامتدادات

بطاقات لكل امتداد مثبت. دبّس على شريط أدوات / فك التثبيت، ثبّت من الكتالوج العام (extensions.xml.php على الخادم)، أو أزل من القرص.

نافذة سجل التغييرات

يرسل panel/change_log.html - ملاحظات الإصدار المجمعة. تم إنشاؤها عبر tools/build_changelog.py.

نافذة عرض المصدر

يطبع بشكل جميل أي كتلة رمز أو HTML لوحة كاملة، مع تمييز بناء الجملة Prism وزر نسخ. يتم الوصول إليه عبر النقر بزر الماوس الأيمن → عرض المصدر.

نافذة الأمر التلقائي

قم بتكوين سلسلة أمر + فاصل زمني للعد التنازلي. بعد كل رد مساعد ينقص العد التنازلي؛ عندما يصل إلى صفر يرسل CBE تلقائياً الأمر المكون. يتم تشغيل/إيقاف عبر زر شريط أدوات الأمر التلقائي.

الإعدادات ↑ أعلى

تعيش جميع الإعدادات في واحد من مكانين:

الحسابات ومفاتيح API ↑ أعلى

يمكن لكل موفر أن يحتوي على حسابات متعددة مع تسميات - مفيد إذا كنت تريد التبديل بين المفاتيح الشخصية والعملية، أو اختبار مستوى مختلف. تتيح لك نافذة الحسابات:

  • إضافة حساب جديد بتسمية + مفتاح
  • تحرير حساب موجود (إعادة تسمية واستبدال المفتاح)
  • تعيين أي حساب نشط للجلسة الحالية
  • إزالة حساب

يتم تخزين المفاتيح مقنعة (آخر أربعة فقط مرئية) في config.ini. لا توجد نسخة نص عادي في workspaceState.

حيوان Tamagotchi الأليف ↑ أعلى

Tamagotchi عبارة عن حيوان أليف بتنسيق البكسل يعيش في اللوحة تحت جلد tamagotchi. يتقدم في العمر ويجوع/يتسخ ويمكن اللعب معه ويموت إذا تم إهماله لفترة طويلة. تستمر الحالة في workspaceState.

المظاهر ↑ أعلى

المواضيع البصرية لكل لوحة - الأزرار والنوافذ وكتل الرمز وحتى الخط. اختر واحداً في الإعدادات → المظهر. كل جلد يعيش في skins/<id>/ مع manifest.xml (يعلن الألوان + التأكيد) و styles.css (يتجاوز متغيرات CSS).

  • codex-black (افتراضي) — الظلام وأحادي المسافة وتأكيد سماوي نيون
  • glassy — أسطح زجاج مجمد على خلفية ناعمة
  • tamagotchi — جهاز يدوي LCD أخضر جير؛ يعرض تلقائياً أداة الحيوان الأليف المرسوة في زاوية المؤلف
  • office — أسلوب Word كريم/أزرق Chrome
  • macos-color-dock / mint-dock — أشرطة أدوات الرسو السفلي مع رموز زجاجية
  • terminal / arch / kde / gnome / xfce / ubuntu / redhat — مواضيع سطح المكتب Linux

تأتي ألوان النافذة من إدخالات <colors> في قائمة كل جلد وتُدفع إلى :root كمتغيرات --cbe-modal-* حتى تتم معالجة كل نافذة (بما فيها هذه المساعدة) بما يتناسب مع الموضوع.

الامتدادات ↑ أعلى

تطبيقات صغيرة تعيش داخل CBE. كل منها مجلد تحت extensions/<id>/ مع:

  • manifest.xml — id و name و version و author و description و entry HTML و icon (رموز تعبيرية أو icon.svg)
  • extension.html (أو أي ما يقول البيان <entry>) — التطبيق الفعلي

انقر على الامتدادات لاستعراض ما تم تثبيته وتدبيس شريط الأدوات وتثبيت الامتدادات الجديدة من الكتالوج العام أو إزالتها من القرص. معرفات مدببة تعيش في extensions/_pinned.json.

التحديث التلقائي (دفع / سحب) ↑ أعلى

يقوم CBE بمزامنة مصدره بين الآلات عبر قناة دفع WinSCP + سحب HTTPS.

الدفع (مسؤول فقط)

إذا كان [updates] is_admin = true في config.ini، فكل تنشيط يشغل خلفية WinSCP synchronize remote -mirror التي تدفع مجلد الامتداد إلى /home/trentontompkins.com/cbe على الخادم. الزناد اليدوي: /push أمر شرطة مائلة. يستبعد الحالة لكل آلة: data/ (1.74 GB Chrome profiles)، bridges/، node_modules/، .git/، logs/، chats/، config.ini، prompt_history.txt، domains.txt، wake.txt.

السحب (كل عميل)

بعد 4 ثوان من التنشيط، يجلب كل عميل https://trentontompkins.com/cbe/manifest.xml.php ويقارن MD5 لكل ملف مقابل النسخ المحلية. يتم تنزيل الملفات المتغيرة/المفقودة فقط عبر GET HTTPS عادي. لا يتم سحب المسارات المستثناة أبداً: config.ini، data/، bridges/، extension.js، panel/panel.js، panel/index.html، package.json، أدوات البناء - والسبب في ذلك هو أن المصدر يأتي عبر .vsix ونسخة الخادم الأقدم يجب أل
