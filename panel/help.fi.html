Claude Codex — Black Edition

Itsenäinen tekoäly-paneeli VSCodelle. Keskustele minkä tahansa LLM-palveluntarjoajan kanssa (suora API tai selaimen välitys), sisäänrakennetulla TTS-, STT-, liitä-tiedostoon-, komentopalettin-, moniasetuksin-, teemoituksella ja pikselihahmoisella Tamagotchi-lemmikillä.

Pika-aloitus ↑ top

  1. Klikkaa Setup (taikasauva-kuvake) ja käy velhon läpi antaaksesi API-avaimesi. Ne tallennetaan config.ini tiedostoon (joka on gitignored — ei koskaan sitoutunut).
  2. Klikkaa palveluntarjoaja-pilleä vasemmassa alakulmassa (tällä hetkellä merkitty "Claude Codex — Black Edition") vaihtaaksesi, minkä tekoälyn kanssa puhut.
  3. Kirjoita tekstikenttään ja paina Enter lähettääksesi. Shift+Enter lisää uuden rivin.
  4. Paina ↑ tyhjässä tekstikentässä muistuttaaksesi aiempia kehotteita (PowerShell-tyylinen historia).

Viestien lähettäminen ↑ top

Tekstikenttä
Kirjoita kehote. Enter lähettää, Shift+Enter lisää uuden rivin. Vastauksen suoratoistamisen aikana lisäkehotteet ovat jonossa ja lähetetään järjestyksessä — paikkamerkki näyttää "Queue another message…" tämän tilan aikana.
Lähetä-painike (pallo)
Pyöreä painike tekstikentän oikeassa reunassa. Sama kuin Enter. Näyttää visuaalisesti kolme tilaa (vapaa / kohdistin / aktiivinen).
Pysäytä-painike
Kirjoittimen oikeassa alakulmassa. Peruuttaa nykyisen suoratoistetun vastauksen ja kaikki jonossa olevat viestit. Suoratoistettava teksti säilytetään; vain lennossa oleva pyyntö keskeytetään.
Palveluntarjoaja-pille
Kirjoittimen vasemmassa alakulmassa. Klikkaa avattavasta luettelosta jokainen palveluntarjoaja, jonka olet määrittänyt. Uuden valinnan valinta käynnistää automaattisesti sen sillan (jos soveltuu) ja lähettää vahvistustietoisen.
Kehote-historia
↑ / ↓ tyhjässä tekstikentässä kävelee taaksepäin / eteenpäin viimeisten 500 kehotteen läpi, jotka olet lähettänyt (PowerShell-tyylinen). Historia tallennetaan osoitteessa prompt_history.txt laajennuskansion sisällä ja kestää paneelin uudelleenlatauksia.

Hiiren oikeanpuoleinen valikko ↑ top

Hiiren oikea painike chat-tekstillä tai koodin lohkolla saa CBE:n kontekstivalikon. Hiiren oikea painike kehote-tekstikentässä avaa nyt alkuperäisen selaimen valikon (Kopioi / Leikkaa / Liitä / Poista / Valitse kaikki) sen sijaan.

Kopioi / Kopioi koodin lohko
Kopioi nykyisen valinnan. Jos ei valintaa mutta klikkasit <pre><code>, kopioi koko koodin lohko.
Näytä lähde
Näyttää napsautetun alueen raa'an HTML/markdownin — joko koodin lohko tai koko paneelin DOM. Hyödyllinen vianmääritykselle teema/CSS ongelmissa.
Avaa DevTools
Kysyy VSCodelle avata Developer Tools niin voit tarkastaa webview-näkymää live.
Asetukset new
Avaa saman asetusmodaalin, jonka työkalupalkin Asetukset painike avaa (palveluntarjoaja / malli / teema / kieli / SFX). Sama kuin /settings.
Tietoja new
Pieni paneelin sisäinen valintaikkuna versioilla, tekijällä, lisenssillä, repo-linkillä, portfoliolla ja yhteystiedolla. Sulkeutuu taustaklikilla, × painikkeella tai Esc.
Lataa paneeli uudelleen new
Lukee panel/index.html + panel.js + skins/* uudelleen per-tiedoston ?v=<mtime> välimuistin kumoamisella ja uudelleenasettaa panel.webview.html. Poimii CSS/JS muokkaukset ilman VSCoden uudelleenkäynnistämistä. Laajennuksen isäntä pysyy elossa — pääte, valvoja, chat-historia säilyvät.
Lataa ikkuna uudelleen new
Laukaisee workbench.action.reloadWindow. Käytä tätä vain kun olet muokannut extension.js (host-puolella koodia) ja paneelin uudelleenlataus ei riitä. Se on koko VSCode-ikkunan uudelleenlataus.

Modaalit ja valintaikkunat ↑ top

Asetusmoduuli — palveluntarjoaja / malli / teema / kieli / SFX
  • Palveluntarjoaja: täydellinen avattava luettelo jokaisen suora-API + silta palveluntarjoajan. Valinta vaihtaa aktiivisen istunnon JA käynnistää automaattisesti vastaavan sillan exe:n (jos soveltuu).
  • Malli: palveluntarjoaja-kohtainen sallittujen mallien luettelo (esim. claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 Anthropicille).
  • Teema: visuaalinen teema. Katso Teemat.
  • Kieli: 39 kielialuetta saatavilla. Kielenvaihto poistaa uudelleen kaikki merkkijonot ja kääntää jokaisen työkaluvihjeen / etiketin / ohje-painikkeen live.
  • SFX käytössä: vaihtaa käyttöliittymän ääniefektit (klikkaukset, tikitys, modaalin avaus/sulkeminen, jne.).
  • SFX äänenvoimakkuus: 0–100 liukuri. Esikatselu live kun vedät.
  • Peruuta palauttaa kaikki live esikatseet (SFX/teema), jotka koitit; Tallenna kestävöi ja lähetää setProvider.
Asennusvelho — monivaiheinen API-avaimen kirjautuminen

Kävely jokaisen integraation läpi. Jokainen vaihe kysyy kirjautumistiedot ja kirjoittaa ne config.ini. Ohita siirtyy ilman kirjoittamista; Seuraava kirjoittaa ja siirtyy; viimeisen vaiheen Valmis sulkee. Vaiheet sisältävät: Anthropic, OpenAI, Gemini, xAI/Grok, GitHub PAT, Email/SMTP (Gmail app-salasana), Cloudflare, Twilio, ElevenLabs, Stability AI, Runway, SendGrid, NameSilo, ja paljon muuta.

Tilit-moduuli — moniasetuksen API-avaimen hallinta

Jokaista palveluntarjoajaa kohti hallitse useita merkittyjä tilejä (esim. "henkilökohtainen", "työ"). Vaihda, kumpi on aktiivinen istunnon aikana ilman toisten ylikirjoittamista. Avaimet peitetään päästä päähän ja tallennetaan palveluntarjoaja-kohti config.ini.

Verkkotunnukset-moduuli — NameSilo

Luettelee jokaisen verkkotunnuksen NameSilo-tilillä nimipalvelimilla + rekisteröinti päivämäärillä. Lataa painike pakottaa uuden API-haun (muuten välimuistii domains.txt).

Käsikirja-moduuli

Muuntaa projektin käsikirja HTML:ää (tarkoitus järjestelmä-kehote viitteenä, jonka malli voi kuulemaan). Konfiguroitava projekti-kohti.

Tallennetut kehotteet moduuli

Lisättävät kehote-mallit stored_prompts/. Jokainen tiedosto on yksi malli; tiedostonimi etuliite NN- ohjaa lajittelujärjestystä. "+" painike luo uuden.

Chat-historia moduuli

Valitse UTC päivämäärä lataa chat-loki osoitteesta chats/<date>.log. Vain-luku.

Laajennukset moduuli

Kortit jokaista asennetusta laajennusta varten. Kiinnitä työkalupalkkiin / irrota, asenna julkisesta luettelosta (extensions.xml.php palvelimella) tai poista levyltä.

Muutosloki moduuli

Muuntaa panel/change_log.html — pakatut julkaisun muistiinpanot. Luotu tools/build_changelog.py.

Näytä lähde moduuli

Kauniisti tulostaa minkä tahansa koodin lohko tai paneelin koko HTML, Prism syntaksin korostuksella ja kopioi-painikkeella. Saavutettava hiiren oikea painike → Näytä lähde.

Auto Prompt moduuli

Määritä kehote-merkkijono + laskuri aikaväli. Jokaisen avustajan vastauksen jälkeen laskuri pienenee; kun se saavuttaa nolla CBE lähettää automaattisesti määritetyn kehotteen. Vaihtaa päällä/pois Auto Prompt työkalupalkin painikkeella.

Asetukset ↑ top

Kaikki asetukset sijaitsevat yhdessä kahdesta paikasta:

  • workspaceState (VSCode-hallittu, per-työtila) — palveluntarjoaja, malli, teema, kieli, sfx käytössä/äänenvoimakkuus, fontin koko.
  • config.ini (laajennuksen juuri, gitignored) — API-avaimet + per-integraatio kirjautumistiedot.

Asetukset jatkuvat paneelin uudelleenlatauksia automaattisesti. Asetukset moduuli on turvallinen tapa muuttaa mitä tahansa; muokkaus config.ini suoraan toimii myös.

Tilit ja API-avaimet ↑ top

Jokaista palveluntarjoajaa kohti voi olla useita merkittyjä tilejä — hyödyllinen jos haluat vaihda henkilökohtaisen ja työn avaimien välillä, tai testata eri tasoa. Tilit-moduuli antaa sinulle:

  • Lisää uusi tili merkinnällä + avaimella
  • Muokkaa olemassa olevaa tiliä (uudelleen merkitse, korvaa avain)

  • Poista tili

Avaimet tallennetaan peiteltyina (viimeinen neljä näkyvissä) config.ini. Ei yksinkertaista kopioita workspaceState:ssa.

Tamagotchi-lemmikin ↑ top

Teemat ↑ top

Visuaaliset teemat koko paneelille — painikkeet, modaalit, koodin lohkot, jopa fontti. Valitse yksi Asetukset → Teema. Jokainen teema asuu skins/<id>/ kanssa manifest.xml (ilmoittaa värit + korostus) ja styles.css (ohittaa CSS muuttujat).

  • codex-black (oletus) — tumma, monospace, neonsininen korostus
  • glassy — huurteinen lasi pinnat pehmeän taustan päällä
  • tamagotchi — limenvihreä LCD kannettava; automaattisesti näyttää lemmikin vimpain telakoiduna kirjoittimen kulmassa
  • office — Word-tyyli kerma/sininen kromi
  • macos-color-dock / mint-dock — alasäiliö-työkalupalkit huurteisilla ikonilla
  • terminal / arch / kde / gnome / xfce / ubuntu / redhat — Linux työpöydän teemat

Modaali värit tulevat <colors> merkinnöistä jokaisen teeman manifestissa ja tuodaan :root kuin --cbe-modal-* muuttujat niin jokainen moduuli (sisältäen tämä ohje) muuntaa teemaan.

Laajennukset ↑ top

Mini-sovellukset, jotka asuvat CBE:ssä. Jokainen on kansio extensions/<id>/ kanssa:

  • manifest.xml — id, nimi, versio, tekijä, kuvaus, merkintä HTML, kuvake (emoji tai icon.svg)
  • extension.html (tai mikä tahansa manifestin <entry> sanoo) — varsinainen sovellus

Klikkaa Laajennukset selaa asennettu, kiinnitä työkalupalkkiin, asenna julkisesta luettelosta, tai poista levyltä. Kiinnitetyt ID:t asuvat extensions/_pinned.json.

Automaattinen päivitys (push / pull) ↑ top

CBE synkronoi lähteensä koneiden välillä WinSCP push + HTTPS pull kanavalla.

Push (vain admin)

Jos [updates] is_admin = true config.ini:ssä, jokainen aktivointi ajaa tausta WinSCP synchronize remote -mirror joka siirtää laajennuskansion osoitteeseen /home/trentontompkins.com/cbe palvelimella. Manuaalinen käynnistys: /push kauttaviiva-komento. Poissulkee per-koneen tila: data/ (1.74 GB Chrome profiilit), bridges/, node_modules/, .git/, logs/, chats/, config.ini, prompt_history.txt, domains.txt, wake.txt.

Pull (jokainen asiakas)

4 sekuntia aktivoinnin jälkeen, jokainen asiakas noutaa https://trentontompkins.com/cbe/manifest.xml.php ja MD5-vertaa per-tiedosto vastaan paikallisia kopioita. Vain muuttuneet/puuttuvat tiedostot lataa tavalliselle HTTPS GET. Kuuman lataamisen ↑ top

Kaksi latauspolkua paljastetaan hiiren oikea-painike valikon kautta:

  • Lataa paneeli uudelleen — lue panel/index.html + jokainen JS/CSS omaisuus per-tiedoston ?v=<mtime> välimuistin kumoamisella ja uudelleen asettaa panel.webview.html. Poimi panel.js / skin CSS / dotmatrix muokkaukset ilman VSCoden uudelleenkäynnistämistä. Laajennuksen isäntä pysyy elossa (pääte, valvoja, viesti käsittelijät, chat-historia säilyvät).
  • Lataa ikkuna uudelleen — laukaisee workbench.action.reloadWindow. Käytä vain kun olet muokannut extension.js (host-puolen koodi) ja paneelin uudelleenlataus ei riitä.

Skin CSS muokkaukset myös auto-levitys paneelin olemassa teema katsojalla — ei valikon klikkausta tarvitaan.

Vianmääritys ↑ top

"bridge X chat failed: api key empty in config.ini"

smart_bridge.py taustaprosessi välimuisti vanhaa porttia tarkista muistissa. Kiinteä C++-exe reititys kääntöä. Jos näet silti, tapa vanhat daemonit:

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
"copilot has no public REST API — use the browser bridge"

Vanha extension.js oli reititys sillan chatia REST reitittimen kautta sen sijaan todellinen C++ kelluva exe. Lataa ikkuna uudelleen poimi kiinteä extension.js, sitten chat menee suoraan bin/CBE-Bridge-Copilot.exe.

Vanhentunut lyhyt alias Claude silta asetuksissa. Kiinteä — täydet ID:t (claude-sonnet-4-6, claude-opus-4-7, claude-haiku-4-5) ovat nyt käytössä.

Muokkasin tiedoston mutta paneeli ei näytä muutosta
  1. Jos se on panel.js / skins/*.css / index.html → hiiren oikea painike → Lataa paneeli uudelleen.
  2. Jos se on extension.js / bridges_cpp/*.py → hiiren oikea painike → Lataa ikkuna uudelleen.
  3. Jos et voi saavuttaa valikkoa (esim. valikko ei vielä ole ladattu), käynnistä uusi VSCode instanssi eristetyllä käyttäjä-data-dir:
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Claude Codex Black"
STT epäonnistuu "not-allowed" kanssa

VSCode hiekkalaatikko webview-näkymän mikrofonin luvalta. CBE auto-palautuu Windowsin SAPI:iin (System.Speech.Recognition) käynnistettynä isännällä PowerShellin kautta. Sinun on ehkä myönnettävä mikki pääsy OS-tasolla (Asetukset → Yksityisyys → Mikrofoni).

Silta exe puuttuu

Jäljity loki näyttää BRIDGE:MISSING target=<t> expected=<path>. C++ kelluva exe asuu bin/CBE-Bridge-<Pretty>.exe. Jos sinulla ei ole, rakenna bridges_cpp/ lähteestä (MSVC) tai poista uusi .vsix.
