Claude Codex — Black Edition

Автономная многопровайдерная панель чата с ИИ для VSCode. Нажмите Ctrl+Alt+B для переключения.

1. Добро пожаловать

Claude Codex Black — это webview для VSCode, позволяющий общаться с несколькими провайдерами ИИ (Claude, OpenAI, Gemini, Grok, Azure, локальный Ollama) из одной настраиваемой панели. Все ключи читаются из config.ini в корне расширения — интерфейс параметров расширения не требуется, но модальное окно параметров отражает наиболее полезные поля для редактирования через интерфейс.

Новичок? Начните с открытия Параметры (значок шестеренки), выберите провайдера, вставьте свой ключ API, затем введите промпт и нажмите Enter. Все остальные функции в этом руководстве являются опциональными.

3. Поле ввода промпта

Большое редактируемое текстовое поле внизу. Вводите, вставляйте, перетаскивайте файл, прикрепляйте через скрепку — все, что вы туда поместите, будет пользовательским вводом следующего вызова API.

Шрифт привязан к моноширинному шрифту редактора VSCode (через переменную CSS --vscode-editor-font-family, поэтому панель выглядит естественно внутри редактора.

4. Кнопки на панели

Нижний ряд, слева направо. Подсказки появляются при наведении; панель также воспроизводит их на выбранном языке (см. Язык).

5. Модели и провайдеры

CBE поставляется с 11 мостами в виде готовых к использованию плагинов .bridge в папке bridges/. Каждый — это самостоятельный архив с manifest.xml + bridge.py + значками. Просто положите новый файл .bridge, и он появится в раскрывающемся списке картриджей — изменение кода расширения не требуется.

Текстовые чат-мосты (7)

  • ChatGPT — chatgpt.com, подписка Plus/Pro
  • Grok — grok.com, встроенный вход xAI (анонимный уровень сильно ограничен; сначала войдите)
  • Gemini — gemini.google.com, учетная запись Google
  • Claude — claude.ai, вход по волшебной ссылке (запустите tools/sign_in_helper.py claude один раз)
  • Copilot — copilot.microsoft.com, бесплатная учетная запись Microsoft
  • DeepSeek — chat.deepseek.com, встроенный вход по почте/паролю (НЕ используйте Google SSO)
  • Ollama — локальный 127.0.0.1:11434, вход не требуется

Мосты генерации видео (4)

  • Sora 2 — sora.com, переиспользует вход ChatGPT Plus/Pro
  • Google Veo — gemini.google.com (режим Veo), подписка Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, отдельная подписка Runway
  • Bing Video Creator — bing.com/videos/create, бесплатный Sora-2 с учетной записью Microsoft

Созданные видео сохраняются в videos/<bridge>/<timestamp>_<prompt-slug>.mp4 и автоматически воспроизводятся в панели видеотеки (см. раздел о видеотеке ниже).

Выберите мост и модель из раскрывающегося списка картриджей рядом с полем промпта или через Параметры → Основное. Выбор сохраняется для рабочей области в workspaceState. Чтобы добавить новый мост, см. docs/WRITING_BRIDGES.md.

5a. Видеотека

Специальная панель для просмотра видео, созданных видео-мостами (Sora, Veo, Runway, Bing Video Creator). Открывается через палитру команд: Claude Codex Black: Open Video Library или команда codexBlackEd.openVideoPlayer.

  • Боковая панель перечисляет все .mp4 / .webm / .mov в videos/<bridge>/, сгруппированные по мосту и отсортированные по новизне.
  • Самое свежее видео автоматически воспроизводится при первом открытии.
  • Панель отслеживает папку videos/ с интервалом 2 секунды — любое новое созданное видео появляется со значком ✨ «Только что создано» и автоматически воспроизводится (выключается через Автозапуск ▶ новый).
  • Нажмите 📂 Открыть, чтобы открыть папку videos/ в диспетчере файлов ОС.

6. Распознавание речи

Нажмите на микрофон, говорите, нажмите еще раз, чтобы остановить (или ждите истечения времени молчания). Две системы используются по порядку:

  1. Web Speech API — облачный распознаватель Google в webview. Использует сеанс Gmail/Google; дополнительный ключ не требуется.
  2. Windows SAPI (отступ) — предварительно прогретый процесс PowerShell, вызываемый при блокировке доступа к микрофону в webview. Настраиваемое окно прослушивания через [voice] listen_seconds в config.ini.
SAPI предварительно прогревается при активации расширения, поэтому первый клик микрофона избегает холодного старта на 2-4 секунды, который раньше перехватывал ранние клики остановки.

7. Автоматический промпт

Кнопка со значком. Когда ВКЛЮЧЕНО, после N секунд неактивности панель автоматически отправляет ваш настроенный текст пробуждения. Цифра обратного отсчета отображается в --cbe-highlight-color, который определяет каждая тема.

Редактируйте текст пробуждения через кнопку 🔁 Пробуждение — он взаимодействует с wake.txt.

8. Авточтение (TTS)

Значок рта. Когда ВКЛЮЧЕНО, каждый ответ помощника воспроизводится через синтезатор речи Web Speech (Google) или отступ SAPI. Синий ореол светится вокруг значка во время воспроизведения аудио.

9. Компактный режим и использование контекста

Массив разговора, отправляемый в модель, растет с каждым ходом. Кольцо вокруг значка Компактный показывает текущее использование контекстного окна как коническую градиент — пустое при запуске, полное при приближении к пределу контекста модели.

Нажмите Компактный, чтобы сократить историю до последних четырех ходов. Следующий вызов API использует меньший массив.

10. Ответ пробуждения

Хранится в wake.txt в корне расширения. Используется автоматическим промптом как сообщение для отправки при срабатывании таймера неактивности. Редактируйте через кнопку 🔁 на панели.

11. Загрузка файлов

Нажмите 📎, чтобы выбрать один или несколько файлов. Удерживайте Ctrl или Shift в диалоговом окне для множественного выбора. Каждый файл вставляется в промпт как блок кода с его названием и языком. Бинарные файлы размером более 1 МБ пропускаются с уведомлением.

12. Модальное окно Git

Нажмите 📁 Git. Если папка проекта не настроена, сначала появится диалоговое окно выбора папки — выбранный путь записывается в [project] path в config.ini. Последующие вызовы git выполняются с cwd, установленным в этот путь.

13. Репозитории GitHub

Перечисляет все репозитории, доступные для вашего [github] pat. Нажмите строку, чтобы вставить URL клонирования в промпт. Список разбит на страницы и кэширован.

14. Домены NameSilo

Получает все домены вашей учетной записи NameSilo с помощью [namesilo] api_key (или [api_keys] namesilo_api_key в качестве отступа). При первом открытии результаты кэшируются в domains.txt; последующие загрузки панели используют кэш. Нажмите Перезагрузить в модальном окне для принудительного обновления.

Если вы когда-либо видели «нет доменов» с кодом ответа 300, проверьте канал трассировки — пустые кэши больше не отравляют будущие загрузки панели, но устаревший domains.txt в другом пути установки мог бы.

15. Темы оформления

Кнопка 🎨 открывает диалоговое окно выбора темы, которое сканирует skins/ в реальном времени (не при запуске), поэтому просто бросьте новую папку при работе. Каждая тема имеет manifest.xml, определяющий её палитру — включая цвет выделения, на который ориентируются значок обратного отсчета автопромпта, кольца фокуса и пульс супервизора.

Встроенные темы включают: gnome (серый Adwaita), terminal (черный/зеленый с ярко-розовым акцентом), tamagotchi (пастельные скорлупки с панелью спрайта талисмана), blocky и другие.

16. Параметры

Открывается из значка ⚙. Вкладки:

  • Основное — отображаемое имя, модель по умолчанию, отправка по Enter
  • Голос — устройство микрофона, listen_seconds, выбор двигателя STT, авточтение TTS
  • Обновления — флаг is_admin, сеанс WinSCP, удаленный путь
  • Ключи — ключ API каждого провайдера
  • Монитор — переключение супервизора VSCode, порт, интервал опроса
  • Язык — выбор из 39 локалей; см. § 17

Модальное окно запоминает размер и позицию между сеансами.

17. Язык

Панель поставляется с переводами для 39 наиболее распространенных языков. Файлы локалей находятся в languages/<code>.xml и загружаются один раз при активации расширения. Отсутствующие ключи возвращаются к английскому.

Выберите язык в Параметры → Язык. Рядом с каждым вариантом показан значок флага (загружается из assets/flags/<code>.svg). Выбор сохраняется в [settings] language в config.ini.

18. Монитор VSCode

Служба Windows (CBEVSCodeSupervisor) оборачивает скрипт tools/vscode_supervisor.ps1 через NSSM и привязывает HttpListener на http://127.0.0.1:3434/. Кнопка монитора панели светит синим при ответе конечной точки /status супервизора кодом 200 OK.

Если проба HTTP не удается, но служба установлена, дозорный панели автоматически перезапускает служу (30-секундное охлаждение, чтобы избежать цикла перезапусков).

Левый клик по кнопке монитора для установки/запуска/остановки. Правый клик для открытия канала трассировки.

19. Автообновление (pull)

Через 4 секунды после активации расширения панель получает https://trentontompkins.com/cbe/manifest.xml.php — манифест MD5+размер самых последних опубликованных файлов. Для каждого удаленного файла сравнивается MD5 локальной копии; только измененные/отсутствующие файлы загружаются по HTTPS.

Состояние пользователя (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) находится в списке исключений pull и никогда не перезаписывается.

20. Администраторская передача (push)

Только клиенты с [updates] is_admin = true когда-либо отправляют на сервер. Запускается через:

  • Палитра команд → Claude Codex Black: Push update
  • Слэш-команда /push

Использует сохраненный сеанс WinSCP с именем в [updates] winscp_session (по умолчанию vps). Отправляет через /script=… с командой синхронизации и маской файлов, которая исключает секреты и состояние, зависящее от машины.

21. Маркетплейс расширений

Нажмите кнопку 🧩 Расширения. Открывается модальное окно iframe на адресе https://trentontompkins.com/cbe/extension/extension_marketplace.php, которое получает каталог из extensions.xml.php и отображает каждое доступное расширение как карточку с описанием, тегами, версией, размером файла, MD5 и кнопкой Установить.

Расширение упаковано как <id>.ext — архив zip, содержащий manifest.xml плюс код расширения (обычно один extension.html). При нажатии на кнопку Установить iframe маркетплейса отправляет postMessage обратно в панель; панель загружает файл .ext непосредственно с сервера и распаковывает его в папку extensions/ в папке расширения.

Три демонстрационных расширения поставляются с каталогом запуска: Калькулятор, Сапер и Средство выбора эмодзи.

22. Слэш-команды

23. Меню по правой кнопке

Правый клик где-либо в панели открывает контекстное меню (определяется как одна XML-строка в panel.js). Пункты включают Обновить (перезагрузить панель без касания хоста расширения — никогда не используйте reloadWindow), Очистить разговор, Открыть параметры и Инспекционировать (DevTools, только отладочные сборки).

24. Канал трассировки

Расширение записывает подробную временную шкалу в debug.log рядом с расширением. Все замечательное попадает туда: переключения провайдеров, жизненный цикл STT, зонды супервизора, коды ответов NameSilo, сообщения моста панель↔хост, количество манифестов push/pull.

Правый клик по кнопке монитора для однократного открытия канала трассировки.

25. Решение проблем

СимптомВероятная причина
Поле промпта выглядит пропорциональным, а не моноширинным --vscode-editor-font-family не применяется; проверьте переменные :root
Спиннер автопромпта — черная точка Неправильный ресурс SVG; должен быть auto_read_spinner.svg с ореолом drop-shadow
Кнопка компактного не работает Обработчик хоста отсутствует — case 'compactConversation' в маршрутизаторе extension.js
«0 доменов» в модальном окне доменов NameSilo ответ reply.code != 300 (в канале трассировки), или устаревший domains.txt
STT «речь не обнаружена» мгновенно Вы остановили до привязки микрофона SAPI. Предварительный прогрев теперь пропускает это ожидание — проверьте stt: using pre-warmed SAPI в debug.log
Push не удается на пути с пробелами Использование встроенного /command=; всегда используйте /script=tempfile.winscp
Синий свет супервизора не включается Служба не работает. Левый клик по кнопке монитора для установки/запуска, или запустите Start-Service CBEVSCodeSupervisor
Перезагрузка «исправляет» что-то Не исправляет. Никогда не используйте reloadWindow. Используйте пункт Обновить в контекстном меню вместо этого.
