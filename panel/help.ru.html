Codex Black Ed.

Автономная панель ИИ для VSCode. Общайтесь с любым поставщиком LLM (прямой API или мост браузера), со встроенными TTS, STT, подключением к файлу, палитрой команд, поддержкой нескольких аккаунтов, скинами и пиксельным питомцем Tamagotchi.

Быстрый старт ↑ вверх

  1. Нажмите Setup (значок палочки) и пройдите мастер для ввода ваших ключей API. Они сохраняются в config.ini (который находится в gitignore — никогда не коммитится).
  2. Нажмите таблетку провайдера в левом нижнем углу (в настоящее время с меткой "Codex Black Ed."), чтобы переключиться на другого ИИ.
  3. Введите текст в поле ввода и нажмите Enter для отправки. Shift+Enter вставляет новую строку.
  4. Нажмите ↑ в пустом поле ввода, чтобы вспомнить предыдущие запросы (история в стиле PowerShell).

Каждый мост — это небольшой исполняемый файл C++ в системном лотке bin/CBE-Bridge-<Target>.exe, который открывает залогиненный профиль Chrome, перехватывает ваш запрос и возвращает ответ модели. Выбор провайдера моста в параметрах автоматически запускает соответствующий exe. В первый раз, когда вы используете мост, необходимо войти на сайт в его окне Chrome один раз.

Чат моста использует протокол строк на TCP: одна строка JSON на вход ({action:"chat", target, message, model}), одна строка JSON на выход. Ключ API не требуется.

Отправка сообщений ↑ вверх

Поле ввода
Введите свой запрос. Enter отправляет, Shift+Enter вставляет новую строку. Пока ответ потоком загружается, дополнительные запросы ставятся в очередь и отправляются по порядку — заполнитель показывает "Поставьте ещё одно сообщение в очередь…" в этом состоянии.
Кнопка отправки (сфера)
Круглая кнопка на правом краю поля ввода. То же самое, что Enter. Визуально показывает три состояния (без дела / наведение / активно).
Кнопка остановки
Внизу справа в композере. Отменяет загружаемый ответ и все сообщения в очереди. Загруженный текст сохраняется; отменяется только выполняемый запрос.
Таблетка провайдера
Внизу слева в композере. Нажмите для выпадающего списка всех настроенных провайдеров. Выбор нового автоматически запускает его мост (если применимо) и отправляет тост подтверждения.
История запросов
↑ / ↓ в пустом поле ввода перемещает назад / вперёд через последние 500 отправленных запросов (в стиле PowerShell). История хранится в prompt_history.txt в папке расширения и сохраняется при перезагрузке панели.

Кнопки панели инструментов ↑ вверх

Перечислены в порядке панели инструментов. Все подсказки локализуемы для каждого языка через languages/*.xml.

Новый диалог addBtn
Очищает текущую ветку, стирает внутреннее состояние разговора и начинает заново. Предыдущая ветка сохраняется на диск в chats/<UTC-date>.log, поэтому ничего не теряется. Эквивалентно /clear.
Сохранённые запросы storedPromptsBtn
Открывает модальное окно со списком всех сохранённых шаблонов запросов в stored_prompts/. Нажмите одного для вставки в поле ввода; кнопка "+" добавляет новый шаблон. Шаблоны поддерживают подстановку переменных.
История чатов chatHistoryBtn
Просмотр лога чата на диске (один файл на дату UTC в chats/). Выберите дату для прокрутки прошлых разговоров.
Подключить файл attachFileBtn
Открывает обозреватель файлов. Выбранный файл загружается со следующим запросом — изображения идут встроенными (видение), текстовые/кодовые файлы становятся огороженным блоком в вашем запросе. Поддерживает множественное подключение.
Читать вслух (TTS) ttsBtn
Озвучивает самый последний ответ помощника. Использует ElevenLabs (если установлен [elevenlabs] api_key) или откатывается на Windows SAPI. Щелчок правой кнопкой переключает режим автозвучивания, в котором каждый новый ответ озвучивается автоматически — кнопка получает анимированный индикатор во время активности.
Речь в текст (STT) sttBtn
Записывает аудио с микрофона и расшифровывает в поле ввода. Сначала пытается использовать Web Speech API вебвью; если это не удаётся (not-allowed, частое в песочницах VSCode), откатывается на Windows SAPI (System.Speech.Recognition), запущенный на хосте через PowerShell. Нажмите снова для остановки.
Автоответ autoReplyBtn
Открывает модальное окно автоответа. Определите запрос + интервал обратного отсчёта; после каждого ответа помощника обратный отсчёт начинает отсчитываться и автоматически переотправляет запрос автоответа при достижении нуля. Полезно для "продолжить", "следующий шаг", повторяющихся сеансов инструментов. Нажмите снова для отключения.
Ответ пробуждения wakeUpBtn
Редактирует сообщение пробуждения, хранящееся в wake.txt. Пробуждение — это то, что отправляет автоответ, если обнаруживает, что модель застопорилась — обычно короткий пинг вроде "Эй! Продолжайте."
Показать меню команд showCommandsBtn
Открывает палитру слэш-команд в модальном окне. Смотрите Слэш-команды для полного списка. То же самое, что ввести / в начале поля ввода.
Компактный разговор compactBtn
Публикует запрос на резюмирование и обрезку, который заменяет текущую ветку сокращённым резюме. Эквивалентно /compact. Полезно, когда разговор стал длинным и вы хотите сохранить контекст, но перестать сжигать токены на переотправку всей истории.
Справочник handbookBtn
Открывает модальное окно справочника сотрудников/проектов. Загружает handbook.html или какой-то другой настроенный документ. Используется как справочник системного запроса, который модель может быть приглашена использовать.
Параметры settingsBtn
Открывает модальное окно параметров (провайдер, модель, скин, язык, SFX). Смотрите Параметры.
Аккаунты accountsBtn
Открывает менеджер многоаккаунтов. Добавляйте/редактируйте/удаляйте ключи API для каждого провайдера, переключайтесь между ними в сеансе. Смотрите Аккаунты.
Расширения extensionsBtn
Открывает обозреватель встроенных расширений в панели. Показывает, что установлено в extensions/ (каждое с manifest.xml + HTML entry), позволяет закреплять расширения на панели инструментов, устанавливать новые из публичного каталога или удалять их.
Папка проекта projectFolderBtn
Выбирает рабочую папку, используемую подключением файла, терминалом, Git и любыми инструментами, требующими корня проекта. Текущая папка показывается рядом с таблеткой провайдера.
Браузер browserBtn
Открывает панель браузера QtWebEngine рядом для быстрого поиска без выхода из панели.
Монитор VSCode monitorBtn
Переключает сторожевую собаку наблюдателя VSCode — фоновый процесс, который перезагружает VSCode при сбое. Щелчок левой кнопкой переключает запуск/остановку, щелчок правой кнопкой открывает канал трассировки наблюдателя.
Терминал terminalBtn
Открывает интегрированный терминал VSCode в папке проекта. Если папка проекта не установлена, откатывается на рабочий стол. Переиспользует один постоянный терминал с меткой "CBE".
Мастер настройки setupBtn
Проведёт вас через каждый ключ API + интеграцию, которую знает расширение (~12 шагов). Смотрите Мастер настройки.
Git gitBtn
Открывает представление управления источниками VSCode, сосредоточенное на текущей папке проекта.
GitHub githubBtn
Перечисляет ваши репозитории GitHub, используя [github] token. Нажмите репо для клонирования/открытия/просмотра проблем.
Домены (NameSilo) domainsBtn
Перечисляет все домены на вашем аккаунте NameSilo с серверами имён. Требует [namesilo] api_key. Кнопка перезагрузки принудительно получает свежее содержимое.
Размер шрифта fontSizeBtn
Переключается между обычным и крупным шрифтом для цепи чата. То же самое, что /font.

Tamagotchi tamaBtn
Переключает панель пиксельного питомца (видна только на скине tamagotchi, где она закрепляется в углу композера). Смотрите Tamagotchi.

Контекстное меню ↑ вверх

Щелчок правой кнопкой на текст чата или блок кода открывает контекстное меню CBE. Щелчок правой кнопкой на поле ввода запроса теперь открывает нативное меню браузера (копирование / вырезание / вставка / удаление / выделить всё) вместо этого.

Копировать / Копировать блок кода
Копирует текущий выбор. Если нет выбора, но вы щёлкнули правой кнопкой на <pre><code>, копирует весь блок кода.
Просмотр исходного кода
Показывает raw HTML/markdown щёлкнутого региона — либо блок кода, либо весь DOM панели. Полезно для отладки проблем со скинами/CSS.
Открыть DevTools
Просит VSCode открыть его инструменты разработчика, чтобы вы могли проверять вебвью в реальном времени.
Параметры new
Открывает то же модальное окно параметров, что и кнопка параметры панели инструментов (провайдер / модель / скин / язык / SFX). То же самое, что /settings.
О программе new
Небольшой встроенный диалог с версией, автором, лицензией, ссылкой репо, портфолио и телефоном контакта. Закрывается щелчком фона, кнопкой × или Esc.
Перезагрузить панель new
Переодитывает panel/index.html + panel.js + skins/* с per-файловым cache-buster ?v=<mtime> и переназначает panel.webview.html. Подхватывает изменения CSS/JS без перезагрузки VSCode. Хост расширения остаётся живым — терминал, наблюдатель, история чата сохраняются.
Перезагрузить окно new
Запускает workbench.action.reloadWindow. Используйте это только, если вы редактировали extension.js (код на стороне хоста) и перезагрузка панели недостаточна. Это полная перезагрузка окна VSCode.

Модальные окна и диалоги ↑ вверх

Модальное окно параметров — провайдер / модель / скин / язык / SFX
  • Провайдер: полный выпадающий список каждого прямого API + провайдера моста. Выбор переключает активный сеанс И автоматически запускает соответствующий exe моста (если применимо).
  • Модель: per-провайдерский список разрешённых моделей (например, claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 для Anthropic).
  • Скин: визуальная тема. Смотрите Скины.
  • Язык: доступно 39 локалей. Переключение переполучает карту строк и переводит каждую подсказку / метку / кнопку справки в реальном времени.
  • SFX включён: переключить звуковые эффекты интерфейса (щелчки, тиканье, открытие/закрытие модального, и т. д.).
  • Громкость SFX: ползунок 0–100. Просмотрено в реальном времени при перетаскивании.
  • Отмена отменяет любые живые предпросмотры (SFX/скин), которые вы пробовали; сохранение сохраняет и отправляет setProvider.
Мастер настройки — многошаговый ввод ключа API

Пошаговое руководство для каждой интеграции. Каждый шаг запрашивает учётные данные и записывает их в config.ini. Пропустить переходит без записи; далее записывает и переходит; финальный шаг готово закрывает. Шаги включают: Anthropic, OpenAI, Gemini, xAI/Grok, GitHub PAT, Email/SMTP (пароль приложения Gmail), Cloudflare, Twilio, ElevenLabs, Stability AI, Runway, SendGrid, NameSilo и многое другое.

Модальное окно аккаунтов — менеджер многоаккаунтных ключей API

Для каждого провайдера управляйте несколькими помеченными аккаунтами (например, "личный", "работа"). Переключайтесь между активными в сеансе без перезаписи других. Ключи маскируются end-to-end и сохраняются per-провайдерски в config.ini.

Модальное окно доменов — NameSilo

Перечисляет все домены на вашем аккаунте NameSilo с серверами имён + датами регистрации. Кнопка перезагрузки принудительно получает свежее значение API (иначе кэшируется в domains.txt).

Модальное окно справочника

Отображает HTML справочника проекта (предназначен как справочник системного запроса, который модель может использовать). Настраивается per-проект.

Модальное окно сохранённых запросов

Вставляемые шаблоны запросов из stored_prompts/. Каждый файл — один шаблон; префикс имени файла NN- управляет порядком сортировки. Кнопка "+" создаёт новый.

Модальное окно истории чатов

Выберите дату UTC для загрузки лога чата из chats/<date>.log. Только для чтения.

Модальное окно расширений

Карточки для каждого установленного расширения. Закрепите на панели инструментов / открепите, установите из публичного каталога (extensions.xml.php на сервере) или удалите с диска.

Модальное окно журнала изменений

Отображает panel/change_log.html — прилагаемые примечания к выпуску. Создаётся через tools/build_changelog.py.

Модальное окно просмотра исходного кода

Pretty-печатает любой блок кода или полный HTML панели, с подсветкой синтаксиса Prism и кнопкой копирования. Доступно через щелчок правой кнопкой → просмотр исходного кода.

Модальное окно автоответа

Настройте строку запроса + интервал обратного отсчёта. После каждого ответа помощника обратный отсчёт уменьшается; при достижении нуля CBE автоматически отправляет настроенный запрос. Переключается вкл/выкл через кнопку автоответа панели инструментов.

Параметры ↑ вверх

Все параметры находятся в одном из двух мест:

  • workspaceState (управляется VSCode, per-workspace) — провайдер, модель, скин, язык, sfx включен/громкость, размер шрифта.
  • config.ini (корень расширения, gitignored) — ключи API + per-интеграционные учётные данные.

Параметры сохраняются автоматически при перезагрузке панели. Модальное окно параметры — безопасный способ изменить что-нибудь; прямое редактирование config.ini также работает.

Аккаунты и ключи API ↑ вверх

Каждый провайдер может иметь несколько помеченных аккаунтов — полезно, если вы хотите переключаться между личными и рабочими ключами или тестировать другой уровень. Модальное окно аккаунтов позволяет вам:

  • Добавить новый аккаунт с меткой + ключом
  • Отредактировать существующий аккаунт (переметить, заменить ключ)
  • Установить, какой аккаунт активен для текущего сеанса
  • Удалить аккаунт

Ключи хранятся маскированными (видна только последняя четвёрка) в config.ini. В workspaceState нет копии открытого текста.

Питомец Tamagotchi ↑ вверх

Tamagotchi — это пиксельный питомец, который живёт в панели под скином tamagotchi. Он стареет, голодает/пачкается, может играть и умирает при достаточной небрежности. Состояние сохраняется в workspaceState.

Статистика (верхняя часть виджета)

СтатистикаЧто отслеживает
🥚 ЭтапЖизненный цикл: яйцо → детёныш → ребёнок → подросток → взрослый → пожилой → мёртвый. Стареет с настоящими минутами.
🍖 Голод0–100. Падает со временем; кормление повышает. Достигает 0 → здоровье падает.
😀 Счастье0–100. Падает со временем; игра повышает.
❤️ Здоровье0–100. Падает при болезни или голодании. Укол исцеляет.
✨ Чистота0–100. Падает, когда питомец какает. Уборка повышает.
⏱ ВозрастМинут с момента вылупления.

Кнопки действия в LCD (нижняя часть виджета)

ЗначокДействие
🍖Кормление — цикл мяса ↔ баклажана. Выберите для фактического кормления.
🧹Уборка — уберите какашку.
⚾Игра — мини-игра; повышает счастье.
💉Укол — исцеляет при болезни.
💡Свет — переключить лампу LCD; питомец спит в темноте.
✅Выбрать — подтвердить / продолжить (эквивалент оригинальной кнопки Bandai посередине).

Спрайт питомца рисуется на холст 240×240 (компактно: 138×116). Спрайты + логика жизненного цикла находятся в panel/dotmatrix-tamagotchi-sprites.js и panel/dotmatrix-tamagotchi-game.js.

Скины ↑ вверх

Визуальные темы для всей панели — кнопки, модальные окна, блоки кода, даже шрифт. Выберите одну в параметры → скин. Каждый скин находится в skins/<id>/ с manifest.xml (объявляет цвета + акцент) и styles.css (переопределяет переменные CSS).

  • codex-black (по умолчанию) — тёмная, моноширинная, неоновый-голубой акцент
  • glassy — матовые стеклянные поверхности над мягким фоном
  • tamagotchi — лайм-зелёный ЖК портативный; автоматически показывает виджет питомца, закреплённый в углу композера
  • office — стиль Word cream/blue chrome
  • macos-color-dock / mint-dock — нижние панели инструментов с глянцевыми значками
  • terminal / arch / kde / gnome / xfce / ubuntu / redhat — темы рабочего стола Linux

Цвета модальных окон берутся из записей <colors> в manifest каждого скина и отправляются на :root как переменные --cbe-modal-*, чтобы каждое модальное окно (включая эту справку) отображалось в теме.

Расширения ↑ вверх

Мини-приложения, которые живут внутри CBE. Каждое — это папка в extensions/<id>/ с:

  • manifest.xml — id, имя, версия, автор, описание, HTML записи, значок (emoji или icon.svg)
  • extension.html (или то, что говорит <entry> manifest) — фактическое приложение

Нажмите расширения для просмотра установленного, закрепления на панели инструментов, установки новых из публичного каталога или удаления с диска. Закреплённые ID находятся в extensions/_pinned.json.

Автообновление (push / pull) ↑ вверх

CBE синхронизирует свой исходник между машинами через канал WinSCP push + HTTPS pull.

Push (только администратор)

Если [updates] is_admin = true в config.ini, каждая активация запускает фоновую синхронизацию WinSCP synchronize remote -mirror, которая отправляет папку расширения на /home/trentontompkins.com/cbe на сервер. Ручной триггер: /push слэш-команда. Исключает per-machine состояние: data/ (1.74 GB профилей Chrome), bridges/, node_modules/, .git/, logs/, chats/, config.ini, prompt_history.txt, domains.txt, wake.txt.

Pull (каждый клиент)

Через 4 секунды после активации каждый клиент получает https://trentontompkins.com/cbe/manifest.xml.php и сравнивает MD5 per-файл с локальными копиями. Только изменённые/отсутствующие файлы загружаются по простому HTTPS GET. Исключённые пути НИКОГДА не загружаются: config.ini, data/, bridges/, extension.js, panel/panel.js, panel/index.html, package.json, инструменты сборки — суть в том, что исходник поставляется через .vsix и старая копия сервера не должна перезаписывать текущую работу разработки.

Горячая перезагрузка ↑ вверх

Два пути перезагрузки доступны через контекстное меню:

  • Перезагрузить панель — переодитывает panel/index.html + каждый JS/CSS актив с per-файловым ?v=<mtime> cache-buster и переназначает panel.webview.html. Подхватывает panel.js / скин CSS / dotmatrix изменения без перезагрузки VSCode. Хост расширения остаётся живым (ваш терминал, наблюдатель, обработчики сообщений, история чата сохраняются).
  • Перезагрузить окно — запускает workbench.action.reloadWindow. Используйте только когда вы отредактировали extension.js (код на стороне хоста) и перезагрузка панели недостаточна.

Изменения CSS скина также автоприменяются через существующий в панели наблюдатель скинов — щелчок меню не требуется.

Решение проблем ↑ вверх

"bridge X chat failed: api key empty in config.ini"

Демон smart_bridge.py кэшировал старую проверку ворот в памяти. Исправлено в pivot маршрутизации C++-exe. Если вы всё ещё видите это, убейте устаревшие демоны:

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
"copilot has no public REST API — use the browser bridge"

Старый extension.js маршрутизировал чат моста через REST маршрутизатор вместо фактического C++ exe лотка. Перезагрузите окно для получения исправленного extension.js, тогда чат пойдёт прямо на bin/CBE-Bridge-Copilot.exe.

HTTP 404 model: sonnet-4.6

Устаревший краткий alias в конфигурации моста Claude. Исправлено — полные ID (claude-sonnet-4-6, claude-opus-4-7, claude-haiku-4-5) теперь используются.

Я отредактировал файл, но панель не показывает изменение
  1. Если это panel.js / skins/*.css / index.html → щелчок правой кнопкой → перезагрузить панель.
  2. Если это extension.js / bridges_cpp/*.py → щелчок правой кнопкой → перезагрузить окно.
  3. Если вы не можете достичь меню (например, меню ещё не загрузилось), запустите свежий экземпляр VSCode с изолированным user-data-dir:
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Codex Black"
STT не удаётся с "not-allowed"

VSCode песочница вебвью от разрешения микрофона. CBE автоматически откатывается на Windows SAPI (System.Speech.Recognition), запущенный через PowerShell. Вам может потребоваться предоставить доступ к микрофону на уровне ОС (параметры → конфиденциальность → микрофон).

Отсутствует исполняемый файл моста

Лог трассировки показывает BRIDGE:MISSING target=<t> expected=<path>. C++ exe лотков находятся в bin/CBE-Bridge-<Pretty>.exe. Если ваши не существуют, перестройте из исходника bridges_cpp/ (MSVC) или получите свежий .vsix.
