Claude Codex — Black Edition

VSCode साठी ऑफलाइन-फर्स्ट मल्टी-प्रदाता AI चॅट पॅनल। टॉगल करण्यासाठी Ctrl+Alt+B दाबा.

1. स्वागत

Claude Codex Black एक VSCode वेबव्यू आहे जो तुम्हाला एकाच, थीमेबल पॅनेलमधून अनेक AI प्रदाताकडून (Claude, OpenAI, Gemini, Grok, Azure, स्थानिक Ollama) चॅट करू देतो। प्रत्येक गोष्ट ज्याला की आवश्यक आहे ती एक्सटेंशन रूटवरील config.ini मधून वाचली जाते — कोणत्या एक्सटेंशन सेटिंग्ज UI आवश्यक नाही, परंतु एक सेटिंग्ज मोडल क्लिक-केवळ संपादनासाठी सर्वाधिक उपयोगी फील्ड्स मिरर करतो.

येथे नवीन आहात? सेटिंग्ज उघडून सुरुवात करा (गियर आयकन), तुमचा प्रदाता निवडा, तुमची API की पेस्ट करा, नंतर प्रॉम्प्ट टाइप करा आणि Enter दाबा. या मार्गदर्शनातील इतर प्रत्येक वैशिष्ट्य पर्यायी आहे.

3. प्रॉम्प्ट बॉक्स

तळाशी मोठा संपादनयोग्य textarea। टाइप करा, पेस्ट करा, फाइल ड्रॅग करा, पेपरक्लिपद्वारे जोडा — जे काही तुम्ही येथे ठेवता ते पुढील API कॉलचा वापरकर्ता टर्न आहे.

फॉन्ट तुमच्या VSCode एडिटरच्या मोनोस्पेस फॉन्टवर लॉक केला आहे (--vscode-editor-font-family CSS व्हेरिएबलच्या माध्यमातून) जेणेकरून पॅनल एडिटरमध्ये घरातले दिसते.

5. मॉडल्स आणि प्रदाता

CBE bridges/ अंतर्गत ड्रॉप-इन .bridge प्लगइन्स म्हणून 11 ब्रिजेस शिप करतो. प्रत्येक manifest.xml + bridge.py + icons सह स्व-समाविष्ट zip आहे. bridges/ मध्ये एक नवीन .bridge फाइल ड्रॉप करा आणि ते कार्ट्रिज ड्रॉपडाउनमध्ये दिसते — कोणतेही एक्सटेंशन कोड बदल आवश्यक नाही.

टेक्स्ट-चॅट ब्रिजेस (7)

  • ChatGPT — chatgpt.com, Plus/Pro सबस्क्रिप्शन
  • Grok — grok.com, नेटिव्ह xAI लॉगिन (अनॉनिमस टियर भारीपणे गेटेड आहे; पहिले लॉगिन करा)
  • Gemini — gemini.google.com, Google खाते
  • Claude — claude.ai, जादू-लिंक लॉगिन (tools/sign_in_helper.py claude एकदा चलवा)
  • Copilot — copilot.microsoft.com, फ्री Microsoft खाते
  • DeepSeek — chat.deepseek.com, नेटिव्ह ईमेल/पासवर्ड (Google SSO वापरू नका)
  • Ollama — स्थानिक 127.0.0.1:11434, कोणती लॉगिन आवश्यक नाही

व्हिडिओ-जनरेशन ब्रिजेस (4)

  • Sora 2 — sora.com, तुमच्या ChatGPT Plus/Pro लॉगिन पुनः वापर करतो
  • Google Veo — gemini.google.com (Veo मोड), Gemini Advanced सबस्क्रिप्शन
  • Runway Gen-3/4 — app.runwayml.com, वेगळी Runway सबस्क्रिप्शन
  • Bing Video Creator — bing.com/videos/create, Microsoft खात्यासह फ्री Sora-2

जेनरेट केलेल्या व्हिडिओ videos/<bridge>/<timestamp>_<prompt-slug>.mp4 ला सेव होतात आणि व्हिडिओ लायब्रेरी पॅनेलमध्ये ऑटो-प्ले होतात (§Video Library खाली पहा).

प्रॉम्प्ट बॉक्सच्या पुढील कार्ट्रिज ड्रॉपडाउन किंवा सेटिंग्ज → जनरल द्वारे ब्रिज + मॉडल निवडा. निवड प्रति-वर्कस्पेस आहे आणि workspaceState मध्ये कायम केली जाते. नवीन ब्रिज जोडण्यासाठी, docs/WRITING_BRIDGES.md पहा.

5a. व्हिडिओ लायब्रेरी

व्हिडिओ ब्रिजेस (Sora, Veo, Runway, Bing Video Creator) द्वारे जेनरेट केलेल्या व्हिडिओ ब्राउज करण्यासाठी आणि पाहण्यासाठी एक समर्पित पॅनल. कमांड पॅलेटद्वारे उघडा: Claude Codex Black: Open Video Library किंवा codexBlackEd.openVideoPlayer कमांड.

  • साइडबार videos/<bridge>/ अंतर्गत प्रत्येक .mp4 / .webm / .mov सूचीबद्ध करतो, ब्रिज द्वारे गटबद्ध आणि नवीनतम-प्रथम क्रमांकित.
  • सर्वात ताज्या व्हिडिओ पहिल्या ओपनवर ऑटो-प्ले होतो.
  • पॅनल 2-सेकंड टिकवर videos/ डिर पाहतो — कोणतीही नवीन जेनरेट केलेली व्हिडिओ ✨ "Just generated" बॅज आणि ऑटो-प्ले सह पॉप अप होते (§Auto ▶ नवीन द्वारे टॉगल बंद करा).
  • 📂 उघडा क्लिक करा तुमच्या OS फाइल व्यवस्थापकमध्ये videos/ फोल्डर उघड करण्यासाठी.

6. स्पीच टू टेक्स्ट

मायक क्लिक करा, बोला, पुन्हा क्लिक करा थांबवा (किंवा मौन-टाइमआउटच्या प्रतीक्षा करा). दोन इंजिन क्रमाने वापरले जातात:

  1. Web Speech API — वेबव्यूमध्ये चालणारा Google चे क्लाउड रिकॉग्नाइজर. तुमचे Gmail/Google सेशन वापरतो; कोणती अतिरिक्त की आवश्यक नाही.
  2. Windows SAPI (फॉलबॅक) — जेव्हा वेबव्यू मायक एक्सेस ब्लॉक करतो तेव्हा प्रीवार्मड PowerShell प्रक्रिया आमंत्रित केली जाते. सुसज्ज लिसन विंडो [voice] listen_seconds द्वारे config.ini मध्ये कॉन्फिगरेबल.
SAPI एक्सटेंशन अ‍ॅक्टिव्हेटवर प्रीवार्मड आहे जेणेकरून पहिल्या मायक क्लिक 2-4 सेकंडची कोल्ड स्टार्ट टाळतो ज्यामुळे सुरुवातीच्या स्टॉप-क्लिक गिळली जायची.

7. ऑटो प्रॉम्प्ट

बॅज-विथ-स्पिनर बटन. जेव्हा ON असतो तेव्हा N सेकंडच्या निष्क्रियतेनंतर पॅनल तुमचा कॉन्फिगर्ड वेक-अप टेक्स्ट ऑटो-पाठवतो. काउंटडाउन अंक --cbe-highlight-color मध्ये रेंडर केला जातो, जो प्रत्येक स्किन परिभाषित करतो.

🔁 Wake बटनद्वारे वेक-अप टेक्स्ट संपादित करा — ते wake.txt राउंड-ट्रिप करतो.

8. ऑटो रीड (TTS)

तोंड आयकन. जेव्हा ON असतो तेव्हा प्रत्येक असिस्टंट उत्तर Web Speech सिंथेसाइजर (Google) किंवा SAPI फॉलबॅकद्वारे बोलले जाते. ऑडिओ प्ले होत असताना आयकनच्या सभोवतालदेशी निळा हॅलो चमकतो.

9. कॉम्पॅक्ट आणि संदर्भ वापर

मॉडेलला पाठविलेली संभाषण अ‍ॅरे प्रत्येक टर्नसह वाढते. कॉम्पॅक्ट आयकनच्या सभोवताली रिंग वर्तमान संदर्भ-विंडो वापर कॉनिक ग्रेडिएंट म्हणून दर्शवतो — ताज्यावेळी रिकामे, मॉडेलच्या संदर्भ मर्यादेच्या जवळ असताना भरून.

इतिहास शेषतम चार टर्न्सपर्यंत ट्रंकेट करण्यासाठी कॉम्पॅक्ट क्लिक करा. पुढील API कॉल लहान अ‍ॅरे वापर करतो.

10. वेक-अप प्रतिसाद

एक्सटेंशन रूटवर wake.txt मध्ये संग्रहित. निष्क्रियता टाइमर फायर होताना पाठवायचा संदेश म्हणून ऑटो प्रॉम्प्ट द्वारा वापरला जाते. 🔁 टूलबार बटनद्वारे संपादित करा.

11. फाइल अँटॅचमेंट्स

📎 क्लिक करा एक किंवा अधिक फाइल्स निवडा. पिकरमध्ये मल्टी-निवडण्यासाठी Ctrl किंवा Shift होल्ड करा. प्रत्येक फाइल प्रॉम्प्टमध्ये त्याच्या फाइलनाम आणि भाषा सह फेन्सड कोड ब्लॉक म्हणून इनलाइन केली जाते. 1 MB पेक्षा मोठ्या बायनरी फाइल्स नोटिससह स्किप केल्या जातात.

12. Git मोडल

📁 Git क्लिक करा. जर कोणत्याही प्रकल्प फोल्डर कॉन्फिगर केल्या नाहीत तर तुम्हाला पहिले फोल्डर पिकर मिळतो — निवडलेला पाथ config.ini मध्ये [project] path ला लिहिला जातो. त्यानंतरच्या git आमंत्रणे त्या पाथवर cwd सेट करून चलतात.

13. GitHub रेपोजिटरीज

तुमच्या [github] pat साठी सुलभ असलेल्या प्रत्येक repo सूचीबद्ध करतो. प्रॉम्प्टमध्ये त्याचा क्लोन URL घालण्यासाठी एक पंक्ती क्लिक करा. यादी पेजिनेट आणि कॅशेड आहे.

14. NameSilo डोमेन्स

[namesilo] api_key वापर करून (किंवा [api_keys] namesilo_api_key फॉलबॅक) तुमच्या NameSilo खात्यातील प्रत्येक डोमेन खेचतो. पहिल्या ओपनवर, परिणाम domains.txt ला कॅशे केले जातात; त्यानंतरच्या पॅनल बूट्स कॅशमधून सेवा करतात. ताजा फेच लागू करण्यासाठी मोडलमध्ये पुनरावृत्ती क्लिक करा.

जर तुम्हाला कधीही 300 उत्तर कोडसह "no domains" दिसले तर ट्रेस चॅनल तपासा — रिकाम्या कॅशे यापुढे भविष्यच्या पॅनल बूट्स विषम न करतात, परंतु दुसर्या इंस्टॉल पाथमधील स्टेल domains.txt असू शकते.

15. स्किन्स आणि थीम्स

🎨 बटन डिस्कव्हरी पिकर पॉप करतो जो skins/ लाइव्ह स्कॅन करतो (स्टार्टअपवर नाही), तर रनटाइमवर नवीन फोल्डर ड्रॉप करणे पुरेसे आहे. प्रत्येक स्किनला manifest.xml आहे जो त्याचे पॅलेट परिभाषित करतो — हाइलाइट रंग सह, जो ऑटो प्रॉम्प्ट काउंटडाउन बॅज, फोकस रिंग्स आणि पर्यवेक्षक पल्स सर्व की करतात.

बिल्ट-इन स्किन्स समाविष्ट करतात: gnome (Adwaita gray), terminal (black/green with hot-pink accent), tamagotchi (egg-shell pastels with a sprite mascot panel), blocky, आणि इतर.

16. सेटिंग्ज

⚙ गियर मधून उघडा. टॅब्स:

  • जनरल — डिस्प्ले नाम, डिफॉल्ट मॉडल, सेंड-ऑन-एंटर
  • व्हॉयस — मायक डिव्हाइस, listen_seconds, STT इंजिन पिक, TTS ऑटो-रीड
  • अपडेट्स — is_admin फ्लॅग, WinSCP सेशन, रिमोट पाथ
  • की — प्रत्येक प्रदाताची API की
  • मॉनिटर — VSCode पर्यवेक्षक टॉगल, पोर्ट, पोल अंतराल

मोडल सेशन दरम्यान त्याचे आकार आणि स्थान लक्षात ठेवतो.

17. भाषा

पॅनल 39 सर्वाधिक-बोलल्या जाणार्‍या भाषांसाठी अनुवाद शिप करतो. स्थान फाइल्स languages/<code>.xml वर राहतात आणि एक्सटेंशन अ‍ॅक्टिव्हेटवर लोड केल्या जातात. हरवलेल्या की इंग्रजीला फॉलबॅक करतात.

सेटिंग्ज → भाषा मध्ये तुमची भाषा निवडा. प्रत्येक विकल्पच्या पुढे फ्लॅग आयकन दर्शविला जातो (assets/flags/<code>.svg मधून लोड केला). निवड config.ini मध्ये [settings] language ला सेव केली जाते.

18. VSCode पर्यवेक्षक

Windows सेवा (CBEVSCodeSupervisor) NSSM द्वारे tools/vscode_supervisor.ps1 स्क्रिप्ट लपेटते आणि http://127.0.0.1:3434/ वर HttpListener बांधतो. पर्यवेक्षकचा /status एंडपॉइंट 200 OK उत्तर दिल्यास पॅनेलचा मॉनिटर बटन निळा चमकतो.

जर HTTP प्रोब अपयशी पडला परंतु सेवा इंस्टॉल केली असेल, पॅनेलचा वॉचडॉग सेवा ऑटो-रीस्टार्ट करतो (30-सेकंड कूल-डाउन तर ते रीस्टार्ट-स्टॉर्मला भडकाऊ नाहीत).

इंस्टॉल / स्टार्ट / स्टॉप करण्यासाठी मॉनिटर बटन डावीकडून क्लिक करा. ट्रेस चॅनल उघडण्यासाठी उजवीकडून क्लिक करा.

19. ऑटो-अपडेट (पुल)

एक्सटेंशन अ‍ॅक्टिव्हेटनंतर 4 सेकंद, पॅनल https://trentontompkins.com/cbe/manifest.xml.php — नवीनतम प्रकाशित फाइल्सचा MD5+size मॅनिफेस्ट. प्रत्येक रिमोट फाइलसाठी, स्थानिक कॉपीचा MD5 तुलना केला जाता; फक्त बदललेल्या/हरवलेल्या फाइल्स HTTPS द्वारे डाउनलोड केल्या जातात.

वापरकर्ता-स्थानिक स्थिति (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) पुल एक्सक्लूजन यादीवर आहे आणि कधीही ओव्हरराइट केले जात नाहीत.

21. एक्सटेंशन्स मार्केटप्लेस

🧩 एक्सटेंशन्स बटन क्लिक करा. एक iframe मोडल https://trentontompkins.com/cbe/extension/extension_marketplace.php ला उघडतो, जो extensions.xml.php वर कॅटलॉग फेच करतो आणि प्रत्येक उपलब्ध एक्सटेंशन कार्ड म्हणून विवरण, टॅग, आवृत्ती, फाइल आकार, MD5, आणि इंस्टॉल बटनसह रेंडर करतो.

एक्सटेंशन <id>.ext म्हणून पॅकेजेज केल्या जातात — manifest.xml अधिक एक्सटेंशन कोड (विशेषत: एकल extension.html) समाविष्ट करणारी zip आर्काइव. तुम्ही इंस्टॉल क्लिक केल्यावर, मार्केटप्लेस iframe पॅनेलला postMessage परत पाठवतो; पॅनल सर्व्हरमधून .ext फाइल थेट डाउनलोड करतो आणि एक्सटेंशन फोल्डरमध्ये extensions/ अंतर्गत काढतो.

लॉन्च कॅटलॉगसह तीन डेमो एक्सटेंशन शिप केल्या जातात: कॅलकुलेटर, Minesweeper, आणि Emoji पिकर.
