Claude Codex — Black Edition

VSCode 的離線優先多提供商 AI 聊天面板。 按 Ctrl+Alt+B 切換。

1. 歡迎

Claude Codex Black 是一個 VSCode webview，讓你可以在單一可主題化的面板中與多個 AI 提供商 （Claude、OpenAI、Gemini、Grok、Azure、本地 Ollama）聊天。 所有需要密鑰的內容都從擴展程式根目錄的 config.ini 讀取 — 不需要擴展程式設定 UI，但設定模組會鏡像最有用的欄位供單擊編輯。

新手？首先打開 設定（齒輪圖標），選擇提供商，貼上 API 密鑰，然後輸入提示並按 Enter。本指南中的其他功能都是可選的。

2. 鍵盤快捷鍵

按鍵效果

Enter發送當前提示
Shift+Enter在提示欄內換行
↑ / ↓循環通過之前發送的提示（來自 prompt_history.txt）
← / →當光標在文本域的開始/結束位置時，循環通過策劃的 prompts.txt 條目
Esc關閉任何打開的模組
/打開斜杠命令調色板

3. 提示欄

底部的大型可編輯文本區域。輸入、粘貼、拖動文件、通過迴紋針附件 — 你在這裡放的任何內容都是下一次 API 調用的用戶轉向。

字體被鎖定為你的 VSCode 編輯器的等寬字體（通過 --vscode-editor-font-family CSS 變數），所以面板在編輯器內看起來很自然。

5. 模型 & 提供商

CBE 配備 11 個橋接，作為 bridges/ 下的即插即用 .bridge 插件。 每個都是自成一體的 zip，包含 manifest.xml + bridge.py + 圖標。將新的 .bridge 文件放入，它將出現在軟體選擇器中 — 無需更改擴展程式代碼。

文本聊天橋接（7 個）

  • ChatGPT — chatgpt.com，Plus/Pro 訂閱
  • Grok — grok.com，原生 xAI 登錄（免費層受限制；請先登錄）
  • Gemini — gemini.google.com，Google 帳戶
  • Claude — claude.ai，魔法鏈接登錄（運行 tools/sign_in_helper.py claude 一次）
  • Copilot — copilot.microsoft.com，免費 Microsoft 帳戶
  • DeepSeek — chat.deepseek.com，原生電子郵件/密碼（不要使用 Google SSO）
  • Ollama — 本地 127.0.0.1:11434，無需登錄

視頻生成橋接（4 個）

  • Sora 2 — sora.com，重複使用 ChatGPT Plus/Pro 登錄
  • Google Veo — gemini.google.com（Veo 模式），Gemini Advanced 訂閱
  • Runway Gen-3/4 — app.runwayml.com，單獨的 Runway 訂閱
  • Bing 視頻創建器 — bing.com/videos/create，免費 Sora-2 與 Microsoft 帳戶

生成的視頻保存到 videos/<bridge>/<timestamp>_<prompt-slug>.mp4 並在視頻庫面板中自動播放（見下文視頻庫部分）。

從提示欄旁邊的軟體選擇器或通過 設定 → 常規 選擇橋接 + 模型。 選擇是按工作區的，並保存在 workspaceState 中。要添加新橋接，見 docs/WRITING_BRIDGES.md。

5a. 視頻庫

用於瀏覽和播放由視頻橋接生成的視頻（Sora、Veo、Runway、Bing 視頻創建器）的專用面板。 通過命令面板打開：Claude Codex Black: Open Video Library 或 codexBlackEd.openVideoPlayer 命令。

  • 側邊欄列出 videos/<bridge>/ 下的每個 .mp4 / .webm / .mov，按橋接分組並按最新優先排序。
  • 最新的視頻在首次打開時自動播放。
  • 面板以 2 秒間隔監視 videos/ 目錄 — 任何新生成的視頻會彈出 ✨ "剛生成" 標籤並自動播放 （通過 自動 ▶ 新 關閉）。
  • 點擊 📂 打開 在操作系統文件管理器中顯示 videos/ 文件夾。

6. 語音轉文字

點擊麥克風，說話，再次點擊停止（或等待靜默超時）。 按順序嘗試兩個引擎：

  1. Web Speech API — Google 的雲識別器在 webview 中運行。 使用你的 Gmail/Google 會話；無需額外密鑰。
  2. Windows SAPI（備用方案）— 當 webview 阻止麥克風訪問時調用的預熱 PowerShell 進程。 可通過 config.ini 中的 [voice] listen_seconds 配置監聽窗口。
SAPI 在 擴展程式激活時預熱，所以第一次麥克風點擊避免了曾經吞掉早期停止點擊的 2-4 秒冷啟動。

7. 自動提示

帶有微調器的徽章按鈕。打開時，N 秒不活動後，面板會自動發送配置的喚醒文本。 倒計時數字以 --cbe-highlight-color 呈現，每個皮膚都定義該顏色。

通過 🔁 喚醒按鈕編輯喚醒文本 — 它雙向轉移 wake.txt。

8. 自動朗讀（TTS）

嘴巴圖標。打開時，每條助手回覆都通過 Web Speech 合成器（Google）或 SAPI 備用方案朗讀。 當音頻播放時，藍色光暈在圖標周圍發光。

9. 精簡 & 上下文使用量

發送到模型的對話陣列隨著每個轉向而增長。精簡圖標周圍的環形圖顯示當前上下文窗口使用情況為圓錐漸變 — 新鮮時為空，接近模型上下文限制時為滿。

點擊精簡以將歷史截斷為最後四個轉向。下一次 API 調用使用較小的陣列。

10. 喚醒響應

存放在擴展程式根目錄的 wake.txt 中。由自動提示使用作為不活動計時器觸發時要發送的消息。 通過 🔁 工具欄按鈕編輯。

11. 文件附件

點擊 📎 選擇一個或多個文件。在選擇器中按住 Ctrl 或 Shift 進行多選。 每個文件以帶有文件名和語言的圍欄代碼塊內聯到提示中。超過 1 MB 的二進制文件被跳過並帶有通知。

12. Git 模組

點擊 📁 Git。如果沒有配置項目文件夾，你首先得到文件夾選擇器 — 選擇的路徑被寫入 config.ini 中的 [project] path。後續 git 調用以該路徑作為 cwd 運行。

13. GitHub 倉庫

列出每個可訪問你的 [github] pat 的倉庫。點擊一行將其克隆 URL 插入提示中。 列表被分頁和緩存。

14. NameSilo 域名

使用 [namesilo] api_key（或 [api_keys] namesilo_api_key 作為備用方案） 拉取 NameSilo 帳戶中的每個域名。首次打開時，結果被緩存到 domains.txt； 後續面板啟動從緩存提供。在模組中點擊 重新加載 強制進行新的提取。

如果你曾看到帶有 300 回覆代碼的 "無域名"，檢查跟蹤通道 — 空緩存不再為未來的面板啟動添加毒害， 但另一個安裝路徑中的過時 domains.txt 可能會。

15. 皮膚 & 主題

🎨 按鈕彈出實時掃描 skins/ 的發現選擇器（不在啟動時）， 所以在運行時放入新文件夾就足夠了。每個皮膚有一個定義其調色板的 manifest.xml — 包括 高亮顏色，自動提示倒計時徽章、焦點環和監督器脈衝都使用該顏色。

內置皮膚包括：gnome（Adwaita 灰色）、terminal （黑/綠帶熱粉色口音）、tamagotchi（蛋殼粉色帶精靈吉祥物面板）、blocky 等。

16. 設定

從 ⚙ 齒輪打開。選項卡：

  • 常規 — 顯示名稱、默認模型、輸入發送
  • 語音 — 麥克風設備、listen_seconds、STT 引擎選擇、TTS 自動朗讀
  • 更新 — is_admin 標誌、WinSCP 會話、遠程路徑
  • 密鑰 — 每個提供商的 API 密鑰
  • 監控 — VSCode 監督器切換、端口、輪詢間隔
  • 語言 — 從 39 個地區設置中選擇；見 § 17

模組記住其大小和位置跨會話。

17. 語言

面板隨附 39 種最常用語言的翻譯。地區設置文件位於 languages/<code>.xml 並在擴展程式激活時載入一次。遺漏的密鑰回退到英語。

在 設定 → 語言 中選擇你的語言。每個選項旁邊顯示一個標誌圖標 （從 assets/flags/<code>.svg 載入）。選擇被保存到 config.ini 中的 [settings] language。

18. VSCode 監督器

Windows 服務（CBEVSCodeSupervisor）通過 NSSM 包裝 tools/vscode_supervisor.ps1 腳本 並在 http://127.0.0.1:3434/ 上綁定 HttpListener。 當監督器的 /status 端點回覆 200 OK 時，面板的監控按鈕發出藍光。

如果 HTTP 探測失敗但服務已安裝，面板的看門狗自動重啟服務（30 秒冷卻，所以不會重啟風暴）。

左鍵單擊監控按鈕進行安裝/啟動/停止。右鍵單擊打開跟蹤通道。

19. 自動更新（拉取）

擴展程式激活後 4 秒，面板獲取 https://trentontompkins.com/cbe/manifest.xml.php — 最新發佈文件的 MD5+大小清單。對於每個遠程文件，比較本地副本的 MD5； 只有更改/遺漏的文件通過 HTTPS 下載。

用戶本地狀態（config.ini、debug.log、 domains.txt、wake.txt、prompt_history.txt） 在拉取排除列表上，從不被覆蓋。

20. 管理員推送

只有具有 [updates] is_admin = true 的客戶端才推送到服務器。 通過以下方式觸發：

  • 命令面板 → Claude Codex Black: Push update
  • 斜杠命令 /push

使用在 [updates] winscp_session 中命名的 WinSCP 保存會話（默認 vps）。 通過帶有同步命令和排除機密 & 每台機器狀態的文件掩碼的 /script=… 推送。

21. 擴展程式市場

點擊 🧩 擴展程式按鈕。iframe 模組打開到 https://trentontompkins.com/cbe/extension/extension_marketplace.php， 它獲取 extensions.xml.php 中的目錄並將每個可用擴展程式呈現為帶有 描述、標籤、版本、文件大小、MD5 和 安裝 按鈕的卡片。

擴展程式打包為 <id>.ext — 包含 manifest.xml 加上 擴展程式代碼（通常是單個 extension.html）的 zip 存檔。點擊安裝時， 市場 iframe 向面板發回 postMessage；面板直接從服務器下載 .ext 文件並將其提取到擴展程式文件夾中的 extensions/ 下。

三個演示擴展程式隨啟動目錄一起提供：計算器、掃雷 和 表情符號選擇器。

22. 斜杠命令

在提示欄中輸入 / 打開斜杠命令調色板。點擊一行 插入 命令文本到提示中 （可編輯），或在可運行行上按 Enter 立即觸發它。

一個非詳盡的列表：

命令效果
/help打開本文件
/skin彈出皮膚選擇器
/push觸發自動更新推送（僅限管理員）
/license顯示 LICENSE.TXT
/clear清空對話歷史
/domains打開 NameSilo 域名模組
/git打開 Git 模組
/wake打開喚醒編輯器
/memory打開項目記憶索引

23. 右鍵菜單

在面板中任何位置右鍵單擊出現上下文菜單（在 panel.js 中定義為單個 XML 字符串）。 條目包括刷新（重新加載面板而不觸及擴展程式主機 — 永遠不要使用 reloadWindow）、 清空對話、打開設定和檢查（DevTools，僅調試構建）。

24. 跟蹤通道

擴展程式在擴展程式旁邊的 debug.log 寫入詳細時間線。 所有值得注意的事項都在那裡：提供商切換、STT 生命週期、監督器探測、 NameSilo 回覆代碼、面板↔主機橋接消息、推送/拉取清單計數。

右鍵單擊監控按鈕以一鍵打開跟蹤通道。

25. 故障排除

症狀可能原因
提示欄看起來比例字體，不是等寬 --vscode-editor-font-family 未應用；檢查 :root 變數
自動提示微調器是黑點 SVG 資源錯誤；應為帶陰影光暈的 auto_read_spinner.svg
精簡按鈕不執行任何操作 主機處理程序遺漏 — extension.js 路由器中缺少 case 'compactConversation'
域名模組中的 "0 個域名" NameSilo reply.code != 300（跟蹤通道有它），或過時的 domains.txt
STT "未檢測到語音" 立即發生 你在 SAPI 綁定麥克風之前停止。預熱現在跳過等待 — 在 debug.log 中用 stt: using pre-warmed SAPI 驗證
帶空格的路徑推送失敗 使用內聯 /command=；始終使用 /script=tempfile.winscp
監督器藍色發光不亮 服務未運行。左鍵單擊 monitorBtn 進行安裝/啟動，或運行 Start-Service CBEVSCodeSupervisor
重新加載 "修復" 什麼 它沒有。永遠不要使用 reloadWindow。改用刷新上下文菜單條目。
