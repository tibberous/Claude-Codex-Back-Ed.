快速開始 ↑ 頂部

  1. 點擊設定（魔杖圖標）並完成精靈嚟輸入你嘅 API 鑰匙。佢哋會被保存到 config.ini（呢個文件被 gitignored，唔會被提交）。
  2. 點擊左下角嘅供應商藥丸（目前標籤為「Codex Black Ed.」）嚟切換你要同邊個 AI 對話。
  3. 喺文本框輸入並按 Enter 嚟傳送。Shift+Enter 會插入換行。
  4. 喺空文本框按 ↑ 嚟回想之前嘅提示詞（PowerShell 風格歷史）。

橋接目標港口

每個橋接都係喺 bin/CBE-Bridge-<Target>.exe 一個小型 C++ 託盤應用，佢打開已登入嘅 Chrome 配置文件、攔截你嘅提示詞，並返回模型嘅回覆。喺設定中選擇橋接供應商會自動啟動匹配嘅 exe。第一次使用橋接時，你必須喺佢嘅 Chrome 窗口中登入該網站一次。

橋接聊天喺 TCP 上使用行協議：輸入一行 JSON（{action:"chat", target, message, model}），輸出一行 JSON。唔需要 api 鑰匙。

傳送訊息 ↑ 頂部

文本框
輸入你嘅提示詞。Enter 傳送，Shift+Enter 插入換行。當回覆正在流式傳輸時，額外嘅提示詞會被排隊並按順序發送 — 喺呢個狀態下佔位符顯示「排隊另一條訊息…」。
傳送按鈕（圓球）
喺文本框右邊緣嘅圓形按鈕。同 Enter 一樣。視覺上顯示三個狀態（閒置 / 懸停 / 活躍）。
停止按鈕
喺作曲框嘅右下角。取消當前流式傳輸嘅回覆同任何排隊嘅訊息。流式傳輸嘅文本會被保留；只有待發請求會被中止。
供應商藥丸
喺作曲框嘅左下角。點擊查看你已配置嘅每個供應商嘅下拉菜單。選擇新供應商會自動啟動佢嘅橋接（如適用）並發佈確認吐司。
提示詞歷史
↑ / ↓ 喺空文本框中來回走過你已發送嘅最後 500 個提示詞（PowerShell 風格）。歷史存儲喺擴展文件夾中嘅 prompt_history.txt 並在面板重載後仍然存在。

工具欄按鈕 ↑ 頂部

按工具欄順序列出。所有工具提示都可以通過 languages/*.xml 按語言本地化。

新對話 addBtn
清除當前線程，擦除內存中嘅對話狀態，並重新開始。前一個線程會被保留喺磁盤上嘅 chats/<UTC-date>.log 下，所以唔會丟失任何內容。等同於 /clear。
保存嘅提示詞 storedPromptsBtn
打開一個模態框，列出 stored_prompts/ 下嘅每個已保存提示詞模板。點擊一個嚟將佢插入文本框；「+」按鈕添加新模板。模板支持變量替換。
聊天歷史 chatHistoryBtn
瀏覽磁盤上嘅聊天日誌（chats/ 下每個 UTC 日期一個文件）。選擇日期嚟回滾瀏覽過去嘅對話。
附檔案 attachFileBtn
打開文件選擇器。選定嘅文件會隨下一個提示詞上傳 — 圖像內聯顯示（視覺），文本/代碼文件成為你提示詞中嘅圍欄塊。支持多附檔。
朗讀（TTS） ttsBtn
朗讀最新嘅助手回覆。使用 ElevenLabs（如果設置了 [elevenlabs] api_key）或回退到 Windows SAPI。右鍵切換自動朗讀模式，每個新回覆都會被自動朗讀 — 按鈕會喺活躍時顯示動畫指示器。
語音轉文本（STT） sttBtn
記錄麥克風音頻並轉錄到文本框。首先嘗試 webview 嘅 Web Speech API；如果失敗（not-allowed，喺 VSCode 沙箱中常見），回退到 Windows SAPI（System.Speech.Recognition）通過 PowerShell 喺主機上啟動。再次點擊嚟停止。
自動提示 autoReplyBtn
打開自動提示模態框。定義一個提示詞 + 倒計時間隔；每次助手回覆後倒計時會減少，當倒計時達到零時自動重新發送自動提示詞。有用於「繼續」、「下一步」、重複工具會話。再次點擊嚟禁用。
喚醒回應 wakeUpBtn
編輯存儲喺 wake.txt 嘅喚醒訊息。喚醒是自動提示檢測到模型已停止時發送嘅 — 通常係一個短 ping，如「嘿！繼續。」
顯示命令菜單 showCommandsBtn
喺模態框中打開斜杠命令面板。查看斜杠命令以獲取完整列表。同喺文本框開始輸入 / 一樣。
緊湊對話 compactBtn
發佈一個總結並修剪請求，將當前線程替換為濃縮摘要。等同於 /compact。有用於當對話變得很長且你想保留背景但停止燃燒令牌重新發送整個歷史時。
手冊 handbookBtn
打開員工/項目手冊模態框。加載 handbook.html 或任何配置的文檔。用作系統提示參考，模型可以被要求查閱。
設定 settingsBtn
打開設定模態框（供應商、模型、皮膚、語言、SFX）。查看設定。
帳戶 accountsBtn
打開多帳戶管理器。添加 / 編輯 / 移除每個供應商嘅 API 鑰匙，按會話切換。查看帳戶。
擴展 extensionsBtn
打開面板內擴展瀏覽器。列出 extensions/ 下安裝嘅內容（每個都有 manifest.xml + entry HTML），讓你將擴展固定到工具欄，從公共目錄安裝新擴展，或移除佢哋。
項目文件夾 projectFolderBtn
選擇工作目錄，被 Attach File、Terminal、Git 同任何需要項目根目錄的工具使用。當前文件夾顯示喺供應商藥丸旁邊。
瀏覽器 browserBtn
打開並排 QtWebEngine 瀏覽器窗格，用於快速查閱而無需離開面板。
VSCode 監視器 monitorBtn
切換 VSCode 監督看門狗 — 一個後台進程，喺 VSCode 崩潰時重啟佢。左鍵點擊切換運行/停止，右鍵打開監督嘅跟蹤頻道。
終端 terminalBtn
喺項目文件夾中打開 VSCode 集成終端。如果未設置項目文件夾，回退到你嘅桌面。重用一個標籤為「CBE」嘅持久終端。
設定精靈 setupBtn
帶你完成擴展知道嘅每個 API 鑰匙 + 集成（約 12 步）。查看設定精靈。
Git gitBtn
打開 VSCode 嘅源代碼控制視圖，專注於當前項目文件夾。
GitHub githubBtn
使用 [github] token 列出你嘅 GitHub 倉庫。點擊倉庫嚟克隆 / 打開 / 瀏覽問題。
域名（NameSilo） domainsBtn
列出你 NameSilo 帳戶上嘅每個域名及其名稱服務器。需要 [namesilo] api_key。重新加載按鈕強制進行新鮮獲取。
字體大小 fontSizeBtn
喺正常同大字體之間切換聊天線程。同 /font 一樣。
幫助 helpBtn
打開呢頁。同 /help 一樣。
Tamagotchi tamaBtn
切換像素寵物面板（只喺tamagotchi皮膚上可見，喺作曲框角落停靠）。查看Tamagotchi。

右鍵菜單 ↑ 頂部

右鍵點擊聊天文本或代碼塊以獲得 CBE 上下文菜單。右鍵點擊提示詞文本框現在打開原生瀏覽器菜單（複製 / 剪切 / 粘貼 / 刪除 / 全選）。

複製 / 複製代碼塊
複製當前選擇。如果沒有選擇但你右鍵點擊了 <pre><code>，佢複製整個代碼塊。
查看源代碼
顯示點擊區域嘅原始 HTML/markdown — 要麼係代碼塊，要麼係整個面板 DOM。用於調試皮膚/CSS 問題。
打開開發者工具
要求 VSCode 打開其開發者工具，以便你可以即時檢查 webview。
設定 new
打開工具欄設定按鈕打開嘅同一設定模態框（供應商 / 模型 / 皮膚 / 語言 / SFX）。同 /settings 一樣。
關於 new
帶版本、作者、許可證、倉庫鏈接、作品集同聯繫電話嘅小面板內對話框。點擊背景、× 按鈕或 Esc 關閉。
重新加載面板 new
重新讀取 panel/index.html + panel.js + skins/*，帶有每文件 ?v=<mtime> 緩存破壞器，並重新分配 panel.webview.html。無需重啟 VSCode 即可獲取 CSS/JS 編輯。擴展主機保持活躍 — 終端、監督、聊天歷史都持久存在。
重新加載窗口 new
觸發 workbench.action.reloadWindow。僅當你編輯了 extension.js（主機端代碼）且面板重新加載不夠時才使用。呢係完整 VSCode 窗口重新加載。

模態框同對話框 ↑ 頂部

設定模態框 — 供應商 / 模型 / 皮膚 / 語言 / SFX
  • 供應商：每個直接 API + 橋接供應商嘅完整下拉菜單。選擇一個會切換活躍會話並自動啟動匹配嘅橋接 exe（如適用）。
  • 模型：每供應商嘅允許模型列表（例如 claude-opus-4-7、claude-sonnet-4-6、claude-haiku-4-5 適用於 Anthropic）。
  • 皮膚：視覺主題。查看皮膚。
  • 語言：39 個地區可用。切換會重新拉取字符串映射並實時重新翻譯每個工具提示 / 標籤 / 幫助按鈕。
  • SFX 啟用：切換 UI 音效（點擊、滴答、模態框打開/關閉等）。
  • SFX 音量：0–100 滑塊。當你拖動時實時預覽。
  • 取消還原你嘗試過嘅任何即時預覽（SFX/皮膚）；保存持久化並發出 setProvider。
設定精靈 — 多步 API 鑰匙輸入

每個集成嘅走查。每步要求輸入憑證並將佢哋寫入 config.ini。跳過前進而不寫入；下一步寫入並前進；最後一步嘅完成關閉。步驟包括：Anthropic、OpenAI、Gemini、xAI/Grok、GitHub PAT、Email/SMTP（Gmail 應用密碼）、Cloudflare、Twilio、ElevenLabs、Stability AI、Runway、SendGrid、NameSilo 等等。

帳戶模態框 — 多帳戶 API 鑰匙管理器

對於每個供應商，管理多個標籤帳戶（例如「個人」、「工作」）。切換哪個帳戶在當前會話中活躍而無需覆蓋其他帳戶。鑰匙被遮蔽端到端並按供應商保存喺 config.ini 中。

域名模態框 — NameSilo

列出你 NameSilo 帳戶上嘅每個域名及其名稱服務器 + 註冊日期。重新加載按鈕強制進行新鮮 API 獲取（否則佢緩存喺 domains.txt 中）。

手冊模態框

呈現項目手冊 HTML（意圖作為模型可以查閱嘅系統提示參考）。可按項目配置。

保存嘅提示詞模態框

來自 stored_prompts/ 嘅可插入提示詞模板。每個文件是一個模板；文件名前綴 NN- 控制排序順序。「+」按鈕創建新文件。

聊天歷史模態框

選擇 UTC 日期嚟從 chats/<date>.log 加載聊天日誌。唯讀。

擴展模態框

每個已安裝擴展嘅卡片。固定到工具欄 / 取消固定，從公共目錄安裝（extensions.xml.php 喺服務器上），或從磁盤移除。

變更日誌模態框

呈現 panel/change_log.html — 捆綁嘅發佈說明。通過 tools/build_changelog.py 生成。

查看源代碼模態框

任何代碼塊或面板嘅完整 HTML 嘅美化打印，帶有 Prism 語法突出顯示同複製按鈕。通過右鍵 → 查看源代碼訪問。

自動提示模態框

配置提示詞字符串 + 倒計時間隔。每次助手回覆後倒計時遞減；當倒計時達到零時 CBE 自動發送配置嘅提示詞。通過自動提示工具欄按鈕切換打開/關閉。

設定 ↑ 頂部

所有設定位於以下兩個地方之一：

  • workspaceState（VSCode 管理，按工作區）— 供應商、模型、皮膚、語言、sfx 啟用/音量、字體大小。
  • config.ini（擴展根目錄，gitignored）— API 鑰匙 + 每集成憑證。

設定在面板重載後自動持久化。設定模態框是更改任何內容嘅安全方式；直接編輯 config.ini 也可以。

設定精靈 ↑ 頂部

設定精靈（setupBtn）會逐步完成擴展支持嘅每個集成。對於每步，粘貼憑證並點擊下一步（寫入 + 前進）或跳過（前進而不寫入）。步驟：

步驟它要求什麼在哪裡獲取
Anthropic (Claude)API 鑰匙console.anthropic.com
OpenAI (ChatGPT)API 鑰匙platform.openai.com
Google GeminiAPI 鑰匙aistudio.google.com
xAI (Grok)API 鑰匙console.x.ai
GitHub PAT具有倉庫 / 工作流 / admin:org 等嘅個人訪問令牌。github.com/settings/tokens
Email / SMTP帳戶 + 應用密碼（推薦 Gmail）myaccount.google.com/apppasswords
CloudflareAPI 令牌（NOT 全局鑰匙）dash.cloudflare.com
Twilio帳戶 SID + Auth 令牌 + 發件人號碼console.twilio.com
ElevenLabs (TTS)API 鑰匙elevenlabs.io
Stability AIAPI 鑰匙platform.stability.ai
RunwayAPI 鑰匙dev.runwayml.com
SendGridAPI 鑰匙app.sendgrid.com

每個字段都被密碼遮蔽，所以旁觀者無法從屏幕上讀取你嘅鑰匙。

帳戶同 API 鑰匙 ↑ 頂部

每個供應商可以有多個標籤帳戶 — 如果你想在個人同工作鑰匙之間切換或測試不同層級，這很有用。帳戶模態框讓你：

  • 添加帶標籤同鑰匙嘅新帳戶
  • 編輯現有帳戶（重新標籤、替換鑰匙）
  • 設置當前會話中哪個帳戶是活躍嘅
  • 移除帳戶

鑰匙存儲被遮蔽（只見最後四位）喺 config.ini 中。workspaceState 中沒有純文本副本。

Tamagotchi 寵物 ↑ 頂部

Tamagotchi 係一個像素藝術寵物，生活喺tamagotchi皮膚下嘅面板中。佢會老化、變餓/變臟、可以玩、如果忽視足夠長時間會死亡。狀態持久化喺 workspaceState 中。

統計（小工具頂部）

統計它追蹤什麼
🥚 階段生命週期：蛋 → 寶寶 → 兒童 → 少年 → 成人 → 老年 → 死亡。實時分鐘老化。
🍖 飢餓0–100。隨著時間下降；餵食提高它。達到 0 → 健康下降。
😀 幸福感0–100。隨著時間下降；玩提高它。
❤️ 健康0–100。當生病或挨餓時下降。射擊治愈。
✨ 清潔度0–100。當寵物排便時下降。清潔提高它。
⏱ 年齡孵化以來的分鐘數。

LCD 內動作按鈕（小工具底部）

圖標動作
🍖餵食 — 循環肉類 ↔ 茄子。選擇實際餵食。
🧹清潔 — 掃除排便。
⚾玩 — 迷你遊戲；提高幸福感。
💉射擊 — 生病時治愈。
💡燈光 — 切換 LCD 燈；寵物喺黑暗中睡覺。
✅選擇 — 確認 / 進行（原始萬代中間按鈕的等效）。

寵物嘅精靈被繪製到 240×240（緊湊：138×116）畫布。精靈 + 生命週期邏輯位於 panel/dotmatrix-tamagotchi-sprites.js 同 panel/dotmatrix-tamagotchi-game.js。

皮膚 ↑ 頂部

整個面板嘅視覺主題 — 按鈕、模態框、代碼塊，甚至字體。喺設定 → 皮膚中選擇一個。每個皮膚位於 skins/<id>/，帶有 manifest.xml（聲明顏色 + 重音）同 styles.css（覆蓋 CSS 變量）。

  • codex-black（默認）— 暗色、等寬、霓虹青色重音
  • glassy — 柔和背景上嘅磨砂玻璃表面
  • tamagotchi — 石灰綠 LCD 掌上游戲機；自動在作曲框角落顯示停靠嘅寵物小工具
  • office — Word 風格奶油/藍色 Chrome
  • macos-color-dock / mint-dock — 帶玻璃圖標嘅底部停靠工具欄
  • terminal / arch / kde / gnome / xfce / ubuntu / redhat — Linux 桌面主題

模態框顏色來自每個皮膚嘅清單中嘅 <colors> 條目，並被推送到 :root 作為 --cbe-modal-* 變量，以便每個模態框（包括本幫助）都以主題渲染。

擴展 ↑ 頂部

生活喺 CBE 內嘅迷你應用程序。每個都係 extensions/<id>/ 下嘅一個文件夾，包含：

  • manifest.xml — id、name、version、author、description、entry HTML、icon（emoji 或 icon.svg）
  • extension.html（或清單嘅 <entry> 所說嘅任何內容）— 實際應用程序

點擊擴展嚟瀏覽安裝嘅內容、固定到工具欄、從公共目錄安裝新擴展或從磁盤移除。固定 ID 位於 extensions/_pinned.json。

自動更新（推送 / 拉取） ↑ 頂部

CBE 通過 WinSCP 推送 + HTTPS 拉取頻道在機器之間同步其源。

推送（僅管理員）

如果 config.ini 中 [updates] is_admin = true，每次激活都會運行後台 WinSCP synchronize remote -mirror，將擴展文件夾推送到服務器上嘅 /home/trentontompkins.com/cbe。手動觸發：/push 斜杠命令。排除每機器狀態：data/（1.74 GB Chrome 配置文件）、bridges/、node_modules/、.git/、logs/、chats/、config.ini、prompt_history.txt、domains.txt、wake.txt。

拉取（每個客戶端）

激活後 4 秒，每個客戶端都會獲取 https://trentontompkins.com/cbe/manifest.xml.php 並 MD5 比較每個文件與本地副本。只有更改/缺失文件通過純 HTTPS GET 下載。排除路徑永遠不會被拉取：config.ini、data/、bridges/、extension.js、panel/panel.js、panel/index.html、package.json、構建工具 — 理由係源通過 .vsix 發送，服務器嘅較舊副本不得覆蓋進行中嘅開發工作。

熱重載 ↑ 頂部

兩個重載路徑通過右鍵菜單公開：

  • 重新加載面板 — 重新讀取 panel/index.html + 每個 JS/CSS 資產，帶有每文件 ?v=<mtime> 緩存破壞器，並重新分配 panel.webview.html。無需重啟 VSCode 即可獲取 panel.js / 皮膚 CSS / dotmatrix 編輯。擴展主機保持活躍（你嘅終端、監督、訊息處理器、聊天歷史都持久存在）。
  • 重新加載窗口 — 觸發 workbench.action.reloadWindow。僅當你編輯了 extension.js（主機端代碼）且重新加載面板不夠時才使用。

皮膚 CSS 編輯也通過面板嘅現有皮膚監視器自動應用 — 無需菜單點擊。

故障排除 ↑ 頂部

"bridge X chat failed: api key empty in config.ini"

smart_bridge.py 守護進程在內存中緩存舊的閘門檢查。已在 C++ exe 路由樞紐中修復。如果你仍然看到它，殺死過時的守護進程：

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
"copilot has no public REST API — use the browser bridge"

舊 extension.js 通過 REST 路由器路由橋接聊天而不是實際 C++ 託盤 exe。重新加載窗口嚟選擇修復嘅 extension.js，然後聊天會直接進行到 bin/CBE-Bridge-Copilot.exe。

HTTP 404 model: sonnet-4.6

Claude 橋接配置中過時嘅短別名。已修復 — 現在使用完整 ID（claude-sonnet-4-6、claude-opus-4-7、claude-haiku-4-5）。

我編輯了文件但面板沒有顯示更改
  1. 如果係 panel.js / skins/*.css / index.html → 右鍵 → 重新加載面板。
  2. 如果係 extension.js / bridges_cpp/*.py → 右鍵 → 重新加載窗口。
  3. 如果你無法到達菜單（例如菜單本身還未加載），使用隔離用戶數據目錄啟動新鮮 VSCode 實例：
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Codex Black"
STT 失敗，顯示「not-allowed」

VSCode 沙箱化 webview 以限制麥克風權限。CBE 自動回退到 Windows SAPI（System.Speech.Recognition）通過 PowerShell 啟動。你可能需要喺 OS 級別授予麥克風訪問權限（設定 → 隱私 → 麥克風）。

橋接 exe 遺失

跟蹤日誌顯示 BRIDGE:MISSING target=<t> expected=<path>。C++ 託盤 exe 位於 bin/CBE-Bridge-<Pretty>.exe。如果你沒有，從 bridges_cpp/ 源（MSVC）重新構建或拉取新鮮 .vsix。
