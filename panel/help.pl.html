Claude Codex — Black Edition

Panel czatu AI offline-first wielooperatorowy dla VSCode. Naciśnij Ctrl+Alt+B aby przełączyć.

1. Powitanie

Claude Codex Black to webview VSCode, który umożliwia czat z wieloma operatorami sztucznej inteligencji (Claude, OpenAI, Gemini, Grok, Azure, lokalny Ollama) z jednego, szablonowanego panelu. Wszystko, co wymaga klucza, odczytuje z config.ini w katalogu głównym rozszerzenia — nie jest wymagany interfejs użytkownika ustawień rozszerzenia, ale modalne Ustawienia pokazuje najprzydatniejsze pola do edycji tylko klikami.

Nowy tutaj? Zacznij od otwarcia Ustawień (ikona koła zębatego), wybierz operatora, wklej swój klucz API, a następnie wpisz zachętę i naciśnij Enter. Każda inna funkcja w tym przewodniku jest opcjonalna.

3. Pole zachęty

Duży edytowalny textarea na dole. Wpisz, wklej, przeciągnij plik, dołącz za pomocą spinacza — wszystko, co tu umieścisz, to turna użytkownika następnego połączenia API.

Czcionka jest zablokowana na monospace czcionkę edytora VSCode (za pośrednictwem zmiennej CSS --vscode-editor-font-family, aby panel wyglądał naturalnie wewnątrz edytora.

5. Modele i dostawcy

CBE wysyłany z 11 mostkami jako drop-in wtyczki .bridge pod bridges/. Każdy jest samodzielnym zipem z manifest.xml + bridge.py + ikonami. Upuść nowy plik .bridge i pojawia się w rozwijalnym wkładzie — bez zmian kodu rozszerzenia.

Mosty czatu tekstowego (7)

  • ChatGPT — chatgpt.com, subskrypcja Plus/Pro
  • Grok — grok.com, natywny login xAI (warstwa anonimowa jest mocno ograniczona; zaloguj się najpierw)
  • Gemini — gemini.google.com, konto Google
  • Claude — claude.ai, login z magicznym linkiem (uruchom tools/sign_in_helper.py claude raz)
  • Copilot — copilot.microsoft.com, darmowe konto Microsoft
  • DeepSeek — chat.deepseek.com, natywny email/hasło (NIE używaj Google SSO)
  • Ollama — lokalne 127.0.0.1:11434, nie wymagane logowanie

Mosty generowania wideo (4)

  • Sora 2 — sora.com, ponownie używa login ChatGPT Plus/Pro
  • Google Veo — gemini.google.com (tryb Veo), subskrypcja Gemini Advanced
  • Runway Gen-3/4 — app.runwayml.com, oddzielna subskrypcja Runway
  • Bing Video Creator — bing.com/videos/create, darmowe Sora-2 z kontem Microsoft

Generowane wideo zapisuje się do videos/<bridge>/<timestamp>_<prompt-slug>.mp4 i automatycznie odtwarzane w panelu Biblioteka wideo (patrz §Biblioteka wideo poniżej).

Wybierz most + model z rozwijalnego wkładu obok pola zachęty, lub via Ustawienia → Ogólne. Selekcja jest na workspace i persystuje w workspaceState. Aby dodać nowy most, patrz docs/WRITING_BRIDGES.md.

5a. Biblioteka wideo

Dedykowany panel do przeglądania + oglądania filmów wygenerowanych przez mosty wideo (Sora, Veo, Runway, Bing Video Creator). Otwiera się przez Paletę Polecenia: Claude Codex Black: Open Video Library lub polecenie codexBlackEd.openVideoPlayer.

  • Pasek boczny wypisuje wszystkie .mp4 / .webm / .mov pod videos/<bridge>/, pogrupowane po moście i posortowane od najnowszych.
  • Najbardziej świeże wideo automatycznie odtwarzane na pierwszym otwarciu.
  • Panel obserwuje katalog videos/ z tykiem 2 sekundy — każde nowo wygenerowane wideo pojawia się z odznaki ✨ "Właśnie wygenerowane" i automatycznie odtwarzane (przełącz wyłącz via Auto ▶ new).
  • Kliknij 📂 Otwórz aby ujawnić folder videos/ w menedżerze plików OS.

6. Mowa na tekst

Kliknij mikrofon, mów, kliknij ponownie aby zatrzymać (lub czekaj na timeout ciszy). Dwa silniki są próbowane w kolejności:

  1. Web Speech API — rozpoznawacz chmury Google działający w webview. Używa sesji Gmail/Google; nie jest wymagany dodatkowy klucz.
  2. Windows SAPI (rezerwą) — preogrzewany proces PowerShell wywoływany gdy webview blokuje dostęp do mikrofonu. Konfigurowalne okno słuchania via [voice] listen_seconds w config.ini.
SAPI jest preogrzewany przy aktywacji rozszerzenia aby pierwszy klik na mikrofon unikał 2-4 sekundowego zimnego startu który kiedyś połykał wczesne kliknięcia stop.

7. Auto Prompt

Przycisk z odznaką-spinnerem. Gdy WŁĄCZONY, po N sekundach nieaktywności panel automatycznie wysyła skonfigurowany tekst przebudzenia. Cyfra odliczania jest renderowana w --cbe-highlight-color, którą definiuje każda skórka.

Edytuj tekst przebudzenia via przycisk 🔁 Przebudzenie — wymienia wake.txt.

8. Autoodczyt (TTS)

Ikona ust. Gdy WŁĄCZONE, każda odpowiedź asystenta jest wymawiana za pośrednictwem syntezyzer Web Speech (Google) lub rezewa SAPI. Niebieski halo świeci wokół ikony podczas odtwarzania audio.

9. Kompaktowy i użycie kontekstu

Tablica rozmowy wysłana do modelu rośnie z każdą turą. Pierścień wokół ikony Kompaktowy pokazuje bieżące użycie okna kontekstowego jako gradient stożkowy — pusty gdy świeży, pełny gdy blisko limitu kontekstu modelu.

Kliknij Kompaktowy aby skrócić historię do ostatnich czterech tur. Następne połączenie API używa mniejszej tablicy.

10. Odpowiedź na przebudzenie

Przechowywane w wake.txt w katalogu głównym rozszerzenia. Używane przez Auto Prompt jako wiadomość do wysłania gdy timer nieaktywności się uruchamia. Edytuj via przycisk 🔁 paska narzędzi.

11. Załączniki plików

Kliknij 📎 aby wybrać jeden lub więcej plików. Przytrzymaj Ctrl lub Shift w selektorze do multi-select. Każdy plik jest wstawiony do zachęty jako kod ogrodzona blok z nazwą pliku i językiem. Pliki binarne ponad 1 MB są pomijane z notatką.

12. Modalne Git

Kliknij 📁 Git. Jeśli żaden folder projektu nie jest skonfigurowany, najpierw otrzymasz selektor folderu — wybrany ścieżka jest zapisana do [project] path w config.ini. Kolejne gity uruchamiają się z cwd ustawionym na tę ścieżkę.

13. Repozytoria GitHub

Wypisuje każdy repo dostępny do [github] pat. Kliknij rząd aby wstawić jego clone URL do zachęty. Lista jest paginowana i buforowana.

14. Domeny NameSilo

Pobiera każdą domenę w koncie NameSilo za pomocą [namesilo] api_key (lub [api_keys] namesilo_api_key jako rezerwę). Na pierwszym otwarciu, wyniki są buforowane do domains.txt; kolejne uruchomienia panelu służą z buforu. Kliknij Przeładuj w modalnej aby wymusić świeży pobór.

Jeśli kiedykolwiek zobaczysz "brak domen" z kodem odpowiedzi 300, sprawdź kanał śledzenia — pusty bufory już nie trucizna przyszłych uruchomień panelu, ale stary domains.txt w innej ścieżce instalacji mógł.

15. Skórki i motywy

Przycisk 🎨 wyskakuje selektor odkrycia który skanuje skins/ na żywo (nie przy starcie), więc upuszczenie nowego folderu w runtime wystarczy. Każda skórka ma manifest.xml definiując paletę — włączając kolor podświetlenia, który odliczanie Auto Prompt, pierścienie fokusu, i puls supervisora wszystko klucze wyłączenia.

Wbudowane skórki zawierają: gnome (szarość Adwaita), terminal (czarno/zielone z akcentem hot-pink), tamagotchi (skorupki jajek z panelem sprite'a maskotki), blocky, i inne.

16. Ustawienia

Otwiera się z koła zębatego ⚙. Karty:

  • Ogólne — nazwa wyświetlania, model domyślny, wysyłanie na enter
  • Głos — urządzenie mikrofonu, listen_seconds, wybór silnika STT, autoodczyt TTS
  • Aktualizacje — flaga is_admin, sesja WinSCP, ścieżka zdalna
  • Klucze — klucz API każdego operatora
  • Monitor — przełącznik supervisora VSCode, port, interwał ankiety
  • Język — wybierz z 39 lokalizacji; patrz § 17

Modalne pamięta swój rozmiar i pozycję między sesjami.

17. Język

Panel wysyłany z tłumaczeniami dla 39 najbardziej mówionych języków. Pliki lokalizacji znajdują się w languages/<code>.xml i są ładowane raz przy aktywacji rozszerzenia. Brakujące klucze powracają do angielskiego.

Wybierz język w Ustawienia → Język. Ikona flagi jest pokazana obok każdej opcji (załadowana z assets/flags/<code>.svg). Selekcja jest zapisana do [settings] language w config.ini.

18. Supervisor VSCode

Usługa Windows (CBEVSCodeSupervisor) opakowuje skrypt tools/vscode_supervisor.ps1 via NSSM i wiąże HttpListener na http://127.0.0.1:3434/. Przycisk monitora panelu świeci na niebiesko gdy endpoint /status supervisora odpowiada 200 OK.

Jeśli sonda HTTP nie powiedzie się ale usługa jest zainstalowana, watchdog panelu automatycznie restartuje usługę (30-sekundowe chłodzenie aby nie restartowało się w burzy).

Lewy-klik przycisk monitora aby zainstalować / uruchomić / zatrzymać. Prawy-klik aby otworzyć kanał śledzenia.

19. Aktualizacja automatyczna (pull)

4 sekundy po aktywacji rozszerzenia, panel pobiera https://trentontompkins.com/cbe/manifest.xml.php — manifest MD5+rozmiar najnowszych opublikowanych plików. Dla każdego zdalnego pliku, MD5 lokalnej kopii jest porównany; tylko zmienione/brakujące pliki są pobierane przez HTTPS.

Stan lokalny użytkownika (config.ini, debug.log, domains.txt, wake.txt, prompt_history.txt) jest na liście wykluczenia pull i nigdy nie jest nadpisywany.

20. Admin push

Tylko klienci z [updates] is_admin = true kiedy pushują na serwer. Uruchamianie via:

  • Paleta Polecenia → Claude Codex Black: Push update
  • Polecenie slash /push

Używa sesji WinSCP zapisanej o nazwie w [updates] winscp_session (domyślnie vps). Pushuje via /script=… z poleceniem synchronizacji i maską pliku która wyklucza sekrety i stan na maszynę.

21. Marketplace rozszerzeń

Kliknij przycisk 🧩 Rozszerzenia. Modalne iframe otwiera https://trentontompkins.com/cbe/extension/extension_marketplace.php, którą pobiera katalog z extensions.xml.php i renderuje każde dostępne rozszerzenie jako kartę z opisem, tagami, wersją, rozmiarem pliku, MD5, i przyciskiem Zainstaluj.

Rozszerzenie jest pakowane jako <id>.ext — archiwum zip zawierające manifest.xml plus kod rozszerzenia (zwykle pojedynczy extension.html). Gdy klikasz Zainstaluj, iframe marketplace wysyła postMessage z powrotem do panelu; panel pobiera plik .ext bezpośrednio z serwera i wyodrębnia go pod extensions/ w folderze rozszerzenia.

Trzy demo rozszerzenia wysyłane z katalogu uruchomienia: Kalkulator, Minesweeper, i Selektor Emoji .

23. Menu kliknięcia prawym przyciskiem

Kliknij prawym przyciskiem myszki gdziekolwiek w panelu aby otrzymać menu kontekstowe (zdefiniowane jako pojedynczy ciąg XML w panel.js). Wpisy zawierają Odśwież (przeładuj panel bez dotykania hosta rozszerzenia — nigdy nie używaj reloadWindow), Wyczyść rozmowę, Otwórz ustawienia, i Zbadaj (DevTools, tylko kompilacje debugu).

24. Kanał śledzenia

Rozszerzenie pisze szczegółową oś czasu do debug.log obok rozszerzenia. Wszystko godne uwagi ląduje tam: przełączniki operatorów, cykl życia STT, sondy supervisora, kody odpowiedzi NameSilo, wiadomości mostu panel↔host, liczby push/pull manifestu.

Kliknij prawym przyciskiem przycisk monitora aby jednym klikiem otworzyć kanał śledzenia.

25. Rozwiązywanie problemów

ObjawPrawdopodobna przyczyna
Pole zachęty wygląda proporcjonalnie, nie monospace --vscode-editor-font-family nie zastosowany; sprawdź zmienne :root
Spinner Auto Prompt jest czarną kropką Zły zasób SVG; powinno być auto_read_spinner.svg z halo drop-shadow
Przycisk Kompaktowy nic nie robi Brakuje handlera hosta — case 'compactConversation' w routerze extension.js
"0 domen" w modalnej Domeny Odpowiedź NameSilo.code != 300 (kanał śledzenia ma to), lub stary domains.txt
STT "brak wykrytej mowy" natychmiast Zatrzymałeś zanim SAPI wiązał mikrofon. Preogrzewanie teraz omija ten oczekiwanie — sprawdź stt: using pre-warmed SAPI w debug.log
Push nie powiedzie się na ścieżce ze spacjami Używanie /command= inline; zawsze używaj /script=tempfile.winscp
Niebieski blask supervisora nie świeci się Usługa nie działa. Lewy-klik monitorBtn aby zainstalować/uruchomić, lub uruchom Start-Service CBEVSCodeSupervisor
Reload "naprawia" coś Nie naprawia. Nigdy nie używaj reloadWindow. Zamiast tego użyj wpisu menu kontekstowego Odśwież.
