Codex Black Ed.

Samodzielny panel AI dla VSCode. Czat z dowolnym dostawcą LLM (bezpośredni API lub mostek przeglądarki), z wbudowanym TTS, STT, dołączaniem do pliku, paletą poleceń, kontem wielokrotnym, personalizacją skórek i pixel-pet Tamagotchi.

Szybki start ↑ góra

  1. Kliknij Konfiguracja (ikona różdżki) i przejdź przez kreatora, aby wpisać swoje klucze API. Są zapisywane w config.ini (który jest ignorowany w git — nigdy nie commitowany).
  2. Kliknij pigułkę dostawcy w dolnym lewym rogu (aktualnie oznaczoną „Codex Black Ed."), aby przełączyć się na inny AI.
  3. Wpisz w pole tekstowe i naciśnij Enter, aby wysłać. Shift+Enter wstawia nową linię.
  4. Naciśnij ↑ w pustym polu tekstowym, aby odwołać poprzednie prompty (historia w stylu PowerShell).

Każdy most to mały plik exe C++ w zasobniku systemowym znajdujący się w bin/CBE-Bridge-<Target>.exe, który otwiera zalogowany profil Chrome, przechwytuje twój prompt i zwraca odpowiedź modelu. Chat mostu mówi protokołem liniowym na TCP: jedna linia JSON wejścia ({action:"chat", target, message, model}), jedna linia JSON wyjścia. Nie wymagany klucz api.

Wysyłanie wiadomości ↑ góra

Pole tekstowe
Wpisz swój prompt. Enter wysyła, Shift+Enter wstawia nową linię. Podczas gdy odpowiedź jest przesyłana, dodatkowe prompty są umieszczane w kolejce i wysyłane po kolei — placeholder pokazuje „Umieść w kolejce inną wiadomość…" w tym stanie.
Przycisk Wyślij (orb)
Okrągły przycisk na prawej krawędzi pola tekstowego. To samo co Enter. Wizualnie pokazuje trzy stany (bezczynny / najeżdżanie / aktywny).
Przycisk Stop
Prawy dolny róg kompozytu. Anuluje aktualnie przesyłaną odpowiedź i wszystkie wiadomości w kolejce. Przesyłany tekst jest zachowywany; tylko żądanie w locie jest przerywane.
Pigułka dostawcy
Dolny lewy róg kompozytu. Kliknij, aby uzyskać dropdown każdego skonfigurowanego dostawcy. Wybór nowego automatycznie uruchamia jego most (jeśli dotyczy) i publikuje toast potwierdzenia.
Historia promptów
↑ / ↓ w pustym polu tekstowym przechodzi wstecz / do przodu przez ostatnie 500 wysłanych promptów (w stylu PowerShell). Historia jest przechowywana w prompt_history.txt w folderze rozszerzenia i przetrwa przeładowania panelu.

Przyciski paska narzędzi ↑ góra

Wymienione w kolejności paska narzędzi. Wszystkie etykietki są lokalizowalne na język przez languages/*.xml.

Nowa rozmowa addBtn
Czyści bieżący wątek, wymazuje stan rozmowy w pamięci i rozpoczyna od nowa. Poprzedni wątek jest zachowywany na dysku w chats/<UTC-date>.log, więc nic nie jest tracone. Równoważne /clear.
Zapisane prompty storedPromptsBtn
Otwiera okno modalne wymieniające każdy zapisany szablon promptu w stored_prompts/. Kliknij jeden, aby go wstawić do pola tekstowego; przycisk „+" dodaje nowy szablon. Szablony obsługują podstawianie zmiennych.
Historia czatu chatHistoryBtn
Przegląda dziennik czatu na dysku (jeden plik na datę UTC w chats/). Wybierz datę, aby przejść wstecz przez przeszłe rozmowy.
Dołącz plik attachFileBtn
Otwiera selektor pliku. Wybrany plik jest przesyłany wraz z następnym promptem — obrazy są wstawiane w linię (vision), pliki tekstu/kodu stają się blokiem w ogrodzeniu w twoim promptcie. Obsługuje wielokrotne dołączenie.
Czytaj na głos (TTS) ttsBtn
Wymawia najnowszą odpowiedź asystenta na głos. Używa ElevenLabs (jeśli ustawiony jest [elevenlabs] api_key) lub wraca do Windows SAPI. Kliknij prawym przyciskiem, aby przełączyć tryb auto-read, w którym każda nowa odpowiedź jest wymawiana automatycznie — przycisk otrzyma animowany wskaźnik, gdy jest aktywny.
Mowa na tekst (STT) sttBtn
Nagrywuje dźwięk z mikrofonu i transkrybuje do pola tekstowego. Najpierw próbuje Web Speech API webview; jeśli to nie powiedzie się (not-allowed, częste w piaskach VSCode), wraca do Windows SAPI (System.Speech.Recognition) uruchomianego na hoście przez PowerShell. Kliknij ponownie, aby zatrzymać.
Auto Prompt autoReplyBtn
Otwiera okno modalne Auto Prompt. Zdefiniuj prompt + interwał odliczania; po każdej odpowiedzi asystenta odliczanie zmniejsza się i automatycznie ponownie wysyła auto-prompt, gdy osiągnie zero. Przydatne dla „kontynuuj", „następny krok", powtórzonych sesji narzędzi. Kliknij ponownie, aby wyłączyć.
Odpowiedź przebudzenia wakeUpBtn
Edytuje wiadomość przebudzenia przechowywaną w wake.txt. Przebudzenie to to, co Auto Prompt wysyła, jeśli wykryje, że model się zatrzymał — generalnie krótka ping, takie jak „Hej! Kontynuuj."
Pokaż menu poleceń showCommandsBtn
Otwiera paletę poleceń slash w oknie modalnym. Aby uzyskać pełną listę, zobacz Polecenia ze slashem. To samo co wpisanie / na początku pola tekstowego.
Kompaktowa rozmowa compactBtn
Publikuje żądanie podsumowania i oczyszczenia, które zastępuje bieżący wątek skróconą rekapitulacją. Równoważne /compact. Przydatne, gdy rozmowa wzrosła i chcesz zachować kontekst, ale przestać spalać tokeny na ponowne wysyłanie całej historii.
Podręcznik handbookBtn
Otwiera okno modalne podręcznika pracownika/projektu. Ładuje handbook.html lub jakikolwiek skonfigurowany dokument. Używany jako odniesienie systemu-promptu, które model może być poproszony o zapoznanie się.
Ustawienia settingsBtn
Otwiera okno modalne Ustawienia (dostawca, model, skórka, język, SFX). Patrz Ustawienia.
Konta accountsBtn
Otwiera menedżer wielokontowy. Dodaj / edytuj / usuń klucze API na dostawcę, przełączaj między nimi w sesji. Patrz Konta.
Rozszerzenia extensionsBtn
Otwiera przeglądarkę rozszerzeń w panelu. Wymiela co jest zainstalowane w extensions/ (każde z manifest.xml + entry HTML), pozwala pinnować rozszerzenia do paska narzędzi, instalować nowe z publicznego katalogu lub je usuwać.
Folder projektu projectFolderBtn
Wybiera katalog roboczy używany przez Attach File, Terminal, Git i wszelkie narzędzia wymagające katalogu głównego projektu. Bieżący folder jest wyświetlany obok pigułki dostawcy.
Przeglądarka browserBtn
Otwiera okienko przeglądarki QtWebEngine obok siebie, aby szybkie wyszukiwania bez opuszczania panelu.
Monitor VSCode monitorBtn
Przełącza strażnika nadzorcy VSCode — proces w tle, który restartuje VSCode, jeśli się zawali. Lewy klik przełącza uruchomienie/zatrzymanie, prawy klik otwiera kanał śledzenia nadzorcy.
Terminal terminalBtn
Otwiera zintegrowany terminal VSCode w folderze projektu. Jeśli folder projektu nie jest ustawiony, wraca do Pulpitu. Ponownie używa jednego trwałego terminala oznaczonego „CBE".
Kreator konfiguracji setupBtn
Prowadzi cię przez każdy klucz API + integrację, którą rozszerzenie zna (~12 kroków). Patrz Kreator konfiguracji.
Git gitBtn
Otwiera widok Source Control VSCode skupiony na bieżącym folderze projektu.
GitHub githubBtn
Wymiela twoje repozytoria GitHub używając [github] token. Kliknij repo, aby sklonować / otworzyć / przejrzeć problemy.

Wymiela każdą domenę na twoim koncie NameSilo z serwerami nazw. Wymaga [namesilo] api_key. Przycisk Przeładuj wymusza świeże pobranie.

Menu prawego przycisku ↑ góra

Kliknij prawym przyciskiem na tekst czatu lub blok kodu, aby uzyskać menu kontekstowe CBE. Kliknięcie prawym przyciskiem na textarea promptu teraz otwiera natywne menu przeglądarki (Kopiuj / Wytnij / Wklej / Usuń / Zaznacz wszystko).

Kopiuj / Kopiuj blok kodu
Kopiuje bieżący wybór. Jeśli nie ma wyboru, ale kliknąłeś prawym przyciskiem na <pre><code>, kopiuje cały blok kodu.
Pokaż źródło
Pokazuje surowy HTML/markdown klikniętego regionu — albo blok kodu, albo całe DOM panelu. Przydatne do debugowania problemów skórki/CSS.
Otwórz DevTools
Poprosi VSCode, aby otworzyć jego Developer Tools, abyś mógł sprawdzić webview na żywo.
Ustawienia new
Otwiera to samo okno modalne Ustawienia, które otwiera przycisk Ustawienia paska narzędzi (dostawca / model / skórka / język / SFX). To samo co /settings.
O programie new
Mały dialog w panelu z wersją, autorem, licencją, linkiem do repo, portfolio i numerem telefonu kontaktowego. Zamyka się po kliknięciu tła, przyciskiem × lub Esc.
Przeładuj panel new
Ponownie czyta panel/index.html + panel.js + skins/* z bustenem cache'u ?v=<mtime> na plik i ponownie przypisuje panel.webview.html. Wybiera zmiany CSS/JS bez rebootowania VSCode. Host rozszerzenia pozostaje aktywny — terminal, nadzorca, historia czatu, wszystko trwa.
Przeładuj okno new
Wyzwala workbench.action.reloadWindow. Używaj tego tylko gdy edytowałeś extension.js (kod po stronie hosta) i przeładowanie panelu nie jest wystarczające. To pełne przeładowanie okna VSCode.

Okna modalne i dialogi ↑ góra

Okno modalne Ustawienia — dostawca / model / skórka / język / SFX
  • Dostawca: pełny dropdown każdego dostawcy bezpośredniego API + mostu. Wybranie jednego przełącza aktywną sesję I automatycznie uruchamia pasujący exe mostu (jeśli dotyczy).
  • Model: lista modeli dozwolonych na dostawcę (np. claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5 dla Anthropic).
  • Skórka: motyw wizualny. Patrz Skórki.
  • Język: dostępne 39 locales. Przełączenie ponownie pobiera mapę ciągów i retłumaczy każdą etykietkę na żywo.
  • SFX włączone: przełącz efekty dźwiękowe UI (kliknięcia, tikanie, otwarcie/zamknięcie modalu, itd.).
  • Głośność SFX: suwak 0–100. Podglądany na żywo podczas przeciągania.
  • Anuluj przywraca wszelkie podglądy na żywo (SFX/skórka), które spróbowałeś; Zapisz utrwala i emituje setProvider.
Kreator konfiguracji — wejście klucza API wielokrokowe

Przewodnik dla każdej integracji. Każdy krok pyta o poświadczenia i zapisuje je w config.ini. Pomiń przechodzi bez pisania; Dalej pisze i przechodzi; ostatni krok's Gotowe zamyka. Kroki obejmują: Anthropic, OpenAI, Gemini, xAI/Grok, GitHub PAT, Email/SMTP (hasło aplikacji Gmail), Cloudflare, Twilio, ElevenLabs, Stability AI, Runway, SendGrid, NameSilo i więcej.

Okno modalne Konta — menedżer wielokontowego klucza API

Dla każdego dostawcy zarządzaj wieloma etykietowanymi kontami (np. „osobiste", „pracownicze"). Przełączaj które konto jest aktywne w sesji bez nadpisywania innych. Klucze są maskowane end-to-end i zapisywane na dostawcę w config.ini.

Okno modalne Domeny — NameSilo

Wymiela każdą domenę na twoim koncie NameSilo z serwerami nazw + datami rejestracji. Przycisk Przeładuj wymusza świeże pobranie API (w przeciwnym razie buforuje w domains.txt).

Okno modalne Podręcznika

Renderuje projekt HTML podręcznika (przeznaczony jako odniesienie systemu-promptu, które model może zapoznać). Można go konfigurować na projekt.

Okno modalne Zapisane prompty

Wstawiane szablony promptu z stored_prompts/. Każdy plik to jeden szablon; prefiks nazwy pliku NN- kontroluje porządek sortowania. Przycisk „+" tworzy nowy.

Okno modalne Historia czatu

Wybierz datę UTC, aby załadować dziennik czatu z chats/<date>.log. Tylko do odczytu.

Okno modalne Rozszerzenia

Karty dla każdego zainstalowanego rozszerzenia. Pinnuj do paska narzędzi / odpinnuj, instaluj z publicznego katalogu (extensions.xml.php na serwerze) lub usuwaj z dysku.

Okno modalne Dziennik zmian

Renderuje panel/change_log.html — notatki wydania w pakiecie. Generowane przez tools/build_changelog.py.

Okno modalne Pokaż źródło

Ładnie drukuje każdy blok kodu lub pełny HTML panelu, z podświetlaniem składni Prism i przyciskiem Kopiuj. Osiągnąć poprzez prawy klik → Pokaż źródło.

Okno modalne Auto Prompt

Skonfiguruj ciąg promptu + interwał odliczania. Po każdej odpowiedzi asystenta odliczanie zmniejsza się; gdy osiągnie zero, CBE automatycznie wysyła skonfigurowany prompt. Przełączane włącz/wyłącz poprzez przycisk Auto Prompt paska narzędzi.

Ustawienia ↑ góra

Wszystkie ustawienia znajdują się w jednym z dwóch miejsc:

  • workspaceState (zarządzane przez VSCode, na przestrzeń roboczą) — dostawca, model, skórka, język, sfx włączone/głośność, rozmiar czcionki.
  • config.ini (katalog główny rozszerzenia, ignorowany git) — klucze API + poświadczenia na integrację.

Ustawienia utrwalają się automatycznie w przeładowaniach panelu. Okno modalne Ustawienia to bezpieczny sposób zmianę czegokolwiek; edycja config.ini bezpośrednio też działa.

Konta i klucze API ↑ góra

Każdy dostawca może mieć wiele etykietowanych kont — przydatne, jeśli chcesz przełączać się między osobistymi i pracowniczymi kluczami, lub testować inny tier. Okno modalne Konta pozwala ci:

  • Dodać nowe konto z etykietą + klucz
  • Edytować istniejące konto (zmienić etykietkę, zamienić klucz)
  • Ustawić które konto jest aktywne na bieżącą sesję
  • Usunąć konto

Klucze są przechowywane maskowane (widoczne ostatnie cztery tylko) w config.ini. Nie ma kopii w czystym tekście w workspaceState.

Zwierzę Tamagotchi ↑ góra

Tamagotchi to pixel-art zwierzę, które żyje w panelu pod skórką tamagotchi. Starzeje się, głodnieje/brudzni, można się z nim bawić, i umiera, jeśli zaniedbane wystarczająco długo. Stan utrwala się w workspaceState.

Skórki ↑ góra

Motywy wizualne dla całego panelu — przyciski, okna modalne, bloki kodu, nawet czcionka. Wybierz jeden w Ustawienia → Skórka. Każda skórka znajduje się w skins/<id>/ z manifest.xml (deklaruje kolory + akcent) i styles.css (przesłania zmienne CSS).

  • codex-black (domyślna) — ciemna, monospace, neon-cyan akcent
  • glassy — matowe powierzchnie nad miękkim tłem
  • tamagotchi — limonkowo-zielony handheld LCD; automatycznie pokazuje widżet zwierzęcia zadokowany w rogu kompozytu
  • office — styl Word z kremem/niebieskim chromem
  • macos-color-dock / mint-dock — paski narzędziowe zadokowane na dnie z matowymi ikonami
  • terminal / arch / kde / gnome / xfce / ubuntu / redhat — motywy desktopa Linux

Kolory modalne pochodzą z wpisów <colors> w manifest każdej skórki i są przesuwane na :root jako zmienne --cbe-modal-*, aby każde okno modalne (w tym ta pomoc) renderowało się w motywie.

Rozszerzenia ↑ góra

Mini-aplikacje, które żyją wewnątrz CBE. Każda to folder w extensions/<id>/ z:

  • manifest.xml — id, nazwa, wersja, autor, opis, HTML wejścia, ikona (emoji lub icon.svg)
  • extension.html (lub cokolwiek mówi <entry> manifestu) — rzeczywista aplikacja

Kliknij Rozszerzenia, aby przeglądać co jest zainstalowane, pinnować do paska narzędzi, instalować nowe z publicznego katalogu, lub usuwać z dysku. Pinnowane ID-ów żyją w extensions/_pinned.json.

Auto-aktualizacja (push / pull) ↑ góra

CBE synchronizuje swoje źródło między maszynami przez kanał push WinSCP + pull HTTPS.

Push (tylko admin)

Jeśli [updates] is_admin = true w config.ini, każda aktywacja uruchamia tło WinSCP synchronize remote -mirror, które pushuje folder rozszerzenia do /home/trentontompkins.com/cbe na serwerze. Ręczny trigger: /push polecenie slash. Wyklucza stan na maszynę: data/ (1,74 GB profile Chrome), bridges/, node_modules/, .git/, logs/, chats/, config.ini, prompt_history.txt, domains.txt, wake.txt.

Pull (każdy klient)

4 sekundy po aktywacji, każdy klient pobiera https://trentontompkins.com/cbe/manifest.xml.php i porównuje MD5 na plik względem lokalnych kopii. Tylko zmienione/brakujące pliki są pobierane przez zwykłe HTTPS GET. Wykluczone ścieżki NIGDY nie są pobierane: config.ini, data/, bridges/, extension.js, panel/panel.js, panel/index.html, package.json, narzędzia budowania — uzasadnienie jest takie, że źródło wysyłane przez .vsix i starszą kopię serwera nie powinno clobbering pracy w toku.

Hot reload ↑ góra

Dwie ścieżki przeładowania są wystawione poprzez menu prawego przycisku:

  • Przeładuj panel — ponownie czyta panel/index.html + każdy zasób JS/CSS z bustenem cache'u ?v=<mtime> na plik i ponownie przypisuje panel.webview.html. Wybiera zmiany panel.js / skin CSS / dotmatrix bez rebootowania VSCode. Host rozszerzenia pozostaje aktywny (twój terminal, nadzorca, handlery wiadomości, historia czatu, wszystko trwa).
  • Przeładuj okno — wyzwala workbench.action.reloadWindow. Używaj tylko, gdy edytowałeś extension.js (kod po stronie hosta) i Przeładuj panel nie jest wystarczające.

Zmiany CSS skórki również automatycznie są stosowane poprzez watcher skórki panelu — nie trzeba klikać menu.

Rozwiązywanie problemów ↑ góra

"bridge X chat failed: api key empty in config.ini"

Daemon smart_bridge.py buforował stary check gatingowy w pamięci. Naprawiono w pivot routingu exe C++. Jeśli to nadal widzisz, zabij stare daemony:

powershell -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*smart_bridge.py*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
"copilot has no public REST API — use the browser bridge"

Stary extension.js routował most chat przez router REST zamiast rzeczywistego exe tray C++. Przeładuj okno, aby wybrać naprawiony extension.js, wtedy chat będzie przechodzić bezpośrednio do bin/CBE-Bridge-Copilot.exe.

HTTP 404 model: sonnet-4.6

Nieaktualna krótka alias w konfiguracji mostu Claude. Naprawiono — pełne ID-y (claude-sonnet-4-6, claude-opus-4-7, claude-haiku-4-5) są teraz używane.

Edytowałem plik, ale panel nie pokazuje zmianę
  1. Jeśli to panel.js / skins/*.css / index.html → prawy klik → Przeładuj panel.
  2. Jeśli to extension.js / bridges_cpp/*.py → prawy klik → Przeładuj okno.
  3. Jeśli nie możesz dosięgnąć menu (np. menu samo się nie załadowało), uruchom świeżą instancję VSCode z izolowanym katalogiem user-data-dir:
    code --user-data-dir="$env:USERPROFILE\.cbe-edh" --extensionDevelopmentPath="C:\Users\moren\Desktop\Codex Black"
STT fails with "not-allowed"

VSCode piaskuje webview z uprawnienia mikrofonu. CBE auto-spada do Windows SAPI (System.Speech.Recognition) uruchomiany przez PowerShell. Możesz potrzebować przyznania dostępu mic na poziomie OS (Ustawienia → Prywatność → Mikrofon).

Brakuje exe mostu

Dziennik śledzenia pokazuje BRIDGE:MISSING target=<t> expected=<path>. Exe tray C++ żyją w bin/CBE-Bridge-<Pretty>.exe. Jeśli twoje nie istnieją, przebuduj ze źródła bridges_cpp/ (MSVC) lub ściągnij świeży .vsix.
